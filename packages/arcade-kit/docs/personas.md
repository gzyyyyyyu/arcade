# 共用电脑名册（`arcade-kit/personas`）

全站牌类游戏里的电脑是同一批人：名字、人设、口头禅、头像、性格只在这里写一份，每个游戏把性格翻译成自己的打法。
kit 只给数据和纯函数，不懂任何一种牌的规则；随机只用游戏传进来的种子，整数运算，同输入同输出。

## 名册 `ROSTER`

16 个人，每人：`id`、`name`、`bio`（一句人设）、`catchphrases`（和具体哪种牌无关的口头禅）、`level`（0 新手 … 4 高手：谁能上哪张桌，强度由游戏定）、
`traits`（性格，0–100）、`alt` 和 `switchOn`（换打法：在什么情况下改成什么）、`fun`（牌桌互动脾气）、`tempo`（思考时间千分比）、`look`（头像画法）。
只往后加人，不改 `id`；名字同步进平台的昵称保留名单。

| 性格 | 意思 |
|---|---|
| `aggr` 激进 | 抢着出手、加注、碰杠 |
| `risk` 冒险 | 做大、下重注、早用大牌 |
| `bluff` 诈唬 | 牌不好也装作好 |
| `patience` 耐心 | 等好机会、肯跟、肯忍 |
| `care` 细心 | 少犯错、会算、会读别人 |
| `tilt` 上头 | 输了以后打法变形的程度 |
| `form` 起伏 | 一场一场手感差多少 |
| `talk` 话多 | 开口的频率 |
| `switchy` 变招 | 碰到触发条件时换打法的概率 |

## 这一手的性格 `traitsNow(person, ctx, seed)`

`ctx` 只放公开信息：第几手 `hand`、这一场的手感 `form`（−100..100，游戏按种子一场抽一个）、现在上头多少 `tiltNow`、连输 `lossRun`、
位置 `lead`（−100 垫底 .. 100 领先）、这一段被同一家针对的次数 `targeted`、牌桌松不松 `tableLoose`。按这个顺序叠：

1. **换打法**：`switchOn` 里满足的原因（输多了：连输 ≥3 或 lead ≤ −50；领先：lead ≥ 50；被针对：targeted ≥ 2；牌桌松：tableLoose ≥ 70；节奏：一直满足），
   按 `switchy`（节奏是它的四分之一）的概率换成 `alt`。按"段"抽（`SWITCH_WINDOW` = 10 手一段，种子 + 第几段），同一段里不会一手一变。
2. **手感**：`form × 起伏 / 500` 加到激进、冒险上，一半加到细心上（最多 ±20）。
3. **上头**：`tiltNow × 上头 / 100` 的四分之一加到激进、冒险上，从细心、耐心里扣。
4. 夹在 0–100。

返回 `{ traits, mode: 'base' | 'alt', why }`：电脑出牌只读 `traits`；`why` 给画面和台词（"老张收着打了"）。

## 挑人 `pickLineup(rng, weights, n)`

按场地的权重（`{ id: 权重 }`，0 或没写的不挑）挑 n 个不同的人；能挑的人不够 n 个时抛错，场地表要给够人。

## 头像 `personaFace(id, mood)`

程序画的 SVG 字符串（viewBox 0 0 100 100，`mood`：normal / happy / sad / angry），不碰 DOM、不引外部图片；游戏座位头像统一用它。

## 每个游戏怎么用

- 打法：把 `traitsNow` 的结果映射到自己的参数（加注门槛、爱碰爱杠、爱炸……），映射写在游戏里；接入时先让"映射后参数 = 原来的参数"对拍一致，再调强。
- 难度：强度是游戏自己的档；性格露多少随档收（越强露得越少）。
- 底线：电脑只读自己能看到的信息、不读真人表情；`seed` 用游戏自己按用途分出来的熵，不给牌局密钥本身。
