## 0.41.0 — 2026-11-21

不带迁移。游戏要用兑换，先发这一版平台。

### 新增

- 兑换：游戏的服务端经服务绑定调 `WALLET.exchange({ userId, game, op, amount })`，把游戏内货币换成筹码直接进余额，回实际入账 `credited` 和今天剩下的额度 `left`。每人每个游戏每天最多换进 2,000（北京时间日界），管理页"钱包规则"里的"兑换每天最多换进"可调，0 是关掉兑换；超出的只入剩下的那部分，用完回 `exchange_cap`、不写。同一个 `op` 重发回第一次的结果、写 0 行；每次写 1 行，记在钱包写入预算和每人每天 1,000 次里，只读档、钱包预算用完时回 `busy`。浏览器的 `/api` 没有这条路。
- 游戏看钱包（`WALLET.view`）多回这个游戏今天的兑换额度 `exchangeLeft` 和上限 `exchangeCap`（设成 0 时两个都是 0）。
- 钱包流水多一种"兑换"；全站每日统计和管理页的筹码统计、今日概况多一个来源"兑换"，按游戏分开记。
- 管理页邀请码那块顶上一直有"+ 新建长期邀请码"（默认 100 次、不过期），建好显示新码和"复制链接 / 复制码"，不用先筛到"长期码"才找得到。

### 改动

- 所有页面同一个顶栏：排行、动态、好友不再在有侧栏的页面藏起来（原来一点排行顶栏就只剩管理、筹码、头像，一跳一跳的），宽屏上页面外框各页一样宽，换页时顶栏不挪；指向当前页的那一项暖色底。
- 宽屏（≥1200）账号类页面左边那列导航拿掉了：七项（大厅、排行、动态、好友、钱包、战绩、账号）顶栏都有（大厅点标题，钱包点筹码，战绩在账号页里），导航只留顶栏一处，宽度还给内容区，外框宽度不变；红点照旧在顶栏的动态、好友上。
- 排行、战绩、账号、隐私的页签合成一份 `.pills` 样式；账号、隐私页面板的内边距和别的页一样；管理页左边的分区导航描边、投影、选中橙底白字，顶边和内容区对齐。
- 大厅首屏更快：封面多一份 400 宽的小图，手机短卡和电脑一倍屏拿小的（首屏封面手机 226→93 KB、电脑 331→133 KB）；千分位不再走 Intl（手机 CPU 4× 降速下首屏可交互 773→687 ms，长任务 3→2 个）。

### 修复

- 顶栏筹码每次打开页面都从 0 滚到余额（钱包是读回来的，第一个值被当成了变化），现在第一个值直接显示。
- 按高度翻页的列表：有翻页条和没有时整块高度差 1px，"见过的最高一条"每次被清空、条数来回跳到 React #185（管理页邀请码 1280×800 加了入口后出现）；翻到一页高条目多的、每页条数变了时页号不变，中间几条翻不到，改成记"当前页第一条"。
- 管理页邀请码 1280×800：码表一页只放 3 条、下面空一大块。根因是 `styles.css` 里一条没人用了的全局 `.invite-codes { display: grid }`（"我的"页早改用 `me-list`），把翻页列表从竖排弹性布局变成网格，多出的高度一半分给了翻页条；删掉这条，码表吃满面板。

## 0.40.0 — 2026-11-20

要先跑迁移 `0014_invites_and_prefs.sql`，再发平台。

### 新增

- 长期邀请码：管理员在管理页建，一码多人（默认 100 次、不过期，次数 2–1000、有效天数可设），能撤回；码表筛到"长期码"时上面是建码的表单，状态块写"能用 4/100"，下一行列用它注册的人。只有管理员会话能建（命令行令牌不行），用户侧接口传什么都只建普通码。普通码照旧（一码一人、7 天、按额度、注册后自动加好友）；长期码不占额度、不加好友，注册的每 IP、每天上限照样算。
- 占名额和建号在一个 batch 里：条件更新 `uses < max_uses` 没改成就整批不写，最后一个名额两人同时用恰好一人成功；每次使用在 `invite_code_uses` 记一行。
- 隐藏游戏：管理员在 设置 → 隐藏游戏 设默认，每个人在 我的账号 → 偏好 里逐个改（存服务端，跨设备一致，只存和默认不一样的）。被隐藏的不出现在大厅、继续玩、排行页签、动态里，游戏地址照常能玩。新接口 `PUT /api/me/games`、`GET/POST /api/admin/settings/games`，`/api/me` 多 `hiddenDefault`、`user.gamePrefs`。

### 改动

- 带普通码注册多写 2 行（使用记录），共 15 行；注销时按新索引清使用记录，不再扫全表。
- 点赞、扔道具点了马上显示"你赞了"，不等动态重新读回来；好友叫你的那一条点"去"后按钮变"正在进…"。
- 登录、注册后补读一次 `/api/me`：大厅公告和默认隐藏不用刷新就有。
- 我的账号窄屏多了"偏好"页签，六个页签放不下，"云存档""邀请码"在窄屏写成"存档""邀请"。

### 修复

- 改偏好按库里现在的默认隐藏算差量（现读，读不到就报错不写）：不再因为 30 秒缓存是旧的、或读库失败兜底成空，把没动过的游戏写进个人偏好。
- 大厅的"好友超过了你"提醒也按隐藏过滤，提第一个没被隐藏的游戏。
- 好友叫你的那一条点"去"后留在原处显示"正在进…"直到跳走；有好几条时下一条不会被误标成"正在进…"。
- 退出或掉线后清掉上个账号的公告和默认隐藏，同号重登会补读 `/api/me`。
- 发码人注销时，连同别人用他的码的使用记录一起删，不留孤儿行。

### 整理

- 排行榜在拍快照（5 分钟一次）时就把各榜排好序，每个请求只数名次：合成数据下每请求 CPU 100 人 0.55→0.26 ms、500 人 2.1→0.50 ms、2,000 人 4.7→0.42 ms。
- 看钱包时没换日、没到期的不再整份复制状态：6 KB 的钱包每次 123→42 µs。
- `/api/me` 的注册开关、公告、默认隐藏合成一条查询、一起缓存 30 秒；动态的赞按条归一次（原来每条扫全部赞）；好友名单和搭子战绩并行查，少一个来回。
- 模块 AGENTS.md 压到 5KB 以内。
- 冒烟加 `prefs` 段（隐藏游戏）；`invites` 段加长期码。
