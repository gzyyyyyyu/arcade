# 界面冒烟

`npm run smoke` 起一个临时本地 D1 和 `wrangler dev`（固定用 5181，被占就失败），用无头浏览器走一遍，要求控制台零报错、没有意料外的 4xx/5xx，截图放到 `shots/`（`--out <目录>` 改到别处）。
`npm run smoke -- --only=<段>` 只跑一段。段名表在 `tools/smoke.ts` 的 `only`，每段的代码在 `tools/smoke/sections/`，公共部分在 `tools/smoke/lib/`。

## 分段

| 段 | 查什么 |
|---|---|
| `main` | 主流程：注册登录、管理员建号、好友、我的账号 |
| `wallet` | 钱包页和顶栏的筹码牌子，网络卡住时 |
| `chunk` | 发版后旧页面加载分块 404 |
| `next` | 登录页的 `next` 跳转 |
| `stats` | 战绩页 |
| `services` | 只读档、停服、限流、断网 |
| `mobile` | 手机主流程和积分筹码说明 |
| `desk` | 电脑版排版：大厅、好友、我的、战绩 |
| `phone` | 四种常见屏幕（iPhone SE、iPhone、手机横屏、iPad）逐页细查：第一屏、点按区、单手够得着、转屏 |
| `noscroll` | 一屏放下不滚、按钮不重叠、字不被裁，五个尺寸逐页量 |
| `ui` | 界面核对：每页电脑 1280、手机 390 各一张（同样做 `phone` 的检查），加没登录的登录、忘记密码页；不在全量里 |
| `devices` | 26 个尺寸 × 12 页的通用检查：整页横滑、伸出屏幕、点击区（手机平板 44，320 宽 40，电脑 24）、字号、顶栏折行和重叠 |
| `boards` | 排行榜：总榜、游戏页签、只看好友、晒战绩 |
| `podium` | 总榜领奖台：1、2、3、10、15 人 × 我在不在榜 × 五个尺寸，量宽度和滚动 |
| `feedpop` | 顶栏的动态按钮和浮层 |
| `friends` | 好友分享、点名字看战绩、战绩页加好友 |
| `friendsfeed` | 好友页和动态页，好友多、动态多的时候 |
| `rules` | 管理页的钱包规则 |
| `invites` | 管理页的邀请码（含长期码） |
| `meetup` | 约局：顶栏在线数、头像到点小点、好友页的约局和"约一局"（电脑、手机 390 和 360） |
| `prefs` | 隐藏游戏：我的账号 → 偏好里切、大厅和排行跟着变，管理页设默认 |
| `overview` | 管理页的今日概况和账号详情 |
| `tally` | 管理页的真人对局 |
| `notice` | 大厅公告 |
| `nudge` | 大厅提醒 |
| `sound` | 大厅点按声 |
| `recent` | 大厅最近玩过 |
| `tour` | 新人引导 |
| `motion2` | 进出游戏过渡、键盘快捷键、回大厅的筹码演出 |
| `states` | 八个页面的空、加载中、出错各截一张（空数据五个尺寸，加载中和出错 1280、390、360），也量重叠和裁字 |
| `frames` | 动效逐帧：暂停所有动画按 0–100% 截一行；徽章亮相另外逐档判定真在动、落位和静止一致。不在全量里 |
| `boardsmatrix` | 排行页每个页签 × 空榜、1 人、满榜 × 三个尺寸截图，量重叠、裁字、滚动和卡里空白。不在全量里 |

## 什么时候跑哪段

- 改界面：跑相关的那一段，亲眼看截图。
- 改布局：跑 `noscroll`（重叠、裁字都要 0）；大改再跑 `devices`。
- 动到多个页面共用的布局（`Paged`/`PageTabs`、`.page__body`、卡片高度）：`noscroll` 和 `phone` 都要跑。
