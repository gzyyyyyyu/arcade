## 0.32.5 — 2026-10-31

只整理冒烟脚本，平台本身不变。

- **拆分 `tools/smoke.ts`**：原来 3,000 行一个文件，现在入口 `tools/smoke.ts` 只管参数、起停服务、按段调度（约 150 行）。
  - 每段一个文件：`tools/smoke/sections/<段名>.ts`；
  - 公共部分在 `tools/smoke/lib/`：`core`（断言、监视、截图、开页面）、`server`（本地接口服务）、`fakes`（假数据和接口 mock）、`accounts`（真走本地 D1 的账号和管理工具）、`ui`（排版检查和常用操作）。
- 入口文件名没变，`npm run smoke`、`--only=<段名>` 和 CI 都照旧。
- 截图编号收进 `shotFile()`，只有它改编号。
- **修冒烟的竞态**：CI 上偶发"[朋友] 没想到的 401：/api/saves/haidao"。
  - 原因："我的"页面一打开就并发读每个游戏的云存档，冒烟有两处打开 `/me` 后马上点"退出登录"，排在最后的海岛那一个请求晚到，就吃了 401。
  - 修法：退出、注销前先等这些存档请求都回来（`openMe()`）。
- 代码按顶层声明原样搬过去，没改逻辑。
- README 的分段说明和目录结构跟着改。

## 0.32.4 — 2026-10-31

统一请求体的读取和错误码。只有一处对外可见的变化：

- **分数不对一律 422 `invalid_score`**：
  - 挑战（`POST /api/challenges`、`/results`）的分数不是安全整数，原来回 400 `bad_request`，现在和排行榜一样回 422 `invalid_score`；
  - 排行榜的分数不是数字（比如字符串 `"100"`），原来回 400，现在也是 422。
  - 游戏照常只交整数分，碰不到这一处。
- **`worker/api/body.ts`**：读请求体（大小、嵌套层数、必须是对象）从 router 挪过来。字段读取器 `str`、`optStr`、`bool`、`optBool`、`count`、`match`、`oneOf`、`gameId`、`scoreOf` 和判断函数 `isPlain`、`isInt`、`isCount` 都放在这里，各接口里手写的 `typeof` 检查换成它们。`str` 从 auth.ts 搬过来，钱包、搭子、对局汇总不再各定义一份 `isPlain`、`isCount`。
- **错误约定**写在 http.ts 开头：
  - 形状不对 400，分数 422，由读取器抛；
  - 用户名、密码、昵称这类业务规则由 validate.ts 返回错误码，再由 `check()` 变成 422。
- **测试**：新加 `test/body.test.ts`，直接测嵌套层数检查（字符串里的括号、转义引号、平铺的括号）和各读取器的错误码。
- 平台 AGENTS.md 加一条规矩：请求体字段只经 body.ts 读。

- **各游戏总榜**：`games.ts` 的固定榜可以写成 `{id, name}`，夜巡登记成"夜巡守夜""夜巡夜探""夜巡无尽"，各有一个标签，"全部 / 只看好友"照旧。分数写法读游戏的 `boards.json`（格式同 `daily.json`），规则可以写 `fields` 把复合编码的分数拆开、`fmt: {"字段": "mmss"}` 写成分:秒（docs/platform-backend.md 15.12）。`src/daily.ts` 改名 `src/scores.ts`，两个文件共用一套读法。
