# 平台各页面怎么排、怎么用

README 的"功能"一节只写有什么；这里写每个页面的排法和细节。接口约定见仓库根的 `docs/platform-backend.md`，配色和动效见 [style.md](style.md)，界面规范见仓库根的 `docs/ui.md`。

## 共同的规矩

- **一屏放下不滚**（`docs/ui.md` 第 11 节）：页面外框正好一屏高（`styles.css` 的 `.page`：顶栏、提示条、内容区 `.page__body`、一行页脚），高度按看得见的区域算（`main.tsx` 里 `arcade-kit/viewport` 的 `watchViewport` 写 `--app-h`，依次 100vh → 100dvh → 这个变量）。
  内容区不滚，长列表用 `src/features/fit/Fit.tsx` 的 `<Paged>` 按剩下的高度算一页放几条、翻页（默认按最高一条算；条目高矮差得多的给 `uneven`，按每条实际高度装页，网格按每排实际高度；翻页条被 CSS 挪到列表旁边时不给它留高），窄屏几栏用 `<PageTabs>` 改成页签。冒烟的 `noscroll` 段在 1280×720、1920×1080、844×390、390×844、360×640 五个尺寸逐页量，同时查可点元素的框不相交、文字不伸出自己的框。
- **顶栏**：所有页面同一个顶栏，同一组项、同样的顺序和位置（管理、排行、动态、好友、筹码、头像），换页只换内容区；页面外框在各页一样宽（≥1440 都放到 1600），顶栏不跟着挪。指向当前页的那一项暖色底（`aria-current`）。冒烟 `desk` 段逐页比顶栏每一项的位置。
- **子页面布局**：导航只在顶栏一处，各尺寸都一样：没有侧栏，内容区占满外框（大厅点标题，钱包点筹码，战绩在账号页里）。管理页左边是分区导航（概览、用户……），不是页面导航。面板里的一排页签（排行、战绩、账号、隐私）共用 `styles.css` 的 `.pills`。卡片头不画下划线，空列表一律用 `Empty`：一句现状加一个下一步入口。
- **卡片高度**：列表多、要按高度翻页时面板撑满一屏（排行页例外，满榜也按内容高）；空、加载中、出错和内容少（一页肯定放得下）时面板和卡片按内容高，空状态紧跟在标题下面，不在撑满的大框里挤在顶上或飘在正中。"多"按条数判断（排行 3 行、好友 3 个、动态 2 条、进出 3 笔、桌上筹码 2 桌、邀请码 3 个），不靠翻页量出来的结果，免得来回跳。按内容高只在屏幕够高时用（排行页不是矮屏、好友和动态至少 700 高），矮屏（手机横屏、360×640）照旧撑满、按高度翻页，免得一次画完放不下。并排的两栏顶部对齐，不强求等高。
- **读不到数据时**：初次读取失败，在原来列表或内容的位置换成 `ui.tsx` 的 `LoadError`（接口给的 message 加"再试一次"，点了重新读这一页），不冒充空状态、也不另加横幅，好友页的好友栏、动态、排行、战绩、管理概览都这样；提交表单失败仍用 `FormError`。
- **弹窗**：都经 `Modal.tsx`：进场淡入上移、退场、Esc / 遮罩 / ✕ 都能关、焦点锁在弹窗里（`modal-logic.ts` 是纯逻辑）。

## 大厅

- 游戏卡片：最近玩过的排前面；卡上只有封面、名字、一句话和一个按钮（"进入游戏"或"继续玩"；手机短卡上写两个字"进入""继续"，省下的宽给一句话），介绍和标签在电脑上悬停或键盘移到卡上时从封面底下浮出来；手机和横屏是一行一张的短卡。好友房在游戏里开、进，叫人和邀请链接直接链到游戏的 `?room=`；卡片的标签里写着"好友房"。
- 最近玩的那个游戏排第一张，封面左下角写"上次玩 · 多久以前"（手机短卡压在封面左上角、只写"多久以前"，"上次玩"留给读屏）、按钮是"继续玩"（`recent.tsx`：合并钱包流水、桌上筹码和浏览器本地 `arcade.recent.<用户 id>` 里点过的游戏，不多发请求；没玩过的按目录顺序）。大厅一屏只有一个实心橙主按钮：桌上有筹码时是提示条的"回去接着打"，否则是这张"继续玩"，别的卡都是白底次按钮。
- 提醒条：首屏同一时间只有一条，按公告、"桌上还有筹码"（手机和窄窗口写成"德州扑克桌上 2,000"，游戏名和金额不截）、好友超过你的每日纪录排先后，管理员撤下公告后后面的才出来。能领补给时顶栏筹码牌子亮红点，到钱包页领。
- 电脑上（≥960 宽、≥600 高）一页放下全部游戏，一排 4 张，放不下时各排一起变矮、由封面让出；手机和横屏按每张卡的实际高度翻页（平板竖屏封面压矮到 2.2:1，一页 6 张）。手机竖屏的标题和顶栏并成一行（logo 图标 + 排行、动态、好友三个圆角方块按钮，图标下有 12px 小字 + 筹码 + 头像），顶栏吃满 logo 右边的宽、按钮均匀分开（360 宽相邻至少隔 4px，冒烟 `phone`、`devices` 量），竖屏横屏都不写副标题。
- 每日、每周挑战在排行页看，大厅不单独列。匿名访客一个 `/api` 请求都不发。
- **进出游戏的过渡**：点"进入游戏"时封面放大铺满再跳转，从游戏回大厅时缩回那张卡（`enter-fx.ts`，sessionStorage `arcade.enterFx`）；回来时筹码总数（余额加桌上筹码）比进游戏前多，顶栏筹码牌子的数字滚到新值并迸一小撮金币，少了只滚数字，没变不播（`chips-fx.ts`）。
- **快捷键**（电脑）：`1`–`9` 开第几个游戏，`H`/`B`/`F`/`W`/`S` 去大厅、排行、好友、钱包、战绩，`?` 看说明，`Esc` 关弹窗或回大厅（`hotkeys.ts` 纯逻辑，`Hotkeys.tsx` 接键盘和说明面板）；输入框里不抢键，带 Ctrl/⌘/Alt 的不拦。
- **新人引导**（`LobbyTour.tsx`、`tour-logic.ts`）：7 天内注册的账号第一次进大厅，三步气泡指到"进入游戏"、筹码、好友（目标不在页面上就跳过那一步），随时"跳过"或按 Esc；看完或跳过在 localStorage 记 `arcade.tour.<用户 id>` = `done`，不再弹。老账号和没登录的访客不弹。自动化浏览器（`navigator.webdriver`）默认不弹，`arcade.tour.test` = `1` 时照常弹（`--only=tour` 用）。

## 好友和动态

- 好友码和好友链接（`/f/<码>`）、请求、屏蔽；对别人只给公开资料，不给用户名。
- 在线：好友在不在线、在哪个游戏哪个房间（`POST /api/presence`），本人可以在"我的"里关掉。好友在房间里时一键"加入"，好友叫你时顶上弹一条、"好友"带红点（`/api/invites`）。
- 好友页一屏放下：电脑上（≥1100 宽）好友码和加好友 / 好友列表（翻页）并排（人少时顶部对齐、按内容高），有请求（想加你的、等对方接受的、屏蔽的）时右边再加一栏；手机和矮屏用页签（好友、请求、加好友、好友码）；手机横屏卡片头、约局条和翻页条并成一行，下面全给名单（不到 800 宽时卡片头不写标题，页签已经写着"好友"）；删好友、屏蔽的确认在原地换掉那一行。好友卡片头上只有"约一局"（动态的入口在顶栏，这里不重复放；不到 600 宽的竖屏"约一局"放进列表顶上的约局条，已经约了叫"改"）。好友按在房间里、在线、最近来过排。
- 约局（`Meetups.tsx`，docs/social.md 1.6）："约一局"在弹窗里选游戏（只列能开好友房的）、今天或明天、几点（北京时间整点半点），发给全部好友，每天最多 3 次。好友列表顶上一条列好友约的（最多两条）和我约的（"开桌""取消"）；到点（开局前 10 分钟到开局后 30 分钟）那条暖色底、"去"变主按钮：主人在那个游戏的房间里就直接进房，不然进游戏首页。到点时顶栏头像带小点，点头像去好友页。
- 顶栏"好友"左上角绿底数字：几个好友在线（和好友列表同一口径），叠在按钮外不占宽；数据和约局都跟着收邀请的 30 秒轮询来，不另发请求。
- 搭子战绩：好友房打完，好友页写着和每个好友一起打了几场、各赢几场、谁是最佳搭档（房间服务端经钱包绑定的 `together()` 报，浏览器碰不到）。
- 动态（`/api/feed`）：实盘赢了、新称号、游戏里的名场面，好友能赞、扔道具。顶栏"动态"按钮点开看最新几条（最多 8 条，放不下的翻页，另有"看全部"），有新的带红点；电脑是浮层，手机是底部半屏面板。动态页 `/feed` 按高度翻页，电脑上排两列，长说明点"展开"在弹窗里看，"扔个道具"也在弹窗里选。没有动态时：有好友叫"去玩一局"，一个好友都没有改成"去加好友"（只在空的时候问一次 `/api/friends`）。

## 钱包（`/wallet`）

- 顶上一张钱包卡：手上的筹码、本周走势小折线（`wallet-trend.ts` 从已有流水倒推，不多发请求）、领补给（领到时金币从按钮飞进顶栏的筹码牌子，`coinfly.ts`）。
- 电脑上左栏钱包卡、桌上的筹码、这周的输赢，右栏"最近进出"（按游戏筛选、按高度翻页），两栏顶部对齐，余额卡按内容高；窄屏分"筹码 / 这周 / 进出"页签。
- 桌上没筹码时那块收成一行；这周没输赢也没上限提示时"这周的输赢"也收成一行，竖屏够高时并进"筹码"页签。
- 带入、结回、放弃只能由游戏的服务端经 `WalletService` RPC 调，浏览器只能看和领补给。

## 战绩（`/me/stats`、别人的 `/u/<id>`）

- 顶上一排页签："总览"加玩过的每个游戏。总览是玩家名片（头像、昵称、称号数、本周净赢、徽章进度）加并排等高的徽章墙和各游戏概览；游戏页签是这个游戏的局数、胜率、最大一把、本周净赢和称号墙。墙和列表按高度翻页，窄屏上两栏改用小页签切；矮屏和手机竖屏的徽章横着排（奖章在左、字在右），一页放得多。
- 街机厅徽章：15 枚、最多铜银金三档，用战绩在浏览器里现算，点一枚看怎么拿；离下一档有进度条。自己的战绩页上新拿到、升档的徽章第一次看到时翻一下、扫一道光（`badge-seen.ts`）。
- 晒战绩：把成绩画成图发给朋友，链接是自己的好友链接（用 `arcade-kit/share`，图不上传）。

## 排行榜（`/boards`）

- 顶上一排页签（竖屏放不下时折成几行，不横着滑）："总榜"加每个接了钱包或登记了代表性每日榜（`games.ts` 的 `featuredDaily`）的游戏。
- 总榜是全站本周净赢，只排这周赢了的（净赢 > 0）；没赢的"我"那行写"这周还没赢"，谁都没赢时写"这周还没人上榜"。三个人起前三名站领奖台（进页时依次升起），一两个人直接排列表；下面列表按高度翻页，可只看好友。
- 卡片：标题行是榜名、副标题和"晒战绩"（我在全站前 10 或好友第 1 时出现）。我在前三名里只高亮自己那格，不另写"我：第 N 名"；第 4 名以后、或不在前 50 时才有"我"那一行。手机横屏（矮屏）不显示标题行，"我"那一行总在，晒战绩放在行里。
- 卡片高度：外框和卡片一律按内容高，空榜提示紧跟在标题下。名单超过 3 行时按外框能长到的高度算一页放几行（`BoardsCard.tsx` 的 `boardRoom`，交给 `<Paged>` 的 `room`），翻页器跟在名单后面，页面不滚；3 行以内一次画完。矮屏（手机横屏这类）要翻页时外框和卡片撑满、名单量自己的高度（`bcard--fill`）。
- 宽屏只有一块榜（总榜、海岛）且要翻页时分两栏：左栏上面是领奖台（台子固定高度，第一名一格约 200 高），下面是"我的名次"卡，再往下留白；右栏是名单，每行固定高、从顶上排，要翻页时翻页器跟在名单后面。两栏顶部对齐。冒烟的 `podium` 段按 1/2/3/10/15 人、我在不在榜上，五个尺寸量；`boardsmatrix` 段每个页签按空榜、1 人、满榜三个尺寸截图。
- 游戏页签放这个游戏的本周净赢和一个代表性每日榜（标题不再带游戏名，每日榜的标题就是榜名；宽屏并排，窄屏用小页签切；没有代表性每日榜的只放本周净赢）。每日榜只看好友时比这周每人最好的一天，好友超过你时大厅提一句。其余每日、每周、游戏总榜的数据和接口照旧，排行页不列。
- 异步挑战：把一局的开局做成链接发出去，大家的成绩挂在一起（`/api/challenges`）。

## 我的账号、登录注册、隐私说明

- 我的账号（`/me`）按页签分：资料（昵称、好友码、改昵称、退出）、隐私（好友能看到什么）、偏好（大厅显示哪些游戏，点了马上存）、云存档、邀请码、安全（窄屏六个页签，云存档、邀请码写成"存档""邀请"才放得下）（改密码、换恢复码、退出其他设备、注销，一次只摆一个操作，注销要勾确认）。宽屏上资料和隐私并成一页、左右两块顶部对齐、按内容高，云存档和邀请码左边是说明（云存档下面加有存档的游戏数、一共几份、最近一次）、右边是按高度翻页的列表，安全左边选操作。云存档页面一打开就读（等顶栏的钱包先读完，不和它抢连接）。
- 登录、注册、找回（`/login`、`/forgot`）在 360×640 和手机横屏下都一屏放下（矮屏收掉欢迎条、字段并排）。找回页三个框在不矮的屏上一列排齐；高屏提示字在框下面时框里不再重复灰字。
- 邀请码：每人在"我的"里生成（普通用户 3 个、管理员 50 个，7 天有效，管理后台能调），链接 `/i/<码>` 打开就是填好码的注册页；注册关着时必须凭码注册，用普通码注册的人和邀请人自动成为好友。管理员在管理页建的长期码一码多人，不进"我的"列表、不加好友。
- 隐藏游戏：被隐藏的游戏不出现在大厅（含第一张"继续玩"）、排行页签、动态里；过滤只经 `session.tsx` 的 `useVisible`（算法在 `shared/game-prefs.ts`）。总榜是全站合计，不拆游戏。
- 隐私说明（`/privacy`）按小节分页签（概要、筹码、账号、好友、成绩、设备和本站、访问统计、怎么删），页签一行放不下就折行（不横着滑），每节条目按高度翻页，正文在 `src/pages/privacy/privacy-sections.ts`。"积分和筹码"一段适用于所有游戏：免费、没有充值，积分筹码没有现金价值，不能买、换、转让，不设奖品。

## 管理页（`/admin`）

- 控制台布局，分区记在 `?s=`：宽屏分区导航在左边一列，窄屏横排、一行放不下折成两行（不横着滑），表格和列表按高度翻页，宽屏分两栏、窄屏分页签。
- 概览：今天的数字卡片和各游戏、"管理筹码"小窗口；近 7 天趋势图和每天明细。
- 用户：列表顶上"+ 建号"，左边列表、右边详情（钱包摘要、战绩和最近 30 笔流水两个页签、重设密码、删号）。
- 钱包统计；真人对局（近 7 / 30 / 90 天各游戏、玩法、档位的局数、时长和输赢分段，只有汇总，游戏结回、交分时带 `tally` 才记，见 `docs/platform-backend.md` 5.11）；邀请码（宽屏左边额度和单独改额度，右边码表；码表顶上一直有"+ 新建长期邀请码"，点开填次数（默认 100，最多 10000）和有效天数（空 = 不过期），建好显示新码和"复制链接 / 复制码"，码表筛到长期码；长期码的状态块写"能用 4/100"，下一行列用它注册的人，行里有"改次数"（弹框填 2–10000、不少于已用的；用完的改大又能用）；码表按每条的实际高度翻页，名字长折三行的码不让每页都少放）；设置里有默认隐藏的游戏。
- 设置：大厅公告、开放注册、钱包规则，即时生效、留记录。
- 页面上动不了管理员账号，管理员只能用命令行工具建。
