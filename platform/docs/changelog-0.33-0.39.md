## 0.39.4 — 2026-11-02

- **改动：后端按层、界面按功能分目录，只挪代码，行为不变。**
  - `worker/api/`：`lib/`（基础设施，不知道业务）、`core/`（请求上下文、限流、时间、settings 表）、`account/`、`wallet/`、`social/`、`scores/`、`ops/`。`router.ts` 留在原位。新加的架构测试守着 `lib/` 只引自己、`shared/` 和 `env`。
  - `src/`：顶层只留入口和全站共用的几件，其余放进 `features/<功能>/`（组件、逻辑、样式一起）、`lib/`（纯函数和小工具）、`pages/<页面>/`。导出组件的文件统一用 PascalCase（如 `feed.tsx` → `Feed.tsx`）。
  - 挪代码这一步前后的构建产物一致：CSS 逐字节相同（去掉文件名哈希后），JS 分块数不变；README 的目录说明、AGENTS.md 和 docs 里的路径同步改了。
- **修：宽屏三人以内只有领奖台时，"我的名次"卡和台顶之间空一大截**（1920 下约 140px）。现在第一名的格子撑满整块高，二、三名按比例矮一截，台子吃掉名字下面剩的高度，卡和台顶之间只剩行距；`podium` 冒烟段量这个空隙，要求不超过 32。

## 0.39.2 — 2026-11-02

- **修：宽屏总榜只有一个人上榜时，领奖台缩成一根竖条、右栏空着。**
  - 原因：宽屏的领奖台开了尺寸包含（台子按高度升高要用），一个人时又按内容收缩（`max-width` + 左右 `auto`），内容宽被算成 0，整块压成 0 宽。
  - 现在领奖台宽度按人数给（`width: 100%`，每格最宽 240），不看内容。
  - 三个人以内没有翻页名单时不分两栏，"我的名次"和领奖台横跨整宽居中。
- **修：360 宽的手机上顶栏比屏幕宽 6px**（普通用户五个按钮加五位数余额）。手机浏览器为此把整页缩小一点，排行页等一屏放不下、最右边的头像按钮被裁掉一截。现在 379 宽以下收窄按钮间距和内边距；按钮仍是 44 见方，收到 40 宽只在 340 以下。
- 冒烟加 `podium` 段：1、2、3、10 个人 × 我在不在榜 × 五个尺寸，量领奖台宽、每格宽高、页面不滚；矮屏本来不放领奖台，查的是排成列表；也查页面不横向超出。
