# 平台配色表（卡通风格）

变量都在 `src/styles.css` 的 `:root`，界面里不写死颜色。

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面底（奶油） | `--paper` / 顶部渐到 `#ffe9c7` | `#fdf6e8` |
| 卡片、面板底 | `--surface` | `#fffaf0` |
| 描边、阴影、正文 | `--line` / `--ink` | `#2b1d14`（深棕，2–3px 描边） |
| 次要文字 | `--muted` | `#74646a` |
| 主色（按钮平涂、标题字） | `--accent-deep` / `--accent` | `#e0601f` / `#f07a3a` |
| 提示条、高亮行 | `--highlight` / `--highlight-warm` | `#fff3c4` / `#fff3d6` |
| 赢 / 输 | `--good` / `--bad` | `#2f7a3a` / `#b4232d` |
| 在线（好友绿点、顶栏在线数） | `--online` | `#3fae5f` |

形状和质感：圆角 12 / 16；深棕描边；按钮实色下沿 4px（小按钮 3px）、按下下沉；表面上亮下暗的轻渐变（`--face-paper`、`--face-white`、主按钮橙渐变）+ 顶边白高光 `--hl` + 柔和环境投影（都并在 `--sh-*` 里）。面板（`.panel`）用细描边加柔和投影，退到后面当底子；粗黑边和硬投影只给能按的按钮、卡片。

## 动效

- 只动 `transform` / `opacity`，不动布局属性。
- 大厅卡片第一次渲染时依次上浮淡入：每张晚 40ms、时长 220ms、`ease-out`；鼠标设备（`hover: hover`）划过卡片抬起 3px 并加深阴影，封面 400ms 放大到 1.05，介绍和标签 200ms 从封面底下浮上来（键盘焦点进卡同样浮出）；"进入游戏"按下时下沉并缩到 0.97。
- 进游戏（`src/lib/enter-fx.ts`）：
  - 点"进入游戏"后，那张封面从卡片原位 260ms 放大铺满屏幕，铺满再跳转；只拦普通左键。
  - sessionStorage `arcade.enterFx` 记下游戏和时间，30 分钟内回到大厅时满屏封面 220ms 缩回那张卡（卡不在视口里就不播），播完删记录。
  - 同一条记录里还记着进游戏时的筹码总数（余额加桌上筹码，实盘筹码留在桌上不算赢）。回来时总数多了，顶栏筹码牌子的数字 600ms 滚到新值，同时迸出 8 枚金币（`.account--chips .chips-burst`，约 600ms，只动 transform/opacity）；少了只滚数字，没变不播；减少动效、`.no-motion`、自动化浏览器下直接显示新值。
  - 浏览器后退时大厅从往返缓存恢复，在 `pageshow`（persisted）时先拿掉残留的满屏封面再播缩回；跳转后 1 秒也兜底拿掉一次。
- 页面切换：路由换页时新页面 160ms 从下方 6px 淡入（`.page-in`）。
- 按钮三态：按钮、标签、分段选择、筛选小块悬停加深、按下下沉、不可用变淡且不响应；`:focus-visible` 统一 3px `--accent-deep` 描边、外移 2px。
- 高光演出（只在子页，大厅不放）：
  - 战绩页：新拿到、升档的徽章翻一下、扫一道光（`badges.css` 的 `badge--fx`）。等第一枚新徽章 80% 进了视口才开演、演了才记进 `src/features/badges/badge-seen.ts`，手机上徽章在首屏下面也不会白播。
  - 排行页：前三名的领奖台依次升起，台子到位后头像和名字落下，总长 ≤ 900ms（`boards.css` 的 `.podium`）。
  - 钱包页：领补给成功后，8 枚金币沿确定的弧线从按钮飞进顶栏筹码牌子，落地后牌子弹一下，余额再滚动加上（`src/features/coinfly/coinfly.ts`、`coinfly.css`）。飞的时候按钮保持"请稍等"，连点只发一次；请求失败不飞；中途换页，金币层照样清掉。
- 顶栏筹码数字变化时在 600ms 内滚到新值（`src/lib/countup.ts` 的 `useCountUp`），第一次显示直接是当前值；格式仍是 `num()`，最终文字等于格式化后的余额。
- `prefers-reduced-motion: reduce`：所有动画和过渡关闭，数字立刻到位。
- 自动化浏览器（`navigator.webdriver`）：给 `<html>` 加 `no-motion` 类，效果同上，冒烟和截图结果稳定。

## 声音

`src/lib/sound.ts` 用 WebAudio 现场合成，不带音频文件；页脚的"声音"开关（localStorage `arcade.sound`）关着时一点声音都不出，也不建 AudioContext；无头浏览器（`navigator.webdriver`）下四种提示音都是空操作，也不延迟跳转。每种不到 0.6 秒，音量不超过点按声的 1.5 倍。

| 提示音 | 声音 | 响的地方 |
|---|---|---|
| 点按声 | 一声轻"嗒" | 点按钮、链接、折叠标题 |
| `playEnter` | 往上的两声"叮叮" | 点"进入游戏"或"继续玩"（和放大过渡一起响；没有封面可放大时晚 120 毫秒跳转） |
| `playCoins` | 三下高音"叮叮叮" | 领补给成功；顶栏筹码刷新后变多 |
| `playSuccess` | 大三度轻响 | 我接受好友请求、生成邀请码、晒战绩卡生成分享成功 |
| `playError` | 低短的"咚" | 服务端拒绝了用户的操作（`useSubmit` 和好友页的操作收到 `ApiFail`）、好友码没找到；断网、报错不响 |
