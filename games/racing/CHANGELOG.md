# 飞驰（games/racing）更新日志

## 0.2.0 — 2026-11-12

### 新增
- 巡检地址 `/games/racing/health`：不用登录，回 `{ "ok": true, "version": "<版本号>" }`，给平台的监控用。
- 页面上没人接住的报错会报给平台（`arcade-kit/report`），线上 Worker 开了日志（`observability`）。
- 单独部署时 `/api/me` 由 Worker 回"没有平台"，打开页面时控制台不再有一条 404。
- 加了 Biome lint（`npm run lint`，全仓统一的规则）；模块里加了 MIT 许可证文件。
### 改动
- 共用包 `arcade-kit` 从 0.10.1 升到 0.25.2：联机断线重连更稳（iOS 锁屏回来、网络恢复会马上重连），好友房的玩法和协议不变。
- 道具砸中后的污渍多停一会儿（约 1.7 秒到 3 秒），和别的游戏一致。
- README、DESIGN、AGENTS 按现状重写：去掉已办完的立项待办和进度表，README 加截图和"参与贡献"。

## 0.1.4 — 2026-10-20

- 新手教程：选桌页多了"新手教程"按钮，老车手阿驰带你在环湖跑一圈，从认车、挂挡、出牌讲到弯道限速、热量和散热。
- 教程里要你点的东西描一圈闪动的金边；之后你自己开，第一次碰到冲刺、尾流、打滑这些时阿驰会提醒，随时能跳过。
- 冲线后阿驰颁"毕业"，可以"正式开跑"或"再练一次"；阿驰有自己的头像和三种表情。
- 教程不碰你正在跑的那场单机，也不改你的预设和选项。
- 结算弹窗里多了"大厅"按钮（原来弹窗挡住顶栏，回不去大厅）。
- 冲线后先停一会儿再弹结算；结算靠下边放、不挡赛道，还能收起再展开。
- 电脑的表情和说的话不再盖住名次栏里的车手名（横屏冒在那一行左边，竖屏冒在名次栏上沿）。

## 0.1.3 — 2026-10-19

- 每个弯的路边竖一块限速牌，牌杆沿着弯道线伸出去，一眼看出哪个数字是哪个弯；挨得近的两个弯牌子错开放。
- 放大以后弯道线旁边多一块写弯名的小牌；你前面的下一个弯，限速牌描一圈金边。

## 0.1.2 — 2026-10-19

- 换成桌游风格：赛道是一块印刷的地图板，三条赛道各有场景（湖、山城、港口），车是带号码的塑料棋子。
- 卡牌是印刷卡，驾驶台是一张玩家板，名次栏是一列纸签，选桌页和弹窗是一张纸。
- 手机上默认跟着自己的车，出牌时镜头自动框住落点和要过的弯；画面外的车在屏幕边上标出来。
- 缩得很小时只显示赛道、限速牌和车，放大了才出现格号、制动牌和弯名。
- 弯道线前三格印着制动牌 3、2、1，帮你算什么时候降挡。
- 竖屏时赛道整张转 90° 铺满屏幕，出牌按钮不再被手牌盖住。
- 纹理从 11 张（144 KB）减到 4 张（约 21 KB）。

## 0.1.1 — 2026-10-16

- 驾驶台按一回合的顺序重画：上面一条步骤条，先在挡位箱上挂挡，再把手牌放进出牌区，放满了才预览落点。
- 整体换成写实风格：沥青赛道、路肩和缓冲区、俯视的方程式赛车、卡纸质感的卡面；热量一律用火苗表示。
- 静止的赛道开局时烘焙成一张图，跟车、拖动镜头时手机上也是满帧。
- 驾驶台加了牌堆区和弃牌区，点开能看自己用过、剩下哪些牌（只能看自己的）。
- 大家同时出牌时，名次栏里出完牌的那一行边框变绿，一眼看出还在等谁。
- 竖屏铺满细长的手机屏幕，不再上下各空一条黑边。

## 0.1.0 — 2026-10-16

- 第一版：回合制卡牌赛车。换挡出牌、热量、过弯限速、打滑、熄火、冲刺、拼劲、尾流。
- 三条固定赛道：环湖（均衡）、山城（技术弯多）、海港（高速、急弯）；1–3 圈，2–6 辆车。
- 单机对电脑：七个性格分新手、普通、老手三档，每个电脑每场的状态有浮动；跑到一半关了页面，回来接着跑。
- 出牌前在赛道上画一辆虚影车：落在哪、过哪几个弯、要付几张热量、会不会打滑。
- 冲刺、尾流、拼劲、弃牌可以出牌时预设好，轮到时不用再点；赛道能拖动、缩放，一键"跟车"或看全图。
- 好友房：开房定好赛道和规则，分享链接或房间号叫朋友，人不够电脑补位；掉线托管、中途接管电脑、跑完"再来一场"。
- 互动："聊"面板里说一句、发表情、扔道具；电脑按性格主动说话，被点名、被扔东西会回。
- 不要平台也能单独部署：游客打开就能玩，选桌页填昵称。
