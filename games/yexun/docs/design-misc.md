## 12. 已知问题和待办

- **焚天金钟**（8.1）：靠"危险 4 起带两件镇类时精英不吃减速""火葫芦带两件火法器才烧弹""危险 5 起怪不怕克制"压着。
  排除过的改法（危险 5 各 1,000 局）：火葫芦伤害 −10%、金钟罩回层变慢、精英一下打碎全部护罩层、精英抗火葫芦、镇 3 件加伤、镇魂铃减速减半、精英只对凑齐镇 3 件的人不吃减速，都压不下去或连带烈火、镇魂铃掉太多。
- 13.3 的全局升级次数（上限 36）还没按刷新补给、跳过小奖用大样本重核；`tests/core/pace.test.ts` 暂时多留 4 级。
- 噩梦档的夜色只改画面，机器人照样看得见全场，表里噩梦 2、3 的胜率比真人高；以后要给机器人加「只看得见身边」的玩家模型再量。
- 实盘：小白只按小道士、雪原（守夜）和各镇子的小道士（夜探）拟合；各档期望值每次改内容后要重拟（4.2）。
- 架构：`src/core/step.ts`（约 3,600 行）和 `src/view/game/GameScene.ts`（约 2,600 行）偏大，打算按职责拆成几个文件；`step.ts` 里还有少量硬编码系数该挪进 `src/content/`。云存档同步器 `src/platform/cloud.ts` 各游戏各有一份，合并属跨模块，不在本模块单独做。
- **雷劫锁魂**（勾魂锁 + 雷符）全体只在 2.2% 的局出现（普通机器人雪原危险 3）：两件都在池里的只有胖师叔、纸匠、阴阳先生，前者很少拿勾魂锁（22%），后两人很少拿雷符（11%、17%）。试过把勾魂锁放进采药女的池（雷符是她的核心件），她自己的花灯会 69% → 62%，过了「专属掉 1 个点就不做」的止损线，撤了（3.3e）。下一步只考虑加法、不降门槛，候选是让雷符更常进那三人的手，或者找一个不冲稀自己专属的角色。
- 暂无省内存设备的内存估算工具（第 6 节）；26 个尺寸的矩阵检查脚本不在仓库里（docs/art.md）。

## 13. 验收标准

每条后面写怎么查。"机器人"指 `tools/sim.ts` 的玩家模型（第 8 节），"冒烟"指 `tools/shot.ts` 和 `tools/smoke.ts`。发版前按这张表试玩和对账；现状数字见第 11 节。

### 13.1 内容量

- 法器、被动、进化（每件法器一个）、合成与双修（3.1–3.3b）—— 内容测试数表、配方对得上
- 角色每人一个专属被动（3.7）—— 内容测试
- 守夜地图、夜探模板 + 教学镇（3.6）—— 冒烟各进一次截图
- 常规怪、精英、Boss（3.5）—— 内容测试；图鉴截图
- 宝物（四档）、成就 —— 内容测试

### 13.2 难度分层

- 娱乐危险 0–8 九档，逐档继承（2.4 表）；通关一档解锁下一档；噩梦档每档多一种机制、只守夜 —— 内容测试（`tests/core/nightmare.test.ts`）+ 机器人在各档的胜率表（8.1）
- 地图事件每图一种、到点预告、夜探不开（实盘守夜开） —— 核心测试（`tests/core/nightmare.test.ts`）+ 冒烟第 8 段（噩梦 3 × 每张守夜图）
- 咒印：开局自选 0–3 条负面，换更多铜钱；实盘不开 —— 内容测试；实盘开局时咒印为空的测试
- 实盘四档固定映射危险 0 / 2 / 3 / 4 的配置（4.1）—— 测试
- 新手保护：第一局锁危险 0；危险 0 第一局 3 分钟前不会死（血最少留 1）；连死 3 局弹"要不要挨打减伤"（开着时成绩不进总榜）—— 核心测试 + 冒烟

### 13.3 一局节奏（守夜，机器人"普通"在危险 2 量，写成测试 `tests/core/pace.test.ts`，每项 ≥ 200 局的均值）

- 第一次升级 10–20 秒，前 30 秒最多 2 级（"打死一个怪就升级了"太快）
- 前 3 分钟升级 6–9 次，第 5 分钟前 10–14 次
- 全局升级 25–36 次（按会凑双修的机器人量），后半段每分钟 1.5–2.5 次（成型感在 8–10 分钟出现）
- 道具：精英宝箱 1 / 3 / 5 件（5 件 12%、3 件 33%、1 件 55%，1:45 那只纸轿只掉 1 件；纸扎老爷至少 3 件），开箱有演出；场上可碰碎的灯笼架、纸扎（开局散 36 个，主角 760 以内少于 4 个时每 12 秒补一个），碰碎掉肉包 30%、铜钱堆 32%、磁符 10%、符咒炸弹 8%、铜钱袋 12%；
  小怪另有千分之 1.2 掉符咒炸弹（半径 520 内小怪全倒，精英和 Boss 掉 8% 血）、千分之 1.5 掉铜钱袋（12–25 枚）；数值在 `src/content/player.ts`
- 每局都看得到铜钱进账，结算页按来源列：捡到的、摆设、铜钱袋、宝箱、撑的分钟（每分钟 10）、击杀（每 40 只 1）、天亮 120、尸王 200（这四项每高一档危险 +20%）、咒印加成、成就、每日首胜 150（`RUN_BONUS`）
- 结算页在铜钱行上方有一行「今晚」：本局经历的地图事件（同横幅图标）、血月升起、精英发狂的次数，形如 [风]×3 [月]×2 [怒]×5，全为 0 不显示，夜探不显示；次数由画面层（`GameScene.nightLog`）按真正开始的事件计，不进核心和上传
- 精英、中期首领、尸王的时间线见 design-play.md 2.2；精英每次必掉宝箱
- 每个大事件后 20–30 秒收获期（刷怪量、掉落量曲线能看出低谷）
- 3 分钟、8 分钟、12 分钟附近各有一个"小爆点"（围圈、群冲、纸人海）
- 夜探：危险 0 和教学镇第 3 分钟开第一座门；小白迷失 ≤ 10%

### 13.4 构筑

- 三选一 + 刷新（每局 2 次，局外可加）+ 封禁（每局 1–2 次）+ 跳过（换少量魂）
- 卡片和暂停页写清"进化还差哪个被动"
- 套装（标签 2 件、3 件）撑起 ≥ 5 个流派（3.4）
- 幸运属性（黄历）
- 配平：每个流派的机器人（普通）在危险 2 都能撑到天亮，没有"只有一种 build 能赢"—— sim 表（8.1）

### 13.5 留存

- 怪物图鉴、法器图鉴、藏宝阁，主界面显示总收集度
- 每日挑战：每日守夜（固定种子 + 当日咒印）、每日连战（10 只首领 + 终局夜漏君，自己配装）
- 守夜通关后开"无尽"（天不亮、怪一直涨、计时），实盘不开
- 排行：每日榜、总榜（守夜、夜探、无尽）、好友榜
- 本地录像回放（自己的）；分享卡（kit 的 share）；游戏内玩法说明


### 13.6 手感清单（必须全有）

### 13.8 质量（第 1 节五条）

- 60 帧：中端手机横屏 300 怪不低于 50 帧（给数字）；输入一帧内响应
- 每个界面电脑横屏、手机横竖屏截图，没有压字、错位、小于 44 像素的按钮
- 控制台零报错；iOS 省内存设备完整一局不崩
- 音效、音乐能分别关
- 加角色、技能、法器：旧录像回放指纹不变有测试；技能按钮在 844×390 横屏和 390×844 竖屏不挡摇杆和血条；每个技能、每件新法器都有专属特效和音效才算做完

## 14. 和平台的关系（夜巡是平台体系里的一个游戏，不是孤岛）

| 平台能力 | 夜巡怎么用 |
|---|---|
| 账号、登录闸门 | Worker 首页过 kit 的 `loginGate`（5.6）；单独部署时游客 |
| 钱包、实盘 | 两个模式的实盘走平台钱包（client 模式，Worker 转 RPC，先 view 再带回）；配平按 `docs/balance.md`，档位按 `docs/economy.md` |
| 战绩 | 带回时带战绩小结 `stats`（平台 5.10），只转发不改 |
| 排行、每日挑战 | `POST /api/scores`：守夜、夜探、无尽总榜，每日守夜、每日连战，好友榜 `scope=friends`（5.7） |
| 分享卡 | 结算页"分享这一夜"：kit 的 `arcade-kit/share`（`prepareShare`），图上写时长、击杀、build、咒印；标题写模式和档位，每日写"每日守夜"，本周夜事写"本周夜事 · 这周的事件"；不上传 |
| 社交部件 | kit 的 `arcade-kit/social`：`mountSocial` 报位置（在菜单 / 守夜中 / 夜探中）、收好友邀请的横条；只在有平台且登录时挂 |
| 云存档 | 只同步 `profile` 一个槽（局外成长，含教程标记）；合并规则见 5.5 |
| 称号 | 成就给的称号写进 `public/titles.json`，形状照平台读它的格式（平台 5.10），平台战绩页、称号墙能显示 |
| 大厅 | 回大厅入口常驻左上，对局中离开先确认 |

不碰真钱：筹码只在实盘里带入带回；铜钱是游戏内货币，可以按 3:1 单向换筹码（3.8a，每天额度由平台钱包管），筹码不能换回铜钱。
