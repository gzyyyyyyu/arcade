# 《夜巡》设计稿：画风声音、配平工具和测试（第 7–9 节）

> 《夜巡》设计稿的一部分，总纲和目录见 [../DESIGN.md](../DESIGN.md)；节号和代码注释里的「DESIGN x.y」一致。

## 7. 画风和声音

### 7.1 画风（参考同类游戏的风格，不照搬它的角色、图、界面布局）

- **浅色雪地 + 稀疏点缀**：月光下偏冷的浅灰白雪地、零星的青石板、枯树、石头、残碑；底色浅，特效和怪才能跳出来。雪地很亮，特效用饱和色 + 深色边的普通混合，ADD 叠加只用在暗处。
- **角色**：大头 Q 版、粗黑描边、平涂加一层阴影；动作靠压扁拉伸和晃动（走路上下颠、受击压扁、死亡弹起）。
- **怪**：一种一个主色，精英带鬼火紫光（ADD 叠加的外发光），都有脚下椭圆阴影。
- **特效**：金色（符、剑）、青蓝（雷、鬼火）、朱红（火、朱砂）三套主色；发光叠加、拖尾、碎片、墨点。
- **界面**：卡通风格，奶油底 + 深墨描边 + 实色下沿阴影，朱红做强调；数字用粗体无衬线，标题和连斩横幅用毛笔字。配色见 docs/palette.md。

### 7.2 素材

全部程序生成：开局用 Canvas 2D 画进图集（角色、怪、法器、特效、地面贴片），矢量路径写在 `src/view/art/`；毛笔字用马善政楷书（SIL OFL 1.1）按用到的字子集化（`tools/subset-font.ts`）。不引入任何别人的图片、音频；来源和许可写在 `ASSETS.md`。

### 7.3 音乐

WebAudio 程序合成：五声音阶的笛子 / 古筝音色（简单的加法合成 + 包络），夜里低沉的鼓点；守夜按时间段加层，尸王出场换曲；夜探更安静、撤离门开时加紧张的打击层。

### 7.4 音效表（每项一种合成配方，验收 ③）

法器各一（剑风、符纸爆、铜钱叮、飞剑嗖、镜光嗡、雷击、铃声、喷火、绳索、花瓣、护盾起 / 碎、纸鹤）、命中、暴击、怪死、魂火拾取（音高随连吸上升）、升级、三选一选中、进化（长）、宝箱开（守夜、夜探金箱、彩箱）、
宝物入袋、受伤、回血、低血心跳、精英出现、尸王出现、尸王技能 3 种、撤离门开、撤离成功、天亮、死亡、炸弹、铜钱袋、摆设碰碎（木、纸）、点击。名单以 `src/view/audio/sfx.ts` 的 `SfxName` 为准。
同一帧同一种音效最多播 2 个，避免几百个命中音叠成噪音。

## 8. 机器人和配平工具 `tools/`

- **两个玩家模型**（`docs/balance.md` 第 1 节，带种子、确定性；这个游戏没有隐藏信息，但机器人只用屏幕上看得到的范围）：
  - **小白**（novice）：每 10 拍重新决定方向，朝"离怪最远 + 有魂火"的方向走但带噪声，偶尔贴脸；升级只挑看起来最强的（不全随机，随机选卡会拿到引魂灯这类不直接加战力的被动）；夜探见箱就开，撤离门开了才往那边走、常常走不到。
  - **普通**（normal）：每 3 拍决定，按怪的密度场躲（势场法），会绕圈收魂火；升级按流派单子和进化配方挑，会去凑双修的另一半；夜探会算"走到撤离门要多久"决定开不开下一个箱，逛鬼市、按背包价值和血量选第一扇还是第二扇门。夜探另有贪心（greedy）玩家，多待多搜。
  - 流派单子在 `tools/bots.ts` 的 BUILDS，和玩法说明用的 `guide.ts` 是同一份。
- `tools/sim.ts`：多线程跑 N 局，输出胜率、时长分布、倍数分布和每档实盘期望；`--json` 存每局结局（赢没赢、打没打倒尸王、撑了几拍、死因、第一次双修的拍）供离线拟合，`--from` 错开种子分片，`tools/sim-merge.ts` 拼表；`--nodual` 是双修对照臂。大批量（每格 ≥ 1,000 局）拆到 GitHub runner 上跑。
- `--stop`（实盘配平，配 `--live`）：每格小白、普通两条线按批跑（默认每批 50 局），每批后看两条线实盘期望的 ±2SE 区间，「要不要动系数」定了就停。口径和配平的修正规则一致（超带上限 +0.15 才压，普通低于下限 0.10 以上才抬，小白偏低不管）：普通线区间整个高于上限 +0.15（多发）、整个低于下限 −0.10（偏低）、或整个落在 [下限 −0.10, 上限 +0.15] 里（不用动）就算定了；小白线区间整个高于上限 +0.15（多发）、或上沿不超过上限 +0.15（不用动）就算定了。两条线都定了就停，最少 100 局，最多 `--n`（实盘配平用 300）；区间跨着 上限 +0.15 或 下限 −0.10 的格子跑满。表和 json 写每格实际局数和停的理由（不用动 / 多发 / 偏低 / 跑满）。规则在 `tools/early-stop.ts`，同一个文件能拿已有的 json 离线回放（`node tools/early-stop.ts <json>...`）。种子顺序和跑满一样，提前停的结果就是跑满那一格的前 N 局。拿 11-03 全覆盖测量 387 格回放：停时的动作和跑满 300 局按点估计的动作 0 条不一致，局数省约 45%、耗时（拍数）省约 49%。
- `tools/shot.ts` / `tools/smoke.ts`：无头浏览器截图与冒烟（用法见 AGENTS.md 第 5 节）。
- `tools/bench.ts`：核心耗时；`tools/feel.ts`：手感；`tools/cover.ts`：大厅封面。

**配平方法**：先给弱流派补强，给强流派加克制它的怪，少砍法器；改数值的 PR 里贴同口径的结果表；节奏验收（13.3）写成机器人测试（`tests/core/pace.test.ts`）。

**配平流程**（0.21.1 起）：
- **娱乐和实盘分开发**：新内容、界面、娱乐数值好了就交，实盘用 `World.newNN` 闸住、照上一个规则版本原样，不等实盘量测。
- **实盘对齐一天一批**：白天所有影响数值的改动攒着，晚上一次跑流派清点（8.1）+ 实盘量测（`--live --stop`，守夜默认线 + 最优配置线 + 夜探），第二天早上交一版实盘对齐（开实盘的规则版本 + 系数）；白天不为单个改动重跑全量。
- **白天调数值只做粗筛**：一个角色、只跑受影响的格子，约 20 分钟出方向。
- **先写验收口径再跑**：改数值前把「跑什么、过线标准、过不了怎么取舍」写下来，按口径从准备好的几组里选，不多轮试。

### 8.1 全流派配平口径

目标：至少 10 种搭配能通关最高难度，各流派有轻微强弱但不明显。

- **搭配** = 一个主流派 + 一条进化或双修路线。同一流派走不同进化，算不同的搭配。只计机器人能稳定走出来的构筑。
  - **稳定走出** = 路线走成率 ≥ 30%（危险 5）。走成率是这条路线的进化或合成在局里做成的比例。不到 30% 的路线，要么给机器人加路线策略帮它凑，要么不计入 10 个。
  - 机器人照路线优先拿配方里的法器和被动，其余照流派表（模拟器用 `--build 流派:路线`）：路线还缺的法器（没进化也没满级）和它们的进化被动优先拿；三张都不沾边就先用刷新换一批（`tools/bots.ts` 的 `critical()`，真人做得到的找卡办法）。
- **流派**：剑修、符箓、镇守、五雷、烈火、纸兵、水府，共 7 个（水府 0.7.0 加，路线 `water:spring / tide / leiyu / mirror`，全量结果见 3.4 的表）。
- **通关最高难度** = 危险 5 撑到天亮。用普通机器人，每个搭配 ≥ 1,000 局，在 GitHub runner 上分片跑。通关率 ≥ 25% 算可实现；至少 10 个搭配达标，覆盖全部流派。
- **难度曲线**：危险 5 各流派最好搭配目标 30–45%（避免太容易）；仍要保证至少 10 个搭配走成率 ≥ 30%、通关率 ≥ 25%。危险 2→3 普通胜率降 8–10 个点。普通机器人在危险 5 上普遍接近 0 时，先评估：给机器人加一档"高手"（更早躲尸王技能、更会绕圈），或调危险 5 本身；不擅自降最高难度。
  改危险档要同步核对实盘用到的档位系数（危险 0 / 2 / 3 / 4）。
- **噩梦档**（危险 6–8，0.5.0）：通关率要明显低于危险 5。目标（普通机器人，小道士，雪原）：各流派默认搭配和最强路线都落在 噩梦 1 15–30%、噩梦 2 10–22%、噩梦 3 3–15%；小白 ≤ 2%。
  机器人看得见全场，噩梦 2 起的夜色对它不起作用，真人会比表里难一截；所以噩梦 2、3 的目标定得比实际想要的松。
- **流派平衡**：参考档 = 危险 2、普通机器人，每流派取它最好的搭配，各 ≥ 1,000 局。最高和最低通关率差 ≤ 12 个百分点；任一流派离平均 ≤ 7 个百分点。排名可以有先后，但不能出现某流派明显碾压或明显没法玩。
- **双修**：没有一条组合比同流派最好的单修高 8 个百分点以上（用 `--nodual` 对照臂量净强度）；频率上，普通机器人危险 4 每 20 局合成至少 5 次。
- **实盘**：荒庙、纸兵以及全部角色 × 地图组合，用 `LIVE_CHAR_BP`、`LIVE_MAP_BP`、`LIVE_COMBO_BP` 同一套方法拟合；偏离同档平均 ±0.15 份以内才开放。新内容和配平改动一起上实盘（`LIVE_MAP_CLOSED` 留着给以后的新图用）。
- **2.0 的四个新首领和两种特色怪**（0.15.0）：换了首领的竹林、河滩、冰湖、荒庙，加了特色怪的雪原、义庄，通关率要和换之前（0.14.0，同一批种子 1..300）差 ±3 个点以内。量法：普通机器人、小道士剑修，每格 300 局（2 倍标准误约 ±4–6）。结果（改前 → 改后，危险 2 / 危险 5）：雪原 59% → 57% / 28% → 29%；竹林 82% → 80% / 49% → 46%；冰湖 56% → 53% / 13% → 10%；河滩 64% → 64% / 37% → 35%；义庄 41% → 39% / 11% → 15%；荒庙 40% → 40% / 13% → 13%。调过的：千年竹母血 4800 → 3800、技能间隔 150/115 → 175/135 拍、竹笋伤害 10 → 7、一次召竹精 5 → 3（初版竹林危险 2 掉 8 点、危险 5 掉 6 点）；棺钉鬼占比 5–6% → 1.5–2%、钉 3 → 2 枚、伤害 6 → 4、间隔 150 → 180 拍、坐起距离 280 → 220、空棺 20 → 4 秒（初版义庄危险 2 掉 21 点；把它的占比设成 0 正好回到 41%，所以是它造成的，但这么少的怪影响这么大的原因还没查清）。水猴王、冰魄娘娘、无面佛用的是 D 段的数（水猴王血 4500、无面佛血 4800、香炉全灭 ×1.5）。冰湖两档都正好差 3、义庄危险 5 高 4（危险 2 低 2，方向相反，按噪声看），0.16.0 全量配平复核。夜探新镇按同一量法（危险 2、普通机器人、剑修、每镇 200 局）对三个老镇配撤出率和撤出局平均带出价值，老镇是 古镇 50% / 407、渡口 61% / 293、山寺 50% / 362。戏楼镇初版 74% / 375，调后 57% / 384（巡夜将多一个、3/6/9/11 分钟各一；戏台 30 → 24 秒开一场、一场 8 → 11 个；红衣戏子间隔 100/70 → 70/48 拍、水袖半径 160 → 200、伤害 38 → 55；戏班鬼影占比 25%/40% → 30%/48%）。粮仓镇：街巷密（7×7 = 49 个院子，老镇 5×5），院子挨着院子，普通玩家开的铜箱是古镇的两倍多、宝库常被打开，初版带出价值是老镇平均的两倍。现在铜箱比例 0.1、木箱 8 个、不放庙、宝库在正中往东北一格（再往角上挪就比街上的木箱还浅），每格 300 局：小白 撤出 53% / 带出 178，普通 61% / 426，都在老镇平均 ±20% 以内（小白 138–207、普通 286–428；普通贴着上限，古镇自己是 436）。新镇子要先配平再放：能进的镇子是一张白名单 `RAID_OPEN`（`content/explore.ts`；菜单的 `RAID_PICKS` 从它派生），开一局夜探、链接参数 `?raid=`、再来一局都过 `raidOpen`，线上构建只认白名单，白名单外的镇子只在开发服务器（`import.meta.env.DEV`）里能进，局也不交榜（`online/score.ts`）。链接参数开的夜探只是娱乐局：实盘只能在菜单里选档位后由 `startLive` 开，镇子只认三个老镇（`RaidLiveTemplate`），所以这条路拿不到筹码。`tests/explore/raid-open.test.ts` 锁住。
- **画皮**（0.12.0）：换下纸扎老爷的三张图，通关率要和纸扎老爷差 ±3 个百分点以内。量法是配对：同一组种子，两边都是普通机器人、小道士，危险 2 跑七个流派、危险 5 跑七条路线；纸扎老爷那边是每格 500 局的基线，画皮这边取前 150 局（危险 5 100 局）比。
  各次量测的数据和过程见 [balance-play.md](balance-play.md)。

## 9. 测试 `tests/`

- **重放一致性**：同种子同输入跑两遍，状态指纹（所有数组的哈希）逐拍相同；中途"从种子 + 输入重算"得到的指纹和直接跑的一样；录像编解码往返一致。
- **跨实现一致**：一份写死的"种子 + 输入"及其终局指纹作为金标准（`tests/core/core.test.ts`）。
- **架构**：`src/core/`、`src/content/` 不出现禁止的函数和对象（第 5.1 节），不 import 画面、平台代码；`worker/` 不 import 核心（只取实盘档位表）；夜探同理（`explore-arch.test.ts`）。
- **内容**：刷怪表每分钟都有、进化配方对得上法器和被动、伤害公式边界、实盘倍数单调、玩法说明的流派单和机器人一致。
- **节奏**：`tests/core/pace.test.ts` 用机器人跑 13.3 的指标。
- **实盘**：Worker 路由（CSRF、请求体、单独部署 501、超时、按钱包里那一份的金额结回），照开盘的测试。
