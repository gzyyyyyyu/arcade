# 夜巡 · 界面流程与布局规则

> 现行规范。配色见第 6 节，画风和声音见 DESIGN.md 第 7 节。
> 只写改界面时要守的东西：流程、各屏该放什么、各尺寸怎么排、怎么验收。

## 1. 流程

主页（`Home`）→ 选模式 / 地图（`Select`）→ 对局；暂停、结算、玩法说明、角色与加成、图鉴、藏宝阁是叠在上面的面板（`screens/`、`prep.ts`、`codex.ts`、`vault.ts`、`guide.ts`）。

- 第一次打开只有一个大按钮（开始守夜），玩过一局以后才出模式卡和难度（DESIGN.md 13.7）。
- 主页：主视觉（月、灯笼、飘雪、道士）+ 标题 + 快速开始 + 两张模式卡 + 战绩；每日、排行、回放、图鉴、玩法说明收成一排小入口，不压标题。
- 选模式 / 地图：地图是横排卡、按难度排（雪原、竹林、冰湖、河滩、义庄、乱葬岗、荒庙、鬼市），左边缩略图（`drawMapThumb`），右边名字、一句说明和特色怪小头像（悬停写名字）；夜探的镇子卡同样带缩略图（`sprites-townmap.ts`，按镇子模板用固定种子生成一张样板地图画成小地图）；锁着的灰着并写怎么解锁。电脑、平板从上到下：娱乐 / 实盘、守夜 / 夜探两张头图卡、地图格（4 列；镇子 3 列）、一整条配置面板（右边大「开始」）。娱乐的面板和实盘同一个排法、同高：危险 0–5、角色按钮（点开角色页选人）和起手（二选一）、心法（三选一）两组小图标按钮一行；噩梦、咒印、加成、无尽一行；最好成绩一句。实盘的面板：档位（铜钱堆小图）、角色按钮和起手心法一行，危险档一句，再是一行等宽的数字小牌（细则在悬停里）。按钮图标都在 `sprites-selicons.ts`（流派圆章、铜钱堆）。电脑上整块按设计尺寸排好再整体 zoom：`select.ts` 按 min(可视宽/1476, 可视高/700)、限 1～1.6、取到 0.01 写 `--k`（1920×911 是 1.3，1280×720 是 1），卡片不拉伸，多出的空间留在四周，左上的大厅、返回跟着放大；缩略图画布按边长 × k × dpr 画。手机横屏是左边模式和地图、右边一栏配置和开始，竖屏整页一列，起手心法在技能说明下面另起一行。
- 实盘（有平台钱包才显示）作为"模式"的开关放在选模式屏，不占整块卡。

## 2. 对局 HUD：少挡视野

- 左上回大厅（≥ 44×44，窄屏只留小房子）和头像血条，上中计时（夜探加撤离目标条），右上击杀、铜钱，右侧法器格；夜探多背包价值和小地图。
- 手机竖屏顶栏并成一行，血条和计时始终可见；小手机横屏、窄竖屏（≤ 400 宽）、平板竖屏（768–884 宽）各有一档收法（`hud.css`、`raidhud.css`），改 HUD 先看这几档。
- 升级卡在电脑上标快捷键角标（1、2、3 选卡，R 刷新，X 封禁，空格跳过，回车拿高亮那张）；刚弹出的 150 毫秒卡片显示成不可点，按住键不连选。
- 新手提示条是一行小条，放在计时下面，不盖底部视野和小地图。
- 摇杆默认浮动（按哪儿出现在哪儿）；固定摇杆在设置里开，位置避开小地图。只动摇杆外观和位置，不碰输入逻辑（会影响 `tools/feel.ts` 测的手感）。
- 空气墙看得见：守夜场地四边按地图画栅栏、竹篱、石堤或院墙，墙外盖夜雾；顶着墙还在推时冒火星、轻震屏（跟震屏开关走）。

## 3. 各尺寸的排法

- 主视觉里的道士和灯笼按尺寸摆（`sprites-title.ts` 的 `titleLayout`），不压按钮和文字：手机竖屏道士站在按钮下面，手机横屏站右下角，电脑站在左栏；新加主页元素后三种尺寸都要看一眼。
- 暂停面板：手机竖屏上下排（继续、认输在最上面），电脑不强撑高度。按钮有悬停、按下、不可点、键盘焦点四种样子；换页淡入、面板滑入，跟"减少动态效果"走。
- 电脑（≥ 1100 宽）：主页左视觉右信息，两栏均衡（信息栏中心约在 63% 处）；选模式页模式卡、地图格、配置面板从上到下一整块，按可视区整体放大（见上面"选模式 / 地图"）。1920 下其他面板跟菜单一起放大（约 1.3 倍），不是缩在中间一小块。
- 手机横屏：主页单行；地图卡一屏看到三张以上，不要靠横向滑动藏起来。
- 手机竖屏：主页单列；地图卡竖向单列；"开始"始终在屏幕内。竖屏的世界缩放按屏宽定（一屏宽看 460 单位，`worldZoom`），刷怪圈转 90°（`setup.tall`）。
- 字号：说明不小于 12 像素，正文 14，数字 20，毛笔标题 24–40；按钮高度 40 / 48 / 56 三档，点击区仍 ≥ 44。
- 窄屏、小屏放不下的先收（去图标、去月亮、挪行），再考虑缩字；320×568 放不下时整层能上下滑。

## 4. 省内存设备

渲染倍数封顶 2、`100dvh` 加 `--app-h`、safe-area 带兜底值（`viewport.ts`）；主页飘雪减半或静止，待机小动作静止；新界面都写在 `--app-h` 之内。

## 5. 验收

- 每次改界面：`npm run shot -- --flow --view desktop,phone,phonep,wide` 看每屏截图，至少一张不开 `auto` 的真实对局；`npm run smoke` 第 7 段断言 HUD 各块互不相交。
- 多尺寸：手机竖横、平板、折叠屏、电脑共 26 个尺寸，查溢出、点击区 ≥ 44、元素相交、截字、字号 ≥ 12、控制台报错（矩阵检查脚本还没放进仓库）。
- 有意的省略号只留在结算页夜探宝物名这种格子很窄的地方，悬停看全名。

## 6. 配色（卡通风格）

夜蓝是夜巡的主色调；界面元素一律奶油底 + 深墨描边 + 实色下沿阴影，照开盘的卡通样子。

| 色值 | 用在哪 |
|---|---|
| `#17131c` 墨 | 所有描边（2.5–3px）、下沿阴影（按钮 3–4px，按下沉到 1px）、正文字 |
| `#fbf5e4` / `#f6efdc` 奶油 | 卡片、按钮、面板底；选中的卡反过来：墨底奶油字 |
| `#1c2440` 夜蓝 | 菜单背景、HUD 倒计时底（主色调） |
| `#c8402f` 朱红 | 主按钮（开始、确认）、危险提示 |
| `#ffd23a` / `#f2c94c` 金 | 选中描边光、钥匙、铜钱、强调数字 |
| `#8f6110` 暗金 | 奶油底上的小字说明（13px 起，对比度够） |
| `#5a4a3a` 褐 | 奶油底上的次要正文（14px） |

圆角：按钮、卡片 12–14px，面板 14–16px；正文 ≥ 14px，按钮下的小字说明 ≥ 13px。

表面用亮下暗的轻渐变 + 顶边 1px 白高光（`--yx-hi`）+ 细纸纹（`--yx-grain`，feTurbulence 噪声），实色下沿下面再垫柔和投影（`--yx-lift`，0 6px 14px）；选中用深墨渐变，主按钮朱红渐变。
