# 更新日志（归档）

0.19.8 及更早的版本，新版本见 [CHANGELOG.md](../CHANGELOG.md)。

## 0.19.8（2026-11-07）

### 改动

- 电脑宽屏上的选模式页重排成左右两栏：左边是「娱乐 / 实盘」、守夜和夜探两张矮卡、地图格；右边是配置和一直在底部的「开始」钮。以前整页一列，1920 宽屏上顶上的模式切换被顶出屏、底下噩梦和咒印那排被裁。
- 地图卡只留小图、名字和一句描述，特色怪的名字移到鼠标悬停提示里；卡片按张数排满，最后一行居中，不再空出一格（7 张是 4+3，5 张是 3+2）。
- 配置每一行左边加了小标签（难度、角色、技能、起手、心法、噩梦、准备）；小道士缩小站到左下角当背景；夜探的藏宝阁缩成「开始」旁边的小按钮。
- 实盘的三行长说明换成几张数字小牌（几分钟开始回钱、天亮和打倒尸王各几份；夜探是保底、封顶、多少铜钱算 1 份），详细说明鼠标悬停可看。
- 手机、平板的排布没动；冒烟的选模式页检查多量了 1366×768、1440×900、1920×911 三个电脑尺寸。
- 规则没变，旧录像照常回放。

## 0.19.7（2026-11-07）

### 改动

- 手机摇杆有了轻重：刚拖出一点点是慢走，速度减半，摇杆头会缩小变淡，方便微调走位；再拖远一点就是全速，平常的短拖不受影响。键盘不变。

- 规则没变，旧录像照常回放（慢走在录像里多存一个符号）。

- 守夜的规则核心（`src/core/`）：每秒 30 拍、确定性（只用四则运算、写死的方向表、牛顿法开方、按用途分流的随机数），原地推进，状态指纹锁住重放。
  六件法器（桃木剑、符咒、铜钱剑、飞剑、雷符、镇魂铃）和两个进化（斩妖剑、天师符雨）、八件被动、升级三选一、宝箱；
  五种常规怪（纸人、鬼火、跳尸、灯笼鬼、狐妖）、两种精英（石狮怪、跳尸将军）、尸王（跳砸、召唤、尸气）；15 分钟天亮。
- 机器人（`tools/bots.ts`、`tools/sim.ts`）：小白、普通两个玩家模型，普通按剑阵、符箓、镇守三个流派选卡；`tools/bench.ts` 量每拍耗时。
