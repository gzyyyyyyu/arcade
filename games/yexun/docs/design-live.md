# 《夜巡》设计稿：实盘（第 4 节）

> 《夜巡》设计稿的一部分，总纲和目录见 [../DESIGN.md](../DESIGN.md)；节号和代码注释里的「DESIGN x.y」一致。

## 4. 实盘

### 4.1 规则

- 夜探实盘不带娱乐夜探的补给和成长（开箱回血、肉包加量、宝箱三选一、宝气，见 design-play.md 2.3）：它们抬撤出率，带回期望跟着涨，要带得先重拟基准价值、报主线。铜箱、金箱在实盘里仍是随机升一件。
- 两个模式的配置固定，**永久加成（perks）、咒印、挨打减伤不生效**（公平、好配平）。实盘可以**选已解锁的角色**；守夜还可以**选已解锁的地图**（夜探的"地图"是镇子，本来就能选）。
  **不带加成、咒印的理由**：它们是拿铜钱买的永久成长，带进实盘就等于老玩家固定多赚，新老玩家同一份筹码的期望不同；角色和地图是并列的选择，不是成长，所以放开。
  不传角色、地图就是小道士、雪原。局内机制（卡池、选卡三件套、心法保底、夜市、角色初始数值和小特权）实盘和娱乐一样。
- 降难度（`LIVE_EASE`，`World.liveEase`）：守夜实盘危险 2 起挨打 × 0.9、远程弹的伤害倍数封顶 1.0；这是规则核心里唯一按实盘分叉的怪物数值，玩法说明实盘段写着。实盘连战（4.1b）不降。
- 档位 = 危险度的固定配置：小 / 中 / 大 / 豪华（`docs/economy.md` 第 2 节档位表，一份 2,000 / 10,000 / 50,000 / 200,000）守夜分别**固定映射娱乐的危险 0 / 2 / 3 / 4**，只维护一套怪表。
  局内铜钱和娱乐一样，打完存入账户（账户铜钱只买永久加成和请角色，永久加成不进实盘，不影响赔率公平）。夜探四档都开（对应夜探危险 0 / 1 / 2 / 3，见 4.2）。
- 带入固定是这一档的一份（Worker 定，浏览器只报档位）；`mode: client`；带回走 Worker（第 5.6 节）。夜巡自己的档位名是 small / medium / large / luxe，带入时换成钱包的 small / mid / big / lux（`LIVE_TIERS.wallet`）。
- 实盘局接不上（夜巡不存打到一半的局）：局里点「回大厅」或好友邀请的「去」先写明这一份按什么带回、带回多少，确认后当场结完再走；关页、浏览器后退也当场按同一算法结（`LiveClient.leave`，带 keepalive；守夜按撑到的拍数、连战按打倒的只数、夜探是 0）。局已打完、结算页还没出时离开按终局结（`settleOnLeave` → `finish`，带 keepalive），不按中途离开。钱包里不留在桌上的一份，大厅就不会叫人回来接着打。没发出去的照旧在下次打开夜巡时结（`resume`）。
- 默认一场最多赢 3 份、最多输 1 份（`docs/economy.md` 第 2 节）。平台还有每个游戏每天净赢 10 份的上限兜底。

### 4.1b 实盘连战（`LIVE_RUSH`、`rushBp`、`liveRushSetup`）

实盘页除了守夜、夜探还有「连战」：带一份筹码打一局首领连战（玩法同 design-play.md 2.5），按打到哪带回。

- 和娱乐连战的差别：种子每局随机，危险按档位（小 0、中 2），不交榜、不发铜钱、不记纪录。**固定小道士，只能选三套推荐配装之一（稳 / 猛 / 双），不带咒**（`liveRushOk`）：倍数按机器人的配法解，人人一样的起点才对得上。实盘页连战一栏有三个配装 chip。
- 规则核心不分叉：实盘连战和娱乐连战同一套规则，守夜实盘的降难度（4.1 `LIVE_EASE`）不生效。
- 只开小、中两档。
- 带回：一共 11 关（`RUSH_TOTAL`，10 只首领 + 夜漏君）。没全清时打倒 n 关给 `reach × n / 10`（n 最多到 10，就是打到夜漏君没打倒），打倒夜漏君给 `clear`；一关没过是 0。中途关页面按最后报的关数结（`LiveClient.progress`），认输按当时打倒的算。
- 结算边界：和守夜、夜探实盘一样，倍数在浏览器算好、Worker 只收档位和 bp（上限 `LIVE_MAX_BP` 3 份），Worker 不认是不是连战；改过的客户端能多报，靠平台每天每游戏净赢 10 份的上限兜（所有者定过不防作弊）。

| 档 | 打到第 n 关没过（n ≤ 10） | 打到夜漏君 `reach` | 全清 `clear` | 小白期望 ±2SE · 赢的场次 | 普通期望 ±2SE · 赢的场次 | 4.3 目标 |
|---|---|---|---|---|---|---|
| 小（危险 0） | `reach × n / 10` | 1.00 份 | 1.20 份 | +0.173 ±0.004 · 92% | +0.199 ±0.001 · 100% | 小白 +0.05～+0.15 且赢 ≥ 50%；普通 +0.20～+0.40 |
| 中（危险 2） | `reach × n / 10` | 1.40 份 | 1.55 份 | −0.091 ±0.017 · 35% | +0.218 ±0.017 · 70% | 小白 −0.05～+0.05；普通 +0.10～+0.20 |

量法（2026-11-23，0.38.0）：`tools/sim.ts --mode rush --live small,medium --n 2000`，每格 2,000 局，种子 1 起每局随机，小道士三套推荐各 1/3，小白、普通两个机器人。全清：小档小白 92%、普通 100%；中档小白 9%、普通 35%。
小档危险 0 太容易，两条线几乎都全清，倍数分不开，取「打到夜漏君没过≈保本」的形状，两条都离带 ≤0.03；中档取「打倒夜漏君多给 0.15 份」，小白低带 0.04、普通高带 0.02（主线 11-23 定）。

取舍（主线 11-23 定）：按每局对齐而不是按每小时。连战一局从 5 分钟变成 15 分钟上下，同样的每局期望每小时赚得比以前少；带回文案照实写数、不写「稳赚」。

### 4.2 带回倍数（`src/content/live.ts`、`src/content/explore.ts`，数值由模拟器定，这里是形状）

**守夜**：按撑到的时间连续地涨（逐拍插值，不跳台阶），打倒尸王额外加。每档一条形状（`LIVE_TIERS[t].shape`，点是「秒，占天亮倍数的万分比」）：小档 3:00 起，中、大档共用一条 2:00 起，豪华档中途回得更多；
乘这一格的天亮倍数（`dawnBp` × 角色、地图系数，或整套换成组合系数，见 4.2a）；打倒尸王再加 `bossAdd` 0.2 份（不缩放），一场封顶 3 份（`LIVE_MAX_BP`）。小道士、雪原的现值（`vigilBp` 算，份）：

| 撑到 | 小（危险 0） | 中（危险 2） | 大（危险 3） | 豪华（危险 4） |
|---|---|---|---|---|
| ≤ 2:00 | 0 | 0 | 0 | 0 |
| 3:00 | 0 | 0.05 | 0.05 | 0.08 |
| 5:00 | 0.08 | 0.15 | 0.14 | 0.24 |
| 10:00 | 0.31 | 0.60 | 0.57 | 0.93 |
| 14:00 | 0.41 | 0.78 | 0.74 | 1.22 |
| 天亮 15:00 | 1.43 | 1.35 | 1.28 | 1.23 |
| 打倒尸王 | 1.63 | 1.55 | 1.48 | 1.43 |

为什么是这个形状：中途回得少、天亮给得多，小白（早死）和普通（多半撑到天亮）的期望才拉得开，各档才能同时落进 balance.md 4.4 的区间；曲线平滑上升，没有"4 分 01 秒才有钱"的断崖。
中档以上从 2:00 起回、天亮前回得多些，因为技能让中途撑得更久。天亮倍数不随档位单调：各档按期望落进自己的区间来配，档越高怪越难，倍数和期望不是一回事（豪华档天亮 1.23 低于小档 1.43）。
选档页的小牌直接写这一档拿回多少筹码（几分钟后开始拿回、天亮、打倒尸王），结算页写这一局带回多少。

目标（balance.md 4.4，实盘期望，份；收益要配得上难度）：小 普通 +0.60～0.75 / 小白 +0.30～0.45，中 +0.45～0.60 / +0.15～0.30，大 +0.35～0.45 / +0.05～0.15，豪华 +0.20～0.30 / −0.10～0。守夜、夜探同一张表。
配平两头管，口径「宁简勿难」（仓库根 docs/balance.md 开头：拿不准往多给偏，目标线当参考）：只压超过多发线（带上限 + 0.15）的格子，压到普通回到带上限、小白不超多发线；普通低于带下限的抬到带上限（同样两条线、最多抬到原系数 2 倍）。小白偏低不单独抬。
小改动进实盘：不重跑全量，只量改动的方向。在冻结树上每格跑 150 局，和上次全量重拟的大样本同种子配对，新期望 = 大样本期望 + 配对差；只压估计值超多发线、而且配对差本身显著（差 − 2SE > 0）的格子，贴线的格子被噪声推过线不算。没量的图按「只压明显多发」不预先压。
定"夜巡是普通玩家每天拿筹码最有效的途径"后，小档目标最高。每次改内容或危险档都要重拟 `dawnBp`。一个天亮倍数同时管小白和普通，以普通为准。

**夜探**：撤出时倍数 = clamp((带出的宝物价值 + 早搜奖励) ÷ 基准价值, 保底, 封顶 3)；死亡、迷失、认输、中途关页面为 0。基准按"档位 × 镇子"各一个（`RAID_LIVE.base`），不按一个数，免得"挑镇子赚钱"。
档位 → 夜探危险：小 0、中 1、大 2、豪华 3。夜探的危险档单独一条更缓的坡（`waves.ts` 的 `RAID_DANGERS`）：危险 1、2 取守夜危险 0→1 的三分之一、三分之二处，危险 3 起顺延守夜的 1、2、3。
理由：夜探没有天亮可撑、还有巡夜将，同一档比守夜难得多（普通玩家用守夜的危险 1 只撤出 45%、危险 2 约 30%），中、大档怎么定基准都够不着目标区间。

**认真搜要比开门就走多拿至少 0.15 份**（否则认真玩的人会觉得白搜了）。三处设计：
- **保底按撤出时刻给**（`liveFloor`）：从 1 份线性涨到这一档的满额。小档 5 分钟给满 1.6；中档第一座门 5 分钟才开，开门就走也在 6 分钟左右，所以拖到 10 分钟给满 1.6；大档 8 分钟给满 1.25；豪华档 8 分钟给满 1.2（再高「开门就走」就追上认真搜的人了）。
- **早搜奖励**（`RAID_EARLY`）：前 5 分钟开离出生点 1,200 以内的木箱、铜箱，宝物结算时价值 ×1.3（不改抽到什么，只在结算加价；死了包丢了奖励也没了）。纯刷保底不碰箱子拿不到。
- **后半段提价**：补货每波深度 +0.25、宝库 6 件（2.3）。只奖励待到 6、8 分钟以后的人。

拟合口径：全量模拟，每格 2,000 局：三镇 × 三档 × 小白 / 普通 / 贪心。普通玩家 10 分钟后才走，贪心 13 分钟后，小白第一座门开就走。"开门就走"= 手熟、几乎不死的人只拿保底，按 95% 撤出 × 小白撤出时间中位（小档 4 分钟、中大档 6 分钟）时的保底 − 1 估。
基准锚小道士普通玩家；小白中、大档比区间低（选卡三件套、夜市让普通玩家多搜多撤，同一个基准压下来小白就亏），以普通为准。

豪华档：夜探危险 3，目标带和守夜豪华一样（小白 −0.10～0、普通 +0.20～+0.30）。基准把小道士普通锚到 **+0.40**，保底 1.2、8 分钟给满。为什么取 +0.40：「宁简勿难」往多给提，锚在带上限 +0.30 时小道士小白各镇亏得多；但要守住「档越高期望越低」，普通不能到大档带上限 +0.45。别的角色任一线超多发线（带上限 + 0.15）的压到普通回 +0.40、小白不超多发线，写进 `RAID_LIVE.charBp.luxe`。

守夜、夜探的系数都不按规则版本分：倍数在结算时按当时的代码当场算好，所以系数改了，就对改完以后结算的局生效。

带回 = 带入 × 倍数（向下取整，按万分之一传 `bp`，同开盘）。

### 4.2a 角色、地图系数

选哪个角色、哪张地图，同一档的实盘期望（份）不应差出 0.15 份以上，否则玩家会"挑角色、挑地图赚钱"。差出去的单独给一个**实盘倍数系数**（万分比，没写 = 10_000 = 不调），小道士、雪原是基准，永远不写；角色、地图本身的数值和对局规则不动：

- **守夜**：`LIVE_CHAR_BP`、`LIVE_MAP_BP`（`src/content/live.ts`），按档写，乘在这一档的 `dawnBp` 上，所以天亮、尸王前的曲线一起按同一比例缩放，尸王加成不缩放；结果始终封顶 3 份。按档写是因为难度随档位涨得快的角色、地图（义庄、冰湖）在各档需要的补偿不一样。
- **夜探**：`RAID_LIVE.charBp`，按档写，可以按镇子细分；乘在按保底、封顶算好的倍数上（`liveMultiplier`），结果至少 1 份、最多封顶。接在带回上而不是基准价值上：胖师叔、采药女的撤出率高，撤出就有保底，调基准价值压不下去。
  实盘局的角色由核心带上，`settleRaid` 自己取，界面不用管。
- **口径**：角色和地图先**分开扫**（角色在雪原、地图用小道士），两个系数默认相乘；乘出来偏离同档平均 ±0.15 份以上的**组合**单独写在 `LIVE_COMBO_BP`（角色 × 地图 × 档），写了就用整套系数**替换**乘积，尸王加成照旧不缩放。
  原因：胖师叔、采药女这类角色在义庄、冰湖上并不是"各强各的"，乘出来的系数会把他们抬高很多。夜探只有角色一个维度，不需要组合表。目标是每档同档各角色（地图、镇子）之间的普通玩家期望极差 ≤ 0.15 份；系数取到 100（1%）。
  不用封顶、不改加法：组合偏高的原因是角色和地图的强弱不独立，封顶管不到，直接替换乘积最简单。
- **范围**：守夜角色、地图、组合系数夹在 0.5–2.5 倍；小道士 × 雪原也写组合（`dawnBp` 是按小道士拟的，各档又按同种子重拟过）。小白只作参考没有拟合（同一个系数对小白不通用）。
  采药女、胖师叔在夜探里仍是最强的（系数压平了期望，没压平"撤出率"），界面上不要写"夜探最强角色"。
- 以后的新图按同一套方法拟合，偏离同档平均 ±0.15 份以内才开放（`LIVE_MAP_CLOSED`，8.1）。
- **乱葬岗、窑镇**：小道士每格两线各 2,000 局，普通线锚到雪原 / 古镇同档普通；别的角色按角色 × 地图系数相乘，窑镇的夜探角色系数照古镇，只压明确多发的格子。
  窑镇豪华档锚到古镇要基准 40，可小白撤出一次就顶封顶、和普通一样高，技术不值钱，所以取 70（`RAID_LIVE.base.luxe.yaozhen`）。

### 4.3 配平目标（`docs/balance.md` 第 2、3 节，模拟器量）

实盘连战（4.1b）的目标（守夜、夜探用 4.2 抄的 balance.md 4.4）：

| 档位 | 小白 | 普通 |
|---|---|---|
| 小 | +0.05 ～ +0.15，赢的场次 ≥ 50% | +0.20 ～ +0.40 |
| 中 | −0.05 ～ +0.05 | +0.10 ～ +0.20 |
| 大 | −0.20 ～ −0.10 | 0 ～ +0.10 |
| 豪华 | ≤ −0.20 | −0.05 ～ +0.05 |

**实盘技能**：守夜、夜探实盘各档各图都能放技能，HUD 出技能钮；能选的角色同娱乐（`liveCharOk` 读 `LIVE_CHAR_IDS`，十个）。
娱乐是危险 0–8 九档（6–8 是噩梦档）；balance.md 第 3 节的"新手 / 普通 / 高手"按危险 0 / 2 / 4 量：小白胜率 ≥ 60% / 40–50% / ≤ 30%，普通 ≥ 75% / 55–65% / 40–50%（胜的口径见第 2 节表）。
配平机器人除了小白、普通两个玩家模型，还要按流派分，每个流派的普通玩家在危险 2 都要能撑到天亮（8.1）。

**实盘和娱乐同一套规则**（规则核心里没有实盘的卡池、怪表分支）：实盘局的升级三选一、宝箱、合成 / 双修和娱乐一样按角色法器池抽，2.0 的法器、被动、阵法 / 幽冥 / 聚财套件和搭配、新怪和首领都放开。娱乐和实盘的内容差别清单用 `node tools/live-gap.ts` 列（永久加成、咒印有意不对齐：实盘按人人一样的起点结算）。
