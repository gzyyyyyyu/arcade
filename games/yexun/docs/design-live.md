# 《夜巡》设计稿：实盘（第 4 节）

> 《夜巡》设计稿的一部分，总纲和目录见 [../DESIGN.md](../DESIGN.md)；节号和代码注释里的「DESIGN x.y」一致。

## 4. 实盘

### 4.1 规则

- 两个模式的配置固定，**永久加成（perks）、咒印、降低伤害不生效**（公平、好配平）。实盘可以**选已解锁的角色**；守夜还可以**选已解锁的地图**（夜探的"地图"是镇子，本来就能选）。
  **不带加成、咒印的理由**：它们是拿铜钱买的永久成长，带进实盘就等于老玩家固定多赚，新老玩家同一份筹码的期望不同；角色和地图是并列的选择，不是成长，所以放开。
  不传角色、地图就是小道士、雪原。局内机制（卡池、选卡三件套、夜市、角色初始数值和小特权）实盘和娱乐一样（0.4.7 起）。
- 档位 = 危险度的固定配置：小 / 中 / 大 / 豪华（`docs/economy.md` 第 2 节档位表，一份 2,000 / 10,000 / 50,000 / 200,000）守夜分别**固定映射娱乐的危险 0 / 2 / 3 / 4**，只维护一套怪表。
  局内铜钱和娱乐一样，打完存入账户（账户铜钱只买永久加成和请角色，永久加成不进实盘，不影响赔率公平）。夜探四档都开（对应夜探危险 0 / 1 / 2 / 3，见 4.2；豪华档规则 64 起）。
- 带入固定是这一档的一份（Worker 定，浏览器只报档位）；`mode: client`；结回走 Worker（第 5.6 节）。夜巡自己的档位名是 small / medium / large / luxe，带入时换成钱包的 small / mid / big / lux（`LIVE_TIERS.wallet`）。
- 默认一场最多赢 3 份、最多输 1 份（`docs/economy.md` 第 2 节）。平台还有每个游戏每天净赢 10 份的上限兜底。

### 4.2 结回倍数（`src/content/live.ts`、`src/content/explore.ts`，数值由模拟器定，这里是形状）

**守夜**：按撑到的时间连续地涨（逐拍插值，不跳台阶），打倒尸王额外加。曲线是 `VIGIL_SHAPE`（3:00 以前为 0，5:00 占天亮倍数的 5.6%，10:00 22%，14:00 28.8%，15:00 100%），
四档形状相同、只按各档的天亮倍数 `dawnBp` 缩放，打倒尸王再加 0.2（`VIGIL_BOSS_ADD_BP`，不缩放），一场封顶 3 份：

| 撑到 | 小（危险 0） | 中（危险 2） | 大（危险 3） | 豪华（危险 4） |
|---|---|---|---|---|
| ≤ 3:00 | 0 | 0 | 0 | 0 |
| 5:00 | 0.08 | 0.09 | 0.10 | 0.11 |
| 10:00 | 0.30 | 0.37 | 0.39 | 0.42 |
| 14:00 | 0.39 | 0.49 | 0.51 | 0.55 |
| 天亮 15:00 | 1.35 | 1.69 | 1.76 | 1.92 |
| 打倒尸王 | 1.55 | 1.89 | 1.96 | 2.12 |

为什么是这个形状：中途回得少、天亮给得多，小白（早死）和普通（多半撑到天亮）的期望才拉得开，四档才能同时落进 balance.md 4.4 的区间；曲线从 3:00 起平滑上升，没有"4 分 01 秒才有钱"的断崖。
天亮倍数随档位不降（小 ≤ 中 ≤ 大 ≤ 豪华，`tests/platform/live-client.test.ts` 锁住），不然玩家看到的是"大档更难、给得更少"。选档卡上画这条小曲线（横轴时间、纵轴倍数，标出保本点、天亮、尸王），结算时标出这一局停在哪。

目标（balance.md 4.4，实盘期望，份；收益要配得上难度，整体 +0.15，规则 58 起按它拟）：小 普通 +0.60～0.75 / 小白 +0.30～0.45，中 +0.45～0.60 / +0.15～0.30，大 +0.35～0.45 / +0.05～0.15，豪华 +0.20～0.30 / −0.10～0。守夜、夜探同一张表。
配平两头管，口径「宁简勿难」（规则 64 起；仓库根 docs/balance.md 开头：拿不准往多给偏，目标线当参考）：只压超过多发线（带上限 + 0.15）的格子，压到普通回到带上限、小白不超多发线；普通低于带下限的抬到带上限（同样两条线、最多抬到原系数 2 倍）。小白偏低不单独抬。（规则 58–63：超上限 +0.15 压回上限，普通低于下限 0.10 以上抬到带中点。）
小改动进实盘（规则 65 起这样量）：不重跑全量，只量改动的方向。在冻结树上每格跑 150 局，和上次全量重拟的大样本同种子配对，新期望 = 大样本期望 + 配对差；只压估计值超多发线、而且配对差本身显著（差 − 2SE > 0）的格子，贴线的格子被噪声推过线不算。0.28.0（规则 65）量了雪原守夜 9 个角色的默认线、带心法线和三条最优配置线、古镇夜探默认线，120 格平均差在 ±0.02 以内，压了 5 格（`LIVE_SKILL_COMBO_BP_65`，都是小白线：小道士豪华、符师中、大、豪华、纸匠中），其余照规则 64 的表。别的图没量，按「只压明显多发」不预先压。0.29.0（规则 66）量了改到的三个角色（小道士、采药女、阴阳先生），没有要压的格子。0.30.0（规则 67）摆渡人第一次进实盘，七张图、五个镇子各 150 局拟了他自己的系数（多数是抬，压了豪华档冰湖，记录见 [balance-live.md](balance-live.md)）。
（规则 57 及以前用的旧带：小 普通 +0.45～0.60 / 小白 +0.15～0.30，中 +0.30～0.45 / 0～0.15，大 +0.20～0.30 / −0.10～0，豪华 +0.05～0.15 / −0.25～−0.10；下面按日期记的配平过程用的都是旧带。）
定"夜巡是普通玩家每天拿筹码最有效的途径"后，小档目标最高。每次改内容或危险档都要重拟 `dawnBp`。
0.6.0 全量（地图事件开着；6 角色 × 6 地图 × 4 档，每格 300 局普通玩家、六个流派各 50；小白按小道士、雪原每档 1,000 局）锚小道士各图平均到区间中点：
普通 小 +0.53 / 中 +0.37 / 大 +0.25 / 豪华 +0.09，都在区间里；小白 小 +0.36 / 中 −0.02 / 大 −0.19 / 豪华 −0.47。事件让中高档好撑了一点，天亮倍数比 0.4.10 低（中 1.73 → 1.69、大 1.84 → 1.76、豪华 2.01 → 1.92）。
已知的取舍：一个天亮倍数同时管小白和普通，以普通为准：小白小档比上限高 0.06、中档比下限低 0.02、大档低 0.09、豪华低 0.22（小白在危险 4 撑不到 3:00 的局多）。
豪华档两格偏出 ±0.15：更夫 × 义庄 −0.30（胜率 19.9%）、更夫 × 荒庙 −0.16（25.7%），组合系数都已到上限 2.5。

各版本的系数拟合记录（每次重量的范围、改了哪些格子、为什么）见 [balance-live.md](balance-live.md)。

**夜探**：撤出时倍数 = clamp((带出的宝物价值 + 早搜奖励) ÷ 基准价值, 保底, 封顶 3)；死亡、迷失、认输、中途关页面为 0。基准按"档位 × 镇子"各一个（`RAID_LIVE.base`），不按一个数，免得"挑镇子赚钱"。
档位 → 夜探危险：小 0、中 1、大 2、豪华 3。夜探的危险档单独一条更缓的坡（`waves.ts` 的 `RAID_DANGERS`）：危险 1、2 取守夜危险 0→1 的三分之一、三分之二处，危险 3 起顺延守夜的 1、2、3。
理由：夜探没有天亮可撑、还有巡夜将，同一档比守夜难得多（普通玩家用守夜的危险 1 只撤出 45%、危险 2 约 30%），中、大档怎么定基准都够不着目标区间。

**认真搜要比开门就走多拿至少 0.15 份**（否则认真玩的人会觉得白搜了）。三处设计：
- **保底按撤出时刻给**（`liveFloor`）：从 1 份线性涨到这一档的满额。小档 5 分钟给满 1.6；中档第一座门 5 分钟才开，开门就走也在 6 分钟左右，所以拖到 10 分钟给满 1.6；大档 8 分钟给满 1.25；豪华档 8 分钟给满 1.2（再高「开门就走」就追上认真搜的人了）。
- **早搜奖励**（`RAID_EARLY`）：前 5 分钟开离出生点 1,200 以内的木箱、铜箱，宝物结算时价值 ×1.3（不改抽到什么，只在结算加价；死了包丢了奖励也没了）。纯刷保底不碰箱子拿不到。
- **后半段提价**：补货每波深度 +0.25、宝库 6 件（2.3）。只奖励待到 6、8 分钟以后的人。

拟合口径：全量模拟，每格 2,000 局：三镇 × 三档 × 小白 / 普通 / 贪心。普通玩家 10 分钟后才走，贪心 13 分钟后，小白第一座门开就走。"开门就走"= 手熟、几乎不死的人只拿保底，按 95% 撤出 × 小白撤出时间中位（小档 4 分钟、中大档 6 分钟）时的保底 − 1 估。
0.4.10 重拟（三镇 × 三档 × 6 角色，每格 600 局普通玩家；小白小道士每格 500 局），基准锚小道士普通玩家到区间中点：普通 小 +0.53～0.54 / 中 +0.38～0.39 / 大 +0.24～0.26；
小白 小 +0.11～0.18 / 中 −0.20～−0.09 / 大 −0.32～−0.15。取舍：小白中、大档比区间低（选卡三件套、夜市让普通玩家多搜多撤，同一个基准压下来小白就亏），以普通为准；山寺小白一直最低。
"开门就走"和贪心这轮没重量（上一轮普通比开门就走多 0.16、贪心比普通多 0.06～0.12）。

戏楼镇、粮仓镇（0.17.6）：小道士每格 300 局，普通锚区间中点、两条线期望 + 2SE 不超上限。基准 戏楼镇 176 / 184 / 135、粮仓镇 246 / 224 / 210（小 / 中 / 大）。
普通 戏楼镇 +0.464 / +0.316 / +0.155、粮仓镇 +0.494 / +0.332 / +0.175（大档两镇低于下限 0.05 以内）；小白 戏楼镇 +0.038 / −0.253 / −0.306、粮仓镇 +0.227 / −0.170 / −0.413，和老镇一样以普通为准。
别的角色在这两镇还没量，`RAID_LIVE.charBp` 先取同档三个老镇里最低的系数（保守）。

豪华档（规则 64 开）：夜探危险 3，目标带和守夜豪华一样（小白 −0.10～0、普通 +0.20～+0.30）。每个镇子每条线 2,000 局（9 角色 × 5 镇）。基准把小道士普通锚到 **+0.40**：古镇 139、渡口 121、山寺 45、戏楼 79、粮仓 164；保底 1.2、8 分钟给满。为什么取 +0.40：「宁简勿难」往多给提，锚在带上限 +0.30 时小道士小白各镇 −0.08～−0.34，亏得多；但要守住「档越高期望越低」，普通不能到大档带上限 +0.45。锚 +0.40 后小道士小白 −0.31～+0.11；别的角色任一线超多发线（带上限 + 0.15）的压到普通回 +0.40、小白不超多发线，35 格写进 `RAID_LIVE.charBp.luxe`；改完 45 格普通 +0.24～+0.40、小白 −0.39～+0.14，没有多发。

夜探的基准、保底和角色系数不按规则版本分：倍数在撤出时按当时的代码当场算好，所以夜探实盘系数改了，就对改完以后结算的局生效（守夜的组合系数按开局时的规则版本查表，见 4.2a）。

结回 = 带入 × 倍数（向下取整，按万分之一传 `bp`，同开盘）。

### 4.2a 角色、地图系数

选哪个角色、哪张地图，同一档的实盘期望（份）不应差出 0.15 份以上，否则玩家会"挑角色、挑地图赚钱"。差出去的单独给一个**实盘倍数系数**（万分比，没写 = 10_000 = 不调），小道士、雪原是基准，永远不写；角色、地图本身的数值和对局规则不动：

- **守夜**：`LIVE_CHAR_BP`、`LIVE_MAP_BP`（`src/content/live.ts`），按档写，乘在这一档的 `dawnBp` 上，所以天亮、尸王前的曲线一起按同一比例缩放，尸王加成不缩放；结果始终封顶 3 份。按档写是因为难度随档位涨得快的角色、地图（义庄、冰湖）在各档需要的补偿不一样。
- **开了技能的格子**（`LIVE_SKILL_OPEN`，4.2）：用单独的一套 `LIVE_SKILL_BP`（dawnBp、角色系数、地图系数，没写的按 1 倍），`vigilBp` 查表选用；不乘 `LIVE_MAP_BP`，也不用组合系数 `LIVE_COMBO_BP`（那两套是不带技能时拟的）。小档竹林的 9,900 沿用不带技能那套、没有重拟，只核过小道士的期望没超上限。
- **夜探**：`RAID_LIVE.charBp`，按档写，可以按镇子细分；乘在按保底、封顶算好的倍数上（`liveMultiplier`），结果至少 1 份、最多封顶。接在结回上而不是基准价值上：胖师叔、采药女的撤出率高，撤出就有保底，调基准价值压不下去。
  实盘局的角色由核心带上，`settleRaid` 自己取，界面不用管。
- **口径**：角色和地图先**分开扫**（角色在雪原、地图用小道士），两个系数默认相乘；乘出来偏离同档平均 ±0.15 份以上的**组合**单独写在 `LIVE_COMBO_BP`（角色 × 地图 × 档），写了就用整套系数**替换**乘积，尸王加成照旧不缩放。
  原因：胖师叔、采药女这类角色在义庄、冰湖上并不是"各强各的"，乘出来的系数会把他们抬高很多。夜探只有角色一个维度，不需要组合表。目标是每档同档各角色（地图、镇子）之间的普通玩家期望极差 ≤ 0.15 份；系数取到 100（1%）。
  不用封顶、不改加法：组合偏高的原因是角色和地图的强弱不独立，封顶管不到，直接替换乘积最简单。
- **义庄、荒庙豪华档**：规则 40 以前系数 1.79、1.59，乘上天亮倍数 1.92 就封顶 3 份；0.17.3 打通院墙后系数降到 0.85、1.06，天亮不再封顶（部分组合系数折算后仍可能封顶）。
- **0.4.7 全扫**：6 角色 × 6 地图 × 4 档 144 格都量过（角色、地图系数交替拟合，残差超 0.10 的给组合系数，系数夹在 0.5–2.5 倍；小道士 × 雪原不写组合，它就是基准）。
  只有一格出界：豪华档更夫 × 义庄 −0.27（胜率 22.7%，组合系数已到 2.5 倍、赢了也只到封顶 3 份，补不上去）。小白只作参考没有拟合（同一个系数对小白不通用）；
  采药女、胖师叔在夜探里仍是最强的（系数压平了期望，没压平"撤出率"），界面上不要写"夜探最强角色"。
- 以后的新图按同一套方法拟合，偏离同档平均 ±0.15 份以内才开放（`LIVE_MAP_CLOSED`，8.1）。
- **乱葬岗、窑镇（0.32.0，规则 69）**：小道士每格两线各 2,000 局，普通线锚到雪原 / 古镇同档普通。
  乱葬岗 `LIVE_MAP_BP` 小 12,100 / 中 10,100 / 大 10,300 / 豪华 11,700，普通 +0.627 / +0.508 / +0.381 / +0.238（雪原 +0.628 / +0.511 / +0.382 / +0.234），小白 +0.572 / +0.264 / −0.013 / −0.224。别的角色按角色 × 地图系数相乘（同鬼市开放时）。
  窑镇基准 小 219 / 中 170 / 大 123，普通 +0.687 / +0.586 / +0.450（古镇 +0.685 / +0.586 / +0.452），小白 +0.318 / +0.137 / +0.041。
  豪华档锚到古镇（+0.398）要基准 40：小白撤出局带出价值中位 127，一撤出就顶封顶，小白 +0.358 和普通一样高，技术不值钱；取 **70**，普通 +0.331、小白 +0.124（老五镇锚完小白 −0.31～+0.11）。
  窑镇的角色系数照古镇，9 个角色四档两线各 150 局筛查（跨线的 6 人补到 450 局），按两线 ±2SE 判定：明确多发的只有豪华档胖师叔、货郎、阴阳先生（普通 +0.61 / +0.68 / +0.63），压到普通 +0.40：6,100 / 8,300 / 8,000（原 7,100 / 10,000 / 9,300）；没有明确偏低的。

### 4.3 配平目标（`docs/balance.md` 第 2、3 节，模拟器量）

**2.0 的怪和首领暂不进实盘**（`setup.live`）：实盘局（和规则版本 < 38 的旧录像，见 5.4）的中期首领仍是 2.0 之前的表（画皮三图、其余纸扎老爷），雪原的雪童子、义庄的棺钉鬼实盘里不刷；`tests/core/foes.test.ts` 锁住。夜探不受这条限制：戏楼镇、粮仓镇 0.17.6 起开实盘，戏班鬼影、鼠妖和两个守门首领照常出，基准按这样量的局拟（4.2）。2.0 配平段（0.16.0）之后再放进实盘并重拟系数。

两个模式同档位每场期望对齐同一个目标，方差不同（守夜集中、夜探分散）：

| 小 | +0.05 ～ +0.15，赢的场次 ≥ 50% | +0.20 ～ +0.40 |
| 中 | −0.05 ～ +0.05 | +0.10 ～ +0.20 |
| 大 | −0.20 ～ −0.10 | 0 ～ +0.10 |
| 豪华 | ≤ −0.20 | −0.05 ～ +0.05 |
