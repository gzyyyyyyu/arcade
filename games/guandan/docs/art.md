# 掼蛋的美术与界面现状

> 主页和牌桌长什么样、为什么这样画。方向是"灯下的老茶馆夜局"：暖黄的灯、红漆木桌、墨绿绒布，四个熟面孔围坐，热闹但不吵。
> 逐版改动见 `CHANGELOG.md`；代码里的注释会引用本文的第 4 节（主页）和第 9 节（卡通配色表）。

## 1. 原则

- 全部图片程序生成（`src/view/art/` 的 SVG），音效 WebAudio 合成，不引外部图片和音频；唯一的外部素材是内嵌的标题字体子集，来源见 README"素材"一节。
- 宽屏多出来的宽度给主区（主页的主视觉、牌桌两侧的远景），不留空边；世界坐标高 720、宽 1280..1720（`theme.ts` 的 `worldWidthFor`）。
- 画布和 DOM 同一套风格：好友房面板、分享预览、竖屏提示用 `THEME_CSS` 的变量和 kit 的 `--ak-*` 主题变量，和画布里的弹窗一致。
- 不做可换装饰、头像框这类要存储和商品化的东西（和"不碰真钱"冲突的风险）。

## 2. 字体与网格

- 字号只用 `theme.ts` 的 `TYPE` 几级（huge 68、big 40、title 28、body 23、label 20、small 18，世界坐标）；一个画面最多三级。标题和大字用内嵌的思源宋体子集，大数字用粗黑体。
- 手机横屏画布缩到约 0.52–0.54 倍，由 `typeFloor` 托底到字 12、数字 14 CSS 像素，放不下的地方按 `phoneType()` 删字、不缩字（`docs/view.md` 第 2 节）。
- 间距、圆角、投影、按钮配色只从 `theme.ts` 取（`SPACE`、`RADIUS`、`SHADOW`、`BUTTON`），点按区域至少 44 CSS 像素（`minHit()`）。

### 字体子集怎么重新生成

标题字体是思源宋体 Noto Serif SC Bold（SIL OFL 1.1，版权行取自字体 name 表和上游 adobe-fonts/source-han-serif 的 LICENSE，原文在 `src/view/fonts/OFL.txt`）的两个子集：`gd-title.woff2`（画布上的大字、横幅、弹窗标题，字表 `title-chars.txt`）和 `gd-serif-svg.woff2`（SVG 美术里的 logo、牌背、印章，字表 `svg-chars.txt`，内嵌进 SVG）。
加了新的标题文字、`tests/view/view.test.ts` 报缺字时，把字补进字表后重新生成（fonttools 不是项目依赖，需要原字体 `NotoSerifSC-Bold.otf`）：

```sh
pip install fonttools brotli
pyftsubset NotoSerifSC-Bold.otf --text-file=src/view/fonts/title-chars.txt --flavor=woff2 --output-file=src/view/fonts/gd-title.woff2
pyftsubset NotoSerifSC-Bold.otf --text-file=src/view/fonts/svg-chars.txt --flavor=woff2 --output-file=src/view/fonts/gd-serif-svg.woff2
```

## 3. 材质

桌框是红漆胡桃木（feTurbulence 木纹加漆面高光），桌面是绒布（细噪点加中心亮四周暗的灯光圈），面板是象牙纸加木框金线；按钮是卡通立体按钮（第 9 节）。
大背景按世界宽度烘焙一次，不逐帧画；省内存设备不放装饰粒子，灯笼、人物、火星也不动。

光源：一盏顶灯，在画面正上方，所有面都是上亮下暗、影子往下偏；光色和影色在 `theme.ts` 的 `LIGHT`。
- 牌桌（`tableSvg`）：桌面中心偏上一个暖色光池加一块更亮的桌心光斑，四周暗角压一层，绒布是 3 像素的细织纹加两层 feTurbulence 绒毛（亮毛尖、暗毛尖），木框上沿和金嵌线外有一道渐隐的高光线；全部烘在原来那一张背景里，没有新增纹理。
- 牌面（`cardBase`）：牌是有厚度的卡片——右沿、下沿各一条略深的纸边（`paperEdge`，颜色在 `theme.ts` 的 `EDGE`），顶上一段白色渐变高光（画在角标和花色下面），下半略深；牌背、王牌同样。也画在原来的牌面 SVG 里。
  `CardView` 的投影是一层深影加两圈淡晕，晕比牌大几像素，叠放时压在被盖住那张的边上；选中的牌被举起，影子留在桌面往下偏，几层很淡的晕只往下长（不横着压到左右的牌上）。
- 主页：背景加一层从上沿往下渐隐的暖光、下半部压暗；右侧面板是上暖下暗的连续渐变，四边内阴影，标题后面一团暖光。
- 渐变在 Graphics 里用 `vGradient`（24 条细带）画，不要把纸面、面板拆成几块纯色叠放，交界会出现一条横着的色带。

## 4. 主页（标题页）

一屏，不弹窗（`TitleScene`，排版是纯函数 `src/view/common/home-layout.ts`，背景 SVG 和场景共用，有单测）：

- 左边是主视觉：茶馆一角（月洞窗、屋檐、两盏会晃的灯笼 `home:lantern`），围桌的四个人（`home:fig:<id>`，会轻轻呼吸），火星；宽屏时主视觉跟着铺开，面板贴右（宽 500，随世界宽度加到 560）。
- 右边一块漆面板，从上到下：标题"牌馆"、"掼蛋 / 斗地主"切换、主按钮、三张模式卡（娱乐 `fun`、实盘 `stake`、好友房 `online`）、战绩条（胜率、最高连胜、头游次数；没打过时写"打完第一局，这里会记下你的战绩"）。
- 主按钮一步开局：有实盘存档是"接着打实盘"（`resumeStake`），有存档是"继续上局"（`continue`），否则"快速开始"（`quick`，娱乐，按设置里的难度）。
- 右上角圆图标：战绩 `stats`、设置 `settings`、规则 `rules`、云存档 `cloud`；左上"大厅"（单独部署叫"首页"）。
- 点模式卡进选档页（同一场景切换，不是弹窗）：娱乐是三张难度卡（新手 / 普通 / 高手），实盘是档位卡。
- 手机竖屏单列：茶馆和四个人（放大 1.3 倍）在上，整宽的面板在下，弹窗换窄版排版；只有进了牌桌才显示"把屏幕横过来"，背景同主页的茶馆。
- 单独部署（没平台）没有实盘卡和云存档。
- 灯笼晃、人物呼吸、火星只在 `LOW_MEMORY === 0` 且没关动画时开。

## 5. 牌桌

- 背景三层（`art/scene.ts` 的 `tableSvg`）：远景暗室和两侧灯笼的光（世界比 1280 宽时桌子两边让出来，左右两家跟着坐进桌沿，`table/layout.ts` 的 `tableSide`）；绒布上一盏顶灯；桌心淡淡的回纹章。
- 顶栏高 56（`TOPBAR_H`），分三组：左"大厅"（好友房加邀请）；中 我方的级 · 本副打几 · 第几副 · 对方的级，坐庄的一队描金边；右 云存档、规则、设置、返回首页（静音在设置里）。
  云存档留在顶栏而不收进设置：它的红点提示要一直看得见。
- 四个座位的锚点是 `seatAnchors`：我在下，对家在上中，左右两家垂直居中；三家的剩余张数是头像右下角压一张小牌背加数字，联机的电脑角标在左下角。
- 操作条贴在手牌上方、居中；手牌分列由纯函数 `table/columns.ts` 排，一列最多 5 张，保证手机横屏每张都点得中。
- 记牌器是米黄纸签，级牌那格红字。名次不再单列：出完的人头像上盖名次印章（米色实底，头游加金边）。
- 关键时刻：发牌从桌心往四家各飞牌背；炸弹按大小分三档（四炸、五六炸、同花顺和七炸以上，`highlights.ts` 的 `bombDrama`），越大闪得越亮、震得越久，加光圈和纸屑（省内存设备不放粒子）；
  炸出来的牌先举起再砸到桌面（`fx.ts` 的 `bombStrike`，约 210 毫秒，压扁回弹、冲击波圆环、火星、尘土，强度按 `pace.ts` 的 `strikeParams` 四档递增，天王炸、斗地主王炸是第 4 档），和大字同时播、不加总时长；特效期间桌上的"不要"气泡收起（`TrickView.quietPasses`）。压住的是炸弹（这一墩里被压的那手，`TrickView.beaten`）时再叠 `bombClash`：红、金两圈错开的冲击波，更猛的火星和一下重震，大字下面写"炸弹压炸弹！"（王炸、天王炸各自的说法），同样不加总时长。
  头游：出完的人头像上的印章先放大悬着再落下（约 0.6 秒，落地有冲击波和星星），我头游时桌心同时出"头游！"大字，别人头游不再用横幅挡桌心；音效 `first`。
  斗地主春天、反春：`springBloom` 整屏暖色调加花瓣雨和大字（约 1.3 秒，音效 `spring`），结算弹窗右上角盖一个圆印章（春天朱红、反春靛蓝）；
  每副结算的复盘分两框，上面数据（炸弹、最大一炸），下面故事（名场面、称号）；整局结束有"晒战绩"按钮，战绩一行只在真有战绩时写。
- 所有动画时长走 `anim.ts` 的 `dur()`（设置里的速度、`anim=0` 冒烟）。

## 6. 弹窗与 DOM

设置、规则、战绩三个弹窗同宽（`panelW`：世界宽减两边留白，封顶 1120）；战绩没打过时是空状态；规则的牌型示例牌 54 宽。好友房面板（DOM）标题是红飘带、卡片是木框描金。
kit 的 DOM 组件（邀请横条、叫朋友来、分享预览、互动菜单）靠 `--ak-*` 变量取掼蛋的红金木色，不在掼蛋这边改 kit 的 DOM。

## 7. 截图图集

`npm run shot -- --gallery --out <目录>` 按 1280×720、1920×1080、844×390（手机）三种尺寸截主要画面加手机竖屏，改前改后对比用；
加 `--audit --sizes 667x375,844x390` 逐屏量字号和点按区（写 `audit.md`）。截图脚本别和其他浏览器任务同时跑（牌馆是 WebGL 软件渲染，比较重）。

## 8. 不做的

不改规则、电脑、联机协议；不做出牌按钮位置可调；不引外部图片、字体、音频。

## 9. 卡通风格配色表

各游戏统一照开盘的卡通风格：主色是掼蛋红；按钮、面板、名牌一律深墨描边加实色下沿（按下时下沉）；表面上亮下暗的轻渐变加顶边白高光、柔和投影；弹窗是木框金线加象牙纸纹。色值在 `src/view/common/theme.ts`。

| 用途 | 色值 | 用在哪 |
|---|---|---|
| 描边、下沿 | `#2b1d14`（`OUTLINE`，描边 3px、下沿 4px） | 按钮、面板、名牌、图标圆钮、选项组选中项、DOM 按钮和好友房卡片 |
| 主按钮红 | `#d8352f` | 主按钮、标题飘带、选项组选中项 |
| 金 / 绿 / 蓝 / 木 | `#f2b840` / `#2f9a55` / `#3474c4` / `#8a5530`（绿蓝木收沉，红金保持亮） | 要紧、确认、联机、次要按钮和顶栏圆钮 |
| 弱按钮 | `#5f4a3b` 底、`#f0e2cc` 字 | 不要、重选、理牌、上一墩（`quiet`） |
| 禁用 | `#9a948d` 底、`#ece8e2` 字 | 灰掉的按钮（压平，没有高光和投影，字淡一档） |

按钮分三档（`theme.ts` 的 `TIER`、`BUTTON_TIER`，画法在 `ui/kit.ts` 的 `drawPlate`）：主按钮（`red`：出牌、快速开始、开始）最重，下沿厚、面的明暗差大、顶边高光亮、投影深而带本色，一屏里只放一个；
次按钮（`gold`、`green`、`blue`、`wood`：提示、模式卡）是标准立体按钮；弱按钮（`quiet`）更扁、饱和度低、投影浅，退到背景里。调用处只传颜色名，档位由它推出，不各处各写高光和阴影；按下都是面板压到下沿上、字下沉 2。
| 奶油底 | `#fbf1dc`（上 `#fffaf0`、下 `#f3e3c0` 渐变） | 弹窗面板（外套木框 `#6b3f20`/`#8a5530` 金线）、好友房卡片 |
| 正文 | `#2b1d14` 深墨、`#7a6555` 次要 | 面板里的字（对比度够，手机字号仍按 typeFloor 托底） |

场景色（桌面墨绿绒 `#1f5a43`、胡桃木 `#6b3b1f`、漆红 `#b3202a`、金 `#e0b45a`、象牙纸 `#fbf1dc`、对方队色青蓝 `#3a78c8`）是 `theme.ts` 的 `COLOR`，只做队色的青蓝不做装饰。
