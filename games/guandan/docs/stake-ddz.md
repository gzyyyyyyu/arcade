# 斗地主实盘设计（牌馆的分层和各模式见 `docs/doudizhu.md`；掼蛋实盘和通用部分见 `docs/stake.md`）

> 规则在 `src/variants/doudizhu/stake/index.ts`，通用的档位在 `src/core/stake.ts`，
> 一场的数按版本记（第 1 节的"规则版本"），现行是版本 2：3 副（不洗牌是版本 3，第 5 节）。项目要求斗地主实盘一次带入到结回 3–6 分钟、碎片化，所以一场只打 3 副，每分按比例放大。
> 页面会话在 `src/view/doudizhu/stake.ts`，模拟是 `tools/ddz-stake-sim.ts`。单机实盘之外有好友房实盘和实盘快速匹配（第 4 节）；三处都能选不洗牌（第 5 节）。

## 1. 规则

| 项 | 值 |
|---|---|
| 档位 | 和掼蛋同一套：`small` 2,000 / `mid` 10,000 / `big` 50,000 / `lux` 200,000（钱包只认这四个） |
| 每分 | 一份的 1/50：40 / 200 / 1,000 / 4,000（要整除四档的一份；`POINTS_PER_SHARE`，按 第 2 节 的模拟定） |
| 每副 | 分 `s` = 叫分 × 2^k，封顶 24（核心的 `dealCap`，不超过一份；`DEAL_CAP`）；地主赢 +2s、农民各 −s，反之相反，三家和为 0 |
| 一场 | 单机 3 副、好友房 3 副；任何一家累计到 ±50 分（= 一份）就结束，最后那副截的是 `s`（核心的 `cap`，仍然零和） |
| 结回 | `一份 + 我的累计 × 每分`，在 0 到 2 份之间，不另外截断（核心已保证 |累计| ≤ 50，Worker 的 `validSoloResult` 再查一遍：整数、0–3 副、一副最多动 48 分） |
| 电脑 | 1、2 号座位，不碰钱包；我的累计分就是结回额 |
| 流程 | 带入、结回、放弃、重试、no_stake / expired 算办完，全部沿用掼蛋（第 2 节）；请求体多一个 `variant: 'ddz'`，没有就是掼蛋 |
| ref | `solo-ddz-<档位>-<32 位十六进制>`（47 位，拼上 `-refund` 不过 64 位），和掼蛋的 `solo-…` 互不匹配；op 是 `<ref>-in / -out / -refund` |
| 存档 | `guandan.ddz.stake`：`{ v, userId, ref, tier, share, until, rules, state, settle }`；只在这台设备上，不进云同步。钱包里 game 仍是 `guandan`；同一游戏可以同时有几份在桌上，掼蛋和斗地主的单机实盘互不影响，"别的设备上开的那一份"按 ref 分（`strayStake` 不认 `solo-ddz-`，`strayDdzStake` 只认它） |
| 规则版本 | `StakeRules`（`stake/index.ts`）：版本 1 = 最早的 8 副 / 6 副、每分 1/40、封顶 24；版本 2 = 现行。存档（`rules`）、好友房的桌（`DdzStakeTable.rules`）、结回请求体（`rules`）都带版本，**没有这个字段就是版本 1**：开着的旧一场、正在打的旧房间按老数打完（核心状态里的 `opts` 本来就是开局时定的），结回额、分的封顶、Worker 的校验都按它自己的版本；版本 1 的结回请求体和从前一字不差。新开的经典发牌一律版本 2；版本 3 是不洗牌（和版本 2 并列，开一场时选，第 5 节）。Worker 斗地主认 1–3，掼蛋只认 1、2 |

## 2. 模拟

命令、选项（`--table`、`--pps`、`--cap`、`--deals`、`--time`、`--fun`）见 `stake-sim.md` 第 2 节；每格 2000 场，四档 × 两种玩家，每场按现行实盘选项 `{ deals: 3, dealCap: 24, cap: 50 }`，种子各不相同。

**玩家模型**（只在 `tools/ddz-stake-sim.ts` 里，不读隐藏信息，随机按种子派生）：

- **普通玩家** = 电脑的 normal 档代打 0 号座位（会拆牌、记公开信息、农民不压队友）。
- **小白** = 单独写的 `newbieDecide`，不用电脑的任何一档，所以调电脑时它不跟着变。照 `docs/balance.md` 对掼蛋小白的描述类推：叫分凭感觉（王、2 的多少加一点随机）；
  领出就出最小的一手（同点数先出长的）；跟牌能压就压最小的，不分对手还是队友；不记牌；炸弹乱用（压不过时 2/3 会炸，能正常压时也有 1/4 手痒去炸）。

电脑那一栏的"新手 / 普通 / 高手"就是 `DdzLevel` 的 `novice / normal / pro`。新手档带 32% 的出牌失误（`NOVICE_BLUNDER`，见 `docs/ai.md` 斗地主一节），这是调娱乐新手档和实盘小档对小白的旋钮；娱乐单机另有按难度的失误率，见下表。
真人的强弱还要上线后看。

实盘每场期望，单位份，± 是 2 倍标准误；3 副、每分 1/50、每副封顶 24，每格 2000 场（CI 公共 runner）。电脑的搭配见 第 3 节，实盘的电脑不带额外失误（新手档仍是 32%）：

| 档位（电脑 1 号 + 2 号） | 普通玩家 | 普通玩家赢 | 小白 | 小白赢 |
|---|---|---|---|---|
| 小 `small`（新手 + 新手） | +0.086 ± 0.007 | 70% | +0.048 ± 0.008 | 56% |
| 中 `mid`（新手 + 普通） | +0.059 ± 0.007 | 62% | −0.011 ± 0.008 | 44% |
| 大 `big`（新手 + 高手） | +0.007 ± 0.007 | 47% | −0.075 ± 0.008 | 28% |
| 豪华 `lux`（普通 + 普通） | −0.000 ± 0.006 | 45% | −0.095 ± 0.008 | 24% |

pps 50 / cap 24 是这样选的：每小时期望要和别的游戏对齐（小档普通约 +1.1 份），每场就比 `docs/balance.md` 第 2 节的区间低（原因见 第 3 节）。


娱乐单机（`--fun`，每格 4000 局；新手档的 62% / 79% 是 12,000 局的数，普通档 0.25 是 2000 局的数）。电脑按难度带出牌失误 `DDZ_FUN_BLUNDER`：新手 0.32、普通 0.25、高手 0.15。
只有娱乐单机（含每日挑战）用，实盘、好友房、匹配、提示、代打都不用。原因：普通档电脑和"普通玩家"打法一样强，不带失误时普通玩家只赢 45%、高手档只赢 32%。

| 难度 | 失误率 | 普通玩家赢 | 小白赢 |
|---|---|---|---|
| 新手 | 0.32 | 79% | 62% |
| 普通 | 0.25 | 64% | 41% |
| 高手 | 0.15 | 42% | 18% |

高手档那行是 0.41.0 起的数（每格 2,000 局；电脑带深残局和座位性格，`docs/ai.md` 斗地主一节；改前同一工具 42% / 19%）。

扫失误率的胜率表和新手档 0.32 的推导见 `stake-sim.md` 第 3 节。

**时长**（`--time`）：每手 4 秒、叫分 3 秒，电脑停顿、发牌和结算动画取 `src/view/common/pace.ts` 压缩后的节奏；每格表和命令见 `stake-sim.md` 第 4 节。


一场中位 3.5–4.5 分钟、p90 约 5 分钟，在项目要求的 3–6 分钟里；页面写"约 5 分钟"。一手的中位 70–91 秒，超 2 分钟的占 0.3%–6%（小档小白最多）。


## 3. 每档用哪档电脑

单机实盘每档的电脑在 `src/variants/doudizhu/stake/index.ts` 的 `DDZ_SOLO_BOTS`。每场期望整体比 `docs/balance.md` 第 2 节的区间低，原因同掼蛋（1.2）：一场从 8 副缩到 3 副，
按区间配会让每小时期望涨约 2.5 倍，按第 2 节"每小时 +0.6～+1.2、各游戏差不超过一倍"优先，每场期望整体等比压低，各档之间的梯度不变。

| 档位 | 电脑（1 号 + 2 号） | 普通玩家 | 小白 |
|---|---|---|---|
| 小 `small` | 新手 + 新手 | +0.086 ± 0.007 份，赢 70% | +0.048 ± 0.008 份，赢 56% |
| 中 `mid` | 新手 + 普通 | +0.059 ± 0.007 份，赢 62% | −0.011 ± 0.008 份，赢 44% |
| 大 `big` | 新手 + 高手 | +0.007 ± 0.007 份，赢 47% | −0.075 ± 0.008 份，赢 28% |
| 豪华 `lux` | 普通 + 普通 | −0.000 ± 0.006 份，赢 45% | −0.095 ± 0.008 份，赢 24% |

**结论**：小白的期望一路下降 +0.048 → −0.011 → −0.075 → −0.095，普通玩家 +0.086 → +0.059 → +0.007 → 0，每档都比上一档难。小档普通每小时约 +1.1 份，和掼蛋对齐。
大档、豪华档不用"普通 + 高手"和"高手 + 高手"，那两个搭配对普通玩家太难。

小档小白的数字是靠新手档的出牌失误率调出来的（`NOVICE_BLUNDER` 0.32，见上）。

没测的：好友房 3 副的分布。

## 4. 好友房实盘和实盘匹配

规矩照掼蛋好友房（第 3 节）：开房时选档位、至少 2 个真人（不够整场不计输赢）、每个真人开局带入一份、电脑座位的输赢归庄家、电脑一律最强、离开立刻按当时的分结回（一副打到一半的等这副打完）、
走了又回来用新的 ref 再带入、带入被拒有"重新带入"、关房就地结回。带入、结回、离开、再带入这些玩法无关的规矩只有一份实现：`src/net/stake-table.ts`（掼蛋 4 座、斗地主 3 座各绑一份）。不同的只有这些：

| 项 | 值 |
|---|---|
| 开房 | 请求体 `{ variant: 'ddz', stake: 档位 }`，房间的 `options` 校验；没带 `stake` 是娱乐 |
| 一场 | 3 副，或任何一家累计到 ±50 分（核心选项 `DDZ_ROOM_OPTS`：`deals 3`、`dealCap 24`、`cap 50`，最后那副截 `s`，仍然零和）；版本 1 的老房间按 6 副、±40 打完 |
| 记账 | 每副用核心给的每家的分 `delta`，只记到到账座位上并夹在 ±50（老房间 ±40；走了又回来的新一份从 0 记，不等于核心里的累计）；其余座位和夹掉的部分归庄家，庄家 + 到账座位恒为 0 |
| 结回额 | 一份 + 分 × 每分（0 到 2 份），和单机同一个 `payout`；没有战绩小结 |
| 钱包 ref | `ddz-<16 位十六进制>`，op 是 `<ref>-s<座位>-in / out`，第 n 份是 `<ref>s<座位>n<n>`；和掼蛋的 `gd-…`、斗地主单机的 `solo-ddz-…` 互相区分得开 |
| 视图 | `DdzNetView.stake` 公开每个座位的分和到账，被拒的原因只给自己；桌在 `src/variants/doudizhu/net/stake.ts`，状态里是 `DdzNet.stake` |
| 实盘匹配 | 排队档位 `ddz-real-<档位>`（四档），一桌 3 人，开桌选项 `{ variant: 'ddz', stake }`；不洗牌另有 `ddz-clump-<档位>`（开桌选项多 `noShuffle: true`，第 5 节）；没有钱包（单独部署）只开 `ddz-fun` |

没测的：3 副的分布（电脑配平另见 第 3 节）；好友房里电脑暂用最强一档 `pro`。

## 5. 不洗牌实盘（0.39.0）

单机、快速匹配、好友房三处都能选"经典洗牌 / 不洗牌 · 炸弹多"（单机和匹配在选档页顶上切，好友房在"开实盘房间"里切；三处和娱乐共用设置 `ddzDeal`）。
不洗牌只换发牌（成团发牌，三家每副平均 2.30 个炸弹，经典 0.59），叫分、出牌、结算不变，所以一副的分大得多。规则版本 3（`RULES_CLUMP`，和版本 2 并列）：

| 项 | 经典（版本 2） | 不洗牌（版本 3） |
|---|---|---|
| 每分 | 一份的 1/50：40 / 200 / 1,000 / 4,000 | 一份的 1/200：10 / 50 / 250 / 1,000 |
| 每副封顶 | 24 | 48（和娱乐的不洗牌一样） |
| 一场 | 3 副，任何一家到 ±50 分结束 | 3 副，任何一家到 ±200 分结束 |
| 单机电脑 | 第 3 节 | 小、中、大同经典；豪华 普通 + 高手（`DDZ_SOLO_BOTS_CLUMP`） |
| 匹配档位 | `ddz-real-<档位>` | `ddz-clump-<档位>` |

为什么这么配（`tools/ddz-stake-sim.ts --noshuffle`，每格 2000 场，CI 外本机跑，± 是 2 倍标准误）：照搬经典的 1/50、封顶 24，13–23% 的场碰到一份封顶，小档普通玩家每场 +0.27 份（经典 +0.086）；
封顶 48、每分 1/100 仍是经典的两倍左右，而且豪华的"普通 + 普通"（普通 +0.043）比大档还好打。定成 1/200 后：

| 档位（不洗牌的电脑） | 普通玩家 | 普通赢 | 小白 | 小白赢 | 一场中位 / p90（分钟） |
|---|---|---|---|---|---|
| 小（新手 + 新手） | +0.082 ± 0.007 | 75% | +0.018 ± 0.006 | 56% | 3.6 / 4.4 |
| 中（新手 + 普通） | +0.048 ± 0.008 | 61% | −0.017 ± 0.006 | 42% | 3.3 / 4.0 |
| 大（新手 + 高手） | +0.015 ± 0.008 | 53% | −0.043 ± 0.006 | 34% | 3.3 / 4.0 |
| 豪华（普通 + 高手） | +0.002 ± 0.008 | 48% | −0.061 ± 0.007 | 31% | 3.2 / 3.8 |

- 每档都比上一档难；碰封顶 ≤ 0.1%。一场比经典（3.5–4.5 分钟）短约一成，每小时期望和经典差不多（小档普通约高 6%），选档页写"约 4 分钟"。
- 豪华试过"高手 + 高手"：普通 +0.014，比"普通 + 高手"好打（两个高手抢着压），不用。
- 小白在不洗牌下输得少些，小档小白只有 +0.018（经典 +0.048），仍是正的、赢过半。
- 好友房实盘的电脑照旧一律 `pro`，没单独量。
