# 实盘模拟：命令和原始数字

`docs/stake.md` 里的数字是这些命令量出来的；这里放命令、选项和展开的表，stake.md 只留结论。

## 1. 掼蛋实盘（`stake.md` 第 1 节）

扫数用 `--deals N --pps P`（默认就是代码里现在的数，1.2、1.3 的表是这样量的），
`ai-sim` 的 `solo` / `room` / `grid` / `stake-time` 同样认这两个参数：

```bash
node tools/stake-sim.ts --matches 2000 --deals 3 --pps 25 --opp normal,hard   # 扫数时换 --pps
node tools/ai-sim.ts solo --matches 2000 --deals 3 --pps 25                   # 每档 × 普通 / 小白
node tools/ai-sim.ts stake-time --matches 200                                  # 一场多长、输赢幅度、每小时期望
node tools/ai-sim.ts stake-time --matches 2000 --end 10 --deals 99            # 一场打到 10 级（量过实盘短局，没采用，stake.md 1.1）
```

模拟多个代理同时跑时一律 `nice -n 10`，线程用 `--threads 4`（`ddz-stake-sim` 是 `--jobs 4`）。

`stake-sim` 其它常用选项：

```bash
node tools/stake-sim.ts --matches 2000 --mate easy --opp normal,hard            # 搭档简单
node tools/stake-sim.ts --matches 2000 --me easy --opp easy,normal,hard         # 我简单
node tools/stake-sim.ts --matches 2000 --share 1000 --opp normal                # 不封顶，看原始分布（--seed 换一组局）
```

`stake-sim` 的胜率是净分大于 0 的场次，平局不算在里面。1.3 的数字是 CI 公共 runner 上跑的（每格 1000–2000 场），跑法同上。

## 2. 斗地主实盘的命令（`stake-ddz.md` 第 2 节）

`node tools/ddz-stake-sim.ts --table`（每格 2000 场，四档 × 两种玩家）；不带 `--table` 跑 6 种电脑搭配 × 两种玩家的全表（`--me`、`--bots` 可选）。每场按现行实盘选项 `{ deals: 3, dealCap: 24, cap: 50 }`，种子各不相同。
扫规则用 `--pps P`（每分 = 一份的 1/P，也是一场结束的分数线）、`--cap C`（每副 `s` 封顶）、`--deals N`；`--pps 40 --cap 24 --deals 8` 就是版本 1。
`--time` 另给一手的中位 / p90 / p99 秒数、超 2 分钟的比例，以及时间花在叫分 / 我出牌 / 电脑停顿 / 动画横幅 / 结算各占几成。
加 `--fun` 按娱乐单机的一局打（`DDZ_FUN`：6 副、不封顶），"赢"和战绩一样按这局净分 > 0 算。

## 3. 娱乐单机的失误率扫描（`stake-ddz.md` 第 2 节）

扫失误率看胜率（普通玩家 / 小白）：

| 难度 | 失误率 | 普通玩家赢 | 小白赢 |
|---|---|---|---|
| 普通 | 0（不带） | 45% | 19% |
| 普通 | 0.10 | 53% | 27% |
| 普通 | 0.15 | 57% | 31% |
| 普通 | 0.20 | 60% | 35% |
| 普通 | 0.25 | 65% | 41% |
| 高手 | 0（不带） | 32% | 13% |
| 高手 | 0.05 | 35% | 16% |
| 高手 | 0.15 | 43% | 20% |

新手档的 0.32 是两头卡出来的：娱乐新手档小白（4,000 局）0.28 时赢 58%、0.30 时 60%、0.32 时 61%、0.34 时 63%；再往上调会让实盘小档小白超出范围（0.34 时小档小白 +0.162、中档普通 +0.201）。

普通档取 0.25（复测 2000 局：普通玩家 64%、小白 41%）：0.20 时小白只赢 35%，够不着 `docs/balance.md` 娱乐普通档小白的 40–50%；按「宁简勿难」往简单偏，普通玩家落在 55–65% 的上沿。
