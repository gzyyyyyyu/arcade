# 素材说明

本模块没有外部素材、第三方图片、字体和音频文件：画面全部由模块里的代码运行时画出来（Canvas 2D、SVG），声音全部现场合成。
画法和数据都是为本游戏原创的程序代码（整数坐标、手写路径），随模块以 MIT 许可发布，不引用模块外的文件。

| 素材 | 文件和做法 |
|---|---|
| 第一批 6 张地图（厨房面团岛、冰淇淋雪山、雪夜饺子铺、便当群岛、夜市灯笼街、早餐吐司桥）的形状、出生点、材质、远景主题、卡片文案 | 程序数据：`src/core/mapData.ts`（形状、坑、井、出生点、材质码）、`src/view/mapArt.ts`（材质颜色和纹理、主题、卡片） |
| 第二批 5 张地图（生日蛋糕城、火锅沸腾谷、披萨火山、寿司长台、下午茶花园）的形状、出生点、25 种材质的颜色和 13 种纹理、5 个远景主题、卡片文案、焦痕底色 | 程序数据和画法：`src/core/mapData2.ts`（形状、坑、出生点、材质码 26–50）、`src/view/mapArt2.ts`（材质、纹理、远景、卡片、焦痕底色）；和第一批共用的小画法在 `src/view/paintKit.ts` |
| 地形（材质的渐变、纹理、地表皮、炸焦的坑边、材质间细线、深褐墨线）和碎屑颜色 | `src/view/terrainPaint.ts`；`src/view/terrainArt.ts` 按 marching squares 描轮廓、Canvas 2D 分块烘焙 |
| 8 把武器的坑形（包子圆、西瓜宽椭圆、球拍网格方块、萝卜窄深竖坑、烟花六角星、拖鞋鞋底印、飞盘扁槽、奶茶圆坑带流痕） | 整数运算的坑形函数：`src/core/craters.ts`（规则的一部分） |
| 8 把武器坑边的焦痕（包子焦糖色烫痕和蒸汽、西瓜红汁和籽、球拍网格压痕、萝卜刨花、烟花黑灰和火星、拖鞋鞋纹、飞盘彩色擦痕、奶茶茶渍和珍珠） | `src/view/scorchPaint.ts`（Canvas 2D，按位置散列，不用 Math.random、滤镜、渐变）；`src/view/terrainArt.ts` 按地形块分层烘焙 |
| 远景（厨房、冰淇淋店、雪夜、野餐布、夜市、早餐桌等，往下淡成的雾）、纸边和书桌 | `src/view/backdrops.ts`；`src/view/backdrop.ts` 开局烘焙一张，纸边的毛边用写死种子的随机数 |
| 角色（柴柴、橘子、团团、企企、兔兔、鼠鼠）的全身和圆形头像 | `src/view/charArt.ts`（Canvas 2D，不用滤镜、阴影、渐变） |
| 队标、名牌、图钉、画面外小牌、"出局"章 | `src/view/chars.ts`（Canvas 2D） |
| 8 把武器的图标和炮弹、界面小图标（房子、喇叭、规则书、骰子、铅笔、勾） | `src/view/weaponArt.ts`（Canvas 2D） |
| 标题字"弹里个弹" | `src/view/title.ts`（SVG 文字和路径，没有滤镜，用系统字体） |
| 首页、准备房间、结算页的版式和配色 | `src/view/pages.css`；首页的面团舞台、结算的蒸笼领奖台和彩纸是 `src/view/lobby.ts`、`src/view/result.ts` 里程序画的 |
| 地图缩略图 | `src/view/thumb.ts`：远景缩小画，地形一格一个像素 |
| 纸飞机、面粉团、角度盘（三岔时两边的虚线） | `src/view/scene.ts` |
| 音效（蓄力、嗖、噗、命中、掉出画本、爬、道具、轮到你、胜负、按钮） | `src/view/sound.ts`：WebAudio 现场合成（振荡器和滤过的白噪声），不用音频文件 |
| 道具图标（连发 +1、连发 +2、三岔、加力 10% / 20% / 50%、纸飞机、锅盖，各有正常、压暗、去色三套颜色）和按钮上的勾、小锁、爪印 | `src/view/itemIcons.ts`：手写路径的 SVG，不用滤镜、渐变和 id；按钮的边框和四种状态是 `src/view/style.css` |
| 对局顶栏的图标（小房子、全图、喇叭、风向袋、叶子、爪印、爬的箭头） | `src/view/hud.ts` 里手写的 SVG |
| 网页图标 | `index.html` 里手写的 SVG（一只包子） |
| README 的截图 `public/screenshot.webp` | 本游戏的真实运行画面（`npm run shots` 截的，转成 webp） |

文字用系统字体。名字、角色、武器、地图、规则文字都是原创的。
