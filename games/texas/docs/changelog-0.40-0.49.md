# 更新日志归档：0.40–0.49

本文件是 0.40–0.49 已移出 [CHANGELOG.md](../CHANGELOG.md) 的更新日志原文，索引见 [changelog-archive.md](changelog-archive.md)。

## 0.40.1 — 2026-11-21

**调整**
- 打开更快：手机（CPU 降速 4 倍）主页可交互 652 → 464 毫秒、TBT 375 → 218、FCP 528 → 368；电脑可交互 150 → 136。对局中不变（60 帧，手机长任务 2 → 1）。测量和前后数见 docs/perf.md。
  - 先量视口、定好舞台大小再建页面（原来建完整页才量，整页要排两遍）；牌桌藏着时不量荷官站位；筹码数字复用一个 `Intl.NumberFormat`。
  - 带哈希的 JS、CSS 存一年、不再每次打开回源校验（新增 `_headers`，`build:cf` 拷到 `dist-cf/`）。
- 新增 `scripts/perf.ts`：同口径背靠背量主页、选桌页、对局中（docs/perf.md）。

## 0.40.0 — 2026-11-21

**新增**
- 实盘锦标赛也能选极速赛和 9 人赛（原来只有娱乐），四档报名费、报名、结算和经典一样，电脑强弱档也和经典一样（小 / 中 / 大 / 豪华 = 0 / 1 / 2 / 3）。
  奖金：极速赛前四名 3.3 / 1 / 0.9 / 0.9 份（原娱乐表 3.8 / 1.9 / 0.3），9 人赛前四名 4 / 1.4 / 1.3 / 1.2 份（原 4 / 2.9 / 2.1）；娱乐也按这两张表显示。
  配平（`scripts/tour-balance.ts`，每格 2,000 场挑表，再用两组新种子共 4,000 场复核）：三种赛制小档普通每小时都约 +1.0 ～ +1.1 份；9 人赛中、大档小白偏低（−0.17、−0.33）、极速赛大和豪华档小白比经典吃亏，刷不了，按现状接受（docs/tournament.md 14.4）。
  9 人赛中、大档电脑各降一档的试法会让小、中两档完全一样（普通都是 +0.29），没用。
- `scripts/tour-balance.ts` 加 `--threads=n`（和别的模拟同时跑时限线程）。

**修复**
- 冒烟 `tour` 的实盘经典奖金按现行的 3 / 1.2 / 1 / 0.9 核对（原来还是旧表 3 / 1.8 / 1.2，拿第 2–4 名时会误报）；顶栏的核对跟上现状（单机锦标赛顶栏只写到盲注，原断言要求后面还有一段，冒烟一直卡在这里）。
