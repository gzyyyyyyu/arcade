# 德州扑克：画面与手机

> 节号沿用设计总纲的编号，各章在哪个文件见 [DESIGN.md](../DESIGN.md) 目录。

## 8. 画面与手机

### 8.1 渲染：DOM + CSS，不用 Phaser

牌桌是固定布局：2–9 个座位（位置按人数定，8.2）、公共牌、池子、操作区，动的只有发牌、推筹码、翻牌，CSS 的 `transform`/`opacity` 过渡就够，走合成层不卡。

- **包小**：不带 Phaser（它本身约 1 MB，未 gzip），首屏只有自己的代码。`npm run build:cf`：JS 307 KB（gzip 114 KB，含翻牌前胜率表、音效合成和 kit 的互动），CSS 74 KB（gzip 17 KB），页面壳 1 KB，共 3 个文件，没有图片和字体；
- **文字清楚**：任何像素比下文字和牌面都是矢量，不用按像素比栅格化；
- **省内存**：没有大画布、没有 WebGL，iOS 老设备的"画布倍数封顶 2""整屏背景 1 倍""WebGL 上下文丢失"这几条**不适用**，在 README 里写明原因；
- **素材**：牌面、筹码、头像全部用代码生成的 SVG（花色用自己画的路径），音效用 WebAudio 合成，来源写进素材说明。

界面框架：不引 React，用一个小的"状态 → DOM"更新函数（座位、牌、按钮都是固定节点，只改属性和文字）。

### 8.2 横屏布局

- 舞台高 540 个设计单位，宽随屏幕在 860–1170 之间变（4:3 平板到 19.5:9 手机都铺满，不留黑边），再整体缩放到看得见的区域（`src/view/layout.ts`）。
  iPhone 8 横屏（667 × 375）缩放约 0.69。按缩放补偿（`viewport.ts` 在根上写 `--ui` = 1 / 缩放，大屏是 1）：
  字号变量 `--fs-1`…`--fs-6` 按它放大，缩小的屏上实际不小于 12 px（手机横屏矮于 430 的中大号字只放到 12，再大选桌页就折行）；
  触屏上每个按钮用 `::before` 把能点的范围撑到 44 px（看着的大小不变），输入框、滑杆直接做高；挨得近的（选桌页、弹窗按钮、下一手）外扩会被邻居截掉，按钮本身就做到 `--hit` 高；顶栏贴着屏幕上沿，点按范围只往下撑（顶栏不加高，加高会压住牌桌顶上一排的动作签）；
  输赢数字的颜色只用 `style.css` 的 `--win`/`--lose`（深底）和 `--win-ink`/`--lose-ink`（米色、金色浅底），正数带 +、负数带 −、0 写 ±0（`text.ts` 的 `signed`）；
  缩到 0.9 倍以下时换紧凑排法（`.stage.tight`：面板加宽、行距收紧；牌桌左下那一排收窄、"第几手"收起，我的动作签按右边对齐，免得压到头像和底牌）。
- 选桌页：模式按钮（娱乐、实盘、好友房）按字宽给、不折行，挤的是右边那句说明；五个尺寸都一屏放下、不滚（8.8）；手机横屏实盘四张档位卡排成一排。触屏按钮都到 44 以后：手机横屏"返回 · 选桌"并进模式那一行、"坐下开打"和其他玩法并成一行、档位卡的名字和星星并成一行；竖屏选桌时收起大标题，人数键排成两行各四个（矮竖屏"人数"放在左边一格、档位卡收起星星）。
  手机横屏矮于 430 时再收几样次要的：赔率条里"赢面过几成可跟"、一键下注的"⅔ 池"（加注面板里照样能下任意数）、锦标赛那行说明和娱乐难度卡的小字（矮于 340）。
- 赔率条和一键下注最宽只到我的底牌右边（舞台宽度的一半减 90），放不下就折行（平板 4:3、手机横屏）。
- 多尺寸检查：冒烟 `--only devices` 在一个浏览器里跑手机竖横、平板、折叠屏、电脑共 27 个尺寸（含 390×664：iPhone Safari 带着工具栏剩下的高度），
  每个走主页 → 选桌（娱乐、实盘、好友房各一遍）→ 对局 → 结算，加 `--lobby` 只查主页和选桌；
  查横向滚动、伸出屏幕又滚不到、触屏点按区、关键元素互压（名牌、头像、底牌、公共牌、操作区、顶栏、左下一排、我的动作签）、截字、按钮里的字折出按钮、字号 ≥ 12、控制台报错；
  有问题的屏截图，清单写进截图目录的 `devices.txt`。`--sizes 568x320,780x360` 只跑这几个、每屏都截，给人看折行这类量不到的。
- 牌桌互压检查：冒烟 `--only scenes` 用规则核心摆出局面（`scripts/scenes.ts`：2–9 人，一个、两个边池，有人全下，摊牌），写成单机存档、点"继续上局"进去，
  在电脑 1280×720、1920×1080、超宽 2000×950、手机横屏 844×390、667×375、竖屏 390×844、360×640 上逐个查名牌、头像、底牌、动作签、牌型、下注、D、公共牌、底池和边池、结果条、操作区、左下一排、顶栏、聊天框两两不压
  （同一个座位里的、D 和动作签不算）、也不出屏，一手里 D 不许挪位置（竖屏把庄家挨个换到每个座位），每个局面截一张，清单写进 `scenes.txt`；`--sizes 1280x720` 只跑这几个。
  截图可复现：同一份构建跑两次，用 `node scripts/compare-shots.mjs <A> <B>` 逐像素比较（`--px=1` 放过牌边抗锯齿的 1 像素抖动），看前后两版画面变了哪几张；做法见 `scripts/smoke/harness.ts` 的 `stableShot`、`pinPage`。
- 主题：间距、字号、圆角、阴影、按钮底色是 `style.css` 开头的变量；按钮的悬停、按下、禁用、焦点、加载中是一套共用规则，各按钮只写颜色和大小。
- 我坐在下方正中，其他座位沿椭圆桌边排开（2–9 人各有一套固定位置，`layout.ts` 的 `SLOTS`），庄家按钮、盲注标记、下注额放在座位和桌子中间：
  下注额往桌心走 42% 但离座位限在 90–130 之间（只按比例时顶上的贴着名牌、两边的跑到桌子中间），`test/view/layout.test.ts` 查 2–9 人、三种宽度都在这个范围、不压公共牌。
  两侧座位的下注从靠座位那头往桌心长（几摞筹码多了不往回伸到那家的底牌上）。顶上一排离顶栏近的那两家（5、7、8 人桌）往下让 12–20，7–9 人两侧下面那两家往上让 10–19（不钻到顶栏按钮和赔率条下面）。
  竖屏 5 人以上按 `TALL_DEG` 的角度排，两侧不排在和公共牌一样高的地方（底牌朝桌心摆会压到公共牌）；竖屏两侧座位的庄家按钮在头像外侧正中，两侧下面几家的动作签压低到头像上沿（右边的往外偏），不压上家名牌、不出屏；竖屏下半边两侧的下注也从名牌朝桌心那一侧起摆，不压名牌。
  矮竖屏（360×640、375×667 这类，舞台高 940–1050，`layout.ts` 的 `isCompact`）5 人以上不走椭圆，改成固定格子（`compactSlots`）：顶上一排最多 4 家，两侧各上下两家，只放在公共牌两边和池子下面；别人的底牌只露出一半挨着头像。
- 庄家按钮 D 先放在那家下注的左边，压到名牌、头像、底牌、别人的下注、公共牌、池子、结果条那一块或出了牌桌时依次试上、下、右、更左（`table.ts` 的 `placeDealer`）。全按版式算，只在换庄、换版式时变：动作签、实际的结果条不算（签一闪一闪，D 跟着躲就是跳来跳去），签画在 D 上面。
- 结果条按上边摆在池子下面，几行的往下长到底牌、名牌时往上提，最高到公共牌下沿（`fitResult`）。
- 顶上一排桌心右边的座位，动作签在头像右边（外侧，底牌在左边）；桌心左边的反过来。
- 电脑版聊天框（kit 的 chatDock）在牌桌放大入场完了再量一次挤不挤：入场时量的是缩放中的位置，会压到左下那家的名牌；我的牌型（"一对 Q"）也算在要躲的里面。
- 右下角操作区：**弃牌 / 过牌或跟注 X / 加注**；加注展开一条滑杆和"最小、½ 池、¾ 池、1 池、全下"五个预设，按钮至少 44 × 44；没展开时上面是赔率条和"半池、⅔ 池、满池、全下"一键下注（点了直接下）。
  不是自己说话时可以预选"过牌/弃牌""跟任何注"（只在页面里，不发消息）。
  下注额放在滑杆那一行（面板矮一行），电脑上 6 人桌不用再挪座位（冒烟断言）；更挤的桌子照旧：
  加注面板展开时，被它盖住的座位挪开，收起时放回去：先试整个座位往上、再试往左，都会压到别的座位时只留名牌塞到面板上方；
  按实际位置算，冒烟里断言没有座位被盖住、座位之间互相不压。
  竖屏展开加注面板时收成三行（预设、带 −/+ 的滑杆、主按钮），赔率条收起（跟多少已经写在跟注键上），整块约占屏高 18%，我的底牌、名牌都露着；第一次加注的提示也绕开我的底牌。
  赔率条里"赢面过几成可跟"一行写完、不折行，窄的舞台上收起。
  加注面板展开时，桌心已经摆着池子（翻牌后）就把赔率条收起（`.pot-shown`），免得面板下面又写一遍“底池”；翻牌前桌心没有池子（盲注还摆在各人面前），赔率条是唯一写着底池的地方，照常留着。
- 电脑键盘（`actions.ts` 的 `key`）：F 弃牌、C 过牌或跟注、R 加注、回车确认、Esc 收起；面板展开时 1–5 选五个预设，←/→（↑/↓）和滚轮一步一个大盲，按住 Shift 一步五个；Ctrl、⌘、Alt 组合键留给浏览器。
  有鼠标的设备上按钮角上有键位角标（预设的挂在右上角外面，不压字），悬停抬起加白描边，禁用的按钮是禁止光标、不显示角标。
- 一手打完的"亮牌 / 都亮"条浮在"下一手"那一行右端上面，不压我的名牌。
- 收池：每个池子按赢家各飞一串小筹码，走一条弧线落到赢家名牌上，名牌上的筹码从原来的数滚到新数（`fx.ts` 的 `potFlight`，配 `stackup` 声）；摊牌时赢的五张放大一点、发金光，没用上的牌压暗，公共牌上方弹出大字牌型名（`potfx.css`）。
  省内存设备和"减少动态效果"下不放大、不弹，只留光圈。
- 动作签和电脑说话的气泡不出舞台、不出屏幕：画完量一次，超出就推回来（`clampIn`）。
- 轮到谁，谁的头像外圈亮金边，电脑"想"的时候金边一呼一吸（触屏和"减少动态效果"下是静止的金边，8.7）；真人和电脑一眼分开：电脑头像带"芯片"角标。
  单机不限时（对电脑不用催人）；好友房的倒计时环、托管"电脑代打"、掉线变灰在好友房（6.2）。
- kit 画的"互动""聊天"按钮在舞台外面，按舞台的放大倍数放大字和图标，手机上不缩小（经 kit 0.20.1 的 `buttonStyle` 给字号和图标边长）。
- 竖屏：高比宽大 1.5 倍以上（手机竖着拿）换竖的舞台，宽 540、高 810–1170（`layout.ts` 的 `fit`）。桌子是竖的椭圆，
  别人沿桌边从我左下到右下顺时针一圈（人少时往上收），我和操作区在下半屏：三个主按钮铺满一行，快捷下注、赔率在上面并多留一截；
  我的名牌和操作区之间一排"互动、聊天、第几手、补码、歇一手"（"互动"、"聊天"是 kit 画的，13.7；8.14）。平板竖着（4:3）仍用横屏舞台，上下留边。
- 大白话：牌型名用"同花顺、四条、葫芦……"，摊牌时在赢家头上写牌型；翻牌以后我的底牌下面一直写着现在凑成的牌（"一对 Q""两对 K 和 7""顺子 5–9"）；
  新手指引（13.8）：第一次轮到我出手时一步步指着桌上的东西讲，大厅的"怎么玩"、牌桌上的"?"随时再看。

### 8.3 iOS 那几条（AGENTS.md 第 4 节）

- **高度**：CSS 依次 `100vh` → `100dvh` → 脚本按 `visualViewport`（没有就 `innerHeight`）写的 `--app-h`；转屏、收放地址栏后重算，转屏后 350 ms 再补算一次（`src/view/viewport.ts`）。
- **双指放大**：`visualViewport.scale` 明显不是 1 时不重排、不滚动，缩回 1 倍再算。
- **safe-area**：`viewport-fit=cover`，四边 `env(safe-area-inset-*, 0px)` 让出刘海和圆角。
- 不适用的几条（画布倍数、WebGL）见 8.1；冒烟（`scripts/smoke.ts`）里照样模拟省内存设备（iPhone 横屏视口、像素比 3、CPU 降速 4 倍）、双指放大（舞台尺寸不变）、竖屏牌桌（座位、操作区不出舞台、互不压）。

### 8.4 回大厅、登录闸门、云存档

- **回大厅**：左上角常驻小房子 +"大厅"，指向 `/`，任何界面两步内能回去。牌桌上点了先确认一次：
  单机"这手会弃牌，桌上的筹码带回钱包"，确认后结算（keepalive）、补传云存档再走；好友房"离开房间？筹码这手打完结回钱包"。冒烟里点一次。
- **登录闸门**：texas Worker 只在首页三个路径上问 `/api/me`（15.8）：登录了放行、没登录 302 到 `/login?next=<原路径和查询参数>`（平台 0.10.1，登录完整页跳回原链接）、平台不可用回 503 页。开关 `GATE`。
- **云存档**：槽 `stats`（打了几手、赢了几手、最大的一池、最好的牌型、摊牌胜率、新手指引走完的标记 `tips`），按 5.5 的推荐做法接（启动先 `/api/me`、每次写带 `userId`、换号不合并、10 秒防抖、同一槽至少隔 5 分钟、切后台补传）。
  打到一半的牌局只存在浏览器本地（`texas.session`），不同步。钱包不在云存档里。

### 8.5 浏览器存储（一律 `texas.` 前缀）

| 键 | 内容 |

| `texas.tour` | 单机锦标赛的浏览器本地存档（`src/tour/solo.ts`）：刷新、断线后接着打或接着结；操作先记进来再发请求，连不上隔 15 秒用同一个操作 id 重办（14.2） |
| `texas.stats` | 战绩（云存档的 `stats` 槽） |
| `texas.cloud` | 云存档元数据（5.5） |
| `texas.settings` | 止盈 `takeProfit`（8.13）、聊天"不看" `chatOff`（顶栏的开关）、不和陌生人聊 `strangerChat: false`（快速匹配桌，6.11）、音效开关 `sound` 和音量 `volume`（0–1，默认 0.8，坏值回默认；设置面板的滑条）、动画速度 `fast`、自动下一手 `autoNext`（主页面存），加上大厅记的上次选的 `stakes`、`size`、`mode`、娱乐难度 `diff`（两边合并着写，互不覆盖；不同步） |
| `texas.fun` | 互动的总开关 `off`（"互动：不看"，设置面板里的开关，不同步；屏蔽名单不在这里） |

| `texas.room` | 现在在的好友房 `{code, userId, host, at, match?}`（host：是不是我开的，房间不下发房主是谁；match：快速匹配桌）。刷新后 6 小时内标题页给"回到房间"横幅，不自动进；点"离开房间"、房间关了或没了就清掉 |

`texas.hosted`（旧的"我开的房间"）已经不再用，页面启动时只清掉旧值。`texas.fun.muted`（旧的自己记的按人屏蔽，sessionStorage）同样只清掉。

### 8.6 画面和音效

- 布局在 `style.css`，材质、光影、颜色在 `skin.css`（压在后面）。现行皮肤是卡通换皮（奶油底、饱和平涂、深棕描边、按钮实色下沿，色值和规矩见 `docs/art.md`），覆盖写在 `skin.css` 末尾，下面压着夜场皮肤（聚光毡面、皮革木边、纸面牌、金边牌背、镶边筹码）；
  全是 CSS 渐变和内联 SVG，没有图片文件。
- 牌面（`art.ts`、`pips.ts`）：人头牌是半身像画框（上下镜像），数字牌按真牌摆中心花色，A 是带金圈的大花色；小牌只留角标和一个大花色。
- 头像（`art.ts`）：每张脸一组径向渐变（id 每次唯一，同一页面同一张脸会出现好几次）。
- 音效（`sound.ts`）：全部 WebAudio 现合成，经一个总音量和压限器（大场面的筹码声分档、心跳、庆祝和弦、被逆转见 8.10）；同时最多 24 个声音；iOS 切后台回来要等下一次点按才恢复，期间的声音丢掉不补。
  声音和画面都不许卡住牌局：音效出错只记日志；`TableView.play` 出错直接摆成结果；单机循环里画面那一步出错照样往下走；等动画结束最多多等 500 ms。

### 8.7 性能

省内存手机（CPU 降速 4 倍）上对局的主线程占用约 11%，脚本只占约 0.5%；背景斜纹、合成层、阴影这些都不是瓶颈，所以保留。实测方法和各方案的数见 [perf.md](perf.md)。

两条约束（手机卡、闪退后定的）：
- **`:has()` 只挂在小块上**：牌桌、舞台、body 上不写 `:has()`，要按子元素状态改样式时在父元素上切类，比如 `body.texas-raising-tall`、`.seat.badged`、`.hud.inviting`，`test/arch.test.ts` 查。
  `body:has(...)` 这类选择器让每次 DOM 变动都大面积重算样式。手机打 8 手，修之前平均每次重算 596 µs，去掉后 311 µs。
- **iOS 一律按省内存设备处理**：Safari 不报 `deviceMemory`，问不到时按内存小算（8.8）。切到后台时 `body.texas-paused` 停掉所有循环动画。

### 8.8 主页和分层背景（结构说明见 docs/art.md）

- 标题页分两屏（`lobby.ts`）：左边标题、一句玩法、扇形牌不动，右栏先是**主页**——"快速开始"（按上次的设置：上次是实盘且钱包够就实盘满买入，
  否则娱乐；上次是好友房也开娱乐；第一次来是娱乐·新手·6 人），有没打完的一桌时它变成"继续上局"；下面三张模式卡（娱乐 / 实盘 / 好友房）、
  钱包一行和"无任何现金价值"、战绩小卡（云存档的 stats：手数、赢下、最大一池、最好的牌）。点模式卡才到**选桌**（选档位、人数、带多少的那一栏，抬头有"返回"和实盘时的钱包）。
  离桌、离开房间回来都是主页；从平台大厅的"好友房"（`?online=1`）进来直接到选桌的好友房。冒烟查：主页不出现档位卡；快速开始和三张卡在 SE、390 竖屏、手机横屏、电脑的第一屏。
- 电脑版的排法（`lobby-layout.css`，竖屏、手机横屏不变）：左边是 280 px 左右的窄栏（标题、一句玩法、缩小的扇形牌），右栏 600 px（窄屏 540、超宽 680）给选桌；
  行高压矮，1920×900 这类宽而矮的浏览器里实盘选桌一屏放下；档位卡按列平分，止盈钮留在面板里。
  右栏首帧先藏着（只改透明度、位置照占），boot 画完第一版真数据再淡入，1.5 秒还没好也放出来；邀请链接 `?room=` 不等。
- 选桌只有一个金色主按钮"坐下开打"，选项都不折叠、一屏直接摆着（docs/ui.md 第 11 节）：档位卡 → 人数、带上桌、止盈 → 坐下开打 → 一排次按钮（快速匹配、锦标赛，娱乐还有快速局、今日局、今日赛）→ 锦标赛赛制；
  各按钮的 disabled、hidden 条件和灰掉时的说明照旧，好友房选桌换成开房间、输房间码。电脑版去掉档位卡上的桌面小图；竖屏、手机横屏选桌页收起标题下的一句话和扇形牌（`.lobby.on-pick`），手机横屏右栏加宽、四张档位卡一排、人数和带上桌并排；
  矮竖屏（≤700 高）再去掉档位卡的房间名。电脑版和手机横屏左右两栏等高（左边标题居中、右边面板撑满、内容在面板里居中）。
  五个尺寸（1280×720、1920×1080、844×390、390×844、360×640）下主页、实盘 / 娱乐 / 好友房选桌页面和右栏都不滚、可见按钮不小于 32、字不小于 12（冒烟 `--only lobbyui` 量，页面 `scrollHeight` ≤ `clientHeight`）。
  选中的档位卡、模式卡是浅底加深色描边和勾，不和主按钮一样金色填满；手机横屏收起档位卡里"最多输 / 赢很少过"两行小字，让"坐下开打"留在第一屏。
- 分层背景（`scene.ts`、`scene.css`）：放在 `#app` 最前面、舞台后面，按屏幕像素铺满（超宽屏两边也是房间，不是黑边）。从远到近：墙面渐变和护墙板竖纹、
  11 个散景光斑（慢慢漂、一明一暗）、三盏吊灯和两头吧台酒瓶的剪影（内联 SVG）、一道光锥和里面往上飘的浮尘；主页的光锥打在扇形牌上，牌桌和等人页收起光锥、光斑暗一点。
  颜色只走 `--sc-*` 几个变量，主题房只换变量；现行的卡通皮肤把背景底色换成暖色平涂加圆点（`docs/art.md`），层的结构不变。
- 动画只动 transform / opacity。"减少动态效果"、省内存设备（触屏且 `deviceMemory` ≤ 4 或问不到——iPhone、iPad 上的 Safari 都不报，按内存小算；或开了省流量）整张静止；触屏在牌桌上也静止（打牌时省电），主页上照常。

### 8.9 主题房

- 四个档位各一间房（`rooms.ts` 的 `ROOM_NAME`）：小桌"街角牌室"、中桌"湖畔会所"、大桌"红厅"、豪华桌"黑金"，一档比一档华丽（豪华桌要明显更华丽）。

### 8.10 关键时刻和荷官

- 荷官（`dealer.ts`）：程序画的半身像（白衬衫、黑马甲、红领结），站在桌子顶边后面，桌边的木框压住腰、手搭在木框上。画的 80 × 96 缩到 0.8（再大头就顶到顶栏里）。
  能站的点由 `layout.ts` 的 `dealerSpots` 给：横屏才有；顶边上依次试中间、右边 68%、左边 32%、66%、34%、再往里的 63%、62.5%、62% 处（顶栏右边的圆按钮越来越多，靠外的点会碰到；左边碰到钱包的字），离顶上的座位左边要有 150 的空（那边有动作签），右边只有底牌，112 就够；7–9 人桌顶上坐满了就没有（`test/view/layout.test.ts` 查 2–6 人至少一个、离座位够远）。
  再由 `table.ts` 的 `placeCroupier` 按实际位置挑第一个不碰顶栏的（左边"在哪一桌"的字随玩法变长短），都碰就不出现；摆座位、顶栏的字变了时各挑一次。
  有荷官时底牌、公共牌从他右手发出，弃牌、收牌回到他手里；没有时照旧从庄家位置发、收回桌心。发牌时抬手，平时 4.6 秒眨一次眼。荷官不说话、不算电脑人物，不用登记保留名。
- 特效（`fx.ts`）：全下（不算交盲注交到没钱）时桌子暗下去、聚光收在这个座位；赢家头像迸金币，大锅（40 个大盲以上，和"哗啦"的音效同一个门槛）更多更远、舞台四边泛金光。
  都是一次性节点，不等它们放完牌局照走；时长 1.2 秒乘动画快慢（快档 0.66 秒、减少动态效果 0.36 秒），封顶 1.5 秒。只动 transform / opacity。
- 省内存（`scene.ts` 判断，根上挂 `.lowfx`）：不撒金币、荷官不眨眼不抬手，聚光和金边照常（一层渐变，便宜）。
- 名场面特写用 kit 的横幅（`tf.banner`），音效有全下的低鼓、大锅的筹码哗啦、收池的聚拢。
- **大场面**（`src/fun/climax.ts` 的纯函数 + `table.ts`、`fx.ts`、`sound.ts`；只用摊牌时真亮出来的牌，不碰没亮的）：
  - **全下补牌**（`src/view/table/motion.ts` 的 `runOut`）：摊牌、公共牌还没发全时，规则本来就让所有人底牌马上翻开——画面先把每家底牌一起翻开（一声"揭晓"），再一张张补牌；
    每家的牌型位上写"胜率 xx%"（`runoutEquity`：缺 ≤ 2 张公共牌时穷举，更多时抽 600 次，抽样用固定的线性同余，同一局面同一个数），每翻一张跳一次，摊牌后被牌型名换掉。
    转牌、河牌前先心跳两下（`heartbeat`）停一停（转牌 0.48 秒、河牌 0.85 秒），那一张慢翻（2–2.6 倍）、翻起时放大一点带金光（`flipHot`），翻完停一拍再刷新胜率。
  - **大牌庆祝**（`celebration`、`fx.ts` 的 `celebrate`）：赢家亮出葫芦（1 档：光爆、"葫芦！"字、12 枚筹码雨）、四条 / 同花顺 / 皇家同花顺（2 档：更大的转光光芒、"四条！""同花顺！""皇家同花顺！"、26 枚筹码雨，赢家头像的金币也加大），
    配 `cele1` / `cele2` 的和弦（代替普通的赢声）。字落在公共牌正中（kit 的名场面横幅在上沿 18%，不叠在一起）。
  - **被逆转**（`badBeat`）：河牌发完、主池只有一个赢家，转牌时亮出来的牌里有输家胜率 ≥ 80%（`BAD_BEAT` 800‰）：等 kit 的横幅收了（约 2.3 秒）后，输家头像旁冒"被逆转"小签、头像晃两下、一声往下滑的 `badbeat`。不嘲弄，只是一个提示。
  - **筹码声按池子大小**（`potTier`）：分池时按这一手的池总额 ÷ 大盲选声——小（< 10 个大盲）`potS` 叮叮几下、中（< 40）`potM` 一小串、大（< 150，也是金边的门槛）`bigpot` 哗啦、特大 `potXL` 先落一记低频堆叠再来更长一串。
  - **时长**：补牌的悬念只在单机加（总共多约 2 秒，按 pace 缩放：快档约 55%、减少动态效果约 30%）；庆祝、被逆转的节点都不等它放完，不占牌局时间。
    **好友房**（`TableViewOpts.quick`）每帧时长是房间定的：不加停顿、不下筹码雨、不慢翻，补牌的快慢是 1.8 倍；庆祝只放 0.9 秒的光和字、小签 0.6 秒后冒出来。
  - **省内存（`.lowfx`）、减少动态效果**：庆祝只留一团光爆和字（只动透明度，不放大不转）、不下筹码雨、不晃头像、慢翻退回普通翻牌（无金光）；悬念的停顿、心跳声、胜率照常。所有特效节点 `pointer-events: none`、放完就删，CSS 写在 `.fx` 层下（`skin.css` 末尾）。
  - 冒烟 `--only bigmoments`（`scripts/scenes.ts` 的 `bigHand` 摆牌：电脑已全下、我跟注）：真速度走完补牌，查胜率标签、翻牌后胜率变了、"四条！""葫芦！"字、葫芦那手出"被逆转"、四条那手没有、播完特效节点都收了、桌面互压为零，电脑和手机竖屏各截 7 张。
- 加注面板打开时整个挪开的座位挂 `.shifted`，动作签换到名牌朝桌心那一侧（放在头像上方会压着上一家的名牌）；冒烟的"座位互相压着"连动作签一起算。

### 8.11 结算、颁奖和等人页

- 结算（`summary.ts` 的 `hero`）：单机和好友房（我那一行）都在顶上放一块 `.sum-hero`，分 `win` / `lose` / `even` 三种。只看这一场的净输赢，一手没打完的写"还没打完一手"。
  赢的那块背后有一圈锥形渐变慢慢转；`.lowfx` 时不转。输的不写数字以外的负面字眼，只安慰一句。
- 颁奖名字最多两行（`-webkit-line-clamp`，中英文都能断）：不限行的话名字长的会把弹窗撑出屏幕。
- 等人页（`room.ts`）：`.rw-seats` 里一张主题桌（`.rw-felt`，用这一档的毡面和木边变量，中间写 `ROOM_NAME`）。用到的座位按 `π/2 + 2πi/人数` 的角度摆在椭圆上，按百分比定位，竖屏只是把容器拉高。
  空椅子只放"坐这里"，不写号码和"空位"，免得一圈都是字。
- kit 的面板：kit 0.16 起读 `--ak-*` 变量。德州在 `skin.css` 的 `:root` 上设成本游戏的颜色和圆角（现行卡通皮肤：奶油底、深棕字、金色强调，`docs/art.md`）。写在根上，靠继承传进 kit 挂在 body 上的面板。

### 8.12 主动亮牌和好友房聊天

- 亮牌是规则里的一个操作 `{ t: 'show', cards }`（`cards` 是第几张：`[0]`、`[1]`、`[0, 1]`）：只在一手打完停着（`hold`）时、只能亮自己的、摊牌已经亮过的不收；
  同一家可以先亮一张再亮两张（换掉原来那条），亮了不能收回。不比大小、不动筹码，不进战绩和称号。电脑不亮。
  `finishHand` 在开着 `holdHands` 时把各家底牌留在 `kept`（离桌的、没发到牌的留空），`deal` 删掉；模拟器不停着，没有 `kept`，也就亮不了。
  座位一换人（`removeSeat`、`seatPlayer`、电脑坐下）就把这个座位的 `kept` 清空，`lastHand.showed` 里这个座位的那条也拿掉（亮过的是公开的，但按座位号摆，不拿掉会摆在新来的人座位上）：`kept` 按座位号存，不清的话停着时离桌、别人坐进同一个座位，新来的人会拿到上一个人的牌。
  好友房接管电脑座位时，这一手座位上还是电脑（`owner` 不是 `player`），`view` 本来就不给。`fair.test` 在停着时随机让人离桌、别人马上坐进同一个座位来查；做过反证：不清空，新坐下的人拿到了上一个人的两张。
- 好友房：亮牌是 kit 的不轮流操作（`free`），停顿不重新计时；房间的 `parse` 只收上面三种形状。
  **页面给 5 秒，服务端允许整个停顿期**：5 秒是给玩家的节奏，不是安全边界。规则读不了时间，kit 的停顿起点也不公开；
  服务端守住的是只亮自己的、只在这一手停着时、下一手发牌前删掉、没亮的不下发。页面按 `room.pause.until − (HAND_PAUSE_MS − SHOW_MS)` 收起，单机从两手之间那一栏出来起算 5 秒。
- 画面：亮的那张在座位上翻开、没亮的盖着（自己的也盖着，一眼看出亮了哪张）；翻牌声、头像跳一下。单机亮牌不停"自动下一手"的倒数。
- 测试：`test/core/table.test.ts`（亮牌的规矩）、`test/core/fair.test.ts`（停着时每个座位的视图里，别人没亮的牌在任何牌字段里都不出现；做过反证：视图给成下一家的 `kept`，测试失败）、`test/core/room.test.ts`（形状、不轮流、旁观看得到、发牌后不能亮）；冒烟单机点"都亮"、好友房房主亮一张。
- 聊天用 kit 0.18（`docs/chat.md`）：房间开 `chat: true`，页面 `RoomClient` 传 `onChat`、`onChatError`，`TableFun` 传 `chat` 和 `chatEnabled`。过滤、限速、打码、屏蔽都是 kit 的，
  说的话不进状态、不存、不交给规则和电脑。冒烟里 1 号说一句，房主和手机上都看到气泡。
  单机：`TableFun` 传 kit 0.18.1 的 `localChat`（过滤、限速和房间同一套，在浏览器里做），说的话只冒在我自己头上；电脑不读聊天（公平），单机的电脑反应只看牌局和互动编号。
  顶栏的聊天开关进桌就显示（单机、好友房都有）。冒烟单机说一句看到气泡，发链接被挡。
- 用 kit 0.19.1 的聊天界面（`docs/chat.md` 第 5 节）：
  - `TableFun` 多传 `plate`（`TableView.plateRect`：名牌；我自己的连头像和底牌）、`center`（`centerRects`：公共牌、底池、结果条）、`lite`（根上的 `.lowfx`，弹幕默认关）和 `chatDock`。
  - `chatDock`（`TableView.chatDock`）：在整个屏幕上每 16×8 像素试一格，按"盖住的面积 × 权重"挑最小的。公共牌那一片 30，名牌、面前的注、下注区、顶栏、左下那一排、两手之间那一栏、我的头像 10，别人的头像 4，底牌 2，空桌面 0。
    底牌、注、公共牌、下注区按版式算（藏着的时候量不到）。同一个窗口、同一桌人只算一次，聊天框不跟着下注跳。
  - 放不下（找不到一点不盖的地方，1280×720 的 6 人桌）时默认收起：进桌时量一次（好友房等座位坐满再量），经 kit 0.20.1 的 `chatFolded` 告诉 kit，量完这一桌不再变；玩家自己点过收起、展开的以玩家为准（kit 记在 `texas.chat`）。收起时按"聊天"小按钮的大小另挑位置。
  - 手机竖屏的"聊天"按钮在"互动"旁边、我名牌下面那一排（8.14），冒烟查它不压任何座位的头像和名牌。
  - 冒烟：电脑版聊天框（或收起的小按钮）不在右下下注区；房主关了弹幕，1 号再说一句，房主那边只冒气泡、不飘弹幕；手机竖屏"聊天"按钮不压座位。

### 8.13 止盈

赢够了自动起身：选桌的止盈和设置面板里的止盈，是同一个设置（`texas.settings` 的 `takeProfit`）。可选关（默认）、赢 50% / 100% / 200%、自定义金额。
- **怎么算**（`src/core/takeprofit.ts`，纯函数，`test/core/takeprofit.test.ts`）：单机按这一桌带上桌的总数（坐下加补码）算，净赢 = 桌上的 + 还没上桌的 − 带上桌的；
  好友房按一份满买入算（页面不知道房间记的带入总数），净赢用房间下发的 `net`。
- **什么时候走**：一手打完时问一次，够了就自动离桌，不问"离桌吗"，提示"止盈了 +X"，照常出结算页。正在打的一手不打断（单机两手之间、好友房停顿期里走）。好友房只在服务端还停在手间（`phase` 是 idle）时离座：页面动画播完时下一手可能已经发了（切后台、卡顿），这时离座会变成弃牌白丢盲注，就留到那一手打完再问。锦标赛桌不适用（按钮不出、不触发）。
  单机实盘结回钱包，好友房离座结回，娱乐桌只是离桌。好友房开房、进房、邀请都不变。只做止盈，不做止损。
- 冒烟 `--only tp`：实盘设"赢 1"，一直跟注（两手之间点"下一手"），赢的那一手打完自动走、钱包变多；选桌有止盈按钮，1280×720 的"坐下开打"不出屏。

### 8.14 顶栏、设置和键盘（按仓库根 docs/ui.md）

- **顶栏**最多 5 个可点：大厅、帮助"?"、聊天开关（牌桌上）、设置齿轮、离桌（牌桌上，红色危险样式）。没有单字按钮；触屏下每个可点范围按舞台缩放后不小于 44×44、相邻间距不小于 8（看得见的部分最小 32，用透明外扩补足）。
  左边写在哪一桌（"娱乐 · 新手 · 盲注 10/20"），手机横屏整行藏起来（667×375 的 9 人桌会压到顶上那家的头像）；钱包不挂在顶栏。
- **设置面板**（`src/view/settings.ts`，齿轮是唯一入口）：音效开关和音量、动画"快速 / 正常"、互动开关、聊天（开 / 不和陌生人 / 不看）、止盈、战绩和云存档状态、钱包，底部"恢复默认"（止盈、聊天回默认，大厅记的档位和人数不动）。
  改了立刻生效、写进 `texas.settings` / `texas.fun`；✕、Esc、点遮罩都能关，关了焦点回齿轮。游戏没有背景音乐，所以只有"音效"一个开关，不单设"音乐"。
  排布按屏幕分，都不滚动：电脑和手机横屏三栏等高（声音 / 玩法互动 / 画面和账号），每行控件同宽、右对齐成一列，手机竖屏一栏、用"声音画面 / 玩法互动 / 账号"三个页签切换。
- **弹窗**（`src/view/dialog.ts`）：Esc 等于点标了 `cancel` 的按钮；没有的话非 sticky 的关掉，sticky 的（输光等）不关。Tab 在弹窗里转圈，关了焦点还给打开前的元素；
  弹窗开着时键盘在捕获阶段截住，牌桌的 F / C / R 不会误按。离桌、离开房间这类按钮是 `danger`（红），确认框默认焦点在"接着打"。选中态（`.sel`）是浅底描边加勾，和金色主按钮分开。
- **选桌页一屏放下**：见 8.8，五个尺寸都不滚。
- **键盘**：选桌 ← / → 换档位（到头停）、回车坐下开打（焦点在输入框、滑杆，或有弹窗，或按着 Ctrl / ⌘ / Alt / Shift 时不拦；规则是纯函数 `src/view/lobbykeys.ts`）。
  全部快捷键（牌桌、快速局、谜题、选桌）列在新手指引最后一页"电脑快捷键"（`src/guide.ts` 的 `KEYS_TABLE`），入口是大厅"怎么玩"和牌桌"?"。
- **手机竖屏牌桌**：桌面椭圆占 390×844 屏高约 56%（`test/view/layout.test.ts` 查 ≥ 55%）；互动、聊天、补码、歇一手合成我的名牌和操作区之间的一排，加注面板展开时这一排收起；
  别人的"没筹码 / 暂离 / 离桌"徽章挂在名牌正下方，不压头像。
- 冒烟：`--only settings`（三种尺寸量顶栏可点范围、设置刷新后还在、恢复默认）、`--only dialogs`（离桌确认、Esc 关）、`--only lobbyui`（一个主按钮、第一屏可点数、键盘开一局）。
