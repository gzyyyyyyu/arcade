## 0. 一句话

海盗题材的海岛攻防：在自己的岛上摆建筑、升级、攒金币和木材，开船去打别的海盗岛，放兵登陆、用旗舰炮火支援，拆光对面的主寨抢资源。
**建造不用等时间**，节奏靠资源和战役星数卡；一次进攻 2–3 分钟，上线 15–20 分钟能升一两样东西、打下一两座岛。

参考《部落冲突》《海岛奇兵》的玩法骨架（建基地、异步攻防、登陆战、炮舰能量），不照搬它们的角色、图、界面和数值；画面全部程序生成。

## 1. 核心循环和一局时长

```
收资源（产出建筑按真实时间攒，有仓库上限）
  → 建 / 升级 / 摆放（立即完成，只花资源）
  → 编船队（兵按船装，出海时一次性付木材）
  → 出海：选一座岛（战役关卡，或别的玩家的岛）
  → 登陆战 ≤ 3 分钟：选船点海滩登陆，兵自动打；旗舰能量放炮击、信号弹、补给
  → 结算：星级（1–3）、掠夺资源、首次星级奖励 → 回到岛上升级
```

- **一场进攻**：上限 3 分钟（游戏时间），实际 1.5–3 分钟；部署 10–20 秒，其余是看兵打、点旗舰技能。可以 2× 快进。
- **侦察期（登陆战开场不计时）**：玩家第一个操作（出船或放技能）之前，画面不调 `stepBattle`，拍数停在 0，顶栏计时牌显示满时间并带「侦察中」小字；画面照常动（海浪、待机动画、镜头缩放平移都能用），所以选卡、看防御、看射程圈的时间不会白白倒数。
  做法在画面层（`BattleScene.scouting()` → `battlescout.ts` 的 `holdScout`，纯函数，`tests/battlescout.test.ts` 锁住）：只有第 0 拍、玩家这一拍还没排操作、不是回放、预排的电脑操作为 0 条时才停；玩家一点，当拍放行，此后拍数 > 0 永不再停。寻宝航线的一站同理（站内拍数也从 0 起，开场横幅期间也不走）。
  不影响规则、回放和实盘：停着不产生任何操作，等价于"玩家第一个操作发生在第 0 拍"，是一串合法的操作序列；规则核心、`RULES_VERSION`、数值、回放重放和实盘期望都不动，同一套操作前面多停多少帧，每拍事件和最终结果逐位相同（测试里按 0 / 37 / 400 帧对拍）。回放和机器人代打（`?auto`）本来就在第 0 拍出手，不停。
  开场提示也合成一条：俯瞰层只写「红圈是防御的射程 · 点任意处开始侦察，出第一船才开始计时」，「先点船卡，再点发光的沙滩」等俯瞰收起后再出，两条不同时在屏上。
  局内一次性提示：兵团血量总和第一次掉到一半以下、且还有没出的船时，弹一次轻提示（toast，不挡操作）：待命的船里有壮汉或盾兵就说「先上壮汉吃炮」，没有就说「别一次放光，分批登陆」；每局最多一次，回放和机器人代打不弹。
- **开场不白白倒数（侦察期）**：进战场后 3:00 不走，计时牌显示满时间并带「侦察中」小字；玩家的第一个操作（出第一船或放第一个技能）那一拍开始计时。为什么：选卡、看射程圈的十几秒原来白白算进 3 分钟，航线一站的开场横幅期间也在走。怎么做：只在画面层，`BattleScene.stepOnce` 在拍数为 0、不是回放、没有机器人预排操作、玩家这一拍还没点任何操作时不调 `stepBattle`（判定是纯函数 `battlescout.ts` 的 `holdScout`）；画面照常动。为什么不影响规则、回放和实盘：这等价于"第一个操作恰好落在第 0 拍"，本来就是合法的操作序列，规则核心不知道有过等待、拍数仍从 0 起，同种子同操作结果逐位不变，回放按拍数重放、实盘期望按同一套规则算，都不用改（`tests/battlescout.test.ts` 锁住：第一个操作前多停多少帧结果相同）。回放和机器人代打（`?auto`）本来就在第 0 拍出手，不停。航线一站（`MAP_STOP_TICKS` 拍）同样处理。开场俯瞰的两条提示合成一条「红圈是射程、斜线暗圈是打不到的盲区 · 点任意处开始侦察，出第一船才开始计时」（新手第一场只写「这是敌人的岛，红圈里的炮会打你的兵 · 点一下开始」），"先点船卡，再点发光的沙滩"留到俯瞰收起后。
- **局内一次性提示（半数倒下）**：兵团血量总和第一次掉到一半以下、且还有没出的船时，提示一次「分批登陆，先上壮汉吃炮」（没有壮汉 / 盾兵就说"别一次放光，分批登陆"），每局最多一次，不挡操作（`battlescout.ts` 的 `halfLostHint`）。
- **一次上线（15–20 分钟）**：收资源 → 升级 1–3 样 → 打 3–5 场（新关或重打旧关刷资源）→ 再升级。每次上线至少有一样东西能升（资源产出 + 掠夺的设计目标，第 7 节量）。
- **离线**：产出按真实时间攒到仓库满为止（单座矿上限 12 小时的产量），回来一点就收。离线时别人打的是我基地的快照（第 5 节）。

## 7. 配平方法

- 机器人：小白（随便挑一处海滩把船全放下、不放技能）和普通（选防御少的一侧登陆、壮汉先上、信号弹点主寨附近的炮）。
- 量：每关两个模型的星数分布、平均用时、掠夺；主寨各级"打一场的收入 / 升一级的花费"；每天 30 分钟能升几级。
- 大模拟推 `sim/haidao-*` 分支到 CI 跑。实盘期望用 `tools/live-sim.ts` 按 balance.md 第 2 节的表量（4.3）。
