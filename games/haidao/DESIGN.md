## 0. 一句话

海盗题材的海岛攻防：在自己的岛上摆建筑、升级、攒金币和木材，开船去打别的海盗岛，放兵登陆、用旗舰炮火支援，拆光对面的主寨抢资源。
**建造不用等时间**，节奏靠资源和战役星数卡；一次进攻 2–3 分钟，上线 15–20 分钟能升一两样东西、打下一两座岛。

参考《部落冲突》《海岛奇兵》的玩法骨架（建基地、异步攻防、登陆战、炮舰能量），不照搬它们的角色、图、界面和数值；画面全部程序生成。

## 1. 核心循环和一局时长

```
收资源（产出建筑按真实时间攒，有仓库上限）
  → 建 / 升级 / 摆放（立即完成，只花资源）
  → 编船队（兵按船装，出海时一次性付木材）
  → 出海：选一座岛（战役关卡，或别的玩家的岛）
  → 登陆战 ≤ 3 分钟：选船点海滩登陆，兵自动打；旗舰能量放炮击、信号弹、补给
  → 结算：星级（1–3）、掠夺资源、首次星级奖励 → 回到岛上升级
```

- **一场进攻**：上限 3 分钟（游戏时间），实际 1.5–3 分钟；部署 10–20 秒，其余是看兵打、点旗舰技能。可以 2× 快进。
- **侦察期（登陆战开场不计时）**：玩家第一个操作（出船或放技能）之前，画面不调 `stepBattle`，拍数停在 0，顶栏计时牌显示满时间并带「侦察中」小字；画面照常动（海浪、待机动画、镜头缩放平移都能用），所以选卡、看防御、看射程圈的时间不会白白倒数。
  做法在画面层（`BattleScene.scouting()` → `battlescout.ts` 的 `holdScout`，纯函数，`tests/battlescout.test.ts` 锁住）：只有第 0 拍、玩家这一拍还没排操作、不是回放、预排的电脑操作为 0 条时才停；玩家一点，当拍放行，此后拍数 > 0 永不再停。寻宝航线的一站同理（站内拍数也从 0 起，开场横幅期间也不走）。
  不影响规则、回放和实盘：停着不产生任何操作，等价于"玩家第一个操作发生在第 0 拍"，是一串合法的操作序列；规则核心、`RULES_VERSION`、数值、回放重放和实盘期望都不动，同一套操作前面多停多少帧，每拍事件和最终结果逐位相同（测试里按 0 / 37 / 400 帧对拍）。回放和机器人代打（`?auto`）本来就在第 0 拍出手，不停。
  开场提示也合成一条：俯瞰层只写「红圈是防御的射程 · 点任意处开始侦察，出第一船才开始计时」，「先点船卡，再点发光的沙滩」等俯瞰收起后再出，两条不同时在屏上。
  局内一次性提示：兵团血量总和第一次掉到一半以下、且还有没出的船时，弹一次轻提示（toast，不挡操作）：待命的船里有壮汉或盾兵就说「先上壮汉吃炮」，没有就说「别一次放光，分批登陆」；每局最多一次，回放和机器人代打不弹。
- **开场不白白倒数（侦察期）**：进战场后 3:00 不走，计时牌显示满时间并带「侦察中」小字；玩家的第一个操作（出第一船或放第一个技能）那一拍开始计时。为什么：选卡、看射程圈的十几秒原来白白算进 3 分钟，航线一站的开场横幅期间也在走。怎么做：只在画面层，`BattleScene.stepOnce` 在拍数为 0、不是回放、没有机器人预排操作、玩家这一拍还没点任何操作时不调 `stepBattle`（判定是纯函数 `battlescout.ts` 的 `holdScout`）；画面照常动。为什么不影响规则、回放和实盘：这等价于"第一个操作恰好落在第 0 拍"，本来就是合法的操作序列，规则核心不知道有过等待、拍数仍从 0 起，同种子同操作结果逐位不变，回放按拍数重放、实盘期望按同一套规则算，都不用改（`tests/battlescout.test.ts` 锁住：第一个操作前多停多少帧结果相同）。回放和机器人代打（`?auto`）本来就在第 0 拍出手，不停。航线一站（`MAP_STOP_TICKS` 拍）同样处理。开场俯瞰的两条提示合成一条「红圈是防御的射程 · 点任意处开始侦察，出第一船才开始计时」，"先点船卡，再点发光的沙滩"留到俯瞰收起后。
- **局内一次性提示（半数倒下）**：兵团血量总和第一次掉到一半以下、且还有没出的船时，提示一次「分批登陆，先上壮汉吃炮」（没有壮汉 / 盾兵就说"别一次放光，分批登陆"），每局最多一次，不挡操作（`battlescout.ts` 的 `halfLostHint`）。
- **一次上线（15–20 分钟）**：收资源 → 升级 1–3 样 → 打 3–5 场（新关或重打旧关刷资源）→ 再升级。每次上线至少有一样东西能升（资源产出 + 掠夺的设计目标，第 7 节量）。
- **离线**：产出按真实时间攒到仓库满为止（单座矿上限 12 小时的产量），回来一点就收。离线时别人打的是我基地的快照（第 5 节）。

## 2. 成长与等级

### 2.1 卡节奏的东西（不靠等待时间）

| 卡什么 | 怎么卡 |
|---|---|
| 资源 | 金币（建筑、升级）、木材（造兵、研究、旗舰）。来自产出建筑和掠夺；仓库有上限，逼人花掉、逼人出门打 |
| 战役星数 | **主寨升级要求累计星数**（例：升 3 级要累计 7 星、升 5 级要 16 星）。星数只能靠打赢关卡拿：想升级就得会打 |
| 主寨等级 | 其他建筑的等级 ≤ 主寨等级；每级主寨开放新建筑、多几个同类建筑名额、新兵种、更多旗舰能量 |
| 进攻成本 | 每场出海付造兵的木材，打输也花掉；木材不够整支船队时自动少带兵（先减单价最高的，船坞配置不动，`trimArmy`），一个兵都带不起才开不了；重打已三星的关只给三成掠夺，逼人往前推 |

### 2.2c 第三期：战术和收获感（0.3.0，以 `src/core/` 为准）

- **城墙和寻路**（`battle.ts`）：城墙 1×1，主寨 2 级开放，名额 10–60。兵按格子做确定性的代价流场找路：别的建筑不能穿，墙能穿但代价 7，
  所以有缺口就绕、绕太远就砸最近那段墙；流场按目标缓存，建筑占格或存亡变了才重算。炸药兵 6 格内有墙先去炸（对墙 ×3），火炮兵专打防御塔。
  `tests/tactics.test.ts`：同一支部队，有墙引导的布局摧毁率平均 50%，无墙 66%。c30 岛加 46 段墙整场重放约 130 毫秒（服务端重放的预算 200 毫秒）。
- **推荐布局**（`presetLayout(p, 'turtle'|'spread'|'trap')`）：只重摆现有建筑，不增不减。龟壳 = 墙一圈、防御围主寨；分散 = 资源和防御拉开、怕溅射的打法吃亏；陷阱 = 墙圈留口子，口子里外地雷焦油、炮盯口子。
- **侦察**：出海前看敌岛布局和射程，地雷、焦油不显示（和战斗里一样）。开场 3 秒俯瞰，首领岛写机制和解法（`LevelDef.counter`）；普通机器人按同样的解法打（躲海怪一侧、火箭塔多就分两侧登陆、雾里不炮击）。
- **连胜和安慰奖**（`settleCampaign`）：≥1 星连胜 +1，每场掠夺 +10%、封顶 +50%；0 星清零连胜，给该关掠夺的 15% 加 10 木材。以上（含首次星奖励）最后再乘收入倍率（2.4）。
- **掉宝**（`rollDrops`，确定性）：≥1 星必有一个金币或木材箱；稀有（3 种装饰 + 8 兵种 × 3 皮肤）按星数 3% / 6% / 10%，首领岛首次三星必掉一件；不重复掉已有的。
  装饰只占格不打仗；皮肤只换颜色（`equipSkin`），不改数值。存档校验只认稀有池里的、已拥有的。
- **每日悬赏**打 `dailyBounty` 当天生成的那座岛（翻转后的布局），掠夺 = 悬赏奖励（关卡掠夺 × 2 × 收入倍率）× 摧毁率；≥1 星才算完成，不改战役星数和连胜、不掉宝。
- **首领岛布局**：c15、c20、c25、c30 是通道式布局（`gen.ts`）：主寨四面各留一条两格宽的道，塔放四个象限，地雷焦油只埋在道上，从哪面登陆差别很大（c30 小白按面 0.7–2.5 星）。主寨 7、8 要的星数见 2.2 主寨表（27、36）；主寨 6→7 的停留最长。
- **关卡难度曲线（`node tools/sim.ts --n 100`，种子 1–100 / 1001–1100）**：只靠关卡内容调，规则不动。普通机器人 ≥ 1 星胜率 c01–c12 约 95–100%，c13 起约每关 −1.75 点、c30 约 65%（c13 100% / c14 98% / c15 96% / c16 93% / c17 85% / c19 90% / c20 84–92% / c22 85–88% / c23 74–79% / c25 69–77% / c27 75–79% / c28 68–74% / c29 76–79% / c30 64–69%），相邻落差大多 ≤ 8，最大 −14（c22→c23、c29→c30 在种子 1001–1100）。
  **细档旋钮**（`gen.ts` 的 `TUNE`，每关一条）：`lv` 基础等级，`up` 按固定顺序（先外圈后内圈）把 `up` 座炮塔再升一级（最高 8，狙击塔和震荡炮不参与，用 `lvBy`），`wall` 墙单独等级，`add` 在原有数量上加狙击塔 / 震荡炮，`pos` 摆位方案。同一关的 `lv` 差一级普通机器人胜率常常 100% → 20–50%，`up` 把这一级拆成 `up` 个小步。
  **胜率主要由狙击塔和震荡炮决定**：c13、c20 单靠升塔到主寨等级也还是 100%，要靠狙击塔（射程 11）和震荡炮把难度拉起来，所以这两种塔按关加（`add`：c15 加 2 狙击 + 2 震荡、c16 / c17 / c23 各加 1 座狙击、c18 和 c22 各加 2 + 2、c20 加 4 + 1、c21 加 1 座震荡、c24 加 2 + 1、c25 加 1 + 1、c29 加 1 座狙击并少 1 座火箭塔；c21、c24、c27 原有的保留）。通道式的 c15、c20、c25 也按 `n` 里的狙击塔 / 震荡炮摆（`SNIPE_POS` / `SHOCK_POS`）。塔等级不超过主寨等级（`tests/base.test.ts` 检查），所以 `up` 到顶以后不再加。
  **摆位对胜率的影响很大**：两种机器人会挑登陆的海滩，摆位一动，胜率可以整段翻转。c26、c28、c29 用 `EDGE`（沿岛边）后小白不再被打光——原来 `CORE`（贴主寨）的 c26 小白 10%、`NORTH` 的 c28、c29 的 S 面登陆（小白 1/50）都被火箭塔 / 加农近距离扫掉。
  **小白**：只当参照；各关 35–95%，相邻落差 ≤ 25，仅 c11→c12 约 −32、c19→c20 在种子 1001–1100 是 −31。c11→c12 是 c11 偏高（小白 86%，c10、c12、c13 都在 53–62%）：c12 降喷火 / 炮 / 枪塔 / 臼炮、拿掉地雷，小白最多 +6，普通却掉到 50–63%；c11 升喷火 / 臼炮 / 枪塔 / 炮，小白只到 80–87%，普通平均星从 1.7 掉到 1.0–1.4（会让主寨 6→7 凑星更慢）。机器人输赢主要看登陆哪面，升降塔调不动小白，所以两关都不改。c29 少一座火箭塔（南面登陆正对两座火箭，小白从南面上岸只赢 28%）：小白 59–66% → 74–81%，夹在 c28（76–77%）和 c30（79–83%）之间，普通 76% → 76–79%。
  `TUNE` 里没有的关（c30、前 12 关）保持手写布局。悬赏借用的 c07、c10、c16 已冻结成悬赏专用表，战役这份随便调。

## 4. 经济与筹码（四种实盘 + 单向兑换）

- **两层资源**：金币、木材是游戏资源，可以抢、不碰钱包（异步攻防只抢这两样，第 5 节）；筹码只在四种实盘（悬赏出海 4.1、悬赏守岛 10.5、护航 12.1、寻宝航线 11.1）和"兑换"（4.4）这几个入口进出。
- 双向兑换不做：会让攻防掠夺间接变成玩家之间转筹码，违背 economy.md"不能转让"。平台的"两人原子结算"因此也不需要。
- 代码：规则和表在 `src/core/live.ts`（出海）、`tdlive.ts`（守岛）、`escortlive.ts`（护航）、`maplive.ts`（航线），Worker 都走 `worker/live.ts`（照夜巡 `worker/live.ts`），浏览器在 `src/net/live.ts`、`src/view/live.ts`。

### 4.0 哪些玩法挂筹码、每天合计上限

**挂筹码的前提**：结果只由"档位 + 种子"（航线是"档位 + 日期"）和局内操作决定，不看玩家自己的存档和养成，也不涉及别的玩家；这样模拟器量出来的期望就是所有人的期望，养成多的人不会在实盘里白占便宜。

| 玩法 | 实盘 | 理由 |
|---|---|---|
| 悬赏出海 | 有（4.1） | 雇来的固定船队打冻结的悬赏岛 |
| 悬赏守岛 | 有（10.5） | 固定的岛、常驻塔、英雄等级 |
| 护航 | 有（12.1） | 开局本来就不读存档：图、塔、英雄等级都由关卡定 |
| 寻宝航线 | 有（11.1） | 全服同一条航线、同一支船队，只看局内的决定 |
| 战役（登陆战 30 关） | 只有娱乐 | 带的是自己的船队、研究等级和旗舰能量，结果跟养成走；它的实盘版就是悬赏出海（同样的登陆战、固定船队） |

### 4.4 单向兑换：筹码 → 金币或木材

- 顶栏金币旁"换"：一次换一份小档（2,000 筹码）→ 2,000 金币或 1,200 木材，**每天最多 2 次**（北京时间，`EXCHANGE_PER_DAY`，管理页调不了，写在常量里）。金币、木材永远换不回筹码。
- 比例的理由：金矿每小时产 150–520（1–6 级），主寨 2 级时两座金矿合计约每小时 400，2,000 金币约等于 5 小时的产量，和打一关前期战役的掠夺同一量级：
  换了省点时间，不至于让建造和战役失去意义。木材的产量约是金币的 0.8 倍、升级花得也少，按 0.6 折。
- 钱包里兑换用独立的 ref 命名空间（`hx-` 前缀，浏览器的实盘请求不许用这个前缀）：实盘的 settle / refund 打不到兑换那一份，兑换也借不到结过的实盘 ref。
- 实现只用现有钱包动作：`buyin` 一份小档后立刻 `settle` 0（筹码归庄家，按 economy.md 第 6 节就是"输给庄家"那一项）。当天次数、每次换成了什么记在这个人 `Base` DO 的状态行里，按 ref 幂等；
  换来的资源记成待领，浏览器同步时加进存档再 ack（和攻防的待领同一套，仓库放不下的部分丢掉）。余额不够时名额退回。
- 需要 economy.md 第 0 节加一条"可单向换成本游戏资源"（仓库文档，需另行修改）。

## 5. 异步攻防与服务器权威

> 打别的玩家的岛：资源会在玩家之间流动，所以"谁掉多少、谁拿多少"由服务端用同一份规则核心重放算，浏览器报的结果不算数。
> 只抢游戏资源（金币、木材），永不碰筹码（筹码只在第 4 节的悬赏出海和兑换里进出）。不防作弊的口径照旧（排行榜、单机），进攻方的部队按他自己上传的快照算。

### 5.1 规则核心（浏览器和服务端共用）

- `src/core/` 纯函数、确定性：自带的 sfc32 按用途分流，禁 `Math.random`、`Date`、三角函数、`Math.sqrt` 等；距离用整数（1 格 = 100 单位），开方用整数牛顿法（`tests/arch.test.ts` 锁住）。
- 进攻固定步长 20 拍/秒，输入只有"第几拍、哪条船、落在哪"和"第几拍、哪个技能、打在哪"，外加进攻方点"结束"时的拍数。
- `src/core/pvp.ts`：`replayRaid`（按 布局 + 部队 + 种子 + 操作 + 结束拍 重放，和 `runBattle` 指纹一致）、`sanitizeActions`（只留认得的字段，一条不合格整串作废）、
  `raidLoss` / `raidGain`（掠夺）、`trophyDelta`（奖杯）、`shieldMs`（护盾）、`wandererIsland`（流浪海盗岛）。
- `src/core/validate.ts` 的 `validateBase`：上传快照的把关，全部按内容表数据驱动（种类、等级 1..上限、坐标在岛内、不重叠、id 不重复、恰好一座主寨、
  这个主寨等级开放的种类和名额、建筑等级 ≤ 主寨、研究在已开放范围且不超过军械所、船上的兵种已开放、资源非负且不超过这个主寨等级所有仓库摆满升满的容量 `maxCapacity(hq)`）。不合格整份拒收，回一个原因码。浏览器上传前也用它自检。
  城墙按 HQ_LEVELS 的名额（主寨 2–8 级 10–60 段）；宝藏箱按名额收，分叉要过 `branchError`（坏的回 `branch`），英雄研究 `hero` 不超过 `heroCap`（主寨 8 级前等于主寨等级，8 级后到 12）、2 级以上要军械所（规则版本 6）；王阶 `rank` 只在主寨 ≥ 8 级时保留（1..10），`rankFund` 不进快照；掉宝装饰（雕像、旗杆、宝箱）和章节纪念装饰在快照带了收藏时必须已拥有，没带收藏的旧快照放行（装饰不挡路、不算摧毁率，不影响结算）。
- 重放预算：主寨 8 级、60 段城墙、满防御的岛打满 3 分钟（3,600 拍）约 90–150 毫秒（`tests/pvp-walls.test.ts` 量，规则版本 5）；
  c30 的岛加宝藏箱、全部分叉、8 级驻岛英雄，普通机器人打一场（1,745 拍）15–23 毫秒（规则版本 6，2026-10-28，`tests/raid-rules.test.ts`）。结算在防守方的 `Base` 里同步跑。
- **规则版本**：锁和防守记录里存的 setup 带 `rules`，`battle.ts` 按 setup 的版本走（版本 6 的新规则全在 `rules >= 6` 分支里），所以旧记录按当时的规则逐位重放；
  `tests/raid-rules.test.ts` 用升版本前录下的指纹锁住版本 5。回放只对版本 5 以前的记录提示"可能放得不对"。

### 5.2 数据放哪：游戏自己的 Durable Object（SQLite 后端），不进平台 D1

| 对象 | 是什么 | 存什么 |
|---|---|---|
| `Base`（每人一个，`idFromName(userId)`） | 这个人的岛 | `s` 一行：昵称、建号时间（第一次上传快照）、基地快照、奖杯、护盾到期、被打的锁（含锁住时的布局副本、部队、种子、仓库数）、自己正在打的一场、待扣 / 待领、24 小时内打过谁、结过的进攻（raidId 幂等）、限流计数；`d` 一行：最近 10 条防守记录（含回放要的布局、部队、种子、操作） |
| `Harbor`（全站一个，`idFromName('all')`） | 匹配索引 | 每人一行：奖杯、主寨等级、护盾 / 新号保护 / 锁的到期、上次上传快照的时间。SQLite 表在奖杯上有索引，挑对手是带 `LIMIT` 的奖杯区间查询，不扫整张表；超过 14 天没上传快照的人不进匹配，旧记录在写得不满 2 行的调用里顺手删一行 |

- 每个方法最多写 2 行（docs/platform-backend.md 4.2，`tests/pvp-*` 数过）；不用闹钟、不用 `setTimeout`；只走 HTTP，不用 WebSocket。
- **本期存档正本仍在浏览器**（`haidao.save`）：浏览器每次写档后防抖 30 秒（切后台立刻补一次）把基地快照 `PUT` 上来。
  下一期再把存档正本搬进 `Base`（建造、升级、收资源都由服务端算），那时进攻方的部队、防守方的仓库服务端才有准数。
- 写入照 kit 的计量记账（`METER` → `RoomMeter`，`meterReport`）；计量到门槛时不开新的进攻（已开始的照常结完），计量连不上不挡玩。

### 5.3 一次进攻

```
浏览器                       Worker（认人：kit whoIs → 平台 /api/me）     Base(进攻方)      Harbor        Base(防守方)
海图"打玩家"→ 找对手 ─POST pvp/find─▶ prepare：限流、取部队和奖杯（1 行）
                                    ─▶ pick：奖杯 ±150、主寨差 ≤1（先找同级和低一级，没有才给高一级，5.9）、排除自己 / 护盾 / 新号保护 / 被锁 / 24 小时打过 / 3 分钟内在线（2 行）
                                    ──────────────────────────────────────────▶ lock：再查一遍，锁 4 分钟，回布局（≤2 行）
                                    ─▶ begin：记这一场、丢掉自己的护盾（1 行）
◀─ {raidId, 对手昵称 / 奖杯 / 主寨, setup（布局带地雷，画面不画）, 最多能抢} ─
浏览器里实时打（同一份核心），出海木材本地先扣
打完 ─POST pvp/finish {raidId, actions, endTick}─▶ ──────────────────────▶ settle：重放，算星、摧毁率、掉多少、奖杯、护盾，写防守记录（2 行）
                                    ─▶ credit：奖杯、待领，按 raidId 幂等（1 行） ─▶ Harbor 更新双方（2 行） ─▶ tally：记进汇总（1 行，5.9）
◀─ 结果（以服务端为准）；浏览器取待领加进存档、ack ─
```

- 没有合适的真人（港口里没人、都不合格、连试 3 个都锁不上）：生成"流浪海盗岛"（`wandererIsland`：按奖杯挑战役关卡、按种子左右镜像），标"电脑"，掠夺来自系统（关卡掠夺 × 摧毁率 × 50%），奖杯减半，不扣任何人。
- **两个对象不是一次原子写**：以防守方 `Base` 的结果为准，进攻方 `credit` 按 raidId 幂等；重复交 finish 只算一次（回原结果，`dup: true`）。
- **超时**：锁 4 分钟。过期没交的按"空打"结（防守方不掉东西、不给护盾，进攻方记一场输）：进攻方后来再交、别人再来锁这座岛、进攻方下次找对手时，哪个先到哪个结。
- **放弃**（`POST pvp/cancel`）："换一个""不打了"按空打结掉：防守方解锁、什么都不掉，进攻方记一场输、扣奖杯，这场算用过，之后再交 finish 只回原结果。服务端核实不了有没有开打，放弃要是不算数，打得不好就放弃、拿同一个种子反复重来挑最好的结果。
- **并发找对手**：同一个人还挂着一场真人岛时又来 find（两个标签页、连点），先把旧的那场按放弃结掉、解开那个防守方的锁，再开新的，不让对方白锁 4 分钟。
- **复仇**（`POST pvp/revenge {raidId}`）：防守记录里 24 小时内的进攻方可以打回去一次，不经匹配、不看在线，但尊重新号保护、护盾和锁。复仇不给系统赏金（最多拿回对方掉的），复仇本身不能再被复仇；同一对人 24 小时内不分方向最多打 2 场（正常一场加复仇一场），超了 409 `pair_limit`。两个号互相复仇因此造不出资源。

### 5.4 掠夺、奖杯、护盾、新号保护

- **掠夺**：防守方掉 仓库 × 20% × 摧毁率（仓库 = 快照里的资源 − 还没扣的待扣，没上线的人不会被按原数反复抢）；进攻方拿掉的那些再加 50% 系统赏金。
- **待扣 / 待领**：服务端记在各自 `Base` 里，浏览器下次同步（打开游戏、打开面板、打完一场）时取回加 / 扣进本地存档（扣不到负数，领不超过仓库上限），浏览器本地记下处理过的 raidId（`haidao.pvp`），再 `ack` 清掉。上传快照时带上已经计入存档的 raidId（最近 100 个），ack 只给快照加减还没计入的那几笔，免得算两次。待扣、待领各最多 50 条，满了把同方向的并成一条（合计数加每场明细），不丢账。
- **奖杯**：赢（≥1 星）加 10 + 5×星数，按双方奖杯差（每 30 杯 ±1）调整，夹在 10–30；输扣 10 按差调整，夹在 5–15；防守方反向，都不扣到 0 以下。
- **护盾**：被打后摧毁率 ≥ 90% 给 12 小时、拆掉了东西给 8 小时；去打别人（含流浪海盗岛）立刻失去护盾。
- **新号保护**：第一次上传快照起 3 天不进匹配，复仇也不能打。
- **限流**：每人每小时找对手（含复仇）≤ 20 次、上传快照 ≤ 30 次，超了 429；计数在 `Base` 的状态行里。

### 5.5 接口（`/games/haidao/api/pvp/*`，`run_worker_first` 放行 `/games/haidao/api/*`）

| 接口 | 说明 |
|---|---|
| `PUT snapshot {profile}` | 上传基地快照，≤ 16 KB（超了 413）；`validateBase` 不过回 400 `bad_snapshot` + `reason` |
| `POST find` | 找对手（5.3），回 `{raidId, wanderer, opponent, setup, until, maxGain}` |
| `POST finish {raidId, actions, endTick}` | 交操作，回 `{stars, pct, gain, lost, trophies, total, wanderer, expired, dup}`；浏览器报的星数、摧毁率、掠夺字段一概不看 |
| `GET me` | 奖杯、护盾、新号保护、待扣 / 待领、防守记录摘要 |
| `POST ack {raidIds}` | 确认待扣 / 待领已经进了本地存档 |
| `GET defense/<raidId>` | 一场防守的回放数据（布局、部队、种子、操作、结束拍） |
| `POST revenge {raidId}` | 复仇（5.3） |
| `POST cancel {raidId}` | 没开打就放弃（"换一个""不打了"）：防守方解锁，这场不算、不记防守记录 |
| `GET stats` | 真人攻防汇总（5.9），只有平台管理员能看 |

- 写接口查 `X-Arcade: 1` 和 Origin（同夜巡 live.ts），不过 403 `csrf`；没登录 401 `login`，平台不可用 503 `unavailable`。
- 单独部署（没有平台 `ARCADE`）时这些接口回 501 `no_platform`，页面把入口藏起来，单机照常。

### 5.6 防守回放、通知、隐藏信息

- 回放：防守记录里存这场的布局副本、部队、种子、操作，浏览器拿到后在 BattleScene 里按记录的操作重演（玩家点的不算），到结束拍停；规则版本变了的标"旧版本，可能放不对"。
- 通知：平台没有推送，打开游戏时查一次，"你不在时被打了 N 次"列出每次的对手、星数、掉了多少，带"看回放""复仇"。
- **地雷**：快照里带地雷、只是不画（`BBuilding.revealed`），服务端重放结算（原第 5 节的选项 A）。懂行的人能从网络包里看到地雷位置；作弊最多是躲开地雷，抢多少仍由服务端算、有封顶。

### 5.9 匹配顺序和攻防统计

- **匹配偏同级**：评估（2026-10-28）发现防守方主寨比进攻方高一级时，进攻方胜率很低。`Harbor.pick` 把候选分两档：先找主寨同级和低一级的（防守方主寨 ≤ 进攻方），这一档里一个合格的都没有才找高一级的。
  奖杯区间、护盾、新号保护、锁、24 小时冷却、在线排除这些条件两档都一样，只改先后；高两级以上仍然不给。每档内部沿用「rand 定起点、往上往下取 `PICK_LIMIT` 个再挑」。流浪海盗岛的兜底不变。
  找到比自己主寨高的对手时，对手卡片上标一个红色的「更强」，让玩家知道这场难。
- **统计口径**（只读，不加客户端遥测）：真人对真人的每场攻防在服务端 `finish` 重放结算后，由 `Harbor.tally` 累进一行汇总（`pvp_stats` 表，单独一行 JSON，不进匹配索引；
  `settleAt` 里 `upsert` 已写满 2 行，所以 `tally` 是单独的 RPC 方法，自己写 1 行）。汇总不含 userId、昵称、raidId，只有计数。
  - 维度：主寨差（防守方 − 进攻方，−2 以下并成 −2、+2 以上并成 +2）× 进攻方主寨等级 → 场数 `n`、0/1/2/3 星各多少场 `stars`、≥1 星场数 `ge1`、平均摧毁率 `avgPct`；另有总场数 `total`、统计开始时间 `since`。
  - 放弃（`cancel`、没交就又找对手、过期按空打结）只记 `cancelled`，不进格子；流浪海盗岛不记；重复交 `finish` 只记一次。`counted` = `total` − `cancelled`。
  - 看法：管理员登录平台后直接打开 `/games/haidao/api/pvp/stats` 看 JSON（没登录 401，不是管理员 403，单独部署 501）。
  - 用法：先攒到约 200 场（`counted`）再看各主寨差格子的 `ge1 / n`，决定要不要加强进攻方兵种；样本不够不改数值。

### 10.1 一局怎么打（2–4 分钟）

- **关卡岛**：战役的每一关是一张写死的岛（9 张图、每张出两关），路线、木台、驻守台、障碍都由关卡定，不读玩家自己的布局，所以同一关对所有人一样难，路线也看得懂。敌人从登陆口上岸，沿流场去最近的**宝藏箱**；墙能砸但代价高（绕路的 7 倍），工兵专炸挡路的墙，鹦鹉群直线飞。
- **驻守台**（每关 1–3 个，`TdIslandLevel.garrison`）：开局从自己基地的防御塔里挑一种放上去。阶 = 基地同类塔最高等级折算（1–3 级 1 阶、4–6 级 2 阶、7–8 级 3 阶，`garrisonTier`），封顶这座台写的上限阶；分叉沿用基地那座塔选的。之后和木台上的塔一样能升、能卖。默认挑「这关推荐」（画面层 `garrisonrec.ts`：按这一关敌人的护甲占比挑克制的伤害，有船时射程够远的加分，几座台尽量不重样；没进选塔面板就直接开打的入口也用它），"空着"也是一项。规则核心的 `tdAutoPicks`（只按阶挑）只给配平模拟和指纹锁的养成开局用。
- **木台**（4–10 个）：局内金币造，从 1 阶起，只能造基地已经解锁的塔（主寨等级到了，`tdUnlockedTowers`）。一部分木台被沉船压着，清掉才能用（10.1 经济）。
- **基地加成**：同类塔在基地的最高等级每级 +2% 伤害，封顶 +10%（`baseBonusPct`）。养成好的玩家多一两座免费塔、伤害最多 +10%，难度主体仍由关卡定。
- **塔的阶**：1 → 2 阶花造价的 80%，2 → 3 阶花 120%；3 阶才选分叉（先 3 级那档、再 6 级那档）。阶的数值在 `TD2_TOWERS`，界面的等级显示用代表等级 2 / 5 / 8（`TD_TIER_LEVEL`）。
- **宝藏和星数**：一局 20 枚。敌人摸到宝藏箱拿走 1–3 枚掉头回船，半路被打死就掉在原地；地上的宝藏英雄走过去立刻捡回，5 秒没人捡自己滚回箱子。一枚没丢 3★，丢 ≤ 3 枚 2★，丢 ≤ 10 枚 1★，丢到 11 枚当场结束、算输（`TD2_STAR_LOST`、`TD2_LOSE_AT`，对所有守岛玩法都生效）。
- **波次和预告**：每关 8–12 波。每波开打前有倒数，倒数一开始就预告下两波（`tdPreview(s, 2)`）：这一波走哪几路、每路什么敌人多少个、各护甲的占比和"建议：炮弹"这类提示（第一波全是布衣时建议只会是「火」，可喷火射程短、后面打不了重甲和飞的：照着造就输的九关写了开局造法 `opener`，第一张卡改成「先造：火枪塔、臼炮」这样的造法、木台标金圈；只给画面读，规则和机器人不读，不进指纹，不升规则版本）；地图上画出路线（`tdRoutes`）。首领波前多给 10 秒倒数、预告变红。机器人也只读这份预告，不读波次表。
- **局内经济**（只在这一局有效）：开局一笔，打死敌人、清障、叫波都给。花在：

| 用途 | 规则（数在 `TD2_ECON`） | 取舍 |
|---|---|---|
| 造塔、升级 | 见上 | 覆盖面还是单点强 |
| 卖塔 | 退已花金币的 70%，木台空出来 | 按预告换克制，代价三成 |
| 清障 | 花 60 金马上清，或让英雄去打（打完给 30 金） | 先多一个塔位还是先造塔 |
| 修墙 | 一段 25 金 | 小额救急 |
| 叫下一波 | 奖励 = ⌊下一波击杀金 × 剩余倒数 ÷ 这段倒数 × 60%⌋，剩下的倒数一比一抵英雄技能冷却（`tdCallBonus`） | 用两波叠在一起的风险换钱和技能 |

  关卡给的总金币按"木台全造到 2 阶、一半升到 3 阶"来给，不够全部升满。
- **守岛英雄**（数值在 `TD2_HERO`，每级 +8%，`tdHeroStats`）：没被指挥时自己守：站到当前威胁最大那条路的路口（路线上离宝藏 4 格），永远不站在木台上（规则版本 14）；要指挥就先选中英雄（点英雄或底栏英雄钮）再点地面（点的地方就是守点，之后一直听玩家的，倒下复活后重新自己守；没选中时点地面什么都不做），守点附近主动迎击（10.2b），自动打最近的敌人（枪弹），最多同时缠住 3 个地面敌人，多的绕过去；倒下 12 秒后在宝藏箱旁复活。技能按"这一关每波平均"写成相对值，各关一致：
  - **拒马**：在英雄 4 格内的路上放一道，挡周围 3×3 格 5 秒，地面敌人过不去只能砸（血 = 一波平均敌人总血的 15%，`tdBarricadeHp`），冷却 20 秒；
  - **炸药桶**：扔 5 格内，爆破伤害 = 每波平均单个敌人血量 × 2.5（`tdBombDmg`），半径 1.8 格，冷却 25 秒；
  - **号令**（被动）：英雄身边 3 格的塔攻速 +15%；
  - **锚钩**（规则版本 20，英雄 8 级起，只在战役和海盗来袭，`core/tdhook.ts`）：钩 5 格内一个敌人，钩子飞 4 拍，再朝英雄拉回最多 3 格（每格 2 拍，一拍挪半格），拉完定住 1 秒，冷却 25 秒。
    补的是"敌人抢到宝藏往回跑时只能靠打死它"这个空当：正往船上跑的也能钩回来，宝藏还在它身上。船长、海盗王（首领）和海上的船钩不动。
    拉的路线全是整数格：朝英雄所在格按 Bresenham 一格一格走，不进英雄脚下那格；地面敌人碰到墙、建筑、水面、拒马挡的格就停在前一格，斜走时两侧任一格挡住也停（和流场一样不从两格之间的缝挤过去），飞的不挡。
    悬赏守岛（英雄 3–6 级）、大潮（周榜，英雄 5 级）、护航（有实盘）都没有锚钩，那几种模式和规则 19 逐局一样。英雄不够 8 级时技能栏照样摆出锚钩钮、锁着写"8级"，军械所的英雄一行也写明。
- **第二个英雄航海士**（规则版本 23，`core/tdnav.ts`，数值在 `TD2_NAV`、`TD2_NAV_SKILL`）：守岛第一章每关至少 1 星后解锁（`navUnlocked`），开局前在驻守台面板或海盗来袭卡片上切换，存在 `Profile.heroPick`（只认 `'nav'`，没解锁的存档读进来时删掉），和船长共用英雄等级。只在战役和海盗来袭（`navEnabled`：`heroKind === 'nav'`、规则 ≥ 23、模式是 campaign 或 home）；悬赏守岛、大潮、护航第一版不开放，攻防的驻岛英雄仍是船长。
  船长靠挡、炸、拉处理敌人，航海士不碰敌人，只**放大塔**和**多挣钱**，漏怪只能靠塔和走位补：
  - 身板：血、伤害同船长，射程 3.5 格、移速 7（船长 2.5 格、6），没被指挥时的站位、缠住人数、复活都和船长一样；
  - **急射旗**（技能一）：插在英雄 5 格内一点，圈心 2.5 格内（按塔中心算）的塔 12.5 秒装填减半（攻速翻倍），冷却 15 秒；船长的号令在她的局里不生效，由急射旗代替；
  - **重赏**（技能二）：画在英雄 6 格内一点，半径 2.5 格，8 秒里倒在圈里的敌人击杀金 ×2（和战书相乘，赏金船的赏金走 `payBounty`、不翻），冷却 30 秒；
  - **精打细算**（被动）：叫波奖励的金币部分 ×1.5（`tdCallBonus`；抵冷却那部分不变）；
  - 8 级没有第三技能，只换外观；两个技能的冷却直接用 `kegReady`（技能二）和 `barricadeReady`（技能一），叫波抵冷却、补给箱刷新技能都不用另写，`TdHero` 的注释写明。
  方案里还试过重赏圈减速、她的枪打中减速、圈里的敌人多挨打，模拟下来都让两人在个别关差到 40–60 点而且不稳（td10 的减速把地面敌人拖在塔前，正好撞上下一波的鹦鹉），按"能不加就不加"都没上，配平数见 `docs/balance-haidao.md`。
- **塔怎么挑目标**：见 10.2b。地雷炸完 20 秒重新埋好。
- **海盗特色**：落潮时多露出一条登陆路（10.6d）；地上的火药桶被打中会爆炸并引爆相邻的，敌我都炸；沉船和木桶挡路，打掉给金币。

### 10.2 一张克制表

伤害类型是塔的固有属性，护甲是敌人的固有属性，规则核心只有这一张表（`COUNTER`），界面原样显示（谁打哪种伤害、谁穿哪种护甲，界面从 `TD_TOWER_DAMAGE`、`TD_ENEMY_ARMOR` 和英雄、火药桶等几个常量现算，不手写名单）：

| 伤害 \ 护甲 | 布衣（水手、水手长、大副、工兵、掷弹兵） | 重甲（铁甲、船长、盾兵） | 木船（分裂小艇、小艇、雾船） | 飞禽（鹦鹉群、鹦鹉王） |
|---|---|---|---|---|
| 枪弹：火枪塔、鱼叉炮、狙击塔、英雄普攻 | 1 | **0.5** | 1 | **1.5** |
| 炮弹：加农炮、臼炮、火箭塔、震荡炮 | 1 | **1.5** | 1 | 0 |
| 火：喷火塔、燃烧弹和火油留的火 | **1.5** | **0.5** | **1.5** | 0 |
| 爆破：火药桶（地上的、英雄扔的）、地雷 | 1 | 1 | 1 | 0 |

- 倍率 0 的不能瞄准。没有"穿甲""减伤"这类开关，打不打得动、打不打得到全看这张表。
- **界面怎么讲这张表**（玩家原来看不懂抽象的"伤害 × 护甲"矩阵）：格子写人话，1.5 = "多打一半"（绿）、1 = "照常"、0.5 = "只打一半"（橙）、0 = "打不到"（灰），表上一句"每座塔打一种伤害，每个敌人穿一种护甲"带三个色块；行头是伤害加属于它的塔的小图，列头是护甲加穿它的敌人头像（矮屏放不下小图就只留名字），表下按名字列出每种伤害有谁打、每种护甲有谁穿。塔卡写"炮弹 · 克 甲 船"，敌人图鉴每种敌人一行"水手 · 布衣：火打它多一半"，首次见到的提示卡同一个说法；徽记悬停（手机上点一下）出这一类的说明。
- **雾**不是护甲，是状态：雾船和雾区里的敌人，要被灯塔或英雄照到才能被瞄准；爆破、地上的火不用照亮。
- **例外只有两条**（`TD_BRANCH_DAMAGE`，写在分叉卡上）：火箭塔"高射"能打飞禽（按 1 算）；臼炮"燃烧弹"留的火按"火"算。
- **价格拉平**：同阶各塔"每 100 金单体秒伤"差 ±10% 以内，溅射塔按平均打到 2 个折算、单体秒伤压到单体塔的六成（`TD2_TOWERS` 的注释有口径）。
- **分叉在守岛里的解释**（`content/tdbranches.ts`）：分叉 id 和基地上选的一样，效果按守岛自己的一套算；和 `branches.ts` 不同的只有加农炮"穿甲弹"改成"打重甲再加三成"、火箭"高射"能打鹦鹉。登陆战和攻防快照仍只读 `branches.ts`。

### 10.2b 寻敌、攻击和走位（守岛规则版本 8 起、进攻 9 起，以 `src/core/combat.ts`、`src/core/td.ts`、`src/core/battle.ts` 为准）

进攻和守岛共用 `combat.ts` 这一套规则（docs/v2.md 第 3、4 节）。进攻从规则版本 9 起接入（`battle.ts` 的 `stepDefensesCombat`），差别：rank 用距离（塔中心到兵的距离平方，没有"拿着宝藏"这类优先级类），加农炮在进攻里是单体、伤害跟着兵走，弹丸只画到提前量落点；海怪按 8 拍估提前量；兵的错开是 ±2 档 × 12 单位（登陆的兵抱团走、贴着建筑拆，偏 24 仍离建筑占格有余量）；臼炮、火箭仍按原来的弹速飞（臼炮每拍 14、火箭 30），不夹 20–28 拍；必死不按克制折算（进攻没有克制表）。"不打必死的"和火箭轮发两边一样。进攻另有：兵追驻岛英雄被建筑挡住就 1 秒内不理英雄，信号弹生效期间不被英雄引走。每条都有单测：`tests/combat.test.ts` 测规则本身，`tests/td-rules.test.ts`、`tests/raid-combat.test.ts` 在整局里测。

| 规则 | 怎么定 |
|---|---|
| 射程 | 塔中心到敌人中心的距离在 [最小射程, 射程] 以内才打（`inRing`）；界面画的圈用同一个数（`tdTowerRange`、造塔前用 `tdBuildRange`） |
| 挑目标 | 按优先级类排：防空的先打飞的 → 拿着宝藏回船的（护航是正在咬船的）和工兵关里会炸哑塔的工兵 → 其余；同一类里离宝藏箱路程最近的（走在最前面的），再按 id（`rankTargets`） |
| 不打必死的 | 已经发出、还没落地的直射伤害（按克制折算）够打死的敌人算"必死"，排到所有人后面；全都必死才接着打。只在装填好、要开火的那一拍算，装填中照旧盯着锁定的 |
| 锁定 | 上一个目标还在射程里、优先级类不比最好的低，就接着打它，直到它死、走出射程、必死，或出现更高一类的；不因为别人往前挪了一点就换 |
| 多发（火箭） | 第一发打锁定的，其余按同一个顺序往下挑；人不够就从头再轮 |
| 飞行时间 | 距离 ÷ 弹速向上取整、至少 2 拍（`flightTicks`）；臼炮按距离夹在 20–28 拍（1–1.4 秒），火箭每拍 50、喷火 60、其余 35 单位 |
| 提前量 | 炸点 = 敌人这一拍的速度 × 飞行拍数往前估，最多 3 格；一拍位移超过 0.3 格（被拉回）不估（`leadPoint`）。溅射在炸点结算；直射追着敌人走、落地时还活着就中 |
| 开火事件 | 带目标 id 和落点（`shoot` 的 `target`、`x1`、`y1`），画面弹道飞到落点；英雄开枪也发，`id` 记 -1 |
| 走位 | 同一条路上按 id 错开：横竖各 5 档 × 0.18 格（最多偏 0.36 格，仍在格子里），相邻 id 横竖都不同档（`laneOffset`），不叠成一个点 |
| 英雄守点 | 玩家选中英雄后点的地方是守点；守点 4.5 格（`TD_HERO_GUARD`）内有能打的敌人，就朝最近的那个走到射程八成处站住开火；射程内先打拿着宝藏的，其次最近的，同样锁定；没了就回守点。手动走位那一趟走完前不被守点逻辑拽走 |
| 画面（`src/view/tdfx.ts`、`TdScene.ts`） | 点开塔画 `tdTowerRange` 的圈（死区压暗画斜线），塔卡悬停预览 `tdBuildRange`；选中的塔画到 `aim` 的虚线和准星，开火闪准星；直射弹每帧追目标精灵，溅射弹飞向落点；炮管只跟 `aim`；英雄朝目标转身，`id -1` 的开火事件播攻击和弹道。画面不自己挑目标 |
| 确定性 | 全是整数运算、按 id 定序，`tests/td-golden.json` 的金样随规则版本更新 |

**规则版本 12 起：进攻兵的寻敌和站位**（只管登陆战的兵，`battle.ts`；`s.rules >= 12` 才生效，旧版本逐位不变）

| 兵种 | 挑目标 | 站哪里 |
|---|---|---|
| 掷弹兵 | 在"射程 + 3 格"内的建筑里，给每座打分 = 它落点半径（溅射）内所有非墙建筑之和，防御建筑记 3、其余记 1（不含墙、地雷、焦油、装饰）；分高的先，同分离得近的先，再按 id。一座都没有就退回"最近的建筑"。上一个目标还活着、没出射程就不换（锁定，免得来回抖）。原来是"全岛最近的建筑" | 照旧走到射程边缘就停（不再往前贴）；路被墙堵死才往墙上扔（只算三成），目标够得着时先扔目标，不扔墙 |
| 盾兵 | 照旧：最近的防御；没有防御再找最近的建筑 | 走在远程兵前面：同队的火枪手、鱼叉手、火炮兵、掷弹兵要"往前挪"（目标不在射程里）时，若离目标比最近的活盾兵近 1.5 格以上，就原地等；最多连等 60 拍（3 秒）就放行，所以盾兵被墙卡住、被震晕、死了都不会卡死队伍。已经在射程里开火的不受影响 |
| 船医 | 在自己 6 格内的受伤友军里挑血量比最低的（同比按 id）；6 格内没有就挑全队最近的受伤友军；没人受伤就跟最近的友军（不再跟 id 最小的）。回血每次给射程内血量比最低的 4 个，同比按 id（原来按兵的序号） | 走到离伤员 `射程/2` 处，但从"离伤员最近的防御"的反方向靠近（站在伤员背后），不抢到伤员前面去；不是目标的兵让开路不用管，没有路径就直线 |
| 船长 | 不变（进攻里没有指挥光环，光环只属于守岛的敌人船长）：近战，打最近的建筑 | 同水手 |
| 其他 | 不变 | 不变 |

为什么这么定：掷弹兵的卖点是手雷越墙一炸一片，按"最近建筑"选目标会把雷浪费在单个金矿、木场上；按溅射内建筑数加权，就会去炸扎堆的、尤其是扎堆的塔。盾兵最慢，不给远程兵"等盾"的规则，盾只是碰巧在前面；等待有上限，换来的是盾真的在前面挡枪。船医追全队最低血的人会一路追进火力网，改成"附近最缺的"并站在伤员背后。
单测锁住：掷弹兵在"孤零零的最近金矿"和"稍远一点的两座塔"之间选塔；盾兵在前沿（行军时名次百分位低于同队远程兵）；船医选 6 格内血量比最低的、站在伤员背后；版本 11 的回放逐位不变。


- 实测指标表见 docs/balance-haidao.md 第 3 节。

掷弹兵改打扎堆的塔后更容易先被打死，每局扔的雷变少（W8 龟缩 38 → 8 颗），平均摧毁率在 6 局的噪声内没有系统变化；来回掉头、路程 / 直线比、换目标次数没有变坏。战役的样例部队里没有掷弹兵和盾兵，战役配平不受影响。

关卡里新旧两套组并排写（`TdGroup.since` / `until`），`createTd` 按局的规则版本挑（`levelForRules`），所以 15 以前的局逐位不变。
td07 从第 6 波起：从第 4 波起时，稳机器人在 5 号木台挑塔看的预告里水手少、水手长多，挑狙击塔，可第 5、6 波是小艇、水手长、水手混着来，臼炮的溅射守得住、狙击守不住（丢宝几乎全在这两波）。预算 108% 到 110% 之间它改挑臼炮，三星率从 70% 跳到 88%，没有一个预算既对上现在的 65%、又离这个陡坎远。精英晚两波出，预算 100% 时三星率 68%，和规则 14 下一样，±4% 预算 67% / 73%（每格 500 局）。
td16（船长的怒火）用大副（规则版本 17）：它有狙击塔和三座 3 阶驻守台，换水手长时高单发打 360 血不浪费，预算 100% 稳三星率 48% → 85%，要加到 130% 才回来，那时一局人反而更多。护甲是按伤害种类的倍率，只是把"狙击吃掉它"换成"加农吃掉它"，所以换成死后分裂：
本体被高单发打掉后散出的 90 血水手又让它每发溢出一大半，挤在一处给溅射收。预算 100% 时稳三星率 48% → 76%（每格 200 局），比水手长那版难得多，但仍比原来简单；预算加到 105% / 110% / 115% 是 75% / 74% / 77%，加预算只多人不加难，按"宁简勿难"保持 100%，落在 td14、td17、td18 中间。
一局从船上下来的人 602 → 497、同屏最多 68 → 50。"只造狙击"在原来的 td16 上就守不住（1%），大副版 2%，这个对照只说明狙击单靠自己不行，不说明是大副带来的。

### 10.4b 海盗来袭（守自己的岛）

- 选关页入口，守下第 1 关（≥ 1★）解锁。用玩家自己的岛和布局：常驻塔照常开火（按基地等级表），木台、火药桶从 `TD2_HOME` 的候选位置里挑不压建筑的摆（`placeTdLevel`），英雄按研究等级。
- 波次按主寨等级对应的难度现生成（`tdHomeWave`：`waveBudget(levelByHq[主寨], w)`），一共 `TD2_HOME.maxWaves` 波，敌人按战役教机制的顺序陆续出现，落潮路第 5 波起开，每 10 波最后一波是船长首领波；丢到 11 枚宝藏就结束。
- **不算星、不进难度曲线**：每撑住一波给"这个主寨等级三星一局"奖励的 `perWavePct`%，和战役共用每天的守岛收入上限（`settleTdHome`），满了照样能打、结算页写明。结算标题写"撑住 N 波"，撑不到 5 波按失败的样式演。
- **加难档**（规则版本 20，`TD2_HOME.hard`）：主寨 6 级起入口卡上多一颗「加难」开关，默认关，开局时记进 `TdHomeGen.hard`（回放能复现；不选时生成参数里没有这个字段，普通档和规则 19 逐位一样）。
  加难：等效关下标 +3（每波敌人约多 9%），第 8 波起水手长、鹦鹉王进敌人池，第 12 波起再加大副；每撑住一波给 8%（普通档 6%），照样和战役、护航共用每天的守岛收入上限。结算标题后挂「加难」标签、下面一行写多几成，玩家看得出奖励为什么多。
  加难的取值看下面「撑住几波」那张表的加难列。初稿是下标 +6、精英第 6 波起：主寨 7 级中位数只撑 2 波、平均奖励反而少 34%，没人会选，按"宁简勿难"减到现在这样。
- **带谁**（规则版本 23）：解锁航海士后入口卡上多一颗「带：船长 / 带：航海士」，和选关页驻守台面板是同一个开关（存档的 `heroPick`），开局时 `tdHomeSetup` 按它写 `heroKind`（10.1 守岛英雄末尾）。
- **登陆点按布局挑**（规则版本 21，`tdhome.ts` 的 `homeLanes`）：`TD2_HOME.lanes`、`tide` 只是候选的原位置。开局摆好玩家的岛后，每条路先看原位置到最近宝藏箱的路程（敌人寻路的流场，砸墙按墙代价算），≥ `TD2_HOME.laneMinPath`（80，约 8 格空路）就不动；不够就在同一条海滩上挑离原位置最近、够远、没被别的路占的格（一样近取坐标小的），都不够挑最远的。
  为什么：登陆点原来写死在岛边，主寨 8 级的推荐布局（spread）把一个宝藏箱摆在 (10,1)，北路登陆点 (10,-2) 离它只有 2 格，海盗一上岸就抢到，塔来不及打，满配也只撑约 4 波（turtle 的西路离箱子 5 格，同样吃亏）；同一套 8 级的敌人打 6 级的岛能撑满 20 波，问题在路程不在敌人。挪完 spread 的北路到 (3,-2)、turtle 的西路到 (-2,14)，trap 不挪。
  开局预告卡写的路名、地上的登陆旗、屏边箭头都读 setup 里挪过的位置，画面层不另算。规则 20 及以前开的局不挪（`TdHomeGen.rules` 定），旧回放和 `v20-home-*` 指纹逐位不变；`td-golden.json` 用成长档的岛录的 `v21-home-*` 键没有路要挪，和 `v20-` 逐个相同，挪动由 `tests/td-home.test.ts` 锁住。
- **撑住几波**（`node tools/td-home-sim.ts --n 50`，推荐布局满配的岛，规则 21，普通 / 贪两种机器人取平均，2026-11-19）：

  | 主寨 | spread 普通档（平均 / 四分之一 / 中位） | turtle 普通档 | trap 普通档 | spread 加难 | 加难的平均奖励比普通（spread） |
  |---|---|---|---|---|---|
  | 6 | 20 / 20 / 20 | 19.9 / 20 / 20 | 20 / 20 / 20 | 20 / 20 / 20 | +33% |
  | 7 | 13.2 / 7 / 14 | 15.5 / 14 / 16 | 16.8 / 14 / 19 | 11.8 / 2 / 12 | +18%～+20% |
  | 8 | 12.8 / 8 / 12 | 16.9 / 17 / 20 | 17.6 / 16 / 18 | 9.4 / 6 / 8 | −3%～−2% |

  规则 20 时 spread 主寨 8 级普通档平均只撑 4.3 波（7 级 13.2，陡降）；挪完三套布局 8 级都和 7 级持平或更高，曲线不再陡降（trap 本来没有贴着箱子的路，数字和规则 20 一样）。没动的两处（宁简勿难）：主寨 6 级满配三套都打满 20 波，偏松；spread 布局路边木台偏少，7、8 级的四分之一位只有 7–8 波。spread 8 级的加难档平均奖励比普通档还少两三个百分点（撑的波数少了约三成），turtle、trap 8 级加难多 6%～39%。

### 10.5 悬赏守岛（实盘）

和悬赏出海（第 4 节）同一个原则：**岛按档位和种子固定**（固定布局、固定常驻塔和分叉、固定英雄等级），不看玩家自己的岛和养成；规则和战役同一套（克制表、预告、局内经济、星数区间）。

- **只有局内决策影响结果**：英雄走位和放技能、临时塔造在哪、选什么分叉、卖塔清障、什么时候叫波。期望因此只和打得好不好有关，模拟器量出来的就是所有人的期望。
- **档位**（钱包的 small / mid / big / lux，一份 2,000 / 10,000 / 50,000 / 200,000）：

| 档位 | 岛模板 | 敌人 | 电脑多强 |
|---|---|---|---|
| 小 | 小岛，一个宝藏箱，两条路 | 水手、铁甲 | ★ |
| 中 | 中岛，落潮多一条路 | 加雾船、分裂小艇 | ★★ |
| 大 | 大岛，两个宝藏箱 | 加工兵、鹦鹉 | ★★★ |
| 豪华 | 大岛，三个宝藏箱，临时塔位少一个 | 全部敌人加首领波 | ★★★★ |

  模板在 `src/content/tdlive.ts`，常驻塔的种类按克制表配齐（防空不再靠不选分叉的火箭）。
- **结回**：倍数（万分之一，`src/core/tdlive.ts` 的 `TD_LIVE_TIERS.bp`）`[0★ 按撑过的波数折算的满值（最多 0.79 份）, 1★, 2★, 3★]`。形状：1★ < 1.0 倍（守得勉强算小亏）、2★ 1.1–1.3、3★ 1.4–1.8，档越高三星越值钱，相邻星级差不超过 0.5 份，一场最多赢 3 份、最多输 1 份。0★ 就是丢到 11 枚，按"岛上宝藏最后一次归零或丢到 11 枚那一刻已经清完的波数"占总波数的比例 f，走凹曲线 1 − (1 − f)³ 乘满值：撑过前几波就拿回大半，撑到后面才接近满值。
- **配平**：目标是 docs/balance.md 第 2 节四档区间（小 小白 +0.05～+0.15、赢 ≥ 50% / 普通 +0.20～+0.40；中 −0.05～+0.05 / +0.10～+0.20；大 −0.20～−0.10 / 0～+0.10；豪华 ≤ −0.20 / −0.05～+0.05）。

### 10.6d 关卡机制（由关卡字段开关）

    机器人开打前 5 秒判断：落潮路占下一波人数四分之一以上、而且 0 号路被塔盖住的格数比落潮路多两成才关（只看人数就关会把敌人赶进没塔的雾路，td11 实测三星 37% → 5%）；小白一半的时候想得起来。
  - **岸防老炮**（`battery`，td17、td18，`TD2_BATTERY`）：东南角沙滩上一门旧炮。点「老炮」再点地面，1 秒后落一发，伤害和炸药桶同一个口径（这一关每波平均单个敌人血量 × 250%），半径 2.2 格，
    按爆破算（打不到飞的，雾里照打，炸障碍不炸自己人），全岛都打得到、不看英雄站哪；冷却 30 秒，开局就能打。落点在格子外不打、不进冷却。
    先试的 400% / 25 秒让 td17 稳机器人三星 23% → 100%，章末关一炮清场没意思，按炸药桶的伤害、拉长冷却后约 80%。
    机器人冷却好了就打炸得到最多地面敌人的那一点（≥ 4 个或圈里有船长，同样多打走得最靠前的）；小白每秒一半的机会想起来，≥ 3 个就打。
- **第四章：远洋**（规则版本 18，td19–td22）：
  - **水面**（`TdMapDef.water`、`bridges`）：关卡岛上的一片水，`createTd` 把它记成封死的格子（谁都走不过、不能造塔），所以地上的敌人只能绕或过桥；飞的照飞。分裂、首领召人落在水里时挪到最近的岸上（`offWater`）。
    双子岛（J）南北两座岛中间一道海峡，只有一座两格宽的桥，北边两路都得过桥；桥是很强的卡口（只靠它 td19 预算翻倍也是 100% 三星），所以后岛（东南角）另开一路短的上岸路，第 3 波起来水手，逼玩家分一点塔到后面。
    火山口（K）中间一口火山湖，北路绕湖走两边，东西两路贴着湖岸。
  - **军医**：每秒（`tick % 20 === 0`）给 2 格内掉了血的同伴回 3% 最大血（至少 1），不给自己、不给船长回；回血飘绿色「+」。狙击塔挑目标时把军医和船长排在第一档，所以"有狙击就先点掉军医"不用玩家操心。
  - **炮艇**（`TdEnemyDef.shell`）：出生在登陆点就停住，`until` 到了开走（`sail` 事件，不算漏、不拿宝藏）。冷却好了就打 9 格内最近的一座塔（同样近按 id），炸哑 3 秒（`shell` + `jam` 事件），只砸哑不拆塔：拆塔会让第四章变成"白造塔"，砸哑只是一阵子不打。
    海上的目标只有射程 ≥ `TD_SEA_RANGE`（8 格）的塔打得到（`targetable` 读塔的射程，英雄不传射程、打不到）。机器人看到预告里有炮艇、木台上能打海的塔不到两座时，先在臼炮、鱼叉、火箭、狙击里按克制挑一座（`counterKind`；没有炮艇的关不走这条，旧关的机器人逐位不变）。
  - **海盗王**（规则版本 19，td24 最后一波）：首领，一波固定 1 个、份额写 0（和船长同一套）。停在海上的登陆点，和炮艇一样炸哑塔、只有射程够远的塔打得到；停泊期间每 `drop.every` 拍在身边放下一船人，血掉到一半叫来两艘炮艇，
    沿它所在的那条岸边一左一右摆（`stepKing`）；停够 100 秒开走，不拿宝藏。狙击塔把它和船长、军医排在第一档。
  - **难度**：平台期，按"宁简勿难"稳机器人三星靠 55%、小白至少一星 ≥ 65%：td19 60% / 83%、td20 57% / 91%、td21 62% / 85%、td22 52% / 67%、td23 53% / 92%、td24 54% / 88%（200 局）。
    双子岛的两关只造臼炮比混着造好（桥口溅射通吃）、td22 的 tall 守住率比 focus 低 18 点（炮艇砸哑少塔吃亏大），试过的改法和为什么不硬调见 docs/balance-haidao.md 第 5 节。
- **友军巡航船**（规则版本 19，`fleet`，td23、td24，`TD2_FLEET`）：技能栏多一颗「援船」（快捷键 4），一按就来、不用瞄。船从岛外 1.5 格的海上一圈里离海上敌人（炮艇、海盗王，有好几艘挑编号最小的）最近的地方进场，
    没有海上敌人就从离宝藏箱最近的地方进场，顺时针开半圈，用 15 秒；每秒朝船边 4 格内最近的地上或海上敌人开一炮（打不到飞的），0.5 秒后落地，半径 1 格，伤害和炸药桶、老炮同一个口径（这一关每波平均单个敌人血量 × 120%）。
    叫一次冷却 60 秒，开局就能叫；船在海上时再按没用。机器人看到海上停着两艘以上的船（海盗王一艘就算）就叫，小白一半的时候想得起来。船就是玩家自己的旗舰那张图。
- **找路**：守岛和登陆战共用 `src/core/grid.ts` 的格子流场（守岛 `flowField`、登陆战按自己的墙代价和终点调 `flowFrom`，`nextCell` 共用，0.28.3 起）；`tdRoutes` 给每条开着的登陆路到宝藏箱的格子序列，墙被打破、修好时重算，界面和机器人都读它。

### 10.6e 大潮无尽（以 `src/content/tdtide.ts`、`src/core/tdtide.ts`、`src/net/tide.ts` 为准）

选关页多一个"大潮无尽"入口（通过第一章第 3 关、≥ 1 星解锁，没解锁显示锁和条件）：每周一张固定的图，所有人守同一座岛，波次无限，丢到 11 枚宝藏才结束，比谁撑得久。

- **周**：北京时间的 ISO 周（周一 0 点换周，年份按这周的周四算）。`beijingIsoWeek(ms)` 返回 `{ year, week }`，算法照平台 `platform/src/weekly.ts` 的 `beijingIsoWeek`，只是年份用整数算法（规则核心不许用 `Date`）；
  单测把 2019–2034 每 3 小时一个时刻都和平台算法逐个对齐，另测跨年边界（2026 年有 53 周）。榜名 `tideBoardId` = `week-2026-W44-tide`。
- **图和种子**：周种子 = `hash32("haidao-tide-2026-W44", 1)`；用同一个标签再各哈希一次，选 4 张手写模板里的哪一张、是否左右镜像（所以不是严格轮换，一年里四张都会轮到）。种子也是一局的 `setup.seed`（登陆点抖动），所以全世界这周一局的敌人出场逐位一样。
  模板在 `content/tdtide.ts` 的 `TIDE_MAPS`，每张都是固定的岛：主寨 5 级、6–7 座 5 级常驻塔带分叉、一个宝藏箱、墙和地雷、5 个临时塔位、英雄 5 级固定，不看玩家自己的岛和养成（同悬赏守岛的原则：只有局内决策影响成绩）：

| 图 | 来路 | 特点 |
|---|---|---|
| 双口湾 | 北口、西路，落潮南边多一条 | 基础款 |
| 三叉滩 | 北、西、东三路，落潮在南 | 鹦鹉从东路绕后（`flank`） |
| 东风礁 | 西路、北路，落潮在东 | 喷火、鱼叉守口，近身火力强 |
| 回廊岛 | 北、南两头，落潮在西 | 塔分守南北，英雄两头跑 |

  每张图有自己的敌人血量底数 `hp`（写在图上），用来把四张图的难度拉到一个量级；调过之后改模板或 `hp` 都要重跑 `td-tide-sim`。
- **波次无限**：关卡字段 `endless(w)` 按波数现生成（`tideWave`，只由波数、周种子和路数决定，确定性），`waves` 只是已生成的前缀，开局和每开一波都往后补 6 波（机器人和预告条看得到后面几波）。
  - 预算：第 w 波预算点数和战役同一条公式 `waveBudget(TIDE_LEVEL, w)`、同一张敌人点数表 `TD2_ENEMY_POINTS`；主打一种解锁了的敌人占一半、再配一种占三成、其余补水手。
  - 解锁：水手第 1 波，铁甲第 3 波（w=2 起），分裂小艇第 5 波，雾船第 6 波，鹦鹉第 7 波，炸塔工兵第 9 波。
  - 首领波：每 8 波一个（第 8、16、24… 波），船长加护卫（三成预算），每 24 波多一个船长；首领血量过半发怒（召 6 个水手、炸哑最近 2 座塔 8 秒）。
  - 血量：每波再乘 `tideHpPct(w)` = 100 + 9w（第 10 波后每波再多 +3），用波次字段 `hpPct`，所以越往后同一种敌人越肉。
  - 机制：前三波只走北口 / 西路；落潮路从第 6 波起两波开、两波关（`tideOpen`）；雾区从第 9 波起才起作用（`fogFrom`）；工兵冲击波 3 格 5 秒（`sapperJam`）。
  - 一局最多 60 分钟（`maxTicks`），正常撑不到。
- **得分**：`tideScore(waves, kills)` = 撑过的波数 × 10000 + 击退敌人数（封顶 9999）。"撑过"沿用守岛的 `tdResult.waves`（宝藏归零或丢到 11 枚那一刻已经清完的波），击退数 = 被打沉的敌人（含分裂的小艇和召出来的水手，工兵自爆、空手回船的不算）。
  `public/weekly.json` 用平台的 `fields` 拆：`w` = ⌊分数 ÷ 10000⌋，`k` = 分数 mod 10000，显示"撑过 {w} 波 · 击退 {k}"（单测按平台的拆法验过）。
- **交分**（`src/net/tide.ts` 的 `submitTide`）：局结束时只交一次；登录了（`loggedIn()`）才调同域 `POST /api/scores`，体 `{ gameId: 'haidao', boardId: 'week-<YYYY>-W<ww>-tide', score }`，头 `Content-Type: application/json`、`X-Arcade: 1`、`credentials: same-origin`。
  周按**开局那一周**算（开局时存进 `TdData.tide.week`），跨周一 0 点打完的局也交开局那周（平台一天内还收上周）。返回 `{ best, improved }`：improved 为真，结算页提示"新纪录！已上榜"；
  429、503 提示"榜单忙，成绩没交上"；没登录、单独部署（501、404、401）、422、网断了都静默跳过，不报错。
- **浏览器本地记录**：`haidao.tide` = `{ week: "2026-W44", best: 分数 }`，只记这周最高，换周从 0 开始；选关页入口和结算页都显示"本周最好"。
- **奖励**：大潮不发金币木材、不记章节星数、不动存档，只上榜。守岛每日收入上限因此不会被绕开，也不接筹码。
- **界面**：入口显示第几周、这周的图名和我的本周最好；局中顶栏显示"第 N 波"（没有总数），预告条的潮汐提示不写方位；"回大厅 / 回岛 / 撤退"和别的守岛局一样随时可用（撤退按撑过的波数记成绩）。
- **规则**：和战役同一套（克制表、预告、局内经济、丢到 11 枚就结束），只是波次无限、宝藏不按星算；四张图的 `hp` 底数按新克制表配，目标普通机器人 15–25 波、小白不超过普通的 65%。
- **配平**：`node tools/td-tide-sim.ts --n 30`，四张图 × 两种朝向 × 两种机器人，每格 30 局，局序号当 setup 种子。同一张图的两种朝向会差几波（路线、塔的先后顺序不对称），单局的离散也大，看量级不看个位。
- **每周海况**（规则版本 22，`content/tdtide.ts` 的 `TIDE_MODS`、`core/tdtide.ts` 的 `tideMod`）：一周一条，按 `TIDE_MOD_ORDER` 轮换（按周一是第几周取模，相邻两周一定不同），只由周号算出来，所以同一周所有人守同一座岛、同一串敌人、同一条海况；榜名和得分编码不变。
  从 2026 年第 48 周（`TIDE_MODS_FROM`，北京时间 11 月 23 日周一 0 点）换榜起才有：`tideRules` 第 46、47 周钉在 21、第 48 周起用 22，周中不换规则（0.47.0 赶不上这个周一就把常量往后挪一周，只这一处）。剩下的风险是有人从上周开着旧页面跨过周一，打出来的是没有海况的成绩；排行榜本来不防作弊，不另做校验。
  选关页入口的标题后面写海况名（悬停提示写怎么回事），第 1 波的开波横幅、结算页「本周最好」那一行也写。

  | 海况 | 改什么 | 普通（平均波数） | 小白 | 小白 / 普通 |
  |---|---|---|---|---|
  | （无海况） | — | 21.3 | 14.8 | 69% |
  | 大雾周 | 雾区从第 1 波起就起作用 | 23.1 | 14.5 | 63% |
  | 富港周 | 开局金多五成，击杀金只给八成 | 21.7 | 13.7 | 63% |
  | 英雄周 | 英雄技能的冷却减半 | 24.4 | 14.8 | 61% |

  （`node tools/td-tide-sim.ts --n 30 --mod <海况>`，四张图 × 两种朝向 × 两种机器人，每条 240 局，2026-11-19。）方案里另有三条没过"普通 15–25 波、小白不超过普通的 65%"，按"不硬调"拿掉了：暴雨周（整局下雨，普通 15.2 / 小白 74%）、赏金周（每 4 波一艘赏金船，21.2 / 70%）、铁甲周（主打铁甲、炮塔伤害多两成，23.1 / 78%）。没有海况的基线本身也是 69%，这条线现在的大潮就没达到。

### 10.6g 关内事件（规则版本 22，以 `src/core/tdevent.ts`、`src/content/td2units.ts` 的 `TD2_EVENT` 为准）

战役里 12 关各多一件"这一局会碰上的事"，每件逼玩家做一种取舍；只由关卡字段 `events` 打开，规则版本低于 22 的局不建状态、遇到操作忽略，旧回放逐位不变。

- **挑波**：每关一条 `{ kind, from: 2, to: 6 }`，开局用这一局的种子另开一条随机流（`Rng(seed, 'td.event')`）在第 3–7 波里挑一波，不挑首领波（战书会把首领也翻多，事件压在首领波上太乱）；同种子同一波，每局不一样。预告卡提前一波写出来（`WavePreview.event`），开波横幅的副标题先说事件。
- **赏金船**（`bounty`，td04、td09、td14、td20）：开打 5 秒后从这一波第一条登陆路上岸一个挂悬赏令的水手，血量是同波水手的 3 倍，不抢宝藏，上岸就往离它最远的另一条登陆路跑（当"回船"处理）；打倒多给这一波击杀金的 40%（至少 30），跑掉没有损失、不算丢宝藏。要想的事是"英雄离开防线去追值不值"。机器人不去追（追要反复改英雄守点，追完回不到原来自己守的样子，误差比赏金大），塔打得到就拿，所以模拟里这四关几乎不变。
- **暴雨**（`rain`，td08、td10、td15、td21，火占比重大的关）：那一波开打到下一波开打之间，火的伤害只剩 80%、地上的火不烧，飞的速度只剩 85%。要想的事是"靠火守的路临时补别的塔"。初稿是火 50%、飞的 70%，td15 小白至少一星 71% → 64%，拆开看两项各掉 4 点，减到现在这样。
  画面（`view/tdrain.ts`）：全屏斜雨加压暗。手机帧率（390×844 @2x、CPU 降 4 倍、td08 下雨那一波量 8 秒，和 0.46.0 同一波背靠背各两次）：先做的画在 Phaser 画布里（雨丝、压暗两层整屏）少 15%–25%，合成一层后少约 10%，改成画布上面的 CSS 层（只动 transform）后 15.0 / 11.9 帧/秒对 0.46.0 的 13.9 / 13.9，一高一低、平均差 3%，在噪声里。开销在多铺一整屏，和雨丝画几道无关。
- **战书**（`dare`，td13、td16、td19、td22）：那一波的倒数里浮出一张卷轴，「接」「不接」两颗钮（默认不接，开打前随时改，命令 `dare`）；接了这一波每组敌人多 50%（向下取整，单个的首领、精英不会变成两个），这一波的击杀金翻倍。初稿是多 25%：贪机器人（一律接）三星率反而比稳机器人高 12–14 点，接战书等于白赚，加到 50% 后稳、贪差 ≤ 9 点。稳机器人这一局没丢过宝藏、木台全造满才接，小白一半的时候想得起来。
- **不放的地方**：第一章前三关（还在教基本操作）、每章的章末机制关（避免一关塞两件新东西）、悬赏守岛、海盗来袭、护航（实盘期望和每日收入不动）。
- **验收**（`node tools/td-sim.ts --level <关> --n 200`，规则 21 和 22 背靠背，2026-11-19）：每关稳机器人三星率变化在 ±5 点内，小白至少一星降不超过 3 点，稳、贪差 ≤ 10 点。

## 11. 寻宝航线（每日航线，娱乐 + 实盘）

一天一条航线，全服同一条、同一支船队，比宝分。一局三四分钟，有选择、有损耗、有终点开宝箱的高光，每天不一样。入口是出海面板的"今日航线"卡。

**规则**（`src/core/map.ts`，契约在 `maptypes.ts`，内容在 `content/maps.ts`；纯函数、整数，种子只由北京日期算）：

- 航线 4 层：第 0–2 层各两个节点二选一，第 3 层是终点宝岛。第 1、2 层各有一半机会把一个节点换成补给礁（补兵 / 补能量二选一）。岛从 12 座微型岛按层抽（可左右镜像），终点从 3 座宝岛里抽，同一条航线不重复。
- 船队从 4 个模板里按日期抽（雇来的船，兵种、等级、每船人口固定，不看玩家存档），所以每日榜可比。
- 每站一场登陆战，最多 50 秒（`MAP_STOP_TICKS`），到点按当时摧毁率结算。死掉的兵不回来；旗舰能量整条航线共用（开局 8、每站后回 2、上限 20）。出战前可以让一条船休整：这站不上，缺员补回一半。
- 每站宝分 = 岛的满分 × 摧毁率 + 每颗星 10。任何时候可以收航，已拿的宝分照算；船队打光按七成算。
- 终局星按宝分 90 / 150 / 200 定。`tools/map-sim.ts` 跑 60 天：普通机器人平均约 1.75 星、三星约 23%；小白约 1.4 星、约三成会打光。

**画面**：航线图页（四层节点、侦察图标、整备和补给礁）→ 登陆战一站 → 站间结算条 → 终点开宝箱（终点站拿到宝分时才开，金币按这站宝分飞出；没拿到就船回港）→ 结算页（星、宝分、各站明细、分享、再跑一趟）。

**存储与榜**：浏览器本地 `haidao.map` 记当天进度和最好成绩，刷新后接着走；结算往平台每日子榜 `daily-<北京日期>-map` 交宝分（多跑几趟取最好），分数显示写在 `public/daily.json`。

### 11.1 航线实盘

> 以 `src/core/maplive.ts`、`tools/map-live-sim.ts` 为准；每天 1 趟（`HAIDAO_MAP_DAILY`），合计上限见 4.0。

- **跑的就是今天的航线**：航线和船队仍是全服同一条（`routeOf` 只看北京日期），实盘不另改，每日榜照样可比。所以四档的难度一样，**档位只换结回倍数**：档越高，同样的星回得越少（选档卡不写"电脑多强"，写"同一条航线，档越高结回越少"）。
- 流程和娱乐一样（选岛、休整、补给礁、收航），进度另存 `haidao.maplive.run`、不碰娱乐的 `haidao.map`，不交每日榜；同一天刷新后接着跑，战斗中途离开那一站按 0 宝分；跨天了按当时的宝分收航结。
- **结回**：按终局星数（宝分线 90 / 150 / 200 不变）查表；0 星按宝分占 1 星线（90）的比例线性折算，最多回 0.79 份。四档三星倍数一样（1.55），档越高 0 星、1 星、2 星越少。
- 实测表（八格都在区间里，豪华档小白贴着上沿）见 docs/balance-haidao.md 第 6 节。

## 12. 护航（商船队，娱乐 + 实盘）

> 以 `src/core/escorttypes.ts`、`escort.ts`、`escortbot.ts`、`escortrun.ts`、`src/content/escortmaps.ts`、`escortlevels.ts` 为准；界面在 `src/view/escort*.ts` 和 `TdScene.ts` 的护航分支。

**一句话**：商船沿一条写死的航线从起点开到终点，海盗从沿岸登陆口上岸追着船咬；玩家在航线边的木台造塔、英雄贴身守，随时定船速（停 / 巡航 / 冲），还能花金币修船。到港时船剩多少血定星。

**规则**（只在关卡带 `escort` 字段时生效，守岛其余玩法逐位不变：`tests/td-golden.json` 不重新生成；护航自己的版本号 `ESCORT_RULES`，不升 `RULES_VERSION`）：
- 船的位置是整数 `pos`（1 格 = `ESCORT_CELL` 600），每拍按船速前进：停 0、巡航 6（100 拍一格）、冲 9（约 67 拍一格）；开局停在起点。冲不能比敌人快太多，否则船把所有波甩在后面、塔和英雄都用不上（配平时冲 20 让普通机器人几乎全三星）。
- 有 1–2 个敌人在咬时船速减半，`ESCORT_PIN_AT`（3）个及以上钉死。咬船伤害 = 敌人一次攻击伤害 × `ESCORT_BITE_PCT`（60）÷ 100。
- 不摆宝藏箱：敌人上岸后用 `grid.ts` 流场追"船此刻所在的格"（按航线下标缓存），贴近就咬；鹦鹉直线飞来。塔优先打正在咬船的，其次离船近的；英雄近身先挨打、缠住 3 个的规则照旧，所以英雄贴船就是保镖。
- 波次、两波预告、提前叫波、局内经济、塔的阶和分叉、拒马炸药桶全部和守岛一样；预告每波多一个"相遇点"`meet`（按当前船速推算先头敌人在航线哪一格追上船，只读）。
- 修船 `mend`：花 `ESCORT_MEND.gold` 金回 `pct`% 满血，冷却 `cd` 拍，不超过满血，被咬住时也能修。跟随 `follow`：英雄每 10 拍走到船旁；手动挪英雄会关掉跟随。
- 终局：到港（剩余血量 ≥ `stars[1]`% 3★、≥ `stars[0]`% 2★，其余 1★）、沉船或超时（`maxTicks` 6,000 拍）都结束，后两种 0★。星数线现在是 `[50, 90]`。

**内容**：3 张图（直波海峡、双湾回廊、鹦鹉岬）× 新手 / 普通 / 高手三档 = 9 关，id `<图>-<难度>`；三档敌人配方相同，难度只靠船血、预算倍率、开局金、木台数、波间倒数。第一张图三档开放，后一张图要前一张任一档 ≥ 1★。

**奖励**（娱乐）：只给游戏资源，不碰筹码（实盘见 12.1）。结算 `settleEscort` 按 `escortRunReward` 给金币木材：关卡建议主寨等级下全部金矿、伐木场 15 分钟的产量，按星数折 40% / 70% / 100%（产量乘了收入倍率，所以跟着涨；不跟守岛的战役掠夺表），**和守岛共用 `Profile.td` 的每日上限、按仓库截**（`tests/escort-run.test.ts` 锁住：先守岛拿满后护航只记星，反之亦然，换天重置）；首次拿星另给奖励、同一关重打不重复给。进度存 `Profile.escort.stars`，云同步保留。

**界面**：出海海图上一张"护航"卡 → 选图选难度（锁的写条件，各档写最好星数）→ 守岛场景的护航分支：海面画航线（走过的变实线）、隘口锚标、商船；顶栏商船血条带 2★ / 3★ 刻度；底部速度三联钮（当前档金底上浮发光，停 = 锚、巡航 = 帆、冲 = 双箭头，键盘 Q / W / E）、修船钮（价格、冷却、钱不够写还差多少）、跟随开关，都 ≥ 44 像素；预告卡写相遇点，航线上红点跟着船速变；手机竖屏镜头跟船（和登陆战、守岛同一套自动构图），一拖一捏就让位、出"回到船"钮，点了或停手 4 秒接回。结算标题 到港 / 沉没 / 撤退 / 误了潮（撤退和误了潮在规则里都是没到也没沉，标题按是不是玩家点的撤退区分），大数字是剩余血量。

## 13. 新内容第一片：震荡炮 + 掷弹兵（0.29.0，规则版本 10）

1. **震荡炮**（防御，2×2，主寨 5 级开放，名额 5–6 级 1 座、7–8 级 2 座；`buildings.ts`）：射程 6 格、3 秒一发（60 拍）、每发伤害是同级加农的七成（`grow(28)` 对加农 `grow(40)`）、落点 1 格溅射，炸到的兵**震晕 1.2 秒**（24 拍，`levels[].stun`），不走不打；震晕结束后 **2 倍时长免控**（`STUN_IMMUNE_MUL`，2.4 秒内再炸到也不晕），船长只晕一半（免控也按减半算）。弹丸 `BProjectile.kind = 'shock'`，按加农的速度飞、瞄提前量，事件 `stun`。分叉：3 级"快装"（装填 -20%）/"远震"（射程 +20%），6 级"连震"（溅射 +0.5 格）/"重锤"（伤害 +40%、只晕 0.8 秒）；进攻里分叉照例按 `RAID_BRANCH_PCT` 打折，震晕时长不折。

3. **掷弹兵**（兵种，人口 2，主寨 6 级开放；`troops.ts`）：射程 4.5 格、2.5 秒一发、1.2 格溅射，血是火枪手的一倍半（82），走得慢（1.3 格/秒），打最近的建筑。手雷 `BProjectile.kind = 'grenade'` 抛出去（最少飞 12 拍），**越过城墙**落在目标上，落点半径里的建筑都挨炸，**城墙只算三成**（`GRENADE_WALL_PCT`）；路被墙挡住时往墙上扔雷（不贴脸砸），驻岛英雄在身边时往他身上扔。机器人编队排在火枪手之后（`bot.ts` ORDER）。
4. 克制：专克**墙后挤在一起的建筑**。墙的作用看墙离核心多远：推荐布局的墙圈离主寨只有 3 格，掷弹兵站在墙外就够得着，三套推荐布局去掉墙，摧毁率几乎不变（主寨 5、6 各 6 局：43% 对 43%、34.5% 对 34.5%）；墙圈离核心 6 格时墙外扔不到，就得先拆墙，有墙比没墙低 5 点以上（测试锁住，探针 60.5% 对 67.5%）。所以"墙挡不住雷，但要拆很久，墙后有纵深的布局更难打"成立，贴身的墙对掷弹兵没用；城墙的建造说明里写了"墙圈离主寨远一点才挡得住它"（不改数值）。
5. **守岛的震荡炮**：第 7 种塔，伤害类型"炮弹"（对重甲 1.5 倍），造价 150；1 阶 24 伤害、3 秒一发、射程 6 格、0.8 格溅射，三阶照通用的 ×1.85 / ×3.2，命中震晕 24 拍（`TD2_SHOCK_STUN`），首领（船长）减半。分叉同上（基地 3 级 = 守岛 2 阶，6 级 = 3 阶）。初稿 1 阶 42 伤害、1 格溅射时，只造震荡炮对全掷弹兵波次一枚不漏、别的塔漏 30 枚以上，压过所有塔，所以伤害压到 24（每 100 金秒伤约 5，比溅射塔的 9 低，靠震晕补）。机器人按通用的克制分挑它（`counterKind`）。

宝箱和援军由 `BattleSetup.fun`（`{ chest?, ally? }`）打开；没写 = 全关，整局和没有这个功能时逐位一致（`tests/fun.test.ts` 锁：多关多种子，规则版本 11 / 12 / 13 加全关指纹相同）。必须 `rules >= 13` 才生效。

| 模式 | 宝箱 | 援军 | 原因 |
|---|---|---|---|
| 战役娱乐出海（`startBattle`，不是今日悬赏） | 开 | 开 | 只涉及游戏资源，种子每局现取 |
| 今日悬赏（战役，奖励翻倍） | 关 | 关 | 保持可比 |
| 悬赏出海（实盘） | 关 | 关 | 不动筹码期望 |
| 异步攻防（服务端重放、试打、防守回放） | 关 | 关 | 服务端自己拼 setup，永不带 fun；回放必须逐位复现 |
| 寻宝航线 | 关 | 关 | 每日榜要可比 |
| 守岛（战役、海盗来袭、悬赏、大潮）、护航 | 关 | 关 | 守岛核心独立，有 td-golden；以后可用同一思路做"空投补给" |

模拟器：`node tools/sim.ts --fun` 用 `CAMPAIGN_FUN`（`src/content/fun.ts`）开着打；机器人不用改（宝箱靠兵路过拾取，援军自动靠岸）。

### 15.3 误放撤回

- 操作 `{ t, type: 'recall', boat }`：落地后 `FUN.recallTicks`（10 拍 = 0.5 秒）内，这批兵都活着、满血、还没出过手（`cd` 还是落地那拍）才有效（`canRecall`，画面和规则共用）；兵回船、船可再放，推 `recall` 事件。其余情况忽略。登陆本身不耗能量，所以"退回"只退回船。
- 只在规则版本 ≥ 13 生效；旧版本回放里遇到 recall 忽略。`sanitizeActions` 收 recall（只有拍和船）。落点抖动用掉的随机数不回拨，重放照样一致。
- 画面：刚落地的船在卡片上方出"撤回 + 兵种名"小钮，带 0.5 秒收缩的红条，到点或兵出手就收；回放里不显示。

### 15.4 漂流宝箱

- 开局用战斗种子派生的独立流 `Rng(seed, 'fun.chest')` 在岛上撒 2–3 个，箱与箱至少隔 4 格。只撒在兵走得进去的空格：从海滩往里 4 邻域扩散（`reachableCells`），建筑（含城墙、装饰、地雷）占的格子过不去，所以城墙圈里的格子不撒。
- 任何活着的兵走到 2 格（`pickR` 200）内就捡走，奖励开局时由同一条流定：旗舰能量 +3（封顶 20）、全队回 30% 血、全队挨打减半 8 秒（`damageUnit` 里折算，`funCut`）。事件 `chest`；画面用木箱 + 呼吸光圈，捡到时光圈、图标上浮和数字（⚡+3 / 医药箱 +30% / 盾 8 秒）。
- 玩家不能直接指挥兵走，所以宝箱的意思是：登陆点和信号弹决定兵走哪条路，顺路能捡就赚。第一次打战役时提示一句"漂来宝箱，派兵去捡"（本地存储 `haidao.hint.chest`，只出一次）。

### 15.5 中途援军

- `Rng(seed, 'fun.ally')` 定三件事：靠岸拍（500–799 拍，约 25–40 秒）、海滩点、兵种（水手 / 火枪手 / 壮汉）。援军总血量约为玩家船队的 10%（`FUN.ally.hpPct`，最多 8 个），等级取船队平均。所以难关不会变白给；援军的兵和玩家的兵一样拆楼，摧毁率、星数照常算。
- 靠岸前 60 拍（3 秒）发 `ally` 预告事件，画面在落点画旗标和倒计时；靠岸时放兵（id 照常递增，落点抖动用援军自己的流），再发一次 `ally` 事件。援军没靠岸前，整局不会因为"玩家的兵打光了"提前结束。
- 第一次遇到提示"援军 3 秒后靠岸"（`haidao.hint.ally`，只出一次）。

### 15.6 备选（没做）

每周规则变体（地雷翻倍、旗舰能量无限但技能冷却）；海怪搅局（某一拍升起触手打最近的防御）。
