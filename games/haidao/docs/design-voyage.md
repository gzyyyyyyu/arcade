# 《海岛》设计：寻宝航线和护航（第 11、12 节）

> 设计总纲和目录在 [DESIGN.md](../DESIGN.md)，节号沿用总纲的编号。本文写现状；数值以 `src/content/` 为准。

## 11. 寻宝航线（每日航线，娱乐 + 实盘）

一天一条航线，全服同一条、同一支船队，比宝分。一局三四分钟，有选择、有损耗、有终点开宝箱的高光，每天不一样。入口是出海面板的"今日航线"卡。

**规则**（`src/core/map.ts`，契约在 `maptypes.ts`，内容在 `content/maps.ts`；纯函数、整数，种子只由北京日期算）：

- 航线 4 层：第 0–2 层各两个节点二选一，第 3 层是终点宝岛。第 1、2 层各有一半机会把一个节点换成补给礁（补兵 / 补能量二选一）。岛从 12 座微型岛按层抽（可左右镜像），终点从 3 座宝岛里抽，同一条航线不重复。
- 船队从 4 个模板里按日期抽（雇来的船，兵种、等级、每船人口固定，不看玩家存档），所以每日榜可比。
- 每站一场登陆战，最多 50 秒（`MAP_STOP_TICKS`），到点按当时摧毁率结算。死掉的兵不回来；旗舰能量整条航线共用（开局 8、每站后回 2、上限 20）。出战前可以让一条船休整：这站不上，缺员补回一半。
- 每站宝分 = 岛的满分 × 摧毁率 + 每颗星 10。任何时候可以收航，已拿的宝分照算；船队打光按七成算。
- 终局星按宝分 90 / 150 / 200 定。`tools/map-sim.ts` 跑 60 天：普通机器人平均约 1.75 星、三星约 23%；小白约 1.4 星、约三成会打光。

**画面**：航线图页（四层节点、侦察图标、整备和补给礁）→ 登陆战一站 → 站间结算条 → 终点开宝箱（终点站拿到宝分时才开，金币按这站宝分飞出；没拿到就船回港）→ 结算页（星、宝分、各站明细、分享、再跑一趟）。

**存储与榜**：浏览器本地 `haidao.map` 记当天进度和最好成绩，刷新后接着走；结算往平台每日子榜 `daily-<北京日期>-map` 交宝分（多跑几趟取最好），分数显示写在 `public/daily.json`。

### 11.1 航线实盘

> 以 `src/core/maplive.ts`、`tools/map-live-sim.ts` 为准；每天 1 趟（`HAIDAO_MAP_DAILY`），合计上限见 4.0。

- **跑的就是今天的航线**：航线和船队仍是全服同一条（`routeOf` 只看北京日期），实盘不另改，每日榜照样可比。所以四档的难度一样，**档位只换结回倍数**：档越高，同样的星回得越少（选档卡不写"电脑多强"，写"同一条航线，档越高结回越少"）。
- 流程和娱乐一样（选岛、休整、补给礁、收航），进度另存 `haidao.maplive.run`、不碰娱乐的 `haidao.map`，不交每日榜；同一天刷新后接着跑，战斗中途离开那一站按 0 宝分；跨天了按当时的宝分收航结。
- **结回**：按终局星数（宝分线 90 / 150 / 200 不变）查表；0 星按宝分占 1 星线（90）的比例线性折算，最多回 0.79 份。四档三星倍数一样（1.55），档越高 0 星、1 星、2 星越少。
- 实测表（八格都在区间里，豪华档小白贴着上沿）见 docs/balance-haidao.md 第 6 节。

## 12. 护航（商船队，娱乐 + 实盘）

> 以 `src/core/escorttypes.ts`、`escort.ts`、`escortbot.ts`、`escortrun.ts`、`src/content/escortmaps.ts`、`escortlevels.ts` 为准；界面在 `src/view/escort*.ts` 和 `TdScene.ts` 的护航分支。

**一句话**：商船沿一条写死的航线从起点开到终点，海盗从沿岸登陆口上岸追着船咬；玩家在航线边的木台造塔、英雄贴身守，随时定船速（停 / 巡航 / 冲），还能花金币修船。到港时船剩多少血定星。

**规则**（只在关卡带 `escort` 字段时生效，守岛其余玩法逐位不变：`tests/td-golden.json` 不重新生成；护航和守岛共用 `RULES_VERSION`，护航自己的指纹锁在 `tests/escort-golden.json`，见下面「规则 25」）：
- 船的位置是整数 `pos`（1 格 = `ESCORT_CELL` 600），每拍按船速前进：停 0、巡航 6（100 拍一格）、冲 9（约 67 拍一格）；开局停在起点。冲不能比敌人快太多，否则船把所有波甩在后面、塔和英雄都用不上（配平时冲 20 让普通机器人几乎全三星）。
- 有 1–2 个敌人在咬时船速减半，`ESCORT_PIN_AT`（3）个及以上钉死。咬船伤害 = 敌人一次攻击伤害 × `ESCORT_BITE_PCT`（60）÷ 100。
- 不摆宝藏箱：敌人上岸后用 `grid.ts` 流场追"船此刻所在的格"（按航线下标缓存），贴近就咬；鹦鹉直线飞来。塔优先打正在咬船的，其次离船近的；英雄近身先挨打、缠住 3 个的规则照旧，所以英雄贴船就是保镖。
- 波次、两波预告、提前叫波、局内经济、塔的阶和分叉、拒马炸药桶全部和守岛一样；预告每波多一个"相遇点"`meet`（按当前船速推算先头敌人在航线哪一格追上船，只读）。
- 修船 `mend`：花 `ESCORT_MEND.gold` 金回 `pct`% 满血，冷却 `cd` 拍，不超过满血，被咬住时也能修。跟随 `follow`：英雄每 10 拍走到船旁；手动挪英雄会关掉跟随。娱乐护航照顾新手（规则 25 起，`TdSetup.escortAssist`，只由 `escortSetup` 给娱乐局设）：开局英雄就跟随；第一波开打（倒数走完或提前叫波）时玩家还没碰过船速，船自己开始巡航（`EscortState.autoSail`，事件 `pace` 带 `auto`），玩家先点过任何一档（包括点「停」留在原地）就不替他开。护航实盘不设，开局不跟随、不自动开船，和规则 24 逐位一样。
- 终局：到港（剩余血量 ≥ `stars[1]`% 3★、≥ `stars[0]`% 2★，其余 1★）、沉船或超时（`maxTicks` 6,000 拍）都结束，后两种 0★。星数线现在是 `[50, 90]`。

**内容**：3 张图（直波海峡、双湾回廊、鹦鹉岬）× 新手 / 普通 / 高手三档 = 9 关，id `<图>-<难度>`；三档敌人配方相同，难度只靠船血、预算倍率、开局金、木台数、波间倒数。第一张图三档开放，后一张图要前一张任一档 ≥ 1★。

**规则 25（新手档放宽）**：真人试玩新手档三张图都沉，小白机器人也只有七成多。诊断（`.local` 里的小样本）：差在开局英雄不跟船（不跟随时小白几乎全沉）和看见敌人就停船（停着被钉死），臼炮不是主因。改三处：新手档敌人预算降到原来的 0.85 倍（`escortlevels.ts` 的 `TUNE` 新手档；0.55.0 按共用难度线又把直波海峡降到 25），娱乐护航开局英雄跟随、第一波开打时没碰过船速就自动巡航（亲手打海角时造塔过了头、船停在港口被第一波钉死；准备倒数最后 10 秒「巡航」钮先发光提醒）。普通、高手档和实盘四档不变（`tests/escort-golden.json` 锁九关、实盘四档 × 两种机器人；重生成 `node tools/escort-golden.ts`）。

**奖励**（娱乐）：只给游戏资源，不碰筹码（实盘见 12.1）。结算 `settleEscort` 按 `escortRunReward` 给金币木材：关卡建议主寨等级下全部金矿、伐木场 15 分钟的产量，按星数折 40% / 70% / 100%（产量乘了收入倍率，所以跟着涨；不跟守岛的战役掠夺表），**和守岛共用 `Profile.td` 的每日上限、按仓库截**（`tests/escort-run.test.ts` 锁住：先守岛拿满后护航只记星，反之亦然，换天重置）；首次拿星另给奖励、同一关重打不重复给。进度存 `Profile.escort.stars`，云同步保留。

**界面**：出海海图上一张"护航"卡 → 选图选难度（锁的写条件，各档写最好星数）→ 守岛场景的护航分支：海面画航线（走过的变实线）、隘口锚标、商船；顶栏商船血条带 2★ / 3★ 刻度；底部速度三联钮（当前档金底上浮发光，停 = 锚、巡航 = 帆、冲 = 双箭头，键盘 Q / W / E）、修船钮（价格、冷却、钱不够写还差多少）、跟随开关，都 ≥ 44 像素；预告卡写相遇点，航线上红点跟着船速变；手机竖屏镜头跟船（和登陆战、守岛同一套自动构图），一拖一捏就让位、出"回到船"钮，点了或停手 4 秒接回。结算标题 到港 / 沉没 / 撤退 / 误了潮（撤退和误了潮在规则里都是没到也没沉，标题按是不是玩家点的撤退区分），大数字是剩余血量。

**配平**：机器人在 `escortbot.ts`（小白：一直巡航、木台按顺序造、英雄跟随、不修不叫波；普通：按预告补克制的塔、相遇点落在无塔区且船血够就冲、落在塔群就停、船血低于六成修船）。量：`node tools/escort-sim.ts --n 200 [--level <id>]`（`nice`）。目标是共用难度线（`src/content/difficulty.ts`）：三张图并列，进度按难度档（新手 0、普通 0.5、高手 1），普通机器人三星率 100% / 73% / 45%、小白胜率（到港且 ≥ 1★）100% / 83% / 65%，±20 点。难度旋钮在 `escortlevels.ts` 的 `TUNE` 表（预算倍率 scale、船血 hull；同一张图船血新手 > 普通 > 高手，单测锁住），新手档开局倒数 700 拍，普通 / 高手档开局金 520 / 400。

- 实测表见 docs/balance-haidao.md 第 7 节。

按共用难度线重配（0.55.0）：直波海峡新手、普通档三星从 3%、2% 拉到 100%、91%（敌人预算降、普通档船血加），三张图高手档放宽到小白胜率 59–84%。没进带的只剩直波海峡·高手的普通机器人三星 0%：普通机器人在这张图上冲船挨咬，船血一律停在 2★（小白反而有 12% 三星），是机器人打法所限，按小白胜率定。

### 12.1 护航实盘

> 以 `src/core/escortlive.ts`、`src/content/livetable.ts`、`tools/live-sim.ts --kind escort` 为准；每天 4 场（`HAIDAO_ESCORT_DAILY`），合计上限见 4.0。

- **每档一个关卡池，按种子抽一关，读实盘专用的冻结副本**（`src/content/escortlivelevels.ts`：strait-normal、bays-normal、strait-hard 是 0.55.0 拆分时的定义，bays-easy、bays-hard、cape-easy、cape-normal、cape-hard 是 0.58.0 扩池时的定义，`tests/escort-content.test.ts` 用哈希锁住）：娱乐的同名关以后随便调，实盘不变；改冻结副本就要重跑实盘 sim。
- **结回**：到港按星数查表；没到港（沉船、误了潮）按走过的格数占比**线性**折算，最多回 0.79 份。不用守岛那条凹曲线：机器人沉船、误潮多半在快到港的时候（走完 0.6–0.9），凹曲线下 0 星几乎都拿满值，分不出好坏。
- **档位和关**：池子见 `LIVE_TABLE.escort`（小档直波海峡·普通加两条新手关、中档三条普通关、大档普通 + 高手，豪华档只有直波海峡·高手：双湾、海角的高手关普通玩家在大档就几乎全过，放进豪华档配不进目标）；每关一张倍数表、逐关拟合，同档三星倍数一样、档越高不降（单测锁住）。娱乐的 strait-easy 两种机器人都是 100% 三星、拉不开，不进池。

- 实测表（四档都在区间里）见 docs/balance-haidao.md 第 8 节。
