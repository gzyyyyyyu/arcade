# 海岛画面笔记：守岛、选关、海盗来袭和护航界面

> 总览和目录在 [ui-haidao.md](ui-haidao.md)。约定和硬规矩以 AGENTS.md 为准；改对应代码时同步改这里。

## 守岛界面

- **守岛界面**（`src/view/TdScene.ts`、`td-ui.ts`、`tdplan.ts`；样式在 `tdcss.ts`（第一次画守岛界面时注入）；纯文案和小函数在 `td-ui.ts`，`tests/td-ui-text.test.ts` 锁住）：界面只显示规则核心给的东西，不自己算规则——克制表只画 `COUNTER`，预告和「下一座造」读 `tdPreview(s, 2)`，路线读 `tdRoutes`，卖塔退多少读 `tdSellRefund`，清障价读 `tdClearCost`，叫波奖励读 `tdCallBonus`，驻守台选项读 `tdGarrisonOptions`，能造哪些塔读 `TdSetup.unlocked`，木台为什么造不了（英雄或敌人站在台上）读 `tdBuildBlock`（和核心的 build 同一个函数，面板上写原因、卡片变灰，英雄挡着给「让英雄走开」、敌人挡着给「关掉等它走开」：面板开着时游戏暂停，所以先关面板，台子空了 `reopenWatch` 自动重开）。点塔卡造下去面板就关、游戏接着走（不换成这座塔的升级页，免得每造一座都要多点一下关掉），要升级再点这座塔；升级同理，升到 2 阶面板就关、游戏接着走，升到 3 阶面板留着（接着在这里选分叉）。塔身和塔脚的木台都点得开面板：塔身按图的不透明像素认（`textures.ts` 的 `alphaAt`，裁过透明边的图由 Phaser 的 `getPixelAlpha` 自己换算，别再减一次偏移）。指挥英雄（`tdinput.ts`）：点英雄本人或底栏「英雄」钮（H）选中，再点地面让他过去，再点一次或 Esc 取消；电脑右键地面直接让英雄过去（有选中、在瞄技能时右键是取消）；手指按住英雄拖到落点（拖出 40 像素才算拖，画一条虚线加落点圈，拖动期间不平移镜头），没拖开就是选中 / 取消。没选中时点空地什么都不做，点木台、塔只开面板（"点哪英雄去哪"太乱）。英雄贴着木台站时：点他上半身算点英雄，点脚边算点木台（`heroHit`）。选中提示按手指 / 鼠标分两套说法。
  **暂停**：顶栏「暂停」钮（竖屏手机在顶栏小钮 `.hd-td-pausetop`；手机横屏只画 ❚❚ / ▶ 图标、44 宽，「宝藏」两字收起，不然右边一组会压住波数牌，`layout.ts`）和 P 键，暂停时只把已经排进去的操作走完，游戏不前进，画面写「已暂停 · 点「继续」接着打」（`.hd-td-paused`，和预告卡或「全景」钮叠着就挪到它下面：`tdhud.ts` 的 `placePaused`，暂停时每 300 毫秒量一次，预告卡行数会变，写死的位置总有压住的时候）；开面板时照旧自动暂停。暂停不影响实盘结算：服务端只看局内拍数，不看墙钟（`docs/backend-haidao.md`）。
  **能升级的塔**：塔上不各挂提示，「该升哪座」只由预告卡指的那座的金圈说（`syncGoalMark`，见下面的预告卡）；别的塔能不能升，点开面板看。以前够钱的塔顶都浮一个金 ▲，钱多时满屏箭头，和金圈两套一起说「该升了」。
  **造塔**：开局后造的塔从木台上升起来（`motion.ts` 的 `towerRise`：0.3 秒慢进慢出长到略高于原大、0.1 秒落回，共 `TOWER_RISE_MS` 0.4 秒；基地的 `riseScale` 前三成时间就长完，放在守岛里看不出升起，所以分开），炮台按底座的缩放跟着长；脚下烟尘（`fx.ts` 的 `dust`：有明暗的 `smoke` 烟团贴地冲开、按 `drag` 减速、一边胀大一边线性变淡，登陆战建筑倒塌同一套）、飞木屑；开局就在的驻守塔不演，减弱动态时只扬尘。
  - **克制表**：伤害（方章：枪 / 炮 / 火 / 爆）和护甲（圆章：布 / 甲 / 船 / 飞）的单字徽记，塔卡、敌人头像、预告卡、克制表共用一套颜色；徽记悬停出说明（`damageTip` / `armorTip`：这一类有谁、打谁多一半），不在按钮里的点一下弹 toast（塔卡里的不接点击，点卡是造塔）。建塔卡写伤害方章加克谁，护甲写全名（"[炮] 克 重甲 ~~飞禽~~"：护甲名是带护甲色的小条 `.hd-armn`，单字圆章太小，「飞」「布」容易看错；打不到的划掉、悬停写「打不到…」，不写字，免得卡片折行、手机上面板放不下）；塔面板、驻守台卡写伤害全名加克谁，不写"克首领""打不到鹦鹉"这类旧说法；分叉卡只写克制表的两条例外（`branchDamageHint`）。
  - 克制表卡（`counterCard`）：表上一句"每座塔打一种伤害，每个敌人穿一种护甲"加三个色块；格子写人话（`pctText`：多打一半 / 照常 / 只打一半 / 打不到）按档上色；行头 = 伤害 + 打这种伤害的塔的小图，列头 = 护甲 + 穿它的敌人头像，高度 ≤ 700 的屏不放小图（`.hd-ctr-ic`）；表下按名字列出每种伤害有谁打（`damageSources`：塔从 `TD_TOWER_DAMAGE` 现算，英雄、火药桶、地雷、地上的火在 `DAMAGE_EXTRA` 一处读核心常量）、每种护甲有谁穿（`armorFoes`）。建塔菜单里收成一个按钮（点开后只留表、带"收起"，一屏放下），敌人图鉴里直接展开；电脑上图鉴左右两栏（左两波、右克制表，`layout.ts`），和手机横屏一样。
  - 敌人图鉴在两波下面给看得到的每种敌人一行（`foeLine`："水手 · 布衣：火打它多一半"，两波重复的只写一次）；首次见到的提示卡（`foeText`）同一个说法，"打它多一半"只从这局能造的塔里挑。
  - **预告和决策时间点**：每波倒数里顶部一张预告卡（`.hd-td-plan`，整块算一个牌子）：下一波来哪些敌人（小头像 × 数量）、护甲写全名（只有一种写「全是布衣」，几种写「布衣 60%」）、下一步（`nextStep`）：有空木台写「下一座造」加塔的小图和名字（照建议的新手机器人挑的那座，核心的 `counterKind(s, tdPreview(s, 2))`，按下两波的护甲和每金输出挑、同种塔越多越打折、有飞的先备打飞的），木台造满了写「钱够就升级」加最该升的那座（升阶最便宜的那座，并列取木台序号小的；照卡升的新手比照稳机器人「离路最近的一座攒钱升满」在 td18 高 20 点），场上那座塔描金圈、头上写「升级」（`tdpadguide.ts` 的 `syncGoalMark`，和开局造法的金圈同一个 `addMark`；「下一座造」要造的那块木台也描金圈、头上写塔名，木台是照建议的新手先造的那块，核心的 `freeSlotPick`；开局造法没造完时只画开局造法的圈），都升满了不写；钱不够时塔名后面红字「· 差 N」、升级的开头缩成「升级」（`stepLine`：卡宽 360，长说法会让这一格单独占一行；HUD 每拍只改这两小段字，不重排整张卡）；钱够两步（`tdpadguide.ts` 的 `twoSteps`：金币 ≥ 两步之和，开局造法没造完时不算）时同一格接着写「＋第二座」（升级写「＋升」），第二步是照第一步做完以后卡上会给的那一步（`nextStep` 的 `then`，同一座不连升两次），场上两个金圈一起描，最多两步，卡不变高，护甲那几段不换行（`white-space:nowrap`），放不下时只有这一格换到下一行。点这一格（`.hd-plan-go`，卡的别处照旧开图鉴）镜头平移到它说的那块木台或那座塔（`panToGoal`：开局造法没造完时指第一块，缩放不变，记一笔玩家动了镜头、停手后自动跟拍照常接回）；竖屏放大时那块在画面外，可见区边上出一个金底锤子的箭头（`drawEdges` 的 `goal`，点了一样移过去；同一段的空木台小标让给它，和敌人箭头叠着就顺着边挪一段，`camguide.ts` 的 `goalClear`）。下一步定住（`TdScene.next`）：只在木台上的塔变了（造、卖、升，`stepKey` 进预告卡签名）才重挑，翻波、倒数里不换——跟着预告每波重算时卡会自己变，攒钱造 A 的新手看到它变成 B；图鉴标题写 `nextStepText`；写了开局造法 `TdLevel.opener` 的关，第一波开打前这一格换成「先造」加还没造的那几座（`openerLeft`，同种塔写 ×N，照它造完了就换回「下一座造」），图鉴标题写 `openerText`；那几块木台在倒数里描金圈、头上写塔名，造了就收那块（`tdpadguide.ts`；造什么只由卡上「先造」说，不另出提示条），打开金圈木台时该造的塔卡描金边（`.hd-td-tower.rec`）；开局造法造完以后，打开任意空木台时卡上「下一座造」的那种塔同样描金边）。金圈头上的字压在建筑、英雄、敌人上面（`DEPTH.markerTop`），镜头缩小时按 `padguide.ts` 的 `markScale` 放大，屏幕上不小于 16px（手机横屏全景约 0.4 倍，原来只有 8px）、几秒后开打、从哪几路来 / 潮水 / 关卡的 `note`，再下一波只列护甲；首领波整块变红。英雄倒下时两个技能钮写「复活 N秒」。地图上（`tdplan.ts` 的 `TdPlan`）下一波要走的路画成实线加往宝藏箱流动的箭头、飞的画虚线直飞、没用到的路画淡、关着的落潮路画虚线，路口插旗写敌人头像和数量（雾里的带眼睛）；只在开新的一波、墙破了 / 修好时重算，箭头和旗子是对象池，每帧只推动画。**预告时不自动暂停，决策窗口就是倒数**：波次是叠着来的（倒数从上一波开打算起），每波都停会把 4 倍速打成走走停停，叫波奖励又按剩余倒数算，自动暂停会让"提前叫"失去意义；想停下来想就点「暂停」（P）、预告卡（打开敌人图鉴）或木台，面板、「现在撤退？」确认框开着时整局暂停（`.hd-td-paused`；确认框以前不停，想的工夫宝藏还在被抢）。预告卡平时只留敌人、护甲、下一座和一行「几路来 · 潮水 · 点开看打法」，关卡说明和逐个敌人的打法收进点开的图鉴，免得一张卡五六行压住出生点。预告翻到新一波、里面有第一次见到的敌人时，顶部弹一张不挡操作的「新敌人」卡（头像、会干什么、什么护甲、最怕什么伤害，点一下或 4 秒收起，还没收就来了新卡时新的顶掉旧的；和预告卡压着时（手机横屏卡上写「差 N」变宽）挪到预告卡右边、右边放不下就挪到卡下面，`tdhud.ts` 的 `placeHint`；`tdhint.ts`，每种只弹一次，记在 `haidao.hint.foe`）。首次提示（新敌人、章末机制、关内事件、航海士）一次只弹一条（`pickHint`）：关内事件提前一波讲（「再下一波」有它时），开局讲章末机制和航海士，再是这一波第一次来的敌人，多的排队、下一波接着弹；战书那一波倒数里浮着卷轴，卡让开排到下一波。以前开局一张卡塞三条，占竖屏半屏。开局倒数里叫波按钮写"开打"，电脑按空格开打。
  - **木台面板**：空木台只列 `unlocked` 的塔（电脑 1–6 选）；有塔的写阶、伤害类型、基地加成，3 阶后选分叉（说明读守岛自己的 `TD_BRANCH_DESC`，克制例外读 `branchDamageHint`；电脑按数字键选），能升级（U）、能卖（S，电脑上分叉卡、升级钮、卖钮都挂键位角标；按两下：第一下变红写"再点一下确认"，2 秒内第二下才卖，按钮上写退多少）；竖屏面板盖住下半屏，点的木台落在面板里时镜头把它挪到面板上方那块的中间（`tdsheet.ts` 的 `slotAboveSheet`，`FitCam.panTo` 的 `bottom`）；被沉船压着的木台两个选项：花钱马上清（`clearNow`）或让英雄去打（打完给钱）；驻守台外圈一道金边。
  - **章末机制钮**（规则版本 16，每章最后两关）：排在叫波后面（`.hd-td-mech`，快捷键 4）。水闸的右上角小圆牌是剩余次数，这一波按了没用时灰掉（`.off`），按了说清为什么（下一波不落潮 / 用完了）。
    潮汐水闸：关上下一波后钮变金底写「已关闸」（再点打开），预告卡第二行写「水闸关了：东路的敌人改走北路」、路线和路口旗按改道后重算（`refreshPlan` 的签名带上关了几波），
    落潮路口画一道闸（`tdworld.ts` 的 `syncSluice`，`tdart.ts` 的 `sluiceUp` / `sluiceDown`），关上时闸板落下；那一波开打时横幅写「水闸关上了」而不是「涨潮了」。
    手机竖屏浮在叫波钮正上方、隔 8（`.hd-td-hasmech`；以前挤进技能那一行、间距收到 2–4，点按区挨太近），提示条跟着上移；手机横屏右下角那块板里排在炸药桶旁边，叫波照旧独占最后一行。
    岸防老炮：钮和炸药桶一样先进入瞄准（金底上浮、提示条写「点地面，老炮 1 秒后落一发」），再点地面就打；全岛都够得着，不画范围圈。冷却用同一套扫光和秒数，但不跟英雄倒下。
    开炮时炮口一圈火光、震一下，炮弹沿高弧线飞向落点，落点先画一圈红色预警，1 秒后爆炸（算大事件，和英雄的炸药桶一样震屏）；炮台画在沙滩上（`tdart.ts` 的 `battery`，`drawProps` 摆）。
    漂流补给箱没有钮：箱子落到浪边（一跳）、左右晃，脚下一圈呼吸的金光，飘一句「补给箱漂来了」；点箱子 1.2 格内就叫英雄去捡（地上点一圈确认），
    捡到时箱子往上一跳消失、飘金币数和「技能好了」，没人捡就滑回海里淡出（`tdworld.ts` 的 `addCrate` / `removeCrate` / `crateAt`，`tdart.ts` 的 `crate`）。
    第一次见到时弹「新玩法」卡（`haidao.hint.mech`）。
  - **第五章的断崖和高台**（规则版本 26，DESIGN 10.6h）：断崖格加上这一关用到的高台合成一块崖（`tdcliff.ts` 的 `drawCliffs`，深度 `DEPTH.cliff`，铺在地上、开局画一次），
    每格抬高 `CLIFF_LIFT`（28 像素，一格菱形高 32）：红褐色顶面（一半格子深一点，看得出一块块岩石，撒几点碎石）、朝玩家的两个侧面上浅下深加竖裂缝、朝外的顶边一道亮边、崖脚一道阴影和几块落石，背面的崖边冒几簇草。
    高台上的木台、塔、金圈、哑火标记、出膛点都抬高同样多（`slotLift` / `towerLift`），外圈一道石栏杆、四角石柱（栏杆按木台的深度另画一层，盖在木台上、塔下面）；射程圈和死区的斜线圈照旧画在地上（射程是水平的）。
    高台是 2×2 的菱形（高 64），抬高 28 后大半还压在原位，点木台照格子算也点得到。建塔面板在高台上写高台的射程（「射程 X 格（近 2 格内打不到）」，`rangeText` 的 high），价钱按 `tdBuildCost`（贵一成半）。
    小地图把断崖和高台底下画成红褐色（`.hd-minimap .cliff`），高台本身浅色描边（`.pad.high`）。
  - **第四章的水面、军医、炮艇**（规则版本 18，DESIGN 10.6d 末尾）：水面格在沙滩和装饰之前画（`tdworld.ts` 的 `drawWater`，深度 `DEPTH.water`），一格一块等距菱形，挨着陆地的边描一道白浪花；
    桥（`bridges`）在水上铺木板加两侧栏杆（`DEPTH.bridge`）。选关页和驻守台的小地图（`islemap.ts`）把水面画成蓝色多边形（`.hd-minimap .water`）。
    军医是分件骨架（`e.medic`，动作照水手）：绿头巾、白衬衫、斜挎包上一片绿叶，不用红十字；回血时被回的人头上飘绿色「+」（`heal` 事件）。
    炮艇不是人形，用整帧图（`tdart.ts` 的 `gunboatFrame`：小船、船头一门炮、黑旗，开炮帧炮口一团火光），`RIG_OF` 记 `null`；开炮（`shell`）播炮声，一颗炮弹沿弧线飞到那座塔、落地一圈冲击环，塔的哑火照 `jam` 事件画；开走（`sail`）飘「炮艇开走了」。
