# 海岛画面笔记：质感、配色、皮肤、演出、音效和后期

> 总览和目录在 [ui-haidao.md](ui-haidao.md)。约定和硬规矩以 AGENTS.md 为准；改对应代码时同步改这里。

## 质感、配色和界面皮肤

- **质感和配色**（全部程序生成、烘焙进静态纹理，运行时零开销；`tests/look.test.ts` 锁住确定性）：
  - 调色板：颜色取自 `art/palette.ts`（含光照的混色源 `sunWarm` / `shadowCool`、内线色 `inkSoft`、湿沙和三代建材的色）；素材生成时在 `kit.ts` 的 `wrap` / `piece` 里统一过 `art/grade.ts` 的 `gradeSvg`（轻微降饱和 `GRADE.sat`、拉开明暗、亮面偏暖暗面偏冷）。旗帜红、火焰、紫色技能、宝藏的亮金点登记在 `VIVID` 里保持鲜艳；调色板的 `gold` 是黄铜色，跟着分级走；特效和图标用 `pieceRaw` 不分级。地面（`terrain.ts` 的 `TERRAIN`）也过 `gradeHex`。
  - 光源固定在屏幕左上（`kit.ts` 的 `mat(base, kind?)`；`kind` 是材质类别，三个面共用、交给 `wear()` 选纹理，调用方知道画的是什么就明说——蓝灰的玄武岩、混过冷色的背光面按颜色会被猜成铁，不传才按基色猜一次）：顶面 = 基色 ×1.06 再向暖阳色混 24%（金属 30%），左面 = 基色，右面（背光）= 基色 ×0.78 再向海天冷蓝混 28–35%（木 / 石 / 金属递增），不向纯白、紫黑混；`lighten` / `darken` 同样向暖白、深海蓝混。`wear.ts` 给每个面叠光照：左面檐下一条冷暗带，右面冷影加下沿 25% 的沙滩暖反光，立面下沿冷色暗角；建筑 `shell` 里一层偏右下的长投影加一圈脚下接触阴影；`textures.ts` 的 `finish` 对建筑、`bakeAtlas` 对炮塔会转的部分（`tur.*`）再盖一层左上暖、右下冷的渐变（建筑另加颗粒）。
  - 材质（`wear.ts`，尺度按 1× 看得清定）：木 = 6–8 像素一条的拼板缝（缝下沿一条受光木棱）+ 两三条长木纹 + 至多一个木节；石 = 错缝砌块（行高 6–7、块宽 9–12、灰缝 1 像素，两成整块提亮或压暗），顶面只放几块明暗；铁 = 不撒碎点，下沿一两处锤纹加铆钉；炮管（`tube`，填色必须是 `#rrggbb`）是四段色带（上沿受光 → 中调 → 核心暗带 → 下沿反光）加一条留断口的高光窄带。木质圆台（`cyl` 的材质是木、半径 ≥ 14）顶面每 7 像素一道拼板缝；圆锥顶左前一条迎光亮面、两圈瓦缝。面积太小的面不画。同色同宽同透明度的线段（板缝、灰缝、木纹）和同色的色块（砌块明暗、锤痕）各并成一条 path 输出（`wear.ts` 的 `Batch`、`kit.ts` 的 `lines`，方盒的横纹 / 竖纹 / 砖缝同理）：一面墙几十条线原来是几十个元素，烘焙时逐个光栅化；背光面下沿的冷暗角和沙滩暖反光合成一个渐变，顶面不加渐变。
  - 描边，外重内轻：`box` / `cyl` / `hip` / `gable` / `cone` 各面填色不描边，最后沿整体剪影画一圈外轮廓（`sw` × 1.1，本体色向深褐靠拢 0.62）；面与面的交界画细的内结构线（立面中缝暗线、顶面前两条边和屋脊的迎光亮棱 `#fff7dc`）；`poly` 等的默认线宽 `SW` = 1.4 是门窗屋檐这类内线。渐变等非十六进制色退回 `OUT`；小道具和装饰传小 `sw` 或 0。
  - 等级外观（`buildings.ts`）：每级一种主材质（`LVC`），跟剪影一样两级一档：1–2 级亮木 / 中木、3–4 级亮石 / 花岗岩、5–6 级暖灰重石、7–8 级蓝灰玄武岩（后两档靠冷暖分开；玄武岩受光面亮到看得清体积，7–8 级专用的 `wallDark`/`wallDarkD`/`roofSlate` 系也按这个亮度，满级岛不是一坨近黑），7–8 级只在包边箍圈上点铜金（`trim`）；等级分代和代内名次只由 `levelBand` 算。只有细圆塔（火枪塔、狙击塔、迷雾塔，`PLINTH`）脚下垫圆地坪（1–2 级沙土、3–5 级切石、6–8 级带箍的玄武岩）；自带方底板（主寨、锯木厂、木料场、船坞、军械所、火箭塔）和大圆盘（炮台、电击塔、臼炮、喷火塔、鱼叉、焦油池、金库、地雷）的不垫，免得双层底框、圆盘套方垫。代内名次（1–2 级 1–2，3–5 级 1–3，6–8 级 1–3）是压在底座左前边上的暗铜方钉（`rankPegSpots` 算位置：`FOOT` 表给底座左前边中点，方底板是左角 (−64h, 0) 和前角 (0, 32h) 的中点，圆盘是椭圆 135° 那一点；每颗 9×9 像素，画在本体之上；`tests/look.test.ts` 锁住钉子不离开底座）。旗：只有主寨挂大旗；防御塔只在 7–8 级挂一面镶金边的小红旗（22×14，`towerFlag`，迷雾塔是紫旗），1–6 级防御塔和资源、生产建筑都不插（满级岛上几十栋建筑，旗一多就比建筑还抢眼）；船坞的帆一律帆布色。没有金框、等级点、四角小旗和金冠。城墙是背景：墙沿和墩顶箍用压暗一档的 `trim`，5–8 级墩顶只压一顶 6 像素矮帽（5–6 铁、7–8 暗铜），不用金尖。
  - 防御建筑的剪影（每两级换一次轮廓，1 倍竖屏也认得出；底座按 `tier4` 分 1–2 木构 / 3–4 砖石 / 5–6 重石掩体 / 7–8 玄武岩棱堡，炮头图集同一套四档，7–8 级的铜金只在细箍和包边上，台面边的铜环由 `rim` 画、只露 4 像素）：
    - 主寨（`hqGeom` 管各级高度、屋顶、旗杆和烟囱位置，旗和烟囱的环境动画读同一张表）：1–2 级木桩地台上的木屋，2 级加门廊；3–4 级石基木石大厅、4 级左前长出石头副仓；5–6 级双层石堡，下层宽垛口带拱门，6 级正面两座圆角炮楼；7–8 级三阶要塞加顶层圆塔、门口两盆火，8 级四角包铜。旗的样子按级在 `hqFlagLook`。
    - 加农炮：底座 1–2 级沙袋加木转盘、3–4 级石墩铁齿圈（4 级四角铁撑）、5–6 级暗石胸墙（正面 U 形缺口、后挂弹药箱）、7–8 级玄武岩星形炮座镶铜圈；炮头（`turrets.ts` 的 `cannonDir`）1–2 级木轮短炮、3–4 级加长重炮（4 级两侧护盾）、5–6 级双联装加前护盾、7–8 级楔形装甲炮塔（`wedgeShell`）伸出双联装，8 级炮口箍镶金。双联装从 5 级起，因为 5、6 级共用一档图集。
    - 火枪塔（细高，和矮宽的加农炮拉开）：1–2 级四柱 X 撑镂空木哨塔（2 级白帆布斜棚）；3–4 级下石上铁的封闭方塔（4 级赤陶尖顶）；5–6 级下宽上窄石塔、铁托臂托着外挑的大垛口平台（6 级蓝灰铁尖顶）；7–8 级玄武岩塔、四角扶壁、两层回廊、铜（8 级金）箍盔顶，8 级回廊前挂交叉火枪盾徽。平台高度 `gtPlat`、顶棚 `gtRoof`，炮台转动部件的锚点（`TURRET_PIVOT`）也读它们。
    - 臼炮（矮宽的炮坑，坑墙围着朝天的粗炮筒，越高级墙越厚越高）：1–2 级沙袋半圈围的浅土坑加木炮座；3–4 级切石圆坑（4 级坑边炮弹堆、弹药箱）；5–6 级花岗岩高胸墙、正面留缺口，炮头变三联；7–8 级玄武岩坑、四角挑棱、宽垛口，三联筒脚下套冷钢装甲护环。台面高 `MORTAR_DECK`。
    - 喷火塔（中高的油罐塔，一只立着的油罐托着喷嘴，越高级罐越高越粗、喷嘴越多）：1–2 级木架上的箍木油桶、单喷嘴；3–4 级石脚上的铆铁立罐、侧挂红油桶、两喷嘴；5–6 级砖台上的主罐加侧后副罐和油管、三喷嘴；7–8 级玄武岩台四角扶壁、冷钢高压罐，三喷嘴后包冷钢护罩。台面高 `FLAME_DECK`（逐级）。
    - 鱼叉炮（矮宽的大弩台，横向张开的弩臂是主剪影，越高级弩臂越宽、台越厚）：弩臂半展宽 `BOW_SPAN` 每档张开一截；1–2 级木板圆台、木弩、矛桶绳圈；3–4 级石台、后面木绞盘、弩臂包铁；5–6 级花岗岩台、后半圈矮墙、大绳鼓，两层复合弩；7–8 级玄武岩台四方各一根系缆铁桩，冷钢弩臂、两头铜弩尖。台面高 `HARPOON_DECK`。
    - 火箭塔（方墩发射台，一排斜指天的管子，越高级墩越高、管越多）：1–2 级木托盘、3 管；3–4 级上下两层砖墩、4 管；5–6 级三层收分的花岗岩墩、5 管；7–8 级玄武岩堡、四边宽垛口，7 管两侧立冷钢装甲板。台面高 `ROCKET_DECK`。
    - 震荡炮（矮圆台加喇叭口炮，台后立放电线圈，越高级线圈越高越多）：1–2 级木圆台、地上两颗电容球；3–4 级石台、三颗立在铜柱上的球；5–6 级花岗岩台左后右后两根线圈柱（`coilPost`），旗插左前让开；7–8 级玄武岩台后三根更高的线圈柱，炮头喇叭口张大一圈、炮身绕三道铜线圈。台面高 `SHOCK_DECK`。
    - 狙击塔（全岛最细最高的瞭望架，越高级越高越实）：1–2 级四根原木斜柱加横撑的透空架；3–4 级石脚加高、铁柱；5–6 级铁柱架、平台下一圈木板护裙（上重下轻的岗楼）；7–8 级玄武岩实心细塔身、脚下四片扶壁、平台四边垛口，炮头前立冷钢护盾。平台高 `104 + 4 × 等级`。
    - 焦油池（矮的黑坑，越高级坑沿越高越硬）：坑沿高 2 / 6 / 10 / 14；1–2 级木板围的土坑、一只漏油木桶；3–4 级切石坑沿、骷髅警示牌；5–6 级铆铁锅沿（一圈铆钉）、两只桶接铁管往坑里灌、两块警示牌；7–8 级玄武岩高坑沿镶铜箍、坑后一根冷钢烟管、坑上冒紫烟。
    - 迷雾塔（细的雾灯塔，越高级越高、冠越重）：1–2 级木桩塔身两道铁箍、木圈灯座；3–4 级切石塔、石圈灯座；5–6 级四片扶壁的高石塔、垛口灯座；7–8 级玄武岩尖塔、六根铜尖的冠托一颗紫水晶、紫旗。
  - 资源和生产建筑的剪影（同一套四档：1–2 木构 / 3–4 砖石 / 5–6 重石 / 7–8 玄武岩，铜金只在 7–8 级的箍和包边；不插旗）：
    - 金矿（矮宽的岩丘，丘前挖出矿洞、铺出一段矿车轨道，越高级洞口越大、井架越高、山顶金堆越大）：1–2 级木框小洞口、木枕轨道、一辆手推矿车；3–4 级切石门洞、旁边木吊架、山顶露出小金堆，4 级起两辆铁矿车；5–6 级花岗岩门楼、木井架塔（顶上滑轮）；7–8 级玄武岩门楼带宽垛口和铁闸、冷钢桁架井架和轨道、两辆冷钢矿车。金堆位置 `MINE_TOP`。
    - 伐木场（敞开的锯棚，大锯轮是主剪影：全岛最大的圆，画在棚顶前面、顶出棚檐，越高级棚越实、锯轮越大越多）：1–2 级露天木锯架、单锯轮（2 级茅草棚）；3–4 级石脚木柱、赤陶瓦棚、石墩机架，一大一小两锯轮；5–6 级后两面石墙的半封闭锯房、蓝灰板瓦、高烟囱；7–8 级玄武岩锯坊、冷钢双锯轮和机架、前面一只蒸汽锅炉。主锯轮的几何在 `sawMain`（画图和基地里转的帧共用）。
    - 金库（矮胖的圆仓加圆顶，越高级越高越实）：1–2 级箍木圆仓、木瓦圆顶；3–4 级切石圆仓、铁皮圆顶；5–6 级两层收分的花岗岩圆堡、深铁圆顶；7–8 级玄武岩圆堡、四个扶壁、一圈宽垛口，冷钢圆顶尖上铜（8 级金）球。
    - 木料场（露天原木场，左前一座三角原木垛是主剪影，右边一根吊杆，没有烟囱；越高级垛越高、吊杆越高越长）：1–2 级麻绳捆的原木垛、木三脚吊杆（2 级后面一溜草棚）；3–4 级石脚木柱、赤陶瓦后棚，木吊杆加斜撑；5–6 级后半截矮石墙、蓝灰板瓦，原木垛箍铁带，高木吊架；7–8 级玄武岩矮墙、深板瓦镶铜边，冷钢桁架吊臂，垛上原木头包铜。棚高和吊杆在 `woodGeom`。
    - 船坞（平的码头加一条船，桅杆是主剪影，越高级船越大、桅越多）：1–2 级木栈桥、小舢板（2 级一根小桅）、矮木吊杆；3–4 级石码头、单桅船、高木吊杆；5–6 级石船台、双桅船、门式吊架；7–8 级玄武岩干船坞、三桅深色船壳、冷钢吊架。吊钩位置 `dockHook`，静态图只画吊绳头，货箱只在基地里挂（见下面「建筑的标志动作」），战斗里吊钩是空的。
    - 军械所（方的锻造房，烟囱是主剪影，越高级越像堡、烟囱越多）：1–2 级木墙草顶的铁匠棚、一根石烟囱；3–4 级切石作坊、赤陶瓦顶、两根烟囱；5–6 级花岗岩碉堡、宽垛口、两根更高的烟囱；7–8 级玄武岩堡、四角扶壁、三根烟囱、冷钢大门和冷钢铁砧。门口树墩上一只大铁砧（`ANVIL`，比武器架高一截，砧上搁一把锤）。
    - 每种建筑 1–8 级共用一个裁切框（`CROP`），量法：把那一行注释掉、渲出 1–8 级的并集包围盒，各边留 2 像素；画布顶留白 `UP`、左右留白 `PADX`、底下留白 `DOWN`（脚下伸出去的原木、矿车、金币堆）要盖住最高最宽的那级。
  - 基地按需补烘：开局只烘 1–2 级外观，场景贴图逐级退到已烘好的那张（`bTex` / `sTex`）；`BaseScene.refresh` 按每座建筑这一级本该用的图判断要不要补烘，所以云存档合并、换存档后高等级建筑会在补烘完后换上正确外观。
  - 变体规则：纹路由面的坐标散列（`h32`），同类物件的实例差异由 `ground.ts` 的 `jitter(img, kind, id)`（按建筑 id 的亮度冷暖微差，棕榈左右翻一半；宝藏和箱子不压暗）；全部确定性，不用随机数。别给棕榈加旋转（叶子会缺块）。
  - 地面和海：`terrain.ts` 烘成一张图（海岸线是噪声起伏的轮廓；海这一层（远海底色、压扁成岛形的径向渐变、6 层环礁浅带、几十团洋流深浅斑）全是没有细节的柔和底色，整层画在 1/4 分辨率的小画布上、一次双线性拉伸贴回（比改前 30 圈硬色阶还省）；环礁浅带只画羽化 22 像素的影子（形状挪到画布外、影子偏移回来），叠起来是渐变、没有一圈圈硬边，6 层收在离岛 3.2–5.2 格，羽化也落在地形画布（离岛 6 格）以内，四个尖角外不会被画布边直线切断；短波纹、亮点仍在全尺寸上画；湿沙带内缘一条水渍线，水陆交界一条 4 像素主浪加一道断续副浪；沙上亮暗成对的风成沙波纹、沙粒、贝壳、脚印；草皮比沙高一截：右下一片落影和草根土唇，左上半圈受光草眉，沿草边每 20 来像素一簇草，草地里成簇的三叶小草丛、草叶、小花、小石头、很淡的格子线）；`ambient.ts` 放少量补间动的浪舌、波光、鱼群、海鸥（约 18 个对象，手机 11 个，另有空白海面的船、云影、海鸟 6 个，手机 3 个，系统减弱动态时只放静止的浪舌），位置节奏全由编号定。岛扩了圈（`ext`：基地按 `islandExt`，登陆战、守岛按局里的 `state.ext`）时，地面、海岸件、装饰、浪舌、登陆光带、镜头范围都整体往外挪 ext 格，草地点缀按面积加量，不扩的岛和改前逐像素一样；基地里主寨跨档升级（5→6、7→8）由 `refresh` 发现 ext 变了，当场重烘地面、重摆海岸点缀和装饰、换镜头范围（`BaseScene.reland`）。
  - 渲染倍数：手机平板上限 `viewport.ts` 的 `PHONE_RS_CAP`；`?rs=<1–3>` 强制（测帧率 A/B，`perf.ts --query rs=1.5`）。
  - WebGL 多重采样（`main.ts` 的 `antialiasGL`）按渲染器决定（`src/view/msaa.ts`，`tests/msaa.test.ts`）：建游戏前用临时上下文读 `WEBGL_debug_renderer_info`，电脑上是 SwiftShader / llvmpipe / softpipe / Software / Basic Render 这类软件光栅就关（没显卡时 MSAA 让每个像素多算几倍，0.19 起电脑守岛从 34 帧掉到 24），真 GPU、读不到渲染器、手机平板都开（真 GPU 上几乎不要钱，关了 Graphics 画的格线、椭圆会有锯齿）；`?msaa=1` / `?msaa=0` 强制做 A/B。
- **界面皮肤**（`src/view/skin.ts`，`tests/skin.test.ts` 锁住）：界面退后半步，最亮、最饱和、最黑的留给海岛和战斗特效。胡桃木板（按钮、底栏，2 像素细边框加软投影；只有主行动的金色按钮两头各一颗暗铜钉）、顶栏胶囊和能量牌是半透明深木底（透出后面的海，奶白字加深影）、旧海图色的羊皮纸 + 麻绳边（弹窗、抽屉、信息卡、兵种卡）、麻绳分隔线。三张小纹理（木纹、羊皮纸斑、麻绳）开界面时用 canvas 画一次写进 `.hd-ui` 的 CSS 变量（`--hd-wood`、`--hd-parch`、`--hd-rope`），铜钉是渐变；
  皮肤样式全部写成 `.hd-ui.hd-skin …`（比各界面自己的 `.hd-ui .hd-xxx` 多一级，所以不管注入先后都盖得过），只换底色、边框、阴影和手感，布局规则不动；以后新界面用 `hd-btn` / `hd-dialog` / `hd-pill` / `hd-sheet` 这些现成的类就自动带皮肤，别另写底色。按钮按下去下移 2 像素、阴影缩短，松手用回弹曲线弹起。深色木牌（胶囊）上的红色提示用浅珊瑚色（`#ffb7a8`），别用深红。

## 演出、音效和后期

- **收尾演出**（`src/view/endfx.ts`，弹结算框之前在战场上演一小段，不碰结算数字和存档，结算当场就存好）：登陆战赢了活着的兵原地举武器跳（各兵错开，`cheerAt`），镜头缓推到主寨（`pushView`）；输了屏边压暗。守岛关卡赢了炮台齐射礼花，输了镜头推向冲上岸的海盗、红圈一闪、屏边压暗（`tdEnd`，`tdresult.ts` 的 `endFxLead` 从原来的等待里扣出这段，弹窗总时间不变；战役关、护航、悬赏、大潮、海盗来袭都演，护航按商船到没到港算赢输）。时间走游戏时钟（场景 postupdate，录像的 frameStep 也逐帧走），点一下或滚轮跳过（开始 250 毫秒内的点不算），减弱动态时不演、按原来的延迟直接弹窗。
- **结算演出**（样式在 `skin.ts`，时间点和声音共用 `src/view/audio/result.ts`，`tests/sfx-result.test.ts` 锁住）：框落下 → 横幅落下（`h2` 变成木板横幅，失败是灰蓝色且慢一点、不弹，守岛大潮、海盗来袭没撑过 5 波也加 `hd-lose`，这两种不落星）→ 星星依次落（登陆战每颗 350ms、守岛 300ms，从横幅落地之后开始）→ 战利品滚动 → 图标飞进仓库 → 按钮最后淡入。结算处一律调 `resultTimes(kind, stars, win)` 取 `starAt(i)`、`rollAt`、`flyAt`、`sd`、`fin`，把 `sd`、`fin` 写到结算框 `style` 的 `--sd`（其余内容淡入）和 `--fin`（按钮淡入）；声音用 `resultBeats` 排好、`playBeats`（`audio/beats.ts`）按时间点放：横幅落地一声 `land`、每颗星一声 `star`（音高每颗 ×1.12，三星最后一颗换成 `star3` 号角，不再叠 `win`）、滚动时 `coin` 连击、最后 `win` 短句；失败整体更慢更低（`land` 压低、`coin` 压低、一句 `lose`）。0 星框加 `hd-lose`，三星的遮罩加 `hd-s3`（转动的光芒）。系统开了"减弱动态效果"就不播入场动画（声音照放）。改节奏只改 `result.ts` 的常量，画面和声音一起变。
- **寻宝航线的画面**（`src/view/maproute.ts` 流程和航线图页、`mapend.ts` 终局演出 / 结算 / 分享卡、`mapfx.ts` DOM 动画时钟、`mapcss.ts` 样式、`maprules.ts` 规则注入点）：出海面板顶上一张"今日航线"卡（`.hd-mapcard`，和护航卡一起竖排在 `.hd-seacards` 容器里，按内容高度往下排；卡上只有标题和一行状态、不闪，终点写在悬停提示里，海图的主角是下一关）→ 航线图页（`.hd-route`，盖在基地场景上：羊皮纸海图、港口加 4 层节点从下到上、节点卡带风格 / 侦察 / 满分宝分 / 风险星，岛的小图按风格挑造型（`art/mapart.ts` 的 `STYLE_SHAPES` / `isleLook`：金库厚 → 黑珍珠宝箱、王座城堡，炮台多 → 成排炮台、红帆、龟壳堡垒，有暗雷 → 骷髅礁石、沉船，臼炮多 → 雾、火山要塞，终点 → 首领岛；同组里再按岛 id 散列选造型和配色，`tests/isle-look.test.ts` 锁住），小船沿航路开过去）→ 选岛弹整备条（休整一条船）或补给礁二选一 → 登陆战（`BattleScene` 的 `map` 钩子：到 `MAP_STOP_TICKS` 截断、顶上 `.hd-mapstrip` 站名 + 宝分 + 倒计时条、结束时按 `aliveByBoat` 数每条船的存活交回）→ 站间条（`.hd-route-mid`：这站宝分居中大字带单位「+N 宝分」，累计只在第二站起另起一行；「船队还剩」一格一个兵种，图、剩几 / 满编、红角标写这站折损，打光的灰掉）→ … → 终局（宝箱 / 收航 / 沉船演出后接通用结算框）。画面只调 `maprules.ts` 给的规则函数；休整能回几个人、补给礁加多少都是拿规则函数试算出来显示的。DOM 动画（小船、数字滚动、宝箱、金币）由 `mapfx.ts` 挂在游戏循环的 `step` 事件上推进、曲线用 `EASE`，所以 `frameStep` 录 60 帧视频时也逐帧走；金币走小对象池。电脑：节点卡悬停放大、1 / 2 选节点（补给礁里 1 / 2 选补兵 / 补能量）、Enter 出发、H 收航、Esc 取消。
