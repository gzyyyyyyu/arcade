# 海岛画面笔记：打击感、分件骨架、炮台、镜头

> 总览和目录在 [ui-haidao.md](ui-haidao.md)。约定和硬规矩以 AGENTS.md 为准；改对应代码时同步改这里。

## 打击感、动作和血条

- **打击感分级**（`src/view/feel.ts`，纯逻辑，`tests/feel.test.ts` 锁住）：系统的"减弱动态效果"整个画面层只在这里读一次（`REDUCED`，各处演出压短、不晃、不飘都看它），重击门槛 `HEAVY_HIT` 登陆战和守岛共用（逻辑拍长 `STEP_MS` 在 `motion.ts`）；震屏、顿帧只给大事件（主寨 / 一般建筑倒塌、主寨宝藏箱挨重击、半径 ≥ 1.5 格的大爆炸、首领登场 / 技能 / 被打倒、宝藏被抢；一般建筑倒塌只轻震、不顿帧：出海一座接一座倒，顿一次兵就停一下），调用处一律 `bigEvent(scene, hs, '事件名')` 查 `BIG_EVENT` 表，不自己写档位；
  普通命中（小兵普通攻击、塔普通开火）只给局部反馈：闪白一帧、压扁回弹、对象池里的小火花 / 木屑（`Particles.sparks`，上限 3 粒）。震屏分三档，冷却 300 毫秒，冷却里只有更高一档能打断。放兵、放技能、建筑倒塌、胜负、基地升级完成和放下建筑给 `navigator.vibrate` 短振动（iOS 不支持就跳过）。右上角静音钮下面的开关同时管震屏和振动。
- **动作和缓动**（`src/view/motion.ts` 纯函数，`tests/motion.test.ts` 锁住；`anim.ts` 是 Phaser 侧的倒下列表）：兵、英雄、守岛敌人的位置按逻辑拍（20 拍 / 秒）之间插值显示（`interpPos`，一拍跳 > 4 格算传送不插），不一拍一跳；转向用 `turnStep`（朝向在 -1..1 连续变，scaleX = 朝向 × 基准，经过 0 时压扁，不用 `setFlipX` 瞬切）；
  兵、英雄、守岛敌人的身体动作走下面的分件骨架；退化成单张帧的（远处的兵、鹦鹉群和鹦鹉王）走路按走过的距离换帧（`strideFrame`），攻击按进度换帧（`attackFrame`），倒下 `deathPose`（`DyingList` 每帧推进，不新建补间）；
  建筑受损分阶段（`damageStage`：<66% 冒烟、<33% 着火、<15% 半塌，外观和烟火间隔在 `STAGE_LOOK`），建造升起 `riseScale`，倒塌 `collapseScale`。**缓动统一**：补间的曲线名一律取 `motion.ts` 的 `EASE`（`strike` 出手、`recover` 收招 / 呼吸、`land` 落地回弹、`recoil` 后坐、`fall` / `fade` 倒下淡出、`bounce`），不在各处写 `'Quad.easeOut'` 之类的字符串、不用线性。
- **血条**（`src/view/bars.ts`，`tests/bars.test.ts`）：满血不显示，掉血后显示 3 秒再淡出（`BarTracker`，再掉血重新计时）；挨得近的条上下错开（`stackBars`，临时数组复用）；守岛里扎堆时每 48 像素见方最多画 2 条小条、残血的先留，墙和拒马全画（`crowdBars`，免得十几条错开成一根柱子盖住人）；条的记录用数字作键（兵 / 敌人是编号、英雄 -1、建筑和墙是负数），清单是复用的 `BarList`，不每帧拼字符串、建数组；兵的条小而细、建筑和墙的稍大（`BAR_SIZE`）。登陆战和守岛共用。守岛的精英（水手长、大副）是宽条加金菱形、首领（船长、海盗王）是最宽的条加金王冠，满血也一直显示、不进扎堆裁剪（谁算首领、精英在 `tdboss.ts` 的 `foeTier`，条上的徽记是 `BarItem.mark`）；首领在场时顶栏下面再挂一条粗血条（`.hd-td-boss`，名字 + 血量，跟场上最大血量的首领，`bossOf`；`tdhud.ts` 的 `syncBossBar` 每拍跟一次），`tests/tdboss.test.ts` 锁住。

## 分件骨架（兵、英雄、守岛敌人）

- **分件骨架**（兵、英雄、守岛敌人，`tests/rig.test.ts` 锁住）：
  - 每个兵种拆成影子、后腿、前腿、后臂、身体、头（睁眼 / 眨眼 / 出手张嘴三张）、帽子、前臂、武器、刀光共 10 个部件，另加一张挥砍弧形残影（`rig.arc.<倍数>`，开局用 Graphics 画一次），全部 SVG 程序画（`art/rigparts.ts`，衣服、脸、帽子和原来整张帧共用 `art/troops.ts` 的 `DECO`、`torsoShape`、`head`，守岛敌人共用 `art/tdart.ts` 的 `tdMan`），开局烘进一张图集 `rig`（`textures.ts` 的 `bakeAtlas`，皮肤另烘 `rig~<兵种>~<皮肤>`），每个部件的关节点存在帧的 `customData` 里。
  - 画面侧是 `rigsprite.ts` 的 `Rig`：一个 Container 装 10 张图，每帧由纯函数 `rig.ts` 算：关键帧采样 `sampleClip`（循环动作用 Catmull-Rom 穿过关键帧，一次性动作逐段用 `motion.ts` 的缓动）→ 加站姿 `onRest` → 正解 `solveRig`（腿挂在髋上，头、两肩跟着身体前倾，武器在手上，整个人绕脚底转 `rot`）。姿势通道都是角度（往前为正）和设计单位的位移，`Pose` 的说明在 `rig.ts` 开头。
  - 动作数据全在 `rig.ts`：`WALK`、`IDLE`、`LOOK`、`COMMAND`、`SLASH`、`SMASH`、`SHOOT`、`PISTOL`、`CANNON`、`THROW`、`HEAL`、`RAM`、`HIT`、`HIT_HEAVY`、`DIE_FLY`、`DIE_KNEEL`、`DIE_SHOT`、`DIE_BURN`、`DIE_SOFT`，每个 ≥ 8 个关键姿势，都是相对站姿的增量；兵种差异写在 `STYLE`（站姿、`scaleClip` 放大缩小的走路 / 攻击、节奏 `ms`、受击幅度、待机小动作），骨架尺寸在 `SKEL`。改动作先用 `node tools/rig-preview.ts <目录> [t.sailor,e.fog]` 渲成 PNG 看（走路 8 格、攻击按关键帧、待机、受击、两种倒下），不开浏览器。
  - 对齐规则：走路按走过的距离推进相位（一个循环的步幅 `strideOf` 由腿长和摆角 `WALK_SWING` 算，脚不打滑；身体起伏 `WALK_BOB`，触地那一拍压扁 `WALK_SQUASH`）；走路一个循环两步共 16 个关键姿势（`gaitClip` 按兵种的步态参数生成：落脚压得快、蹬地抬得慢，腿出得快收得慢，手臂反相、比腿晚半拍还带一点过头回弹，头比身子滞后，左右两步不镜像）；各兵种先定想要的步频（重兵慢而沉，水手碎步快），再按规则移速反推腿的摆幅，步幅跟着变，所以仍不打滑；攻击按规则的冷却算进度（`atkPhase`：离下次出手 hit·ms 内是预备和出手，出手后 (1-hit)·ms 内是余势和收招），出手段用 `fall` 加速进、`recoil` 减速出，最快的一帧落在规则的出手拍（远程即 `shoot` 事件），刀光 `trail` 跟着亮；挥砍、重砸、投掷是全身动作（蓄力身子后仰、整体后转、重心后移，出手前压、前脚迈出，收招回原位），`Clip.arc` 标了的画弧形残影（`arcLook`，壮汉的锤最长最亮）；出手点上这个兵自己顿 `HITSTOP_MS`（60 帧下 2–3 帧）再 smoothstep 追回规则进度（`stopK`），不顿全屏、不进大事件；动作之间 140ms 混合，不跳姿势；待机呼吸，偶尔东张西望（只在待机时插）；受击叠加闪白和后仰，一下掉最大血量 ≥ 25% 或伤害 ≥ 90 算重击（`HIT_HEAVY`：更大后仰、踉跄一步、火花 5 粒，判定在 `dmgkind.ts` 的 `isHeavyDmg`）；倒下由 `deathStyleFor` 按伤害类型选：炮弹 / 爆炸炸飞（`DIE_FLY`，落地弹两下带尘）、枪弹中弹倒地（`DIE_SHOT`）、火烧焦（`DIE_BURN`，渐黑冒烟）、被晕着倒的软倒（`DIE_SOFT`），伤害类型由 `dmgkind.ts` 从开火 / 爆炸事件推（规则不给，推不出退回 `deathStyle`：单次伤害 ≥ 90 或一下掉半血以上飞，否则跪倒），帽子单独飞（`hatDrop`），再淡出，交给 `DyingList` 推进，播完回对象池。减速（焦油、冰冻类命中，规则核心只读的 `slowUntil`）的兵身上黑点和脚下粘油挂在 `Rig` 里跟着兵的深度走；焦油陷阱被踩是黑油溅开加地面水洼（`tarfx.ts`，池子 10 个），不放爆炸。
  - 性能：`RigPool` 对象池（不在出兵时新建）；`lodOf`：离屏（留 `LOD_MARGIN` 24 像素）隐藏不算、身高小于 `LOD_PX` CSS 像素换成单张烘焙帧，换回完整骨架那一帧一定重算姿势；屏内完整骨架多于 `RIG_CAP`（36）时按「离屏幕中心的距离 ÷ 体型」排，前 36 个画完整骨架、其余换单张烘焙帧（`rigcap.ts` 的 `RigCap`，用上一帧的排名，正在完整档的打 8 折免得来回换；首领、精英体型大排在前面；守岛和登陆战共用，`tests/rigcap.test.ts` 锁住）；完整骨架多于 `CROWD`（36）时按编号错开隔 2～3 帧重算姿势（`poseEvery`），位置照样每帧插值。显示对象数（容器里的部件也算）由 `countObjects` 报给 `perf.ts`。
  - 测试钩子（只给工具用，地址栏开关全在 `src/view/devflags.ts` 读，改玩法的都要带 `?dev`）：`?dev&devarmy=<兵种>[:<个数>]` 全军换成这种兵；`?dev&devwalls` 登陆战去掉最外面的金矿、在沙滩和炮台之间拉一道城墙（拍手雷越墙）；`__haidao.tdFx('stun' | 'lob' | 'shield')` 守岛里放一次震晕 / 手雷的画面、`tdFx('ship')` 取第一条船画在海里的位置、`tdFx('sink')` 让它当场沉掉（录沉船用）、或把第一个敌人换成盾兵（只在 `?dev` 下）；`snipeLive()` 现在有几条狙击预警线在画（连拍等预警出现再开拍）；守岛的 `units()` 给每个敌人的格子坐标 `x/y`（截某个敌人倒下的局部图用），对盾兵多给盾朝向 `gx/gy`；`?mt1` 把 WebGL 合批限到 1 张纹理（SwiftShader 多纹理合批会随机丢整个精灵，只在录像时开，测帧率别开）；`__haidao.units()` 列出场上单位、`follow(id, zoom)` 镜头跟住一个单位、`towers()` 列出炮台（含当前目标的屏幕坐标）、`lookAt(x, y, zoom)` 镜头对准一点、`turretStats()` 开火次数和开火时还没转到位要补的角度、`occluded()` 画过遮挡剪影的帧数、`frameStep(n, ms)` / `frameEnd()` 停下帧循环手动推帧；`tdAuto()` 让当前守岛局交给普通难度机器人代打（截海盗王、友军船这类后几波才出的画面用，真人截图别开），`tdAuto(false)` 停下（截战书这类要真人点的画面）；`tdInfo()` 带关内事件挑好的波（`events`）、接了战书的波（`dare`）和现在下不下雨（`raining`），`units()` 对赏金船多给 `bounty: true`。`__haidao.dev.load(profile)` 把存档换成给定的整份存档并重载（截某种布局的海盗来袭用，例如 `tools/sample.ts` 的 `fullBase(8, 'spread')`，只在 `?dev` 下）。
  - 盾兵的大木盾（`shieldlook.ts` 纯函数，`tests/content2-fx.test.ts` 锁住）：盾不是兵手里的武器，是图集里单独一个部件（`<种类>.shield`，只有 `t.shield`、`e.shield` 有），`Rig` 把它挂在容器里，每帧按规则给的盾朝向（`BUnit.gx/gy`、`TdEnemy.gx/gy`，世界坐标 ×100，经 `RigIn.gx/gy` 传入）摆：世界方向换成屏幕方向，盾在身体朝那一侧（朝下宽而完整、朝左右变窄、朝上藏到后臂后面），转身时摆法逐帧追向目标（约 100 毫秒绕过去，不瞬跳）；被震晕（`RigIn.gdown`）盾垂下。规则推 `guard` 事件时场景调 `Rig.guard`：盾沿盾面往身体里一顿再弹回（`guardKick`，260 毫秒阻尼振荡）、盾心（`Rig.shX/shY`）爆一团亮闪 + 几粒火星 + 一点木屑、播 `guard` 音效；减弱动态只亮闪不晃。被溅射打到规则不推 `guard`，画面就不出这些。
  - 船长（英雄，登陆战和守岛共用 `t.captain`）拿手枪：部件是 `troops.ts` 的 `pistol`，攻击动作 `PISTOL`（举枪瞄准 → 开火 → 后坐 → 收枪，角度沿用火枪的瞄准和后坐、去掉装填）；守岛里开枪按规则的出手拍对齐（`atkPhase`，`h.cd` 是下次能开火的拍，时长取英雄装填和动作时长的小者），边走边开的那一枪按开火事件补演后半段。守岛英雄比骨架原大再放大一圈（`RigIn.size`，2.0 / 1.7），脚下暖金底盘（`heroRing`，半透明金色实心椭圆加亮边），层级取「自己的格子」和「身边 56 像素内最靠前的地面敌人 + 0.05」的大者（混战里压在人堆上面画）；敌人互相挤开的上限 `CROWD_MAX_TD` 60。
  - 英雄等级外观（`art/rigparts.ts` 的 `heroRank`，`HERO_RANK_LEVELS` 4 / 8 / 12）：4 级帽子插白色长羽，8 级加金肩章，12 级腰带上再插一把手枪；每一档是一张单独的部件图集（`rigTex('t.captain', 'rank1'…'rank3')`，`TdScene` 开局按 `s.hero.level` 按需烘，烘好前用普通图集，烘好用 `Rig.setup` 换上）。测试钩子 `__haidao.dev.td(hq, branch, hero)` 的第三个参数直接给英雄等级。
  - 航海士（守岛第二个英雄，`h.nav`，`tdworld.ts` 的 `heroRig` 按 `s.hero.kind` 挑）：骨架 `man(1.56, …)`，比船长瘦小；部件在 `art/navigator.ts`（`NAV_DECO`：深青短外套、奶白扎巾加深青条、脑后长辫、V 领两排铜扣、腰挂黄铜望远镜）和 `rigparts.ts` 的 `navParts`（和兵共用 `manParts`）；端长管火枪，攻击动作用火枪手的 `SHOOT`，待机偶尔挥手（`COMMAND`）、张望（`LOOK`）。等级外观 4 级辫子金扣、8 级金肩章（和船长同一副）、12 级金边望远镜（`NAV_RANK`）。
  - 守岛里的船（炮艇、海盗王，`tdcommon.ts` 的 `SHIP_FOES`，整张图）：在水里上下起伏（`shipBob`，±2.4 像素）；开炮时船身往炮口反方向坐 7 像素、压扁一点再回位（`shipRecoil`，0.32 秒，`ESpr.fired` 记开炮时刻），炮口冒烟（`cannonSmoke`）；被打沉时不走人倒下，`Rig.sink` 改用 `sinkPose`（1.2 秒：船身按吃水线往下缩、尾巴翘、后四成淡出），溅水花、飞木片、冒烟，半路再冒一串气泡（`bubbles`）。减少动效时不晃不坐。
  - 倒下的单位（`anim.ts` 的 `DyingList`）：深度压低 0.6（排到同格活人下面），压暗到 0.8 倍、后半段更快淡掉（`dyinglook.ts` 的 `dyingDim`），扎堆时活人一眼能挑出来。
  - 遮挡（`occlude.ts`，纯函数 `occludes` / `boxOf` 在 `fxlayout.ts`）：兵走到建筑后面时人照常不透明，在挡住他的建筑上面另画一张他当前动作的整帧剪影（浅蓝、半透明）。建筑的不透明外框按 128 像素的格子分桶，每个兵只查身体中点那一格的几座，不两两全比；剪影图走对象池。城墙、陷阱、海怪、宝藏箱和全部装饰（`category: 'deco'` 的：棕榈、岩石、旗杆、雕像、宝箱、章节纪念，名单 `fxlayout.ts` 的 `NO_OCC`，登陆战和守岛共用）不算挡；只给完整骨架（`lod` 0）的兵画，同屏最多 14 个剪影。护航商船不是 Rig，被塔楼挡住时 `escortview.ts` 用 `Occluder.blocker` 查挡它的建筑，在建筑上面画一张浅蓝剪影（按时间淡入淡出，减弱动态直接到位）；船头顶上另有一条一直在最上层的血条（`shiplook.ts`，掉血时白色残段按时间收回）。
  - 伤害数字（`fx.ts` 的 `DamageNumbers`）：字号是屏幕像素，按镜头的实际缩放换算（录像跟拍时也对），近景不会跟着放大；`dmgFontPx` 封顶到小兵屏幕身高的一半多一点，最小 13 像素。守岛里扎堆时，0.3 秒内、56 像素内的不同目标共用一个键（`tddmg.ts` 的 `DmgClusters`，墙钟毫秒、4 倍速下也一样），合成一个“这一团的总伤害”，再由 `DamageNumbers` 累加和错开；大字比小字升得快，后出的大字追上先出的小字时，每帧把早出的那个往上推开（`fxlayout.ts` 的 `pushApart`，只推不回落）；新数字的落点（`pickSlot`）按它自己的大小错开，两个数字之间至少隔 `DMG_GAP`（4 像素），不再贴成「-117-463」。守岛的「+N」金币字（`tdhud.ts` 的 `ftx`）：0.9 秒内、屏幕 110 像素内的同类字并成一个往上加（`fxlayout.ts` 的 `pickMerge`），敌人在宝藏边成片倒下时只剩一两个数。守岛宝藏被抢走只抖箱子、飘「-N」、宝藏牌变红；整屏红闪只在宝藏真被带走时闪一下（1.5 秒内几处一起漏只闪一次，`tdevents.ts` 的 `lossFlash`），以前抢一下闪一下，第 3 波以后屏幕几乎一直是红的。

## 炮台

- **炮台**（`src/view/turret.ts`、`aim.ts`、`shots.ts`、`art/turrets.ts`，纯函数在 `aim.ts`，`tests/aim.test.ts` 锁住）：登陆战和守岛的加农炮、火枪塔、臼炮、喷火塔、鱼叉炮、火箭塔拆成底座（`turretBaseArt`，原建筑图去掉炮管）加 16 个方向的炮管（每个方向按真透视画，`art/turrets.ts`，开局和底座一起烘进图集 `tur.<种类>.<档>`；档按等级分 `turretTier(kind, level)`：炮台 1–2 / 3–4 / 5–6 / 7–8 四档（`tier4`，和底座同一套分档），火枪塔的火枪手 1–2 / 3–4 / 5–8 三档；整张图（图标、没烘好分件时）上的炮头由 `turretHeadBody` 画，和分件图集同一套画法、同一个代表等级；火枪塔的顶棚另烘一张，只在 2、4、6–8 级有，`gunTowerRoof` 别的等级给 null），朝向在两个方向之间用一点残余旋转补上，转起来是连续的。
  - 瞄准：炮管有角速度上限和加减速（`aimStep` 梯形速度曲线、不过冲），规则的开火拍不动，画面按离下次开火的时间提前转；来不及就在离开火时间很短时切成三角速度曲线赶，开火那一帧还差的角度直接补上（`aimSnap`，`turretStats` 记次数和最大补角）。没目标时慢慢回到待机朝向（`idleAim`）。
  - 开火：预备（往后一缩）→ 炮口闪光加一团烟（粒子池）→ 后坐 → 复位（`recoilAt`，各塔的幅度、时长在 `TURRET_SPEC`），底座小抖（`shakeAt`），不震全屏。火枪塔的小人举枪、开火、通条装填（`musketPose`）；喷火塔的火舌有起、持续、收尾（`flameStep`，火舌图 `fx.flamejet`）；鱼叉炮开火后炮上是空的，叉子带绳飞出去、命中后绳子先绷紧再收回（`ropeBack`），收回才重新装上；火箭塔打完空架子，装填时间到了再装上。
  - 狙击塔（`sniper`，登陆战和守岛共用）：瞭望台底座（`buildings.ts` 的 `sniper()`，四档轮廓见下面「防御建筑的剪影」）加 1.1 格长的细炮管（`turrets.ts` 的 `sniperDir`，管上架瞄准镜、炮口消焰口；铁管木托 / 铜箍黄铜镜 / 乌铁金箍红镜片 / 再加一块冷钢护盾），进 16 方向炮管图集。规则推 `aim` 事件（带 `fireAt` 开火拍）时 `SnipeLines`（`snipefx.ts`，样子在 `snipelook.ts` 纯函数）从炮口到目标胸口画红线、目标脚下画红色等距准星，`SNIPE_WARN`（0.5 秒）里线越来越粗越实、准星越收越紧、最后亮出白芯，开头几下轻闪；预警期间炮管跟着被锁定的目标转（`renderTurrets` / `syncTurrets` 用 `fireAt` 当离开火的时间）。开火（`shoot` 事件）收掉预警：炮口一大团亮光加三团顺炮管拉出去的长焰、深后坐、底座轻颤，弹道用 `snipe` 素材（`Shots` 直线飞、记一道白色弹迹 260 毫秒淡掉，命中点一团白闪）、一声重枪（`synth.ts` 的 `snipe`）。目标倒下、逃走、塔没了，预警自动收掉。减弱动态：线不闪、准星不收缩、弹迹更短。
  - 弹道（`Shots`）：按规则的发射拍 / 命中拍逐帧插值，臼炮高抛、炮弹低弧、火箭微弧、子弹直线（`arcHeight`），地面阴影随高度变小变淡（`shadowLook`），落点按材质（`LandMat`：沙地、水、木、石；地面再按 `onSand` 分岛外沙滩和岛上草地）分轻 / 中 / 重三档出特效：水花加两圈涟漪、石屑加火星、木屑碎片、草地土块加草屑、沙尘（`fx.ts` 的 `impact*` / `ripple`，碎片朝向和数量由落点序号散列，可复现）；落点粒子总量封顶 `IMPACT_CAP`，超了先淡掉最老的（`fadeOldest`），减弱动态只一帧淡闪；图像对象池，阴影和绳子画在两张每帧重画的 Graphics 上。
  - 性能：不在每帧或开火时新建对象；离屏的炮台只推进角度、不改图；分件没烘好时退回旧的整图后坐补间。

## 镜头适配

- **镜头按岛适配（fit）**（`src/view/camfit.ts`，`tests/fitcam.test.ts` 锁住）：基地、登陆战、守岛三个场景进场时，横屏和电脑是整座岛含沙滩都在"可见区"里，不用拖就能找到任何建筑和登陆点；手机竖屏（可见区高 > 宽 × 1.2）改按"有内容的区域"适配（`fitView`，内容 `Content`）：三个场景都放大到内容盒约占屏高 60%（`PORTRAIT_LIVE`），上下完整在可见区里、左右可以裁，主寨（`must`）挪进屏内；另给一个全景（内容盒装进屏，有主寨时可裁左右空沙角），开场先停在全景再推过来（下一条）。基地的开场推镜只在这次打开游戏后第一次进基地时演（`basegeom.ts` 的 `firstBaseEntry`，`Content.intro`），之后回基地直接停在放大档：竖屏里基地横向只露出四成多，一进来要先看到整座岛，但每打完一仗回来都推一遍太烦。横屏和电脑上基地和登陆战按内容盒适配（`Content.tight`，缩出去仍能看全岛）；登陆战的缩放上限放宽到 `BATTLE_Z_CAP`（2.2，`Content.zCap`），以前按含沙滩的整岛适配、封顶 1.5，1280 上岛只占三成、兵二十来像素。可见区 = 整屏扣掉顶栏和底部（手机横屏是右侧）操作区，扣多少不写死，`measureInsets` 读界面真实位置（`.hd-hall` `.hd-bar` `.hd-bar2` `.hd-td-bar` `.hd-td-bar2` 算顶部；`.hd-bottom` `.hd-cards` `.hd-td-bottom` 宽的算底部、窄而靠右的算右侧）；`islandBox` 给包围盒（登陆战含四面 3 格沙滩和登陆点，基地和守岛外沿留 1 格，守岛再加临时塔位和登陆口），`fitBox` 算缩放和中心，最大缩放 1.5。内容盒由各场景给（`cellsBox`，格子矩形外扩 N 格）：基地 = 建筑占地外扩 1 格（`must` = 主寨）；登陆战 = 建筑占地外扩一圈沙滩宽（3 格，夹进登陆区）；守岛 = 塔位、临时塔位、宝藏箱和其他建筑、`tdRoutes` 给的登陆口到宝藏箱的真实路线格，外扩 1 格。放大是可选的：双指 / 滚轮（`CamCtl`，最小缩放是整岛适配的缩放，玩家随时能缩出去看全岛，最大是适配的 3 倍），松手不自动回弹；`FitCam`（第 6 个参数传内容盒）在放大或平移离开全景后显示"回到全景"钮（`.hd-fitbtn`，56 像素），转屏 / 窗口变化时没放大过就重新适配。
  - **竖屏放大的基地、登陆战、守岛**（`FitCam.live`；基地没有下面的自动构图和屏边箭头，只有开场推镜和「全景」钮；纯函数在 `src/view/camguide.ts`，`tests/camguide.test.ts` 锁住）：开场先停 1 秒全景（按内容盒装、不再按含沙滩的整岛盒；有主寨时裁掉左右空沙角再放大一档，岛占的高度比整岛盒多约六成），再用 0.9 秒慢进慢出推到落点（`camAt`，缩放按比例插值），落点由 `FitCam` 第 7 个参数给世界 x（守岛 = 第一波要用的登陆口和离这几路 3 格内的木台一起取平均（`tdworld.ts` 的 `introFocus`），推近后能看到要守的木台，不只看海，登陆战 = 发光沙滩多的那半边的最外沿；登陆战另开 `Content.scoutPano`：竖屏开场不推、停在全景当侦察，所有红圈都在屏里，玩家选船卡或技能时 `endScout` 再推到落点，最后一船上岸时 `panTo` 平移到各登陆点中间（`BattleScene.landAt`，不缩放）），`focusCx` 夹住不越出内容盒；单击（下船、放技能）不打断推镜，拖开超过点按阈值（鼠标 6、触屏 10 像素，`camgesture.ts` 的 `takesCamera`）、双指或滚轮才停下、把镜头交给玩家（以前一点就停，镜头留在全景，竖屏岛只占屏高三成）。"全景"钮一直显示，在整岛全景和开场视角之间切换（字跟着变"全景" / "放大"）；选关页、海图、侦察这些整屏页盖在基地上时它收起（`layout.ts`，钮在 z 30、整屏页在 z 20，不收会压住页上的按钮）。开场推镜走完后是**自动构图**（一套逻辑，登陆战、守岛、护航共用）：`FitCam` 每帧问场景的 `Director` 看哪里（`setDirector`），缩放不动，只平移；死区、限速、慢进慢出是纯函数 `autoStep`（偏离超过可见宽的 18% 才起步，追到 2% 以内停，护航跟船 `track` 没有死区），减弱动态时只慢慢平移。看哪里：登陆战是自己的兵里最大的一簇（`biggestCluster`）加它们多数人在打的那座建筑；守岛是离宝藏最近的敌人那一拨（`groupAround`）加最近的宝藏，岛上没敌人、这一波还有人没上岸时看登陆口沿路往岛里走 3 格（`laneFocus`，`tdIncomingWave`、`tdWaveLanes`），都没有就不动（开波前、两波之间造塔时镜头不乱跑）；护航是船前方 3 格（`EscortView.camFocus`）。主组和目标放得进可见区八成就一起框（`frameFocus`），放不下只看主组，所以一拨人正冲宝藏时新一波上岸不会把镜头拉走。让位：玩家拖、捏、滚轮、点屏边箭头、切全景都记一笔（`FitCam.markUser`），停手 4 秒（`AUTO_IDLE`）后接回；刚点过画面 2.5 秒内（`TAP_HOLD`）、开着造塔 / 升级面板、在瞄技能、登陆战还选着船（还在下船）、停在整岛全景时都不动。守岛里屏外的敌人在可见区边上出红圈箭头加剑图标和「×N」（`.hd-td-edge`，44 像素，点一下镜头平移过去），屏外的补给箱出金圈加箱子图（`.hd-td-edge.crate`，44 像素，点一下镜头平移过去，再点箱子叫英雄去捡），屏外的空木台出不能点的木牌「+」（几块并成「+N」，只在够钱造最便宜的塔时出现，`.hd-td-edge.slot`），护航屏外的路口和关口出黄旗加箭头（`.hd-td-edge.gate`，和地图上的路口旗一致），预告卡指的那块木台（开局造法 / 下一座造 / 升级）在屏外时出金底锤子箭头（`.hd-td-edge.goal`，44 像素，点一下镜头平移过去；`goalClear` 让同段的空木台小标让位、和敌人箭头叠着就顺边挪一段）：`edgeMarks` 沿"可见区中心 → 它"求和边缘轨道的交点，每条边按 52 像素分段、同种同段合成一个，隔 120 毫秒重算、对象池。系统减弱动态时不推镜，直接到开场视角。横屏和电脑不进这个模式，行为不变。
