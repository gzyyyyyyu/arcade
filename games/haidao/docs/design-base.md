# 《海岛》设计：建岛、成长和画面（第 2、6 节）

> 设计总纲和目录在 [DESIGN.md](../DESIGN.md)，节号沿用总纲的编号。本文写现状；数值以 `src/content/` 为准。

## 2. 成长与等级

### 2.1 卡节奏的东西（不靠等待时间）

| 卡什么 | 怎么卡 |
|---|---|
| 资源 | 金币（建筑、升级）、木材（造兵、研究、旗舰）。来自产出建筑和掠夺；仓库有上限，逼人花掉、逼人出门打 |
| 战役星数 | **主寨升级要求累计星数**（例：升 3 级要累计 7 星、升 5 级要 16 星）。星数只能靠打赢关卡拿：想升级就得会打 |
| 主寨等级 | 其他建筑的等级 ≤ 主寨等级；每级主寨开放新建筑、多几个同类建筑名额、新兵种、更多旗舰能量 |
| 进攻成本 | 每场出海付造兵的木材，打输也花掉；木材不够整支船队时自动少带兵（先减单价最高的，船坞配置不动，`trimArmy`），一个兵都带不起才开不了；重打已三星的关只给三成掠夺，逼人往前推 |

### 2.2b 第二期内容（0.2.0，以 `src/content/` 为准）

- **等级上限 8**：建筑、兵种、技能、研究都到 8 级（数值外推）。主寨 7 级 27 星、38,000/8,000，开放鱼叉炮、火箭塔、鱼叉手；8 级 36 星、70,000/13,500，开放焦油陷阱、火炮兵、船医；开局能量 16、18。
- **新兵种**：船医（人口 2，不打建筑，跟着伤得最重的友军，每秒给 3 格内至多 4 个兵回血）；火炮兵（人口 3，只打建筑，射程 8，90 伤害，3.5 秒一发）；鱼叉手（人口 1，射程 5，0.7 秒一发，优先打防御，血薄）。
- **新防御**：鱼叉炮（单体高伤，射程 9，5 秒一发）；火箭塔（一轮三发打三个不同的兵，小范围溅射）；焦油陷阱（隐藏，踩到后 1.5 格内的兵减速一半几秒）。
- **首领岛**（每 5 关，`boss`、`bossName`、`mechanic`）：c05 炮台阵、c10 海怪（长在岛边海里，周期性拍打附近海滩的兵，能被打掉）、c15 迷雾（雾塔 5 格内的建筑在兵走近前看不见、炮击打不中）、c20 焦油沼泽、c25 火箭要塞、c30 终极混合。
- **c13–c30 的布局**由 `src/content/gen.ts` 的生成器按风格摆出（保证不越界不重叠）；首领岛和 c13 起的电脑岛不受玩家主寨名额限制。
- **每日悬赏**（`dailyBounty(dayIndex, p)`）：以最远通关的关为中心往回最多 2 关取模板，随机翻转，掠夺翻倍，同一天同进度结果相同。**成就** 16 个（`ACHIEVEMENTS`、`checkAchievements`），部分带称号。
- **30 关节奏**（`tools/pace.ts`，0.4.0）：c11、c12、c13 首过在活跃第 37、46、49 分钟；c23–c30 首过在第 97–127 分钟，这段最大空档 6.5 分钟，全程最大 13.3 分钟（c17 前后）。原来 c23 之后空等 57 分钟，原因是主寨满级后只剩军械所 7、8 级可买，花费超过仓库容量；所以 7、8 级的花费倍率从 9,500 / 16,000 降到 6,500 / 9,000。
  机器人普通星数大多 1.5–3（0.3.0 的难度调整见 2.2c）。`tests/progress.test.ts` 见 2.4。

### 2.2c 第三期：战术和收获感（0.3.0，以 `src/core/` 为准）

- **城墙和寻路**（`battle.ts`）：城墙 1×1，主寨 2 级开放，名额 10–60。兵按格子做确定性的代价流场找路：别的建筑不能穿，墙能穿但代价 7，
  所以有缺口就绕、绕太远就砸最近那段墙；流场按目标缓存，建筑占格或存亡变了才重算。炸药兵 6 格内有墙先去炸（对墙 ×3），火炮兵专打防御塔。
  `tests/tactics.test.ts`：同一支部队，有墙引导的布局摧毁率平均 50%，无墙 66%。c30 岛加 46 段墙整场重放约 130 毫秒（服务端重放的预算 200 毫秒）。
- **推荐布局**（`presetLayout(p, 'turtle'|'spread'|'trap')`）：只重摆现有建筑，不增不减。龟壳 = 墙一圈、防御围主寨；分散 = 资源和防御拉开、怕溅射的打法吃亏；陷阱 = 墙圈留口子，口子里外地雷焦油、炮盯口子。
- **侦察**：出海前看敌岛布局和射程，地雷、焦油不显示（和战斗里一样）。开场 3 秒俯瞰，首领岛写机制和解法（`LevelDef.counter`）；普通机器人按同样的解法打（躲海怪一侧、火箭塔多就分两侧登陆、雾里不炮击）。
- **连胜和安慰奖**（`settleCampaign`）：≥1 星连胜 +1，每场掠夺 +10%、封顶 +50%；0 星清零连胜，给该关掠夺的 15% 加 10 木材。以上（含首次星奖励）最后再乘收入倍率（2.4），再按仓库上限截；截掉的（`settleCampaign` 返回的 `cut`）结算框写「仓库满了，少拿 N」，带一个「去扩仓库」钮（回家就打开建造面板）；一分没进仓库时不写「安慰奖已经放进仓库」。
- **掉宝**（`rollDrops`，确定性）：≥1 星必有一个金币或木材箱；稀有（3 种装饰 + 8 兵种 × 3 皮肤）按星数 3% / 6% / 10%，首领岛首次三星必掉一件；不重复掉已有的。
  装饰只占格不打仗；皮肤只换颜色（`equipSkin`），不改数值。存档校验只认稀有池里的、已拥有的。
- **每日悬赏**打 `dailyBounty` 当天生成的那座岛（翻转后的布局），掠夺 = 悬赏奖励（关卡掠夺 × 2 × 收入倍率）× 摧毁率；≥1 星才算完成，不改战役星数和连胜、不掉宝。
- **首领岛布局**：c15、c20、c25、c30 是通道式布局（`gen.ts`）：主寨四面各留一条两格宽的道，塔放四个象限，地雷焦油只埋在道上，从哪面登陆差别很大（c30 小白按面 0.7–2.5 星）。主寨 7、8 要的星数见 2.2 主寨表（27、36）；主寨 6→7 的停留最长。
- **关卡难度曲线**：按共用难度线（`src/content/difficulty.ts`，守岛战役、护航同一条）：普通机器人三星率从 c01 100% 线性降到 c30 45%、小白至少 1 星从 100% 降到 65%，偏出 ±20 点算离群（`node tools/sim.ts --fun --n 200` 的目标列和 ↑↓ 标记读它）。布局（下面的 `TUNE`、城墙、摆位）定这一关怎么打，强弱再用每关的 **`defPct`**（`campaign.ts` 的 `DEF_PCT`，防御塔血量和塔、陷阱伤害的百分比，没列的 = 100；`LevelDef.defPct` → `campaignSetup` → `BattleSetup.defPct`，规则版本 28）拉到线上；`--level cNN --def N` 逐关拟合。悬赏出海用冻结副本、流浪海盗岛只借布局，都不带 defPct。实测表在 docs/balance-haidao.md 难度曲线总表。
  **细档旋钮**（`gen.ts` 的 `TUNE`，每关一条）：`lv` 基础等级，`up` 按固定顺序（先外圈后内圈）把 `up` 座炮塔再升一级（最高 8，狙击塔和震荡炮不参与，用 `lvBy`），`wall` 墙单独等级，`add` 在原有数量上加狙击塔 / 震荡炮，`pos` 摆位方案。同一关的 `lv` 差一级普通机器人胜率常常 100% → 20–50%，`up` 把这一级拆成 `up` 个小步。
  **胜率主要由狙击塔和震荡炮决定**：c13、c20 单靠升塔到主寨等级也还是 100%，要靠狙击塔（射程 11）和震荡炮把难度拉起来，所以这两种塔按关加（`add`：c15 加 2 狙击 + 2 震荡、c16 / c17 / c23 各加 1 座狙击、c18 和 c22 各加 2 + 2、c20 加 4 + 1、c21 加 1 座震荡、c24 加 2 + 1、c25 加 1 + 1、c29 加 1 座狙击并少 1 座火箭塔；c21、c24、c27 原有的保留）。通道式的 c15、c20、c25 也按 `n` 里的狙击塔 / 震荡炮摆（`SNIPE_POS` / `SHOCK_POS`）。塔等级不超过主寨等级（`tests/base.test.ts` 检查），所以 `up` 到顶以后不再加。
  **摆位对胜率的影响很大**：两种机器人会挑登陆的海滩，摆位一动，胜率可以整段翻转。c26、c28、c29 用 `EDGE`（沿岛边）后小白不再被打光——原来 `CORE`（贴主寨）的 c26 小白 10%、`NORTH` 的 c28、c29 的 S 面登陆（小白 1/50）都被火箭塔 / 加农近距离扫掉。
  **小白**：只当参照；各关 35–95%，相邻落差 ≤ 25，仅 c11→c12 约 −32、c19→c20 在种子 1001–1100 是 −31。c11→c12 是 c11 偏高（小白 86%，c10、c12、c13 都在 53–62%）：c12 降喷火 / 炮 / 枪塔 / 臼炮、拿掉地雷，小白最多 +6，普通却掉到 50–63%；c11 升喷火 / 臼炮 / 枪塔 / 炮，小白只到 80–87%，普通平均星从 1.7 掉到 1.0–1.4（会让主寨 6→7 凑星更慢）。机器人输赢主要看登陆哪面，升降塔调不动小白，所以两关都不改。c29 少一座火箭塔（南面登陆正对两座火箭，小白从南面上岸只赢 28%）：小白 59–66% → 74–81%，夹在 c28（76–77%）和 c30（79–83%）之间，普通 76% → 76–79%。
  `TUNE` 里没有的关（c30、前 12 关）保持手写布局。悬赏借用的 c07、c10、c16 已冻结成悬赏专用表，战役这份随便调。

### 2.6 海盗王阶（主寨 8 级以后的金币、木材出口，以 `src/content/rank.ts`、`src/core/rank.ts` 为准）

主寨 8 级以后金币木材用不完，王阶给它们一个长线出口：**10 阶，只给外观和展示，不加任何战力**。

- **价**：第 n 阶金币约 40,000 × 1.35^(n-1)、木材约 15,000 × 1.35^(n-1)，表在 `rank.ts` 的 `RANKS`（铁锚、铜锚、银锚、金锚、黑帆、赤帆、金帆、海王冠、深海王冠、海盗王）。10 阶合计 218.3 万金币、82 万木材，约是 8 级玩家 14 天的收入（每天约 15.7 万金币 / 7.2 万木材），先按这个定，看真人数据再调。
- **怎么献**：主寨信息面板的「海盗王阶」区，点「献上」把手里的金币木材按下一阶还差的量献进去（`donateRank`），两样攒满自动升一阶、重新攒。后几阶比 8 级仓库上限（16.2 万金币）还贵，所以每阶可以分几次献。献进去的记在 `Profile.rankFund`，拿不回来，也不在 `res` 里，所以不会被别人抢。

- **登陆战的落点、技能预览和误放撤回**（0.30.2 预览；规则版本 13 起可撤回）：电脑悬停时画兵落地的散开框和技能作用圈（炮击圈内建筑描边、信号弹要标的建筑描边、没有目标是红圈加叉）；信号弹点在范围内无建筑处规则整个不生效，画面提前拦下并提示。手机没有悬停，不加两步确认，保持点一下就放；点错了靠撤回补救（15.3）。兵的走位、绕路、砸墙量过（机器人整局加带城墙的典型布局，首次出手前路程 / 直线 1.0–1.25 倍，无原地抖停），未发现要改规则的问题。
- **建筑选中与遮挡**（基地、守岛选塔通用，画面层，规则不动）：等距视角里高建筑（主寨最明显）的贴图盖住身后好几格，原来按贴图外接矩形、前面的优先，点主寨后面的大炮、仓库永远选中主寨（2026-11-10 实测）。现在的判定：
  1. 先按占地格：点击点换算成格坐标，落在哪座建筑的占地菱形里就是哪座（占地互不重叠，所以最多一座）；
  2. 占地格没命中（点在建筑高出地面的部分），再按贴图不透明像素（alpha）找，前面的优先；
  3. 同一点（几像素内）连点，在这一点下所有命中的建筑之间循环，选中被压住的那座；
  4. 悬停（电脑）和按下（手机）时画该建筑的占地菱形加描边，电脑悬停头上出名字；选中、悬停、拖动摆放的建筑被前面的高建筑挡住时，前面的建筑变半透明，被挡的那座画描边剪影。
  点和拖的区分按移动阈值（按下后移动超过阈值算拖镜头，不算点）。
- **岛的大小**：底子是 22×22（`ISLAND`），玩家自己的岛按主寨向四周扩圈（2.2，8 级 26×26），战役、悬赏、航线、护航的岛不扩；"挤"另靠上面的选中、遮挡半透明和镜头默认缩放（基地默认把主寨和身后一排都放进可见区、建筑不小于可点的尺寸）解决，老存档布局一格不挪。
