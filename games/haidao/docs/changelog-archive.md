# 更新日志（归档）

0.23.0 到 0.30.5 的更新日志。0.31.0 起的见 [CHANGELOG.md](../CHANGELOG.md)，0.22.0 以前的见 [changelog-archive-early.md](changelog-archive-early.md)。

## 0.30.5（2026-11-02）

内部整理，加一处画面修复（规则核心只改了名字、一处纯函数的拆分、加一个只读函数，指纹没动）。

### 修复

- 踩了焦油的兵身上看不到黑点：减速在规则里一直生效（走路确实变慢），但画面去读兵身上一个规则从来不写的字段，所以黑点从没画出来过。规则核心加只读的 `slowUntil`，画面按"当前拍还在减速期内"画黑点、颜色发暗；焦油和命中减速都算。

### 改动

- 接入 Biome lint（`npm run lint`，零报告）：能自动修的几类写法机械改写，逗号表达式拆成语句。
- 去掉 `as unknown as` 强转：`app.save` / `app.game` 改成没初始化就抛清楚错误的取值器；海图、悬赏、装饰直接具名导入美术和规则的函数，不再探测"可能不存在"；双指手势、升级演出的槽位、校验快照时的容量计算不再拼假对象（新增 `capacityOfBuildings`）。
- 战斗里带版本号的函数按作用改名：`stepDefensesLegacy` / `stepMinesLegacy`（规则 < 6）、`stepDefensesBranches`（6–8）、`stepDefensesCombat`（≥ 9）、`stepMines`（≥ 6）；`flowFor` 内联进 `nextCell`。
- 画面层所有 `setDepth` 的层级数收进 `src/view/depth.ts` 的 `DEPTH` 常量表。
- 去掉没人用的 `TROOP_SCALE`；`rewardName` 不再经场景文件转手。
- 文档：README 加"新人上手"和冒烟命令，`package.json` 加 `engines`，AGENTS 补 lint、层级表和函数名。
- 冒烟 `shot.ts --td`：造塔面板里展开克制表后先点"收起"再选塔（0.30.3 起克制表展开时只留表）；测试钩子 `units()` 多给 `slow`（这一拍在减速里），截焦油图用。

## 0.30.0（2026-11-01）

- 新防御「狙击塔」（主寨 6 级开放，6–7 级 1 座、8 级 2 座）：射程 11 格（全岛最远），4 秒一发，一发的伤害是同级加农的两倍多，不溅射。先打船长、船医，再是掷弹兵、火炮兵这类躲在后排的；锁定后 0.5 秒才开火（画面有瞄准线预警），兵走出射程就白瞄。怕人多：一发只打一个。
- 新兵种「盾兵」（主寨 7 级开放，一个占 3 人口）：血是壮汉的八成，走得慢、伤害低，举盾走在前面。盾朝走的方向（打建筑时朝目标），正面 ±60° 来的炮弹、子弹、鱼叉、狙击只吃三成半；身后 1.5 格内的友军也少吃三成。盾挡不住溅射和抛射（喷火、臼炮、火箭、震荡炮、手雷），被震晕时盾放下。
- 守岛里多了第 8 种塔「狙击塔」（枪弹，打重甲只有一半；3 阶可选"穿甲"打重甲不再减半，或"连狙"一次两发；18 关战役开放）和新敌人「盾兵」（重甲，正面挡枪和炮的单体伤害只吃三成半，火、爆和溅射照吃）。盾兵这一版只在海盗来袭第 9 波起出现，预告卡写"盾兵：正面挡枪炮，用溅射、爆破"；大潮无尽（这周的榜）不放盾兵、不能造狙击塔，护航也不能造。
- 旧页面要刷新一次才能继续打攻防和悬赏。
