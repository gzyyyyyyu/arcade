# 海岛画面笔记：基地、升级、摆放、操作和登陆战界面

> 总览和目录在 [ui-haidao.md](ui-haidao.md)。约定和硬规矩以 AGENTS.md 为准；改对应代码时同步改这里。

## 基地和登陆战界面

- **基地界面**：顶栏只留金币、木材、主寨等级、训练营和一个船长钮（手机竖屏只一行：大厅、金、木、船长头像、设置，主寨等级和训练营收起，见 ui-haidao.md「三种屏幕的排布」）（`.hd-profile`，点开"船长档案"面板：星数、成就和称号、收藏）；筹码换资源的"换"钮跟在主寨等级后。底部操作栏（建造、出海、船队、守岛）带红点（`src/view/dots.ts` 的纯函数 `baseDots`，`tests/dots.test.ts` 锁住）：「建造」上红点 = 有建筑现在升得起、金点 = 金矿 / 伐木场有能领的，两颗都在右上角、同时只亮一颗（红的优先，左上角留给数字键角标）；「出海」上红点 = 有没看的防守记录（`pvp.ts` 的 `unseenDefenseCount`）。建造列表顶上列出现在能升级的建筑，点一下回岛上（手机弹它的操作环，电脑开它的信息面板）。
  建造卡灰着的直接写原因：名额满了写「主寨 N 级加名额」（`basefeel.ts` 的 `nextSlotHq` / `fullText`），买不起的写「还差 N 金币」并淡一点。顶栏金币 / 木材花了钱（升级、建造、研究）抖一下并在牌子下半截冒一个红色 -N 往上飘着淡掉（`spendFx`；不往下飘，手机竖屏下面是第二行的「训练营」，在 `updateHud` 里比对上一次的资源，收取不走这里）。
  选中的建筑（点过、右键过、开过面板的那座）占地有一圈细金边，快捷键作用在它上面。
  **选中判定**（`basepick.ts`，规则正本 DESIGN.md 第 6 节「建筑选中与遮挡」）：点击点先换算成格坐标，落在哪座建筑占地里就是哪座；占地没命中再读贴图那一个像素的 alpha（`textures.getPixelAlpha`，先用 `artBox` 外框排除，只读 1×1，一次判定约 0.02 毫秒），前面的优先；同一点（`8 / z` 世界像素内）连点在这一点下所有命中的建筑间循环（`Cycle`）。悬停、右键取最前，不循环。手指按下（`CamCtl.onPress`，抬起、拖开、双指时收）就画占地菱形，电脑悬停加名牌。焦点（摆放虚影 > 按下 > 悬停 > 选中）的占地被前面的高建筑盖住时，前面那座变半透明（0.35，140 毫秒淡入淡出，减少动效直接到位，每 0.6 秒或焦点变了重算）。岛按主寨扩圈（1–5 级 22×22、6–7 级 24×24、8 级 26×26，DESIGN 2.2），老坐标不动；基地进场镜头横屏和电脑也按内容盒适配（`Content.tight`，`fitContent` 顶边多留一截给高建筑），缩出去仍能看全岛。
- **升级面板**（`openInfo`；纯函数在 `src/view/basefeel.ts`，`tests/basefeel.test.ts` 锁住；样式在 `src/view/basecss.ts`，全部限定在 `.hd-sheet` 下）：两栏 `.hd-up`。左栏是当前等级的大立绘（`.hd-up-big`），能升级时下面一排「N 级 ➜ N+1 级」两张小图（`.hd-uphero`，下一级带金光）；右栏（`.hd-up-side`）从上到下：一行描述、路线 / 已满级小牌、数值表（`.hd-stats`：名称 / 当前 / → / 下一级 / +差值，数字 `.hd-n` 等宽右对齐，增量 `.hd-pos`，全部读内容表 `statDiff`；满级只有名称和当前）、花费框 `.hd-upbox`（金币木材图标加数字，`costGap` 不够的那项标红并写「还差 N」）和大升级钮，升不起时按钮灰着写原因（`whyNot`），原因是缺星或缺资源时下面多一个去处钮：缺星「去出海打关拿星」，缺金币「去出海抢金币」（矿里攒着的够补上差额就先「收金矿里攒的 N」），缺木材「收伐木场里攒的 N」。收取（金矿、伐木场）和移动挂在标题栏、关闭钮左边（`.hd-up-acts`），不占内容高度。其余内容收在两栏下面的 `.hd-up-more`：主寨的「升到 N 级开放」和海盗王阶（`rankBlock`），塔的 3 级 / 6 级分叉卡（`branchCards`）和「守岛全额生效」那句，军械所的研究网格。面板最底一行「接着升」（`.hd-up-foot`）列最多 3 个现在也升得起的建筑，点一下直接换过去。三种屏幕：电脑面板在右侧、宽 600（军械所 `min(1040px, 100% - 24px)`，升级两栏在左、研究网格在右），其余内容在两栏下面；手机横屏（高 ≤ 500）面板靠右站满顶栏下面的高度，有其余内容时铺满宽，升级两栏和「接着升」在左、其余内容在右（分叉卡竖排）；手机竖屏两栏变上下：能升级时只留「这一级 ➜ 下一级」两张图（这一级就是当前的样子），满级时小立绘在左、描述数值在右，「接着升」压成一行（12 号字）；矮竖屏（高 ≤ 700）再收紧标题栏和间距、王阶块缩小。五个尺寸都由 `node tools/noscroll.ts --group 基地` 的「建筑信息面板（炮台）」「建筑信息面板（主寨）」「建筑信息面板（主寨满级）」「军械所面板」量。
- **军械所研究**（`baseupgrade.ts` 的 `researchList`）：网格卡片分「兵种」（一排 5 列）、「技能」和「英雄」（并排在下面）三组。每张卡是一整个按钮（`.hd-rs-card`）：图标和等级小牌一行、名字一行、下一级花费一行（缺的数字标红）；升得起的卡是金底，点一下直接升；升不起灰着写原因（主寨 N 级解锁、先升级军械所、已满级，英雄写「主寨 N 级可升」），只缺资源时照样列花费。英雄卡另写 8 级新技能「锚钩」和航海士的解锁情况，悬停提示写 9 级以上只加守岛。电脑、平板和 390×844 竖屏一页放下；844×390 横屏和 360×640 矮竖屏放不下就在研究区（`.hd-up-more`）里页内翻页（`paginate` 的 `sync` 把整组都不在这一页的小标题收起），升级钮和「接着升」不动。
  基地面板的位置：电脑在右侧、按内容高度（最多到屏底 12 像素，`layout.ts`，守岛的造塔面板同样），手机竖屏是底部抽屉、最高到顶栏下面（`basecss.ts`），手机横屏（高 ≤ 500）靠右站满顶栏下面的高度、宽 `min(660px, 78%)`（`layout.ts` 定位、`basecss.ts` 定宽；面板开着时底栏收起，所以能贴边）。开面板时镜头平滑地把这座建筑挪到面板以外可见区的正中（可见区按面板的真实位置和顶栏底栏算，右侧面板让左边、抽屉让上面；建筑太小就拉近一点，不超过最大缩放；`basefeel.ts` 的 `panelFocus` / `camLerp`），这期间镜头的软边界临时放宽（`CamCtl.slack`）；关面板再平滑回到开之前的镜头，玩家中途自己拖过、缩放过就不回。
- **升级演出**（`src/view/upfx.ts` 的 `UpgradeFx`，时间线是 `basefeel.ts` 的 `upPlan` / `upFrame` 纯函数）：升级仍是立即完成（规则不等时间），画面放 1.75 秒（主寨 2 秒）：施工（脚手架从地面升起围住建筑，`art/scaffold.ts` 前后两半各一张、进基地时烘焙；三四下锤子的火星木屑尘土 `Particles.hammer`，`hitWood` 声；建筑颤）→ 完成（脚手架往外倒、落下、淡掉，新外观换上、旧外观残影放大淡出，压扁 - 弹高 - 回弹，加色闪一下，金光柱、光圈、彩带和金币 `Particles.confetti`、泛光，"升级!" 和等级数字跳一下；`upgrade` / `upgradeBig` 声，260ms 后点缀 `coin`（主寨 `star`），`vibrate('upgrade')`）。城墙只放完成那一下（1 秒）。新建筑放下时是建造演出（`UpgradeFx.build`，时间线 `basefeel.ts` 的 `buildPlan` / `buildFrame`）：围脚手架 → 本体按 `riseScale` 从地面升起 → 完工金光，小建筑 1.5 秒、大建筑（主寨或占地 ≥ 3）1.6 秒；城墙用 `UpgradeFx.rise`（`WALL_RISE_MS`，0.38 秒升起），减弱动态时都不演。主寨解锁新建筑后，弹窗关掉时底栏「建造」钮和主寨脚下亮一下（`BaseScene.showNewHint`，样式在 `newhint.ts`）。演出不挡操作，逐帧按 dt 插值，不用补间、不开定时器；脚手架、光柱、残影、文字在最多 4 个槽位里复用（满了把最早那场播完）。施工时 `holds(id)` 让 `refresh` 先别换贴图，换外观那一下由演出回调 `retexture`；正在演的建筑 `busy(img)` 时 `refresh` 不改它的位置。主寨的解锁弹窗等演出播完再出，成就徽章再等弹窗关掉。解锁弹窗里新开放的有建筑时，主按钮「去建造看看」直接打开建造列表、翻到第一种新建筑那一页（`celebrateGo`、`openBuild` 的 `focus`），另有「先不了」；只有兵种技能时主按钮是「好的」。
- **摆放**（建新建筑、移动）：新建时虚影从画面中心往外找最近的一块空地起步（`startSpot`：先找四周留一格、前方再多留一格的地方，免得压在高建筑身后看不见，找不到再放宽，能不能放以 `canPlace` 为准）；新手引导开着时底栏的提示行收起，不和引导文字抢位置。按格吸附，可摆的范围是扩圈后的岛 [-ext, 22+ext)（`BaseScene.ext` = `islandExt`，`clampPlace`、`placeCheck`、`startSpot`、拉城墙都按它），虚影可以探出岛外 size-1 格（`clampPlace`），每一格按能放 / 出界 / 压到建筑涂绿 / 红（`placeCheck`，和规则核心的 `canPlace` 对拍），底栏写原因（`placeReason`："压到金矿了"、"超出岛的边界了"）。电脑：鼠标移动就是预览（不用按住），左键放下，右键或 Esc 取消，滚轮照常缩放，左键拖动照常平移、虚影跟着鼠标，鼠标贴着画布边 40 像素内镜头自己平移（`edgePan`，越贴边越快）；城墙按住左键拖出一排、松手放下。手机：手指拖（虚影比手指高一截），松手不落地，虚影旁边出 ✓ / ✕（52 像素，`.hd-place-float`），点空地把虚影挪过去。手指 / 鼠标按最近一次按下的 `pointerType` 切换。移动已有建筑放下有落地演出（`UpgradeFx.drop`：落下越来越快、压扁回弹、着地一圈尘、轻振，`dropPose`）；放不下时点了虚影左右晃一下并提示原因。虚影平时轻轻上下浮（`hoverBob`）。测试钩子 `where('ghost')` 给虚影占地中心的页面坐标，`focusOn(kind, k)` 镜头对准某种建筑放大到全景的 k 倍（`kind#i` 是这种建筑的第 i 座，从 0 数），`lookAt(x, y, k)` 镜头对准世界坐标一点、放大到全景的 k 倍（`perf.ts` 的基地场景用）。
- **操作环**（手机，`src/view/ringmenu.ts`，`tests/ringmenu.test.ts` 锁住）：手指点建筑在它外圈弹出圆钮（直径 48、环半径 88、底半透明，悬停或按下才不透明，免得把建筑和邻居盖住；升级、信息、收集、训练营（只主寨有）、移动，按建筑可用的显示，项和电脑右键菜单共用 `basefeel.ts` 的 `buildingMenu`；升级不可用时灰着、点了提示缺什么；能升级 / 能收集的钮带红点）。环每帧跟着建筑的屏幕位置，靠边时整圈内收（`ringLayout` 把环中心夹进可见区）；点空白、点别的建筑、开任何面板都会收起 / 换环。环开着时，被某颗圆钮压住的收取气泡先藏起来（`ringCovers`，也点不到），环收起再露出来。"信息"才打开建筑面板；升级、收集在环里直接做。引导第 2 步（看主寨怎么升级）指向环里的"信息"（鼠标用户直接点主寨）。
- **新手引导横幅**（`src/view/tutorial.ts`，八步：收金币、建金库、看主寨升级、看船队、出海、登陆和放炮（选中炮击后横幅收起，只留瞄准条那一句）、回家升主寨（主寨 1 级别的建筑都升不了，所以直接指主寨和操作环的「升级」；星或资源不够就指「出海」）、去训练营看看；老玩家开档直接到最后一步，只被指一次训练营）：一句话和「跳过引导」排一行，宽度跟着字走（最宽 560）；停在顶栏下或底栏上，永远不压在岛上，左右让开贴边的竖排（手机横屏右侧的兵种卡和技能列、海图左上的悬赏和航线卡、海图右上的「回岛」「找下一关」），让完不足 240 宽才不让；换一步时横幅淡入一下。高亮框和箭头每帧跟着目标走。
- **点和拖的区分**（`src/view/camgesture.ts` 纯函数，`tests/camgesture.test.ts` 锁住）：按下后移动超过阈值才算拖镜头——鼠标 6、触屏 10 个 CSS 像素（手指抖得多、指肚大，所以更宽）；否则松手算点。拖过阈值就一直算拖（拖回原处松手也不点），双指、被摆放拖拽接管、按住超过 0.6 秒都不触发点按；惯性滑动中按下会先停住，不吃点按。缩放：滚轮以鼠标、双指以两指中点为不动点。
- **守岛选木台 / 塔**（`src/view/tdpick.ts`，判定顺序同基地 DESIGN 第 6 节）：先按木台占地格（2×2），没命中再按塔图不透明像素（狙击塔、喷火塔是镂空木架，14 CSS 像素内有像素就算，前面的优先），同一点连点在叠住的几座之间循环；电脑悬停、手机按下都在这块台上画占地菱形（按下更实）。
- **电脑操作**（`src/view/inputs.ts`，`CamCtl` 的 `onTap(wx, wy, mouse)` / `onHover` / `onRight(wx, wy, sx, sy)` / `mouse`）：滚轮以鼠标为中心缩放、左键拖动平移（右键、中键不平移也不触发点按）、悬停高亮（基地的建筑占地、登陆战能登陆的沙滩格、守岛的木台，光标变手）、右键或 Esc 取消选择 / 关面板、空格回全景（守岛倒数里空格是"开打"）、数字键选第 n 个按钮（基地 1–4 = 底栏；登陆战数字键选兵种、Q W E… 选技能；守岛 1 拒马、2 炸药桶（带航海士时 1 急射旗、2 重赏）、3 叫下一波、4 章末机制钮（水闸），锚钩排在最后（有机制钮是 5，没有是 4），建塔菜单开着时 1–6 选塔；守岛另有 S 卖塔、U 升级、C 敌人图鉴、H 选中英雄；按钮右上角的小数字只在有鼠标时显示，快捷键写进按钮的悬停提示）。
  基地另有（按每次按下是鼠标还是手指区分，不只看 `(hover:hover) and (pointer:fine)`，无头浏览器和触屏笔记本都对）：左键单击建筑直接开右侧信息面板；右键建筑弹上下文菜单（`.hd-ctxmenu`，贴在鼠标旁 `menuPos`，竖排升级（带花费）/ 信息 / 收集 / 移动，每项右边写快捷键，点外面、滚轮、Esc 收起）；悬停建筑头上一个小名牌（`.hd-nameplate`：名字 + 等级 + 能升级时一个绿箭头）。快捷键（`BASE_KEYS`）：U 升级选中的建筑、I 信息、C 收集全部（所有金矿伐木场一次收）、M 移动、B 开 / 关建造列表、Esc 依次收菜单 / 取消摆放 / 关面板 / 取消选中；没选中时作用在鼠标下面那座；有弹窗时不响应。键位写在按钮的悬停提示里（`withKey`）。所有按钮有悬停态（`layout.ts`，`@media (hover:hover) and (pointer:fine)`）和按下态（皮肤的 `:active`）。≥ 900×560 的屏幕，基地和守岛的面板放右侧（宽 400），不把手机竖排的抽屉拉宽。

- **登陆战落点和技能预览**（`aimpreview.ts` 画、`aimcalc.ts` 纯计算，`tests/aimcalc.test.ts` 锁住，不改规则）：电脑悬停时，选着船画兵落地后的散开框（`LAND_SPREAD` = 规则里的 ±60 单位），选着技能画作用圈（半径取 `SKILLS` 当前等级）；炮击把圈里的建筑描橙边，信号弹用 `flareTarget`（照 `doAction` 的判法：半径内最近、没毁、看得见、不是装饰 / 地雷 / 焦油）描出要标的建筑，没有就是红圈加叉。`battleinput.ts` 的 `tap` 里信号弹点在没目标的地方（规则会整个不生效）时提示并保持选中，手机也走这条；选技能的提示条见 `skillHint`。手机没有悬停，不做两步确认（提示和教程都是点一下就放）。
- **登陆战看懂防御**（`battleranges.ts`）：开场俯瞰画全岛防御的射程红圈（`scoutRings`，首领岛另加首领卡），俯瞰收起后不淡掉，留到出第一船（拍数离开 0）再淡（`BattleScene.scoutG`）；有盲区的（臼炮一类的 `minRange`）在圈里压一圈带斜线的暗圈。什么都没选时点一座敌方防御（没吸到登陆圈的点），单独画它的射程和盲区 2.6 秒（`pickReach`，再点别的换掉）。信号弹标着的建筑头上一直挂一个呼吸的金色准星（`drawFlare`，读规则核心的只读函数 `flareTarget`，标多久挂多久；画在血条那张每帧清空的 Graphics 上）。
- **拿星飞进顶栏**（`battleinput.ts` 的 `flyStar`）：拿到一颗星时屏幕中间冒出一颗大金星（放大一下）、转着弧线飞进顶栏第 N 个星槽（Web Animations，0.76 秒），到了槽里那颗点亮弹一下；减少动效时直接点亮。
- **登陆战兵倒光**：船都出完、兵（医疗兵不算）都倒了、还剩能量时规则不结束（够放技能），以前计时照走、画面上没动静；现在提示条写「兵都倒了：还剩 N 能量，放完技能点「结束」」，「结束」钮一明一暗地亮（`battleinput.ts` 的 `allDown`，`.hd-endglow`，减弱动态时常亮不闪）。
- **登陆战沙滩高亮**：进场就亮（`beachG` 呼吸，外沿一圈金边），选了船更亮更快；所有船登陆后或选了技能就收起。提示条先说"先点船卡，再点发光的沙滩"。点到非沙滩仍提示并闪一下。出船的点：画出来的海岸线和草边是波浪形的，和规则的方环对不齐，所以点在环外 0.8 格、岛内 0.4 格以内的都吸到环上最近处；已经选着船时，点在岛里面多深都吸到最近那条边的沙滩上（`deep`，竖屏一屏大半是草地，试玩里点了 4 下只出去 1 船）（`beachfx.ts` 的 `snapLanding`，悬停的金格按吸附后的那格画；规则照旧只认方环）。寻宝航线一站的竖屏放大档最多推到全景的 1.3 倍、居中不偏一侧（`Content.nearCap`、`camfit.ts` 的 `MAP_NEAR`），四面的沙滩都在屏里。再点已选中的船卡不取消（出完一船再点卡是常见手势），取消用右键、Esc 或点技能；什么都没选时点沙滩，替玩家选上第一组还有船的卡并提示再点一下，这一下不出船。登陆战结算点「再打一次 / 下一关」时，新成就的卡先在结算页弹、点「太棒了」再开下一局（不挡在下一局开场）；点「回岛」照旧在岛上弹。
- **登陆区光带和挤开**：`beachfx.ts` 的 `BeachGlow` 在可登陆区铺浅金呼吸填充、外缘金边和绕圈光点，选了兵种更亮，悬停那一段亮成白弧（按毫秒算，减少动效时静态）；`crowd.ts` 的纯函数把挤在一起的兵在显示层互相推开（按体型留间距、不推进建筑和海里：被挡住时不缩小偏移，而是把推力沿建筑边 / 海岸滑开，正对着墙的按编号分左右；偏移按时间平滑），规则位置不变，`tests/beachfx.test.ts`、`tests/crowd.test.ts` 锁住。守岛的敌人也挤开（`tdsync.ts` 的 `crowdEnemies`，同一个 `crowdOffsets`）：最多推 `CROWD_MAX_TD`（0.4 格，比登陆战小，炮弹和伤害数字按规则位置落，推远了像没打中），不推进没倒的墙和塔台，飞的不参与；前后遮挡按挤开后的位置排。停泊的炮艇、海盗王不参与挤开，另由 `moorOffsets` 画到海上：规则里它们停在海滩圈里，画面上沿最近的岸往外推到沙滩外沿以外，同一条岸边的船沿岸排开（间距 `MOOR_GAP`，整排中点不变），开炮起点跟着显示位置。
- **空白海面**（`ambient.ts` 的 `openSea`）：岛外上下两侧的海面有远处慢漂的船（沿等距方向、淡入淡出）、云影（`coastArt('cloud')`，很淡的大块深蓝，盖在地面上、建筑下面）、海鸟（扇翅膀）；共 6 个对象，手机 3 个，只用补间的 onUpdate、不新建对象；只在镜头里（含一圈余量）时才显示，屏外的不进渲染（电脑横屏时这两条海面大多在屏外）；云影只走这两条海面、不横穿岛（整片半透明填充贵，`perf.ts --query sea=0` 对比 sea=1 差 < 1%）；系统减弱动态效果时都不放。
