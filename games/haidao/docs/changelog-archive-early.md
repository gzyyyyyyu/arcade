# 更新日志（归档，早期）

0.22.0 以前的更新日志。0.23.0 到 0.55.0 见 [changelog-archive.md](changelog-archive.md)，0.56.0 起的见 [CHANGELOG.md](../CHANGELOG.md)。

## 0.22.0（2026-10-31）

- 新玩法「寻宝航线」：每天全服同一条四站航线、同一支船队，每站在两座岛（或补给礁）里挑一个，打一场 50 秒的小登陆战；死掉的兵不回来，旗舰能量整条航线共用，出战前可以让一条船休整。
- 终点宝岛打下来开宝箱，金币按这站的宝分飞出来；中途可以收航，宝分照算；船队打光按七成算。
- 结算给星（宝分 90 / 150 / 200）、各站明细和分享卡，宝分交到平台的每日榜，一天可以跑多趟，取最好的一趟。
- 入口在出海面板顶上的「今日航线」卡；刷新或中途离开，下次打开接着走。
- 电脑上：1 / 2 选节点，Enter 出发，H 收航，Esc 取消。
- 修正：同一档炮台被两个场景同时烘焙时报"贴图名已占用"。

## 0.21.0（2026-10-30）

- 炮台会转身瞄准：炮管平滑转向目标，有转速上限和缓入缓出，开火时已经对准。
- 开火有过程：先微微后缩，炮口火光加一团烟，炮身后坐再回位，底座轻轻一震，不震屏。
- 炮弹沿弧线飞、地上跟着影子，落点按地方不同扬起尘土、水花或木屑；臼炮抛得高、落得重。
- 火枪塔里有小人举枪、装填；鱼叉炮的绳子拉直再收回；火焰塔喷火有起势、持续和收尾。
- 小兵动作更有劲：走路步子和起伏加大一倍，落脚一沉；出手时整个身子先后仰再前压带重心，锤子和刀挥出弧形残影，打中的一下停顿一瞬。
- 镜头拉近时伤害数字不再比人还大。
- 兵走到建筑后面不再看不见，建筑上会透出他的剪影。
- 岛外海面的船、云影、海鸟出了镜头就不画，省下帧率。

## 0.20.1（2026-10-30）

- 修电脑上守岛变卡：0.19.0 一屏看全后电脑上的岛画得更大，没有独立显卡的电脑守岛帧率从约 34 掉到 24、隔一会儿就顿一下；没有显卡、靠 CPU 画的电脑上关掉画布的多重采样后约 42，比 0.19.0 之前还顺；有显卡的电脑照旧开着，画面不变。手机不变。

## 0.20.0（2026-10-30）

- 小兵、英雄、守岛的敌人改成分件骨架：身体、头、两臂、两腿、武器各自会动，不再是整张图来回挪。
  - 走路腿前后摆、身子起伏、手臂反向摆，脚不打滑；待机呼吸、偶尔东张西望。
  - 攻击分预备、出手（带刀光）、余势收招，出手那一下正对上伤害；挨打闪白后仰。
  - 倒下分被打飞和跪倒两种，帽子会掉，最后淡出。
  - 兵种节奏不同：水手轻快，壮汉和铁甲慢而沉，火枪手开完枪要装填，火炮兵推炮会被顶退，船长挥刀大开大合。
- 点建筑弹出的操作环变小、离建筑远一点、底半透明，不再把建筑和旁边的房子盖住。

## 0.19.0（2026-10-30）

- 进攻时能登陆的沙滩一进场就发光，选了船更亮，点沙滩就派。
- 基地顶栏只留金币、木材、主寨等级和船长钮；星数、成就、收藏收进"船长档案"。
- 底栏（建造、出海、船队、守岛）加红点：有建筑能升级、矿和伐木场能领、被人打过。
- 点建筑在旁边弹出操作环（升级、信息、收集、移动），升级和收集直接在环里做。
- 岛外的海面有远处的船、云影和海鸟。
- 手机竖屏、手机横屏（操作区挪到右边）、电脑三种排布；电脑上滚轮以鼠标为中心缩放、左键拖动、悬停高亮、右键或 Esc 取消、空格回全景、数字键选按钮，面板放右侧。

## 0.18.0（2026-10-29）

- 音效重做（全部程序合成）：
  - 基地、战斗、守岛各有自己的环境声（海浪、风、海鸟）。
  - 各种塔开火声音不同；命中按木头、石头、金属发声。
  - 建造、升级、倒塌按建筑大小分档；兵出发吆喝、受击闷哼、阵亡一声。
  - 技能、按钮点击、确认、出错、金币入账都有声音；同类声音有 2–3 个变体，听着不机械。
  - 密集时自动限流，大声音响起时把小声音和环境压低一会儿；静音和切后台照旧。
- 结算的声音和动画对上节奏：横幅落地一声、每颗星一声且越来越高、三星号角、金币连响、最后胜负短句；失败更慢更低。
- 手机竖屏的基地按岛放大，岛撑满顶栏和底栏之间；单指拖动平移、双指缩放，不会触发浏览器页面缩放。
- 战斗和守岛底部的兵种卡、技能钮换成木板和羊皮纸：选中金底上浮、充能时暗化带进度、不可用去色加锁，一眼分清。
