## 0.35.0 — 2026-10-31

## 0.34.0 — 2026-10-31

- 茶馆擂台的称号和最远几桌接上云存档：登录后同步到账号，换设备登录也在，几台设备打的称号合到一起；擂台页标题旁的云朵显示同步状态，没登录点它去登录。换了账号时这台设备上旧账号的称号先存着，登录回去再并回来。
- 擂台中途点"大厅"或"离开"：这一桌的存档留着，下次接着这一手打（以前会按同一副牌从头重开）。

## 0.33.0 — 2026-10-31

- 新玩法"茶馆擂台"：主页"擂台"进，血战、血流、立直三种打法任选，连打三桌（新手 → 普通 → 高手，每桌一局），打完不亏就算赢，输一桌这一轮结束；三桌全赢拿"血战擂主""血流擂主""立直擂主"称号。中途离开，下次接着这一桌打。纯娱乐，不碰筹码。

## 0.32.1 — 2026-10-31

- 按全站界面规范统一界面：结算里的术语（本场、供托、跳满、里宝指示、退税等）点一下看大白话说明，平胡不再写"0 番"，每局重复的长提示只在第一局出；电脑上碰杠胡过按钮角上标出快捷键字母，规则里加"键盘"一页；"声"面板分成音量、茶馆声、提示三组，加"恢复默认"；断网和失败的提示统一成几句固定的话；手机竖屏选档页的"主页"不再盖住灯笼、版本号不再被按钮压住；立直结算的"荣和"章不再被顶栏裁掉，庆祝光环不再盖住役种；顶栏统一成"玩法 · 模式 · 档位"。

## 0.32.0 — 2026-10-31

- 听牌速判新增"今日一轮"：每天所有人同一套清一色题，每天只能打一次，登录后成绩进每日榜；打完可以分享成绩卡，之后随时练习（不计今日成绩）。主页"速判"显示"今天 N 分"或"今天未做"。

## 0.31.0 — 2026-10-31

- 新玩法"听牌速判"：60 秒内把每手清一色听的牌全点出来，全对才得分，连对有加成，越往后听的牌越多越难；主页"速判"进，记着本机最好成绩。只是娱乐，不碰筹码。
- 主页那一排进度（每日、何切、速判、成就、图鉴）：手机上一排放不下时左右滑着看，不再被截掉；电脑上折成两行全摆出来。

## 0.30.1 — 2026-10-31

- 内部重构，玩家看不到变化：页面层按玩法不同的东西收进各玩法的页面钩子（`view/variants/<id>/page.ts`），页面代码不再按玩法 id 分叉；`src/main.ts` 拆成 `src/app/` 下按职责分的文件，会话状态集中到一个对象；架构测试加了一条，防止页面层再出现按玩法分叉。
- 单机冒烟（`npm run smoke`）修好：结算框里的按钮只认开着的那个（关掉的结算框淡出时还在页面上），一场打完按"回选桌"认（单机的按钮早已改叫"再来一局"）。

## 0.30.0 — 2026-10-31

- 川麻新增"血流成河"：胡了不下桌，手牌锁住接着摸打，可以连着胡好几次，一直打到牌墙摸完，每次胡当场结算。连胡越多演出越热闹（"连胡！"→"三连胡！"→"血流成河×n"），名牌上写"胡×n"，一局小结列出每一次胡。娱乐场和好友房能开：选桌页的规则设置里打开，或者在主页选"血流成河"再点快速一局；实盘先不开。
- 主页对血战到底的一句话介绍改对了：血战是胡了下桌，打到只剩一家或牌墙摸完。
