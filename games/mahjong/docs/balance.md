# 雀馆的配平目标

> 本文件是雀馆用到的那部分配平目标；全站总表在总仓库的 docs/balance.md，两边改动要同步。

目标：好玩、爱玩；拿筹码的时间期望和难度要平衡、逻辑清楚；小白在低难度下不能被电脑碾压。
这份是量化目标，`scripts/balance.ts`、`scripts/balance-riichi.ts` 量出来，结果写进 [balance-results.md](balance-results.md) 和 [riichi.md](riichi.md) 第 7 节。
档位、每份多少、封顶以平台的筹码体系为准，这份只管"多难、多快、赢多少"。

## 1. 两个玩家模型

| 模型 | 打法 | 用途 |
|---|---|---|
| 小白 | 打孤张、不防守、不读牌，见碰就碰、见杠就杠，常打错（`scripts/play.ts`） | 定"低难度够不够友好" |
| 普通 | 简单合理的打法：会看牌效、会防守、会弃和 | 定"认真玩能不能赚" |

模型是确定性的机器人（带种子），不读隐藏信息；每个数字至少 2,000 场，报均值 ± 2 倍标准误。

## 2. 实盘：每场期望（单位：份）

| 档位 | 小白 | 普通 | 电脑 |
|---|---|---|---|
| 小 | +0.05 ～ +0.15，赢的场次 ≥ 50% | +0.20 ～ +0.40 | 最弱一档，偶尔犯错 |
| 中 | −0.05 ～ +0.05 | +0.10 ～ +0.20 | 普通 |
| 大 | −0.20 ～ −0.10 | 0 ～ +0.10 | 强 |
| 豪华 | ≤ −0.20 | −0.05 ～ +0.05 | 最强 |

- 一场最多输一份、最多赢 3 份、大多数场次在 ±1 份以内。
- 一场不超过 25 分钟。雀馆实盘一局一结约 2 分钟，每场期望按比例小得多，不套上面的区间，看每小时期望：小档普通玩家每小时 +0.6 ～ +1.2 份。

## 3. 娱乐：难度档（不挂筹码）

难度档叫新手 / 普通 / 高手。"胜"= 一场结束分数为正。

| 难度 | 小白的胜率 | 普通的胜率 |
|---|---|---|
| 新手 | ≥ 60% | ≥ 75% |
| 普通 | 40–50% | 55–65% |
| 高手 | ≤ 30% | 40–50% |

- 新手档的电脑要"看起来像人"地弱：不刻意防守、少碰少杠、少做大牌，不靠明显的蠢操作。
- 第一次玩默认新手档；选档时每档一行说明：电脑多强（★）、一场多久、适合谁。

## 4. 立直的取舍

立直里小白比普通每场少约 0.35 份（要防守、要判断立不立，比川麻吃技术），第 2、3 节两列装不下：

- 实盘小档、娱乐新手档按小白调（小白不亏、新手档小白胜率 ≥ 60%）；
- 中、大、豪华档和娱乐普通、高手档按普通那列调，小白那列照实写；
- 不用"输了打折"之类加规则的办法，也不把小白换成更聪明的机器人凑数。

## 5. 给玩家看的

选档页每档一张卡，写三件事：电脑多强（1–4 颗星）、一场约多久、一场最多赢 / 最多输（实盘写筹码数）。

## 6. 验收

- 第 2、3 节每一格的实测值（均值 ± 2SE）和目标区间对照，超出的写原因。
- 改数值只改电脑强弱、计分系数，不改规则本身；规则核心的确定性和"电脑不看牌"的测试照样过。
