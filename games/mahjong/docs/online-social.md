# 好友房的社交与互动

> 从 [DESIGN.md](../DESIGN.md) 第 6 节拆出：叫朋友、分享卡、颁奖、搭子战绩、好友动态、位置与邀请、牌桌互动与聊天。房间、钱、声明窗口、快速匹配仍在 DESIGN.md 第 6 节。

- **叫朋友来**（kit 的"叫朋友来"面板 `openInvite`，`docs/social.md` 1.3）：等人页的大按钮（座位坐满后退成轻按钮，主按钮让给开打）和顶栏"叫朋友"打开它。登录了列好友（在线的在前、写在哪），每人一个"叫他来"（平台记一条邀请，好友那边顶上弹横条），底下"复制邀请链接"；单独部署、没登录只有复制链接（能系统分享就分享）。链接是 `/games/mahjong/?room=123456`。没登录的人：Worker 的登录闸门 302 到
  `/login?next=<encodeURIComponent(路径 + 查询)>`，页面里发现没登录也一样拼（`platform-features.md` 5.7）；登录完整页跳回原链接，房间码在查询参数里原样带回，本模块不自己存房间码。
- **加入朋友的桌**：好友房选桌页问一次 kit 的 `fetchFriends`，有在线、正在雀馆好友房里的朋友（他报的位置带房号），标题右边摆一个「加入 X · 2/4」（昵称最多 4 个字）（没坐满的在前，只摆一个），点了进房；娱乐房开打后进来直接接管电脑座位（见 design-online.md 6.1 旁观）。
  没登录、单独部署、没人在打都不摆；只在好友房选桌页，大厅、主页不加常驻条（`src/app/social.ts` 的 `friendTable`）。
- **分享卡**（`docs/social.md` 1.1，kit 的 `arcade-kit/share`，接线在 `src/view/share.ts`）：单机、好友房一场打完的结算上有"分享"（坐着打完的人才有），
  每日局的一场结算里，"分享"换成每日挑战版（见 DESIGN.md 第 7 节每日挑战一段）。
  生成一张战绩图：标题"娱乐·新手 · 8 局""实盘小档 · 8 局""好友房 · 娱乐 · 8 局"，大数字是自己这一场的净输赢（娱乐"分"、实盘"筹码"），
  三条小数据胡几局、最大几番、杠几个，一句名场面（自己胡的最后一个；一炮多响记在点炮的人头上，不拿来晒；没有就写拿到的称号），昵称和第一个称号，插画是程序画的"一条"。
  只用自己的、公开的数（结算本来就给所有人看），没有任何一张牌。链接：单机是游戏首页，好友房带房间码；卡片右下角把同一个链接画成二维码（kit 只取路径和查询，域名用页面当前的 origin，单独部署扫出来也是它自己）。手机走系统分享，不支持的出 kit 的预览（存图、复制链接）。结算页一出来就用 `prepareShare` 画好、点击里直接调（iOS 只许在点击那一下调系统分享，点了再画会过期）。不上传、0 行写入。
- **结束颁奖**（`docs/social.md` 第 2 节，`src/game/awards.ts`）：好友房一场打完，结算最上面颁 2–3 个奖，每个奖一张小牌子（奖名、得奖的人大字、一句模板话），
  下面"分享颁奖"出一张分享卡（`prepareShare` 先画好；大字是头一个奖和人，其余的奖做小数据；旁观的也能分享）。
  - 本场 MVP：净赢最多的（要赢了才有）；手气最背：净输最多的（要输了才有，不是 MVP 那个人）；麻将特色奖：杠王（杠得最多、至少 2 个），没人够数就看自摸王（自摸最多、至少 2 次），也不够就不颁。
  - 一样多先比胡的局数、再按座位号，同一场结果每家看到的奖一样；电脑座位也评。
  - 只用结算里本来就公开的数（每家净输赢，胡、自摸、杠的次数），不挂筹码、不进钱包、不写库；话是模板（`view/text.ts` 的 `awardLine`），"最背"那句给台阶不挖苦人。
  - 单机不颁（对面都是电脑，没有可比的人）。`test/awards.test.ts` 覆盖评法、并列、门槛和分享卡；`smoke:room` 打完一整场查两边的奖一样、"分享颁奖"出预览。
- **搭子战绩**（`docs/api-social.md` 15.19，`worker/room.ts` 的 `onStep`、`src/room/rules.ts` 的 `matchWins`）：好友房一个房间只打一场（"再来一场"开新房间），
  这一场打完（`done`：打满局数，或者实盘提前收场 `cut`）时经 kit 的 `reportMatch` 报一次，场次固定 1，op 由 kit 拼成"房间码-开房时刻-1"。
  **win = 这一场分数（净输赢）为正**，平和输都不算；麻将不分队，不带 `team`。娱乐、实盘、不计输赢的都报；电脑座位 kit 按开打时绑的人跳过，中途离座的真人照样算在这一场里。
  打完后还有"再来一场"等几步，房间内存里记着报过了不再报；被驱逐重建后最多再报一次，平台按 op 去重。单机不报。`test/worker/room.test.ts` 查假钱包里记了这一场、重报不加。
- **好友动态的名场面**（`docs/api-social.md` 15.17 第 2 条，`src/game/feed.ts`、`public/moments.json`）：娱乐局（单机、好友房娱乐和不计输赢的）里自己胡出
  天胡地胡、龙七对、清一色、杠上开花、海底捞月、七对，画面层经 kit 的 `postMoment` 报编号和番数，文字由 `moments.json` 的模板给（平台按编号拼）。
  一把只取最响的一个（按上面的顺序），一场最多 2 条、同一个只报一次（平台每人每天也只收 10 条）；一炮多响记在点炮的人头上，不报；实盘由平台带回时自己生成，不报。
  没平台、没登录不报，失败静默。判定是纯函数，`test/feed.test.ts` 覆盖判定、条数和模板格式（编号、≤ 40 字、只用 `{name}` `{n}`）。
- **好友：报位置、收邀请**（`docs/social.md` 1.2、1.3，kit 的 `arcade-kit/social`）：有平台、登录了才挂（单独部署、没登录一个请求都不发）。
  报的位置：好友房里是 `{ place: 'room', game: 'mahjong', room: 房间号, seats: '真人数/4' }`，别的时候是 `{ place: 'game', game: 'mahjong' }`；进房、回选桌时马上报一次，平时 kit 每 2 分钟报。
  好友的邀请在顶上弹横条，点"去"：打到一半先照常确认离开（实盘的带回照旧），去雀馆的房间直接进，去别的游戏跳过去。横条上别的游戏叫"一起玩"（游戏名只有平台知道，不在这里抄一份）。
- **互动**（整套用 kit 的 `arcade-kit/table-fun`，和掼蛋、德州一模一样，规范正本 `docs/table-fun.md`；接线在 `src/view/fun.ts`）。
  底线：人人一样、免费、不挂筹码；不停计时、不延长计时；规则和电脑出牌读不到任何互动（`src/core`、`src/ai` 不许 import，`test/arch.test.ts` 检查）；房间只转发编号；短语只说牌局不说人。
  - kit 管：点头像菜单（8 个道具 + 3 句点名 + 屏蔽他，第一格是上次扔的）、长按连扔、自己头像的 12 个表情、"互动"按钮和面板、首次提示、冷却、护盾、连击回敬、
    电脑的反应（`botReact`：被扔 60% 回、四分之一回扔同类，名场面输家 40% 起哄、赢家 30% 得意，每手最多 2 次，乘互动性格）、名场面横幅。
  - 本游戏管：每个座位的头像矩形、名字、谁是电脑、互动性格（`src/ai/personas.ts` 的 `fun`：幺妹儿、兔头哥爱闹，熊猫哥、板凳儿普通，盖碗儿、火锅婆婆高冷）；
    手牌和操作条的矩形（菜单不盖）；"互动"按钮的位置（牌桌上的空位 `.fun-slot`，自己头像右边）；发送通道（好友房走 kit 的 emote，单机交回组件）；
    四川味短语 14 句（编号 0–13，kit 的编号：14–25 表情、26–33 道具，`funIdCount(14)` = 34）和电脑气泡里的话（`MOOD_LINES`，按情绪）：
    雄起！/ 巴适得板！/ 你娃手气好哦 / 又点炮了哇 / 莫慌，稳起 / 杠起走！/ 这把要清一色 / 快点嘛，花儿都谢了 / 安逸！/ 血战到底，哪个怕哪个 /
    手气背哦 / 这张你要不要嘛 / 好牌，服了 / 下把再来。短语不用骂人话（如"龟儿子"）。
  - **名场面的映射**（`src/game/banter.ts`）：杠 → `kong`，自摸 → `self-draw`，杠上开花 → `gang-flower`，清一色 → `flush`；赢的是杠、胡的人，
    输的是点炮的人，自摸和杠是还在打的其他人。别人点炮的普通小胡不算。单机交给 `TableFun.moment`，好友房由房间（`src/room/talk.ts`，kit 的 `onStep`）
    对比公开统计认出来、每个电脑座位问一次 `botReact`、用 `botEmote` 发；真人冲电脑扔的由 kit 的 `onEmote` 交给房间。电脑的反应只在房间内存里记，不写存储。
  - 横幅：一炮双响 / 三响、杠上开花、抢杠胡、天胡、地胡、海底捞月、龙七对、金钩钓、清一色、封顶，胡牌的牌面放完后挂一条（kit 的 `banner`），记进一场的总结算。
  - 立直的映射和横幅在 `src/game/riichi/fun.ts`（规矩照上面，名场面的种类见 docs/riichi.md 第 4 节）。
  - 好友房聊天（kit 的 `docs/chat.md`）：房间 `chat: true`，kit 过滤（链接、号码、微信 QQ 整条拒发，脏话打码）、按座位限速后只转发给带 `chat=1` 的连接，不写存储、不进快照，电脑不读；
    页面 `Online` 把 onChat / onChatError 交给 TableFun 的 `chat` / `chatError`（房间座位号就是牌桌座位号，不用换算）；设置面板（顶栏齿轮）"聊天：开 / 不看"（`mahjong.chatOff`，只在好友房出现），不看只挡别人说的。
    三档轮着切（开 / 不和陌生人 / 不看，同一个键，见 [storage.md](storage.md)）：不和陌生人只管匹配桌，进房时不给 onChat（连接不带 chat=1）、牌桌不给聊天；好友房、单机当"开"。
    房间测试走真实进房路由测转发、拒发手机号、没带 chat=1 的连接收不到。
    摆放：plate 是整块名牌加头上的倒计时（`table.ts` 的 `plateRect`）；center 是中控盘和四家弃牌区；电脑版聊天框（chatDock）在左上家名牌下面、左家竖排手牌右边，
    往右最多到对家牌河左边，宽 260–300（260 时输入框还放得下整句占位）；展开的框约 265 高，左家牌河上面放不下时（1280×800、1024×768 都是）默认收成"聊天"小按钮放在同一位置（kit 的 `chatFolded`），
    玩家点开后盖住左家牌河靠外的一截，点开过就听玩家的；
    kit 自己挑会放到左下压住我的名牌；手机版"聊天"是紧挨"互动"右边的同样大小的圆钮（位置由 `TableUi.chatButtonRect` 算，碰到下家名牌就挪到名牌左边）；弹幕在对家那排下面、中控盘上面；顶栏也加进 avoid（上家的气泡会盖房间号）。
    弹幕开关存在 kit 默认的 `mahjong.chat`，设置面板（顶栏齿轮）"弹幕：开 / 关"接同一份。
    单机：TableFun 传 kit 的 `localChat((t, m) => fun.chat(0, t, m))`，过滤、限速和房间一样，只在本地显示；说的话不进 `Solo`、不给电脑（`test/arch.test.ts`：规则、电脑、`solo.ts` 不 import `arcade-kit/chat`、`table-fun`）。
  - 设置：总开关"表情道具：显示 / 不看"在顶栏齿轮（设置）的小面板里（`mahjong.comms`）；"屏蔽他""全部屏蔽"在 kit 的菜单和面板里，按房间分开（sessionStorage）。只是自己不看，牌局照常。
  - 互动的菜单、面板、冷却、连击回敬、电脑反应都在 kit 里，本游戏不自己做；kit 里没有催促炸弹，规范也没有，所以不做。
