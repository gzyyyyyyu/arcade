# 称号、图鉴、成就

> 从 [DESIGN.md](../DESIGN.md) 拆出：一场的结算称号、规则小册子里的图鉴和成就。都只用公开信息，不碰规则、电脑和筹码。

- **结算页**：每局谁胡了什么番（番型一条一条列）、杠钱流水、查叫；一场结束给称号，只用公开信息：

  | id | 名字 | 怎么拿 |
  |---|---|---|
  | `xz_winner` | 大赢家 | 一场净赢最多（且赢了） |
  | `xz_pao_king` | 点炮王 | 一场点炮最多（≥ 3 次） |
  | `xz_gang_king` | 杠王 | 一场杠最多（≥ 3 个） |
  | `xz_zimo_king` | 自摸王 | 一场自摸 ≥ 3 次 |
  | `xz_iron_wall` | 铁壁 | 一场一次没点炮（≥ 8 局） |
  | `xz_qing` | 清一色大师 | 胡过清一色 |
  | `xz_dragon` | 龙七对 | 胡过龙七对 |
  | `xz_seven` | 七对达人 | 胡过七对 |
  | `xz_golden_hook` | 金钩钓 | 胡过金钩钓 |
  | `xz_gang_flower` | 杠上开花 | 胡过杠上开花 |
  | `xz_rob_gang` | 抢杠 | 抢杠胡过 |
  | `xz_sea_moon` | 海底捞月 | 海底捞月胡过 |
  | `xz_capped` | 封顶 | 胡过封顶的一把（算出来的番数等于或超过封顶就算，天胡、地胡也算） |

  | `xz_earth` | 地胡 | 地胡 |
  | `xz_last_stand` | 血战到底 | 一局里第三个胡 |

  一场拿到超过 5 个时按表里从下往上（越稀有越先）挑 5 个报给平台，结算页全显示。

- **图鉴**（规则小册子的"图鉴"页签，`view/dex.ts`；规则在 `game/dex.ts`，纯函数）：当前玩法的全部番型 / 役（说明、番数、牌例取自规则表），每样写"和过 N 次"，没和过的整行灰着，顶上"已收集 N / 总数"。
  只记自己座位和出来的那一手（旁观、别人的和牌不记），单机和好友房每一步走完各记一次（重画同一步不重复记）；存 `mahjong.dex`（`{ xz, rc }`，id → 次数），读不出来就当空的。
  第一次和出某个番型 / 役（次数从 0 变 1）时，右上角弹一条"图鉴 +N：名字"（小书本图标，和成就共用 `view/toast.ts` 的提示队列和样式；一手新出好几样合成一条，超过三样写前两样加"等 N 样"），
  同时记进 `fresh`；图鉴页里这些行名字后面带小红"新"标，打开那个玩法的图鉴页看过就清掉（判定是 `game/dex.ts` 的纯函数 `dexNewIds` / `dexMarkSeen`）。立直的白发中、场风、自风合成一行"役牌"，宝牌不列。
  为什么做这个：两种玩法加起来 53 样（川麻 16、立直 25 役加 12 役满），大多数要打很多场才碰得到一次，给了"这场没输没赢也在往前走"的长线目标，又不碰规则、电脑和筹码。
  去重靠记录里的 `last`（最后记过的那一手：场号 + 第几局 + 牌墙余量 + 和牌的牌和点炮者），重画、回到牌桌、刷新页面后同一手都不再记；没有 `last` 也照常读。
- **成就**（规则小册子的"成就"页签，`view/achieve.ts`；判定在 `game/achieve.ts`，纯函数）：22 个，川麻 / 立直共用的 13 个（开张大吉、自摸、杠上开花、海底、截胡、一炮双响、清一色、七对、一场三胡、一场第一、打完 10 / 50 场、图鉴集 10 样）
  加川麻专属 3 个（4 番以上大牌、天地胡、川麻图鉴集齐）和立直专属 6 个（跳满以上、役满、一发、里宝牌、坐庄连庄到 3 本场、立直图鉴集齐）；页签按当前玩法只列能拿的，顶上"已解锁 N / 总数"，已解锁的亮、没解锁的灰着写怎么达成，进度型带"N / 目标"。
  怎么判：和图鉴一样只看自己座位的公开事件（`hu` / `win`、`deal`、`over`），旁观不判；一炮双响数同一张牌同一个放铳的人有几家和；"一场第一"在一场打完那一步取（立直看 `final.rank`，川麻没有名次，看净输赢要严格最多）；
  一场和了几把放在记录里，新开一场（川麻第 0 局、立直东一局 0 本场）和打完都清零；图鉴类成就读刚更新的图鉴（`recordAch` 排在 `recordDex` 后面）。只加不减，解锁了就一直在。
  解锁时右上角（顶栏下面，提示队列在 `view/toast.ts`，和图鉴共用）弹一条"成就解锁：名字"（奖章图标，2.6 秒自己消失，点击穿透，多条排队一条条出）。去重和图鉴一样靠记录里的 `last`（这一步的标识：场号 + 第几局 + 牌墙余量 + 事件数和最后一个事件），重画、回到牌桌、刷新页面后同一步都不再判。
  为什么做这个：图鉴只管牌型，成就补上"一场里的表现"和"打了多久"，给没有大牌的人也有能一点点涨的目标；不碰规则、电脑和筹码，没有奖励，只是荣誉。
