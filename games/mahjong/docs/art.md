# 雀馆 画风与美术

> 现在用的画风、材质、配色和主视觉。各界面具体怎么摆见 [DESIGN.md](../DESIGN.md) 第 7 节；素材来源见 [ASSETS.md](../ASSETS.md)。

## 定调

成都老茶馆的夜场：暖黄的灯，红灯笼，盖碗冒着热气，木格窗外是夜色和远处的灯火；牌桌是墨绿呢子配深色木框，牌是象牙白、有厚度的老牌。
热闹但不吵，像跟熟人打一下午牌。吉祥物是幺鸡那只小麻雀（"雀馆"的雀）。

## 材质

- 牌桌：呢子（程序生成的纹理，`--felt` `#0f5a41`，暗 `--felt-dark` `#0a3d2c`）加桌心一团暖光、四周压暗；深色木框落一圈投影。
- 木头：主页和选桌页用横向木板墙加木格窗。
- 纸：规则小册子、新手引导用宣纸色卡片，和牌桌的绿区分开。
- 主按钮和高亮用暖金（`--gold` `#f3c86b`）；灯笼红（`--red`）只在小面积用（胡、点炮、庄、警示）。
- 全部程序生成（SVG + CSS，`src/view/art.ts`、`art.css`），不引外部图片。

## 卡通风格与配色

规则写在 `src/view/art.css` 末尾"卡通风格"一段：2–3px 深棕描边、圆角 12–16、按钮实色下沿（按下沉 3px）；表面上亮下暗的轻渐变 + 顶边高光 + 柔和投影。
茶馆的板壁、木框、呢子（织纹、绒点、暗角、顶灯暖光）用程序生成的纹理，不平涂。

| 变量 | 色值 | 用在哪 |
|---|---|---|
| `--c-ink` | `#2b1d14` | 描边、实色下沿 |
| `--c-cream` | `#fff6e0`（渐变到 `#f3e3c0`） | 次按钮、档位卡、模式卡、座位卡、"互动"按钮 |
| `--c-panel` | `#14584a`（`#1f7462` → `#0d3d33`） | 名牌、弹窗：深底浅字，结算配色照旧 |
| `--c-teal` | `#17a37f`，标题 `#2fc89c` | 主色：选中档位的外圈、标题、大厅图标 |
| `--c-sun` | `#ffc53d`（`#ffe07a` → `#f0a52a`） | 只给主按钮、钱包数、轮到谁的光圈、选中的规则选项 |
| `--c-orange` | `#c4570b` | 星级 |
| 底色 | 板壁深木 `#3a1a0c`、呢子 `#0f5a41` | 大面积沉稳的底，程序生成的纹理 |

## 字体

正文用系统中文字体（`src/view/css/base.css` 的 `font-family`）；店名、主按钮、模式卡用标题字 Noto Serif SC Black 的子集（SIL OFL 1.1，约 9KB，来源和重做方法见 ASSETS.md）。
字号、间距、圆角是 `src/view/css/base.css` 开头的 CSS 变量刻度，手机上字号按舞台缩放补回（DESIGN.md 第 7 节）。

## 主视觉

游戏主页左（竖屏是上）一张茶馆夜场的画（`art.ts` 的 `homeScene()`）：木格窗外的夜色和远处灯火、两盏灯笼、一手牌和站在牌上的小麻雀、盖碗茶。
灯笼摆、窗灯明暗、热气、麻雀隔一阵跳两下；省内存设备和系统"减少动态效果"时只画静态的（`data-lite`）。

## 进入流程

主页（快速一局 / 继续上局、三张模式卡、本地战绩）→ 选桌页（只摆当前模式）→ 牌桌。没有平台时主页没有实盘卡和钱包。
