# 雀馆设计：画面

> 从 [DESIGN.md](../DESIGN.md) 拆出来的一部分，小节号和总纲一致（别处写"DESIGN.md 第 N 节"指的就是这里）。

## 7. 画面

- **渲染层：DOM + CSS + SVG**，不用 Phaser/WebGL。麻将的画面是静止的牌和少量动画，DOM 足够；还省掉 WebGL 上下文丢失、显存这一类 iOS 的坑。
  AGENTS.md 第 4 节里和画布有关的"渲染倍数封顶 2"在这里不适用（没有画布），其余几条照做：高度按 `visualViewport`、双指放大时不重排、safe-area 带兜底值。
- **牌桌每一步重画，但只换变了的节点**（0.45.1）：每来一个视图，牌河、副露、别家手牌、名牌、中控盘照旧整块重新生成，但先画进空壳，再用 `dom.ts` 的 `sync` 和现在的按位置比（`isEqualNode`），一样的留着不动，没变的牌不重算样式、正在飞的牌不断。
  自己的手牌和操作条挂着点击、拖动，照旧整块重建（`sync` 不比监听）。要量位置的（新进河的牌起飞、互动组件摆头像热区）都放在整桌写完以后：起飞在 `render` 末尾的 `land`，互动的 `refresh` 攒到下一帧（`app/fun.ts` 的 `refreshFun`），不夹在写 DOM 中间逼浏览器反复排版。
  一直在跑的呼吸光（手牌金边、刚打出那张）不动 `box-shadow`：光画在伪元素上，只动 `opacity`，交给合成器，不每帧重算样式。
  量性能用 `node scripts/perf.ts`（主页打开、选桌页打开、对局中的帧间隔和长任务、包体积；电脑 1280 和手机竖屏 CPU 降速 4 倍），改了渲染、开机流程，前后两版交替各跑一遍比。
- 样式：`src/view/style.css` 只按顺序引入 `src/view/css/` 下按界面分的样式文件（顺序就是层叠顺序，不能调换）。
- **牌面全部程序生成**（`src/view/tiles.ts`）：一张 SVG 模板，万字用系统字体写"一二三…九"加红色"萬"，筒画圆圈、条画竹节，一条画一只简笔小鸟；牌背纯色加花纹。没有外部素材，来源写在 `ASSETS.md`。
- 头像（`avatar.ts`）：六个电脑性格各一张手绘 SVG，按名字前缀认（好友房实盘带编号的也认），真人按名字算底色写首字；牌桌、选桌页的画在 `art.ts`（SVG 小纹理平铺，启动时写成 `--art-*` 变量）和 `art.css`。
  主题是成都茶馆：墨绿呢子、木框、红漆中控盘（四边座位色，轮到谁亮）、竹帘、灯笼、盖碗。不用 filter，全部程序生成。
  牌桌页分三层：舞台是茶馆板壁加顶灯一团暖光（电脑宽屏牌桌两边露出来的就是它），木框落一圈投影，呢子只铺在框里、桌心一团暖光四周压暗；
  三人两房（`opts.three`）只有 3 家：自己在下、下家在右、上家在左，上面对家的位置空着（`.table.three` 把对家的名牌、手牌、牌河收起来，不留框），座位换算在 `table.ts` 的 `relOf`；四人局的布局不变。
  中控盘是罗盘样（金色表盘圈住剩余张数、四角铜钉），换三张的方向写在盘的上方，不压盘、不压定缺按钮。灯笼、盖碗这些摆件只在主页的画里，不印在呢子上。
  常驻小动画只在主页（灯笼、窗灯、热气、麻雀，只动 transform/opacity）；省内存设备（触屏、`deviceMemory` ≤ 4）和系统"减少动态效果"时不动（`data-lite`）。
- **游戏主页**（`home.ts`，画风见 [`docs/art.md`](art.md)）：进来先是主页——左（竖屏是上）一张茶馆夜场的主视觉（`art.ts` 的 `homeScene()`，木格窗外的夜色和远处灯火、两盏灯笼、
  一手牌和站在牌上的小麻雀、盖碗茶；灯笼摆、窗灯明暗、热气、麻雀隔一阵跳两下，`data-lite` 时不动），右（下）是店名、一句玩法、"快速一局"（按上次的档位和难度开，第一次是娱乐·新手；规则固定一局一结，川麻 1 局、立直一局，约 2 分钟，碎片时间打一把；
  不改选桌页里平时的规则设置，打完"再来一局"也照这一局的规则；按钮底下有"血战到底 / 血流成河 / 三人两房 / 立直"切换（和选桌页玩法行同一份记忆），点了就换玩法；有没打完的单机换成"继续上局"）、三张模式卡（娱乐 / 实盘 / 好友房，点了进选桌页；选桌页只摆这个模式：娱乐三难度、实盘四档、好友房两样都有加开房进房，开打按钮贴底）、本地战绩卡（`mahjong.record` 加 `mahjong.streak`）、"我的进度"小卡（每日挑战今天打没打和连续天数——两种玩法取较大的、成就已解锁 N / 22、图鉴已收集 N / 53——两种玩法合计；放在插画底部空着的呢子上，三个小胶囊（描线图标加数字；按钮那一栏一屏刚好放满，不往里加），点了直达：每日挑战进娱乐选桌页，成就、图鉴开规则小册子对应页签；汇总在 `game/progress.ts`，读 `mahjong.daily`、`mahjong.ach`、`mahjong.dex`，不新增存储键）。选桌页左上角"‹ 主页"回来；
  平台大厅的"好友房"（`?online=1`）和房间链接照旧直达选桌页、房间。店名、主按钮和模式卡用标题字（Noto Serif SC Black 子集，约 9KB，`ASSETS.md`）。
- **每日挑战**（`game/daily.ts` 纯函数 + `view/daily.ts` 画面）：娱乐选桌页（血战到底、立直，立直入口开着时两种都有）难度卡上面一张入口卡，写今天打没打、连续几天、最近 7 天。每天每种玩法一副所有人相同的牌：川麻·血战到底，娱乐普通档，4 局（单机最短）；立直，娱乐普通档，东风战（立直最短），其余规则都用默认；
  种子 `dailyKey(日期, 玩法)`（川麻的盐不变，立直多加玩法名，同一天两种玩法两副不同的牌；FNV-1a 按位置加盐出 8 个 32 位数，替代平时现生成的密钥，电脑人物也由它定），日期在画面层按北京时间（`Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Shanghai' })`）算，规则核心不碰时间。
  存档 `SoloSave.daily` 记开这一场时的日期，玩法看存档里状态的 `variant`（结算的成绩行和"再练一次"都按它），与普通单机共用一个存档槽，刷新能接着打，过了零点接着打旧的这场仍按旧日期算（补记旧日期不倒着改连续天数）。
  当天第一场打完算"今日成绩"（净得分；成绩、最好、连续天数、最近 7 天按玩法各记一份。净得分就是结算里自己那行右侧的数：立直是终局点数差折成的得分（含马、头名奖）换成筹码后减去带入，一场最多赢 3 份封顶，娱乐里写成"分"），之后再打同一副牌是练习、结算写"练习，不计成绩"，不覆盖；按存档的号认，同一场重画结算不会变成练习。每日局的结算里"再来一场"换成"再练一次"（同一副牌），不跳成平时设置的单机。连续天数：最后一天是昨天就 +1，断了从 1 开始；今天没打时昨天的连续还算。只存本机。
  每日局结算上的"分享"出每日版的卡（`view/share.ts` 的 `dailyCardOf` 纯函数，`view/daily.ts` 的 `dailyCard` 接线）：标题"每日挑战 · 日期"，大字是今日成绩（练习局写"练习"）和玩法，小数据是最好、连续天数、最近 7 天打卡格子（● 打过 ○ 没打），一句"同一天大家打的是同一副牌，来比比"；没有牌，也没有别人的名字。普通单机的卡不变。
  每日榜：当天第一场的净得分（取整，可以是负数，越高越好）交平台每日榜 `POST /api/scores { gameId: 'mahjong', boardId: 'daily-YYYY-MM-DD-xz' | 'daily-YYYY-MM-DD-rc', score, userId }`（川麻 `xz`、立直 `rc`，`game/daily.ts` 的 `dailyBoard`），榜怎么显示写在 `public/daily.json`。
  先记账后交：结算里记下今日成绩以后才交，交成功才在这一天的成绩上写 `sent`，成绩行尾加"已进今日榜"；没交成（断网、榜没登记）不吭声，打开主页时补交（`settleDailyBoards`，只补今天的）。练习、结算重画都不再交。只有登录才交。
- **结算和过场演出**（结算动画 `fx.ts` 的 `settleFx`、胡牌结算的节奏 `settle-fx.ts`、过场条 `cutin.ts`、开局发牌 `table.ts` 的 `dealIn`）：见 [docs/table.md](table.md)。共同规则：只动 transform / opacity，不改计时和规则，系统"减少动态效果"、省内存设备（`data-lite`）和网址 `?turbo`（冒烟）时降级或不放。
- **手机上的字号**（`viewport.ts` 写 `--fs-k`）：舞台等比缩小时字号变量乘 `max(1, 1/缩放)`，屏幕上 xs ≥ 12px、sm ≥ 14px，md、lg、xl 各有下限，2xl 往上不动；放不下的挪位置或藏次要的字（顶栏的玩法名），不缩字。量法是本地审计脚本（点按区、字号、出屏）。
- **规则小册子**（`guide.ts`）：规则和新手说明用米色宣纸卡片，和牌桌上深色玻璃面板分开；规则分四页签，番型表每种牌型配一手牌例（`FAN_EXAMPLE`，按时机算的番没有）；番型页保留 `table`，冒烟按它认。
- **茶馆底噪**（`sound.ts`）：两层滤波噪声（一层慢慢起伏像人声）加隔 7–16 秒一声盖碗，占总音量 5%，走总音量所以跟着静音和滑块；`prefs.ambience` 单独关；页面切后台就停。
- 音效（`sound.ts`）：WebAudio 现合成，每种动作一个声音；总音量 `setVolume`（存在 `mahjong.prefs`），静音时 `play` 和给共用包的 `audioOut` 都不出声；同一种短时间连发会丢，最多同时 8 个。
- **主题和按钮**（`src/view/css/base.css` 开头，按钮在 `src/view/css/buttons.css`）：颜色、间距（4 的倍数）、字号、圆角、阴影、动效时长都是 CSS 变量，组件只用这些刻度；
  牌桌上各块的绝对位置按牌桌几何定，是例外。所有能点的（`.act`、`.pill`、`.chip`、`.stake`、`.link`）共用一套状态（互动的菜单和面板是 kit 的，样式跟 kit 走）：
  悬停（有鼠标时）亮一点、按下沉一点、禁用变淡、键盘焦点金边、发请求时转圈（`dom.ts` 的 `busy`，挂 `aria-busy`，转着再点不发第二次）。
  主按钮金色（`.act.go`）、次按钮浅色玻璃（`.act`）、轻按钮（`.act.soft`、`.pill`、`.chip`、`.link`）。碰杠胡过按紧急程度分级：胡灯笼红底金字最大，杠、碰暖金，过半透明最小；定缺三个按钮茶馆木色。
  点按区域在屏幕上至少 44 像素：舞台缩放后（手机上约 0.7 倍）按钮看着小，`viewport.ts` 按缩放写 `--tap`（44 ÷ 缩放），按钮的 `::after` 是隐形点按区，向四周撑到 `--tap`。
  手牌例外：一手 14 张横着排，手机竖屏每张只有 26 像素宽，做不到 44。数字（筹码、剩几张、倒计时、房间号）用等宽数字，长名字截断。
- **布局**（照主流四人麻将）：四家的牌沿各自桌边居中（自己的在底边、对家在顶边、左右两家竖排），头像带名牌在各自左手那个角，中间红漆中控盘写剩余张数和第几局、四边方向灯指着轮到的人，四个牌河围着中控盘；碰杠胡过大按钮浮在手牌右上方。横屏、电脑版（`data-fit="desk"`）、竖屏的几何和尺寸见 [docs/table.md](table.md)；"互动"和"聊天"是并排在自己头像右边的图标圆钮，碰杠胡过每个按钮看得见的部分不小于 `--tap`。验收用 `node scripts/capture.ts` 截图，并按每张牌的框报出互相压住的部分。
  - 点一下抬起再点打出（连点两下即双击），或按住往上拖过 40 像素松手打出（拖动跟手、拖够了亮边，不够弹回）；有鼠标时悬停先抬一点；
  - 打出的牌从出牌的地方飞进河里（自己的从手里那张、别人的从他的手牌那边；一下多了好几张时原地落下），自己的 220 毫秒、别人的 320（拿起略放大、落桌压扁一下再弹），落桌声按同一时刻放（`table.ts` 的 `FLY_MS`、`landAt`），新摸的牌落进手里。
    都只是画面，不改计时和规则，联机时别人只看到打出去的那张；系统"减少动态效果"时不飞；
  - 键盘 ← → 选牌、回车 / 空格 / ↑ 打出、Esc 放下，H 胡（自摸）、P 碰、G 杠、X 过；
  - Esc 统一管弹窗（`dialog.ts`）：规则册、新手引导这类可关的弹窗 Esc 就是关；确认框 Esc 等于点"不"（接着打 / 不了）；结算、匹配中、出错这几个必须点按钮的弹窗 Esc 不管。有弹窗时牌桌的键盘不响应，所以 Esc 不会同时关弹窗又放下牌；点遮罩关弹窗的行为没变（确认和必须点按钮的不能点遮罩关）；
  - 有鼠标时（`hover: hover` 且 `pointer: fine`）鼠标停在自己的牌上，操作条就显示"打了听"那一排（和选中一样，立直也一样），移开恢复成选中那张的提示；同一手牌同一张只算一次（`pc-hover.ts` 的 `memoPerView`，手牌变了自然作废），连续划过几张只重画一次；触屏没有这个；
  - "点两下或往上拖打出"的提示只在前 6 次打牌显示（`mahjong.hint` 计数，`pc-hover.ts`），之后收起；
  - 轮到我打牌时手牌底下一道金边呼吸（中控盘的方向灯离手牌远）；手牌自动理牌、摸的牌隔半张单放；缺门的牌一道红线、轮到时只能先打缺门（其余变暗）；
  - 听牌提示（打哪张听、听什么、各剩几张）；碰杠胡过的大按钮在手牌右上方，点了当场生效（单机同步走一步就重画）；电脑出牌常速 / 快速两档，速度按钮写现在的速度；
  - "互动"按钮按舞台缩放放大字和图标、和别的按钮一个样子（kit 的按钮浮在舞台外，字是固定 13 像素）；它的空位不小于 `--tap`（iPhone SE 竖屏上 kit 保底 44 像素把按钮撑出来压到手牌），
  - 量法：`node scripts/feel.ts land|port [次数] [keys]` 用鼠标或键盘真点，量点下到抬起、打出到牌开始飞、到落进牌河（毫秒，浏览器里记）；机器忙时数会被拖高，贴数时写上当时的负载；
  - 现状：好友房里打出要等服务器回包才动（网络往返）；好友房电脑每一手固定 0.9 秒（kit 的 `aiDelayMs` 是一个常数，按局面变的停顿要 kit 支持），单机按局面 0.65–2 秒。
- 胡牌高光：`hu` 事件喊完"胡！"，牌桌中间亮一块（`fx.overlay`，不挡点击、不动计时）：谁、怎么胡的、整手牌（副露 + 手牌 + 胡的那张描金）、番型逐条弹出、合计；
  2 番以上金边扫光加喜庆声音，3 番以上背后转光；一炮多响依次亮。只用公开的：胡了的人手牌视图里本来就亮给所有人，番型在事件里。系统"减少动态效果"时不扫光不转。
- 听牌提示（`src/view/variants/<id>/ting.ts`）：轮到打牌时，打了能听的牌头上标"听"，点起来那张在操作条上摆出听哪些牌、各剩几张；
  已经听了就一直摆着。"剩几张"只按自己看得见的算（4 − 自己手里 − 弃牌、副露、胡了亮出的），不看别人手里和牌墙，
  联机时浏览器按自己的视图算，服务端不多给东西（`test/ting.test.ts` 检查别人藏着的牌不减）。
- 推荐出牌（`game/coach.ts` 开在哪、`ai/coach.ts` 按什么打）：单机的娱乐新手档和实盘小档，轮到自己打牌时，推荐的那一张描绿边、头上标"荐"（已经标"听"的只描边）。
  推荐的是这一家视图下"普通玩家"会打的那张（`NORMAL_PLAYER`，就是配平模拟里的普通玩家，只是不故意打错），照着打最多到普通玩家的水平，所以小档期望仍在 `docs/balance.md` 的带内。
  默认开，"声"面板里"推荐出牌"能关；中档往上、每日挑战、擂台不开，好友房和匹配桌有别的真人，从不开。
- **选桌页**：整页铺不渐隐的板壁（`--art-wall-full`），往下压暗，
  舞台和屏幕露出的边在选桌页、等候页也换木色，不再上半木墙、下半呢子。版面和主页一样：横屏左边主页那张茶馆的画、右边一块木框面板（`lobby-panel`），
  竖屏画在上面一条、面板在下（画按剩下的高度缩，太矮就不画）。面板从上往下：模式名、玩法、档位卡（主角，撑满面板宽）、钱包说明、规则摘要、开打贴底；
  好友房七张档位卡，横屏排紧、卡上不画小图标。实盘档位卡的数换短说法（`wan`：15万，不截断）。手机上不重复顶栏已写的"雀馆 · 玩法"，档位卡不画小图标。

### 每日何切、听牌速判、茶馆擂台、云存档

详细规则在 [docs/practice-modes.md](practice-modes.md)；要点：

- **每日何切**（`game/hekiri.ts`、`view/hekiri.ts`）：每天五手一样的牌（北京时间日期派生种子），选打哪张、揭晓牌效，满分 100；第一遍记成绩、交平台每日榜 `daily-YYYY-MM-DD-hekiri`，之后是练习。
- **听牌速判**（`core/puzzles/ting.ts`、`game/ting.ts`、`view/ting.ts`）：60 秒一轮，每题一手 13 张清一色，点全听的牌才得分；只是娱乐。今日一轮每天一次（榜 `daily-YYYY-MM-DD-ting`），另有练习。
- **茶馆擂台**（`game/ladder.ts`、`view/ladder.ts`、`app/solo-flow.ts` 的 `playLadder`）：单机连打三桌（新手 → 普通 → 高手），三桌全赢拿称号，输了从头来（`RETRIES = 0`）；四种打法 `xz`、`xl`、`x3`、`rc`。纯娱乐，称号只存本机和云存档。
- **云存档**（`net/cloud.ts`、`app/cloud.ts`，照 `docs/platform-backend.md` 5.5）：只同步一个槽 `ladder`（称号取并集、最远取较大），其余都不同步；没有平台时不显示。

### 界面规范补充（文案和操作）

- 结算术语（本场、供托、跳满、里宝指示、退税等）是 `view/terms.ts` 的 `term()`：点一下在原地展开一句大白话，再点收起；说明文字都在 `TERMS`。平胡不写“0 番”；“电脑看不到你的牌”那句只在一场的第一局出。
- 快捷键：电脑上（`(hover: hover) and (pointer: fine)` 或 `data-fit="desk"`）碰杠胡过按钮角上标 P/G/H/X，手机不显示（`view/ui-help.css`）；规则小册子最后一页“键盘”列全部键位，改键位时 `table.ts`、`ting.ts`、`guide.ts` 的 `KEYS` 一起改。
- “声”面板分音量 / 茶馆声 / 提示三组，“恢复默认”把音量、静音、茶馆声、安全牌提示、推荐出牌（`prefs.ts` 的 `SOUND_DEFAULTS`）和互动、聊天回出厂值并存回；弹幕跟系统的减少动态设置，不在其内。
- 连不上的话术只有 `text.ts` 的 `NET_FAIL`、`ERR_REFRESH`、`NET_SETTLE_LATER` 三句，各处引用。
