# 雀馆 风格规范

> 所有界面共用的样子：配色、字、圆角、阴影、描边、动效和共用组件。变量正本在 `src/view/css/base.css` 开头；共用组件的形状、尺寸、状态在 `src/view/css/{buttons,dialog,topbar,volume}.css`，
> 颜色、描边、落影统一在 `src/view/art.css` 末尾的「组件皮肤」一段（全部样式里最后加载、带 `.stage` 前缀，各页面改尺寸的规则压不掉它）；开合动效在 `src/view/motion.css`。
> 画风和主视觉见 [art.md](art.md)，牌桌几何见 [table.md](table.md)。

## 1. 调子

成都茶馆夜场。**深色漆木和墨绿呢子做底，哑光鎏金点主操作，象牙白做能点的牌子，灯笼红只给胡、危险和警示，竹青玉只给碰。** 大面积沉静，高饱和只给关键动作。

- 一屏只有一个最亮的东西：主按钮（金）或者轮到我时的手牌。别的按钮都比它暗一级。
- 能点的东西像实物牌子：顶边一道高光、底下一线厚度加柔和落影，按下去沉 2px、缩一点；不描粗黑边。不能点的（说明、标签、数字）没有落影。
- 浅色面（象牙按钮、卡片）描 1px 褐边 `--outline`；深色面（顶栏按钮、弹窗、设置、名牌）描 1px 掐丝金线 `--line-gold`。
- 面板（弹窗、设置）是深色漆面：上亮下暗、金线外框、往里再收一圈更淡的细线；规则册和引导是宣纸色，和漆面板分开。
- 顶栏按钮压低存在感（深漆半透明 + 金线 + 象牙字），一屏最亮的只留给主按钮。
- 颜色有含义，不拿来装饰：金 = 主操作 / 杠 / 选中 / 轮到；红 = 胡 / 危险 / 庄 / 警示；竹青 = 碰 / 成功；象牙 = 普通可点。

## 2. 颜色

只用变量，不在组件里写新的色值（插画、牌面、头像、过场条这类画出来的东西例外）。

| 用途 | 变量 | 说明 |
|---|---|---|
| 呢子 | `--felt` `--felt-dark` | 牌桌 |
| 漆木 | `--wood` `--wood-hi` `--wood-lo` | 板壁、顶栏 |
| 鎏金 | `--gold` `--gold-hi` `--gold-lo` `--gold-deep`，字 `--on-gold` | 主按钮、杠、选中的胶囊用 `--gold-fill`（一屏里最亮）；金字、高亮用 `--gold`；金字的影用 `--gold-deep` |
| 灯笼红 | `--red` `--red-hi` `--red-lo`，字 `--on-red` | 胡、危险按钮、庄、警示 |
| 竹青玉 | `--jade` `--jade-hi` `--jade-lo`、`--green` | 碰、成功；`--green` 是深底上赢的数字 |
| 深底上的字 | `--ink` > `--ink-2` > `--ink-3` | 正文 > 次要说明 > 版本号、占位。不用 `opacity` 调字的深浅 |
| 浅底上的字 | `--ink-dark` > `--ink-dark-2` | 象牙牌子、宣纸上 |
| 象牙 | `--ivory → --ivory-lo` | 次按钮、模式卡、档位卡、座位卡 |
| 漆面板 | `--panel`（`--lacquer → --lacquer-lo`） | 弹窗、设置、名牌 |
| 宣纸 | `--paper` | 规则册、引导 |
| 压暗 / 提亮 | `--surface` / `--surface-hi` | 深底上的标签底、轻按钮 |
| 遮罩 | `--scrim` | 弹窗后面 |
| 线 | `--line`（分隔）、`--line-gold`（深色面的金线）、`--outline`（浅色面的描边，1px `--edge-light`） | |
| 禁用 | `--disabled`，字 `--on-disabled` | 不透明暗褐，不用透明度（会透出木纹、呢子发脏） |

数字：输赢用 `--green` / `--red-hi`，筹码和钱包用 `--gold`；数字一律等宽（`font-variant-numeric: tabular-nums`）。

## 3. 字

- 正文 `--font-ui`（系统中文字体）。标题字 `--font-title`（Noto Serif SC Black 子集）**只给固定的字**：店名、主按钮、模式卡名、过场字；会变的文字（说明、人名、规则）用标题字会缺字、混进系统字体，一律用 `--font-ui`。
- 字号只用刻度，手机上自动补回（`--fs-k`）：

| 变量 | 电脑 | 用在 |
|---|---|---|
| `--fs-xs` | 12 | 角标、版本号、"换""荐"标 |
| `--fs-sm` | 14 | 说明、数字、标签 |
| `--fs-md` | 16 | 正文、顶栏、轻按钮 |
| `--fs-lg` | 18 | 按钮、卡片标题 |
| `--fs-xl` | 20 | 弹窗标题、小节标题 |
| `--fs-2xl` | 24 | 大按钮、结算大数 |
| `--fs-3xl` | 28 | 页面大标题 |

- 字重只用 `--fw-regular`（说明）、`--fw-bold`（按钮、标题、数字）、`--fw-black`（标题字）。行高 `--lh-tight`（按钮、标签）、`--lh-body`（段落）。
- 深底上的标题、大数字压一道实影 `--title-shadow`；正文不加影。
- 层级只靠字号 + 字重 + 字色三样，一块里最多三级。

## 4. 形状、阴影、动效

- 圆角：`--r-sm` 6 角标 / `--r-md` 12 输入框 / `--btn-r` 14 按钮 / `--r-lg` 16 卡片和弹窗 / `--r-pill` 胶囊。
- 描边：浅色面 `--outline`，深色面 `1px solid var(--line-gold)`；标签不描边。不用 2px 以上的描边。
- 阴影：能点的 `--hi` + `--lift`（小的 `--lift-sm`），按下换 `--lift-press` 并 `translateY(2px) scale(0.97)`；深色面顶边 `--hi-dark`；弹窗、设置 `--sh-panel`，其余浮层 `--sh-1/2/3`。轮到、选中加 `--glow-gold`。
- 间距：`--sp-1…6`（4 的倍数）。卡片内边距 `--sp-4`，弹窗 `--sp-5`，同组按钮间隔 `--sp-3`。
- 动效：按下、悬停 `--t-fast`；开合、切换 `--t-mid` + `--ease-out`；入场 `--t-slow`，要弹一下用 `--ease-back`。只动 `transform`、`opacity`；`data-lite`、系统"减少动态效果"、`?turbo` 时不放。

## 5. 共用组件

| 组件 | 类名 | 样子 |
|---|---|---|
| 主按钮 | `.act.go`（大的加 `.big`）、主页 `.act.quick` | `--gold-fill`、深字；一屏一个 |
| 次按钮 | `.act` | 象牙渐变、深棕字 |
| 轻按钮 | `.act.soft` | 象牙稍暗、落影小一号 |
| 危险按钮 | `.act.danger` | 红渐变、白字（离开、放弃） |
| 碰杠胡过 | `.act.ron` / `.kan` / `.pon`（`.chi`） / `.pass` | 胡红底金字最大，杠鎏金，碰（吃）竹青玉，过深漆半透明、没有厚度 |
| 定缺 | `.act.que`（推荐的 `.best`） | 茶馆木色 + 金线；推荐的金色光圈 |
| 顶栏按钮、页内返回 | `.home` `.pill` `.icon`、`‹ 主页`（`.hk-back` `.td-back` `.ld-back`、选桌页 `.back`） | 深漆半透明胶囊 + 金线 + 象牙字，高 `--pill-h` |
| 切换 / 选项 | `.chip`（选中 `.on`） | 胶囊；选中换金底 |
| 卡片 | `.mode` `.stake` `.room-seat` | 象牙牌子 `--btn-r`；选中 = 暖金边 + 香槟底 + `--glow-gold`（和胶囊、主按钮同一种金） |
| 名牌 | `.badge`（轮到 `.turn`） | 漆面 + 金线；轮到的加 `--glow-gold` |
| 互动 / 聊天圆钮 | kit 的 `.atf-btn` | 深漆圆钮 + 金线 + 金色图标，不抢手牌 |
| 弹窗 | `.mask > .dialog` | 漆面板 + 金线 + 内收细线；标题 `--fs-xl` 金字实影；右上角 `×`；弹出时轻轻弹一下 |
| 设置面板 | `.vol`（顶栏齿轮） | 和弹窗同一块漆面；一行一组，左列小标题、右边控件两列等宽，组间细线，「恢复默认」右下 |
| 提示条 | `toast.ts`（样式在 `achieve.css` 的 `.ach-toasts`） | 顶栏下居中一条，点击穿透，自己消失 |

状态（所有能点的）：悬停浮起 1px、主按钮晕金光（有鼠标时）、按下沉 2px 缩一点、禁用换 `--disabled` 暗褐、键盘焦点 3px 金边、请求中转圈（`dom.ts` 的 `busy`）。点按区不小于 `--tap`（见 DESIGN.md 第 7 节）。

## 6. 写新样式时

1. 先找现成组件和变量；没有合适的变量，先来这里加，不在组件里写色值。
2. 新 CSS 限定在雀馆界面根节点（`.stage`）下。
3. 任何界面不滚动、不折叠，字和金额不截断；手机竖屏、手机横屏、1024×768、1280×800 都放得下。
