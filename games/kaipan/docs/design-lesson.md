# 《开盘》新人：新手课、新号照顾、心法

> 新人为什么输、怎么帮：所有者反馈「新人怎么玩都打不赢」。先量清楚为什么输，再做三件事：一局手把手的新手课、新号前几局降难度、几句能翻看的炒股心法。实盘不受影响。

## 1. 新人为什么输

新手档短局（5 个月，开局 10 万，首付比例 0.9），每种打法 200 局，真实行情，机器人只看玩家看得到的东西（`tools/bots/*`，加上取证用的三个：一直空仓、每次买都满仓一只、追热死拿）：

| 打法 | 胜率 |
|---|---|
| 一直空仓 | 78% |
| 乱买 | 84.5% |
| 追热，跌了就卖 | 82.5% |
| 追热死拿 | 59.5% |
| 每次满仓一只 | 48% |
| 小白 `xiaobai` | 88.5% |
| 普通 `putong` | 94% |

结论：

- 输主要输在**死拿**（亏了等回本）和**重仓**（一次买满一只）。乱买、追热只要跌了就卖，胜率和小白差不多。
- 顶栏的目标是「首付 + 账单」，10 万本金只要亏 4.4% 就交不上。新人以为要赚很多才算赢，其实不亏就过，画面没讲清；原有教程只教界面（点哪里），不教该买什么、什么时候卖。
- 照第 4 节心法的规则打（`lesson` 机器人放进普通新手短局）：88.5%；同样的规则但不止损：68.5%；一律重仓：43%。止损和别满仓就是差别。

## 2. 新手课

一局固定行情、固定种子的两个月短局（`src/core/lesson.ts` 的 `LESSON`）：

- 种子 `lesson-8`，行情段 `seg_76141a5a68`（熊市「一路向下的楼梯」）。挑熊市是因为最能看出止损和空仓的用处：从 95 段非崩盘段 × 一批种子里搜，选的是照建议做净赚、不止损和重仓都亏得清楚的一局。
- 两个月 10 个交易日；账单只走个过场（`billMult` 0.05）；最后要交回开局的钱（`goal` 1），不亏就算过。
- 开局设置 `lessonSetup()`：新手人设、第 1 级、`lesson: true`。`checkSetup` 要求新手课必须是短局、不能和每日挑战、闪电盘、本周市场、实盘一起开。`isRankedSetup` 为假：不进档案的局数、最好成绩和排行，也不交分。
- 行情没拿到就开不了（不退回合成行情，那就不是教的那一局），提示一句稍后再试。

**老师傅的建议**（`lessonAdvice`，只在盘前给，只读玩家看得见的：持仓收益、风口体感、群聊、群友战绩、黑天鹅预告）。做完一步再问一次，直到给出「等」：

1. 卖：持仓亏到 8%（`stop` 0.92）就卖（止损）；有下跌的黑天鹅预告就卖（宁愿空仓）；风口过热又有人喊跌就卖（不追高）；风口在降温就卖。
2. 有下跌预告、今天买不了、已经拿着 3 只（`maxHold`）：不买。
3. 买：推荐里挑风口**正在升温**、推荐人说对的不少于一半（发过不到 2 条的先信着）、这个风口手里还没有、不是 ST、群里没人喊跌、买得起「试一口」的；按推荐人战绩打分。一律只买「试一口」。
4. 都不满足：空仓等着。

照着做的结果由 `tests/core/lesson.test.ts` 锁住。这一局的实测（炒股净赚）：

| 打法 | 结果 |
|---|---|
| 一直照建议 | +4 千，过关 |
| 照建议买但不止损 | −3 千，没过 |
| 照建议买但一律重仓 | −6 千，没过 |
| 每次满仓一只 | −3.9 万 |
| 追热死拿 | −5 千 |
| 乱买 | −1.3 万 |

**奖励**：开盘没有娱乐货币，过关的奖励是六张心法全部点亮（图鉴「心法」页），档案记 `lessonWon`。不给筹码，也不给积分。

**入口**：新号第一次打开（还没打过正式局、新手课没过）开始菜单大卡写「先上一课」；以后随时在图鉴「心法」页第一张卡「新手课」重上。结束页按钮是「再上一次」「正式一局」。

## 3. 新号照顾

新号前 3 局（`BALANCE.novice.runs`，按档案的正式局数）开新手档短局时，换成 `noviceSetup`：

- 首付比例 0.9 → 0.85（`BALANCE.novice.goal`）；
- 行情段只从温和段池 `NOVICE_SEGMENTS` 里抽（去掉崩盘和熊市，95 段）。重玩同一局（`isNoviceSetup`）也从这个池里抽，结果相同。

只动娱乐局：实盘、每日挑战、闪电盘、本周市场都不走这里。照顾后同样 200 局的胜率：

| 打法 | 照顾前 | 照顾后 |
|---|---|---|
| 一直空仓 | 78% | 97% |
| 乱买 | 84.5% | 89% |
| 追热死拿 | 59.5% | 78.5% |
| 每次满仓一只 | 48% | 60.5% |
| 小白 | 88.5% | 98% |

满仓一只照顾后还是最差的：照顾只让新人先赢几局，不替他们改掉重仓，那是心法和新手课的事。

## 4. 心法

六张卡（`MINDS`），每张一句大白话：

| 心法 | 一句话 |
|---|---|
| 止损 | 亏到一成就走，别等回本。 |
| 宁愿空仓 | 看不准就不买，空仓也是一种仓位。 |
| 别一把梭 | 一次只买一口，错了还有子弹。 |
| 分散 | 一个风口只拿一只，别把鸡蛋放一个篮子。 |
| 不追高 | 涨过头的不追，过热又有人喊跌就先落袋。 |
| 看战绩 | 只听说对多的人，嗓门大不算数。 |

**当场例子**（`mindMoment`，盘前看一眼局面，最疼的先讲）：一把梭（3 份以上）亏了 5%、亏过一成还拿着、风口最热时买的被套、听了战绩不到一半的人亏了、手里全在一个风口而它凉了、有下跌预告时还拿着股票。例子带着那只股票，气泡指着它的持仓卡。

- 只在没有教程步骤可出的时候弹；实盘局不弹；档案里已经亮了的不弹。
- 「记住了」点亮这张（档案 `minds`，云存档合并取并集）；「以后再说」这一局不再弹。
- 图鉴「心法」页能翻看：亮的写名字和那句话，没亮的是问号。

## 5. 画面

- 教程气泡组件（`src/view/trade/guide.ts`）出三种气泡，摆放、箭头、避让共用一份：教程一步、老师傅、心法。新手课里有心法的当场例子时先讲心法，再出老师傅。
  - 新手课里只出老师傅（和心法），不出通用教程，所以上完课第一局正式局照样有界面教程。
  - 老师傅：「老师傅 · 第 d/10 天」、一句理由、这条建议对应的心法、「不亏就过」；指着要点的那条推荐、那张卖出键或「开盘」；右下写要点哪（「点「买入」选「试一口」」）；左下「我自己来」这一局不再给建议。
- 买入面板里「试一口」是主色按钮，「重仓」不再是最显眼的那颗。
- 结束页：新手课写「过关 / 没过」和「新手课」标签，最好成绩那一行换成过没过、心法去哪看。

## 6. 验证

- `tests/core/lesson.test.ts`：照建议做过关且净赚；不止损、一律重仓都亏；这一局用到了止损、看战绩、一次一口；心法例子在该出的局里出；不进档案；新号照顾的设置和段池。
- 冒烟 `node tools/shot.ts --lesson [--defy] [--portrait]`：新号从开始菜单点「先上一课」，照老师傅做完要过关、六张心法亮、图鉴心法页；反着来要弹心法、没过；全程不出通用教程、控制台零报错。
- 取证脚本（量胜率、搜行情段）不进仓库；改了建议规则、`LESSON` 的段和种子，先跑 `lesson.test.ts`，再按第 1 节的口径各打法 200 局重量一遍。
