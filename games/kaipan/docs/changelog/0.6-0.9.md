# 更新日志 0.6–0.9

较新的版本见 [CHANGELOG.md](../../CHANGELOG.md)。

## 0.9.2 — 2026-10-16（试玩评测小改）

- 交易界面左上角常驻「大厅」（小房子在上、字在下），点了先确认一次（和设置里回大厅同一个确认框），不用再进设置；日期那一块往右让了一点，手机上放不下的日历名截短，全名在悬停里。
- 手机横屏「挑一样」：「都不要」从右上角挪到三张卡片下方居中（以前盖住顶栏的「月底挑道具」、贴着 ? 和设置），卡片矮一截放得下。
- 手机横屏新手引导：气泡放在目标的反方向（目标在上就放下面），不再压住顶栏和要点的卡片。

## 0.9.1 — 2026-10-16（音效补齐、更省电、清理）

- 音效补齐：设置里的开关有了自己的「咔哒」声；月底最后 3 天每过一天响一声提醒（钱不够还时换成警示音）；每日挑战交上成绩、晒战绩分享或保存成功都有声音。
- 静音或总音量调到 0 时一点声音都不出（以前只是把音量压成 0，声音其实还在算）；手机切到后台、来电回来以后，不会把这期间攒下的声音一下全放出来。
- 更省电：没有动画、几秒没碰屏幕时画面降到约 30 帧（小人摇头晃脑照样动），一碰就回满帧。电脑和手机放着不玩时，耗电和发热更少。
- 交易画面的看板在一天里重复刷新时，天气和风口前三名没变就不重画。
- 清理（玩家看不到变化）：删掉没人用的旧图标、旧素材 100 多个和没人调用的代码；线上包不再带股票小人的拆件图（只给美术工具用），构建产物从 22 MB 降到 18 MB；几处重复的截短、千分位、颜色换算小函数合成一份。

## 0.9.0 — 2026-10-16（按钮和对齐）

- 按钮统一一套状态：按下去会往下沉；用键盘玩时按 Tab 在按钮之间走（蓝框标出来，有弹窗时只在弹窗里走），回车或空格按下去，鼠标或手指一点蓝框就收起；等回话时按钮自己转圈（看钱包时的「实盘」、画海报时的「晒战绩」），不再在顶上弹一条提示。
- 平板上（走电脑的布局）按钮的点按区撑到 44 像素以上，弹窗右上角的关闭也是；手机上原来就有。
- 修了触屏长按：长按按钮、卡片本该只看说明，最近却会顺带算成点了一下（长按买入按钮就买进了）。现在手指按下就开始计时，长按照旧只出说明。
- 图鉴里没解锁的卡和解锁的一样大，一排排对齐了（以前窄一圈）。
- 「怎么玩」插图下面的标题上下居中；顶栏账户上面那行小字不再贴着边。
- 每日排行榜上昵称太长时截短加省略号，不压住分数。
- 代码整理：间距、圆角统一成一套刻度（按钮、弹窗、提示框都用它）；三处一模一样的"放不下就截短"合成一个。

## 0.8.0 — 2026-10-16（能单独部署）

- 开盘可以不带平台单独部署：README 加了"单独部署这个游戏"一节和部署按钮。单独部署时单机完整可玩，存档在浏览器里，每日挑战照常打；登录、云存档、每日排行榜、钱包和实盘的入口都藏起来，"大厅"按钮改成"首页"，回游戏首页。
- 怎么判断有没有平台：页面启动时问一次同域 `/api/me`，回 404 或不是 JSON 就当没有平台；断网、超时、平台回 5xx 时照旧按有平台处理（平台暂时不可用）。Worker 没绑平台、也没要求登录时，根路径 `/` 跳到 `/games/kaipan/`，实盘接口回 `501 no_wallet`。
- `wrangler.jsonc` 改成独立配置：去掉平台的两个服务绑定和 `GATE`，打开 `workers_dev`。本站部署时由部署工具补上绑定、`GATE=login` 和路由，玩家在本站看不到变化。
- 数据管线读原始行情的默认位置改成模块里被忽略的 `.data/wiki-prices/`（不再默认读主目录下的数据），环境变量 `KAIPAN_WIKI_PRICES` 和命令行参数照旧能改。

## 0.7.0 — 2026-10-16（群友再打磨）

- 群友每局状态不一样：同一个人这局可能比平时准，也可能更不靠谱，话多话少也有变化（均值不变，只在真实行情下）。想跟谁得看本局战绩，不能背表。
- 群友说话不再翻来覆去那几句：每人每种说法从 3 句扩到 8 句左右，推荐语、得意、甩锅也都扩了；一局群聊里重复的句子从 28% 降到 10%，同一句最多出现 4 次。
- 手气好的时候话里带点得意，手气差的时候找补一句（接在句尾，比如"（再信我一次）"）。
- 收盘时群里按局面接话，谁接话看性格：账户翻倍、月底钱不够还、连赚几天、这个月亏多了、大环境转牛转熊都有人说两句；原来的大赚、大亏、涨停、跌停、踩空也改成按性格挑人（老王叫你见好就收，韭菜收割机什么都能扯到报班，空军老周看你亏了就得意）。
- 股票小人按行情改口（熊市里涨停"大家都在跌，我偏要涨"），买入、卖出的台词扩池并轮着说，同一句一局最多出现 4 次（原来最多 12 次）。
- 难度不变：评估过新手（第一次快速开始是第 1 级），前 5 个月没人出局，曲线不陡。数值模拟前后对照、性格表和做法见 `docs/design-chat.md`。

## 0.6.0 — 2026-10-15（实盘）

**实盘：带一份筹码进场打半年**

- 开始菜单多了「实盘」：选人设和档位（小 2,000 / 中 10,000 / 大 50,000 / 豪华 200,000，越往上越难），从平台钱包带一份筹码进场。
- 实盘打半年，每月的账单只交平时的四分之一；打完按最后的资产结回：资产涨到 1.06 倍就拿回 1.06 份，最多 3 份，破产就是 0。借的钱先还掉再算。
- 打的时候顶栏写着"实盘 · 小档 2,000 → 约 2,104"，每天收盘更新。
- 不想打了：设置里「提前收手」。还没开盘就原样退回，开盘以后按现在的资产结。
- 回大厅、刷新、断网、关页面都不算退出，回来点「继续 · 实盘 3月」接着打完再结。结回时连不上，成绩先记下，联网后自动结回。
- 放着超过一天没打完，本金原样退回钱包，这局可以接着玩，但不再算筹码。
- 结束页最上面写结回多少；今天开盘的进账到顶了，会说清有多少没进钱包。实盘局只有「回开始菜单」。
- 筹码只是游戏里的分数，无任何现金价值，不能买、不能换。
- 实盘局只记图鉴，不算通关、最好成绩、成就和解锁（规则和平时不一样）。娱乐模式（快速开始、新游戏、每日挑战）一点没变。
