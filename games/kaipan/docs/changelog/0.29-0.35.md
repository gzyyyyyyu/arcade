## 0.35.0 — 2026-11-21（像在炒股：押跌开局就开、行情屏、K 线页、自选）

- 娱乐局（真实行情、不是实盘）开局就能押跌：推荐卡上直接有「押跌」，看涨看跌都能做。实盘照旧要解锁（许可证、主题、人设）。送押跌体验卡的事件只在要解锁的局里出。
  空军老周不跟着开局进群：他喊跌会把跟消息的人带偏，模拟里普通打法第 3 档通关率掉 9 个点。电脑模拟每格 200 局（第 1 / 3 / 5 档）：普通打法 100/72/55% → 100/70/57%，
  聪明打法 100/93/77% → 100/92.5/80.5%，专押跌的打法 95.5/62/50.5% → 85.5/44/39%（牛市押跌难赚，崩盘里押跌好赚）。
- 开盘区的行情屏：右边三行改成「情绪」五格 + 一个词（恐慌到疯狂，看近 5 天大环境和涨停跌停家数）、领涨和领跌的风口；跑马灯多了涨停 / 跌停家数、跌停的、涨停没封住的，自选股排最前。手机竖屏在天气后写情绪一个词。
- 股票详情改成 K 线页：日 K + 量柱（开局前的几天淡色）、昨天的分时线和买卖力量条。开高低和分时是按当天真实涨跌画出来的样子，图鉴「行情」里写明了。
- 自选：股票详情里点「自选」加星，跑马灯排最前，风口详情的成分股画星。
- 持仓卡的累计多写钱：「累计 ↓8.5% -¥4,240」，放不下先省字再省钱。
- 妖股的两句重复台词换掉。横着拿手机时「换成横屏版？」提示收起插画，不再上下被裁。
- 开发：规则核心加 `star` 操作和 `stars`、持仓卡 `holdMoney`；娱乐局统一用 `isEaseRun`；删掉月度目标的规则版本分叉，回放基准改成当前版本（30 局数值不变）；
  接口文档拆成 `core-api-*.md`。冒烟 `--market`（电脑 1280 + 竖屏 390×844）；`--pages-a` 竖屏段改成现行为。

## 0.34.0 — 2026-11-21（更好赚、更流畅）

- 娱乐各难度整体简单一级左右，新手前几局能明显赚到钱：真实行情的娱乐局每月要还的钱打 85 折（高手及以后 9 折），靠谱群友的消息和推荐更准（新手档准得最明显；群主照样反着说），短局最后的首付按开局资产的 0.9 / 1 / 1.05 倍（以前 0.95 / 1.05 / 1.1）。
  电脑模拟每格 200 局：短局新手的小白打法达成率 74.5% → 89%、普通打法 81.5% → 96.5%；普通档 38.5% → 61% / 61% → 75%；高手档 28% → 38% / 38.5% → 56%。新手短局小白打法炒股平均多赚开局资产的 9% → 11%。
  实盘四档不变（同一批种子逐位相同），每日挑战、闪电盘、本周市场跟着变简单。
  同种子各 200 局（`bal-*`）炒股净赚平均：新手短局小白 +9.0% → +10.9%、普通 +15.3% → +19.2%，完整一年小白 +18.8% → +25.8%。
- 带头大哥和妖股的买卖台词各多 6 句：变好赚以后买卖多了，同一句不那么常重复。
- 更流畅：交易页每天重画、上传的文字纹理少 13–17%，量字次数少一半，开局少 28%；图集先在后台解码再上传，开机时主线程少卡。办法是文字颜色、描边没变就不重画，换行时量过的字记下来，群聊估高度不再临时建文字，开局群聊只画一遍。
- 开发：`tools/perf.ts` 在正式构建上量开机、开局、交易日（电脑 1280，手机竖屏 CPU 4 倍降速），记长任务、帧时间、纹理上传和量字次数、包体积；`--who` 查纹理上传来自哪段代码。规矩写进 `docs/architecture.md`「性能：文字和纹理」。

- 改动：交易界面的代码（原来一个 1966 行的文件）按职责拆成 9 个文件，每个不超过 800 行：结算演出、月底流程、操作、特效、提示和引导、键盘拖拽、自动化坐标、共用常量。只挪代码，游戏行为和画面不变。

- 冒烟截图更可复现：自动化下 Phaser 自带的随机（相机抖动、粒子）也用固定种子，竖屏提示层的 CSS 动画停掉，结算、奖励、结局这些画面等动画播完、画面静下来再截（`quietShot`）；动画中途截的几张（结算、涨跌停、账单）冻结点随机器快慢变，不做逐像素比对，记在输出目录的 `midway.txt`。试过自动化下按固定 1/60 秒一帧走游戏时间，但无头浏览器出帧不均会让游戏时间停住，没采用。
- 冒烟的长按改成等游戏认了长按再松手（30 秒不生效才算失败），不按固定时长：机器很忙、帧率掉到个位数时，按满固定时长长按计时器也未必到点，松手就被当成点击。
- 冒烟等「空闲」的上限改按游戏时间算（120 秒游戏时间，真实时间封顶 15 分钟）：机器忙时帧率掉下来，同一段演出要的真实时间成倍变长，原来固定 120 秒真实时间会把正常的慢当成卡住。
- lint 配置补上全仓模板的一条：`tools/` 下的冒烟脚本不查 `useDomNodeTextContent`（Playwright 的 `innerText()` 只取看得见的文字，不能被自动修成 `textContent()`），删掉原来逐处写的 5 条忽略。

## 0.31.3 — 2026-11-01（按钮不再点穿）

- 按钮只认在它身上按下、再在它身上松开的那一下：按在别处、松手时才滑到按钮上的不算点击，免得盖在上面的东西刚收起时点穿到下面的按钮。
