# 《开盘》美术与界面（v3）

> 现行的美术和界面规范。各版改了什么见 `CHANGELOG.md`；手机和平板的尺寸、字号见 `mobile.md`。
> 规则核心、数值不因为画面改动而动。

## 1. 方向

温暖热闹的「散户小屋」：白天看盘、晚上算账；纸做的信息、木做的框、屏幕上跳数字。

- Q 版粗描边（描边 `#3a2634`）、右下暗部月牙、纸张颗粒。所有素材是 `tools/art/` 程序生成的 SVG，不引外部图片，来源写进 `public/assets/art/README.md`。
- 色板（`theme.ts`）：纸 `#fff6e6`（信息卡、弹窗）、墙 `#f3e2c7`（底色）、墨 `#3a2634`（描边、正文）、橙 `#ff7a33`（唯一的主按钮色、强调）、
  金 `#f6c02f`（奖励、稀有、通关）、夜蓝 `#22303f`（屏幕、夜里）、涨跌红绿 `#d8342c` / `#137a42`（只给数字和箭头，可在设置里对调）。
- 三种材质，各管一类东西：
  - **纸**（`addPaper`）：会变的信息，持仓卡、群聊气泡、事件卡、弹窗正文、看板；
  - **木**（`addWood`，程序画，不占素材）：不会变的框架，顶栏、风口看板外框、「开盘」按钮下的木托；
  - **屏幕**（夜蓝小屏）：数字在跳的地方，显示器、结束页的月份条。
- 字：中文用系统字体。数字用 Kaipan Num（`public/assets/fonts/`，约 2.6 KB）：由 SIL OFL 的 Fredoka 改出，固定字重、只留数字和 `¥%+-−.,:/×~`、
  0–9 等宽（滚动不抖），万、亿、箭头逐字回退；启动时最多等它 2 秒（画布上的字不会自己重画）。来源和改法见字体目录的 README。
- 字号、间距、圆角从 `theme.ts` 的 `TYPE`、`SPACE`、`RADIUS` 取；新画的东西按 8 像素网格对齐。

## 2. 光：小屋的一天

`Room.setTime` 四个时段，整屏色调盖在房间上、台灯和显示器光下面，切换时 0.5 秒交叉淡化：

- 清晨（暖白，台灯暗）：盘前；
- 白天（不加色，窗外天空随市况变）：开盘；
- 傍晚（橙，台灯半亮）：出收盘结果时；
- 夜里（深蓝压暗，台灯全亮）：月底账单前，第二天盘前回到清晨。

快进时停在清晨（一天一两秒，来回换会闪），只有月底入夜。结束页通关是傍晚、出局是夜里。阴天、雷雨的室内压暗是游戏里画的矩形，盖得到铺满出来的那圈。
「减少动态效果」、关动画时直接换；省内存设备只换色调，台灯不动。

## 4. 对局画面

- 顶栏是木条：每组「图标 + 大数字」一行、小字一行，小字中线对齐（电脑 48、手机 38）；「账户 · 人设 · Lv」写在账户数字下面（娱乐短局换成离首付还差多少，实盘换成实盘小牌子）。
  不放人设小头像：位子只有 24–28 像素，全身立绘缩到这么小只剩一团颜色，而且立绘在 meta 图集里，对局不加载。
- 持仓区：每个空格是一块纸垫（虚线座位）；钱袋放第一块左上角，旁边是现金；今天还能买时纸垫外圈发金光、轻轻呼吸，买不了时写原因；能买时座位里写「空位 · 点右边的推荐买」。推荐只在右栏出现一处，空格里不放推荐位（拖推荐卡进空格照样能买）。
  电脑盘前一屏的信息块：顶栏、风口栏、群聊栏（含推荐）、开盘区（含迷你行情）、一行提示（昨日小结默认收成一行，猫有话时小结卡上挂小猫，点它换猫说）。顶栏没有道具时不画占位。
- 持仓卡下沿：红色「卖出」（押跌的写「不押了」）一步全卖，有仓位玩法时右边一个小按钮「加减」打开加仓 / 减一半的菜单；今天买的「卖出」灰着写「明天卖」，「加减」照常能点。
  卖出时一把金币和一个「+金额」从卡上飞向现金格。

## 4.1 操作（电脑键鼠、触屏共用；`ui/button.ts`、`ui/focus.ts`、`trade/drag.ts`）

- 按钮三态：悬停时抬起 2、白光加重、外圈一圈金边（和 `ui:hover` 音），按下压下去，禁用变灰（大卡上自己加的内容跟着变淡）。
  开始菜单的大卡、模式卡、盘前「买入」键、顶栏键、开局面板的人设卡和难度牌（抬起 4 + 金边）都走这一套；「大厅」是叠在画布上的透明 DOM 按钮，鼠标进出由它转给画布按钮，光标强制 pointer。
- 右键不当点击：持仓卡上右键直接弹加仓 / 卖出菜单；弹窗开着时在任何地方右键、或选格子时在空白处右键，都是取消。浏览器自带的右键菜单只在画布上关掉。
- 键盘焦点：方向键按位置在推荐卡的「买入」、持仓卡的「卖出 / 加减」、开盘键之间移动（第一下落在开盘键或开始菜单的大卡上），Tab / Shift+Tab 按阅读顺序，回车或空格按下焦点项，焦点是蓝框。
  盖在整个画面上的（对话框、月底面板、教程气泡，depth ≥ 100）自成一层，焦点只在最上面那层里走；「怎么玩」自己用方向键翻页，焦点不抢。
- 买卖菜单开着时空格先收起菜单（淡出 + 关闭声），再按一次才开盘；Esc、右键也是收起。菜单里方向键 / Tab 移动、回车执行。
- H 或 ? 打开「快捷键一览」（`view/keys.ts` 是唯一的数据来源，`meta/keysPanel.ts` 画），Esc、右键、× 关闭。
- 拖拽（电脑、手机通用；判断在 `trade/dragGeo.ts`）：推荐卡拖进空格就是买（有仓位玩法时先选买多少；满仓拖到有持仓的格子上就是换掉那一格），持仓卡拖出持仓区就是卖光。
  按下后挪过 8 才算拖；卡的复制品跟手并随速度倾斜（最多 12 度），能放的格子描金边、手在哪格哪格更亮，放下缩进格子，放不下弹回；拖完松手那下不当点击（`ui/clickGuard.ts`）。按钮只认在它身上按下又在它身上松开的那一下（`ui/button.ts`、`ui/clickGuard.ts`），按在别处、松手才落到按钮上的不算；按住时按钮被重画、还在原位的照样算；长按出了说明的那一下不算。
- 教程气泡的「跳过全部引导」：以后都不再弹，设置里能重开。

- 每日挑战面板：右边三块整宽小卡（人设、难度、今日最好）。闪电盘用同一个面板，第三块换成「玩法」（10 个交易日 · 约 5 分钟）。
- 闪电盘：顶栏日期写「第 N/10 天」，右半块写比开局多赚 / 亏了多少和还剩几天，最后 3 天变红闪烁；结束页是单独一套（资产大字滚上去、落定放彩带烟花、名次盖章，电脑一列居中、手机横屏左右两栏）。
- 「这段日子」：右上角一张心情图（牛市太阳、泡沫火箭、横盘多云、熊市下雨、崩盘雷雨）。
- 结束页：月份条是一块显示屏，每格一根柱子是这个月账户的涨跌（悬停看数字），还上的绿边、没还上的红边、没走到的暗格；电脑上收获栏有最赚、最亏两只。
- 好友挑战卡：左边这局的人设立绘，右边发起人（平台不给头像，画一个写名字头一个字的圆）、难度徽记、他的成绩。
- 图鉴、知识卡的锁卡用浅一号的纸色、淡点、淡描边、淡问号。

## 5. 关键时刻

- **开盘**：持仓卡依次翻牌，涨跌数字往上滚，大涨冒火、大跌结冰，音调随涨幅升；屋里灯一亮（`Room.flashLights`，0.3 秒，不占节拍）。
- **收盘**：先一张一张结算（见 5.1），再显示器上的总账砸一下，赚了的话金币从显示器飞进顶栏钱包（终点用顶栏给的钱包位置，不占节拍）。每只的涨跌明细在收盘小结卡里，不在显示器上逐行再跳一遍（每天都会多停）。
- **一天的总长**：按开盘到能再操作，按设计时长算（1 倍速、不按空格）普通日约 6–7 秒，不超过 8 秒。条数会变的几段有总时长上限：
  收盘后的吐槽和新闻逐条冒出合计不超过 0.8 秒、盘前群聊逐条冒出合计不超过 0.9 秒、收盘逐条盖「说对了 / 说错了」合计不超过 0.3 秒（`trade/chat.ts` 的 `AFTER_CLOSE_MAX`、`INTRO_MAX`、`JUDGE_MAX`），
  高光大字最多两条，第二条只停第一条的六成。
- **月底账单**（`trade/monthEnd.ts` 的 `playBill`，节拍在 `billTiming.ts`）：入夜 → 账单纸从桌面滑上来 → 各行依次出现、一行一声音调上升、金额从 0 滚到位 → 总数从还前账户一行一行扣（月供、突发账单、利息，每扣一行跳一下、一声）、落到结果时砸一下 →
  盖章（带震屏，减少动态效果时不震）→ 停一下。本月目标达成没有写在账单最下面。
  每个月自动停不超过 2 秒（`tests/view/bill-timing.test.ts` 锁住），点一下跳过整段（实盘、每日挑战一样）；设置里「月底账单：简短」时账单和章直接出来，停 0.9 秒。
- **减仓**（实盘盘前，事件 `deleveraged`）：减仓按钮上弹出「卸下一档 N×」（降到不加杠杆时是「卸下重担！」），几块灰蓝小铁块蹦起再落下，配铁链松脱的金属声和一口气似的上行和弦（降到 1× 多一声亮钟）。
- **金卡**（月底三选一里的稀有卡）：卡淡入后金框脉冲两下、顶上洒一撮金星，音效是金色闪光琶音（`rareCard`，在「三选一亮相」之后约 0.4 秒）。
- **被轧**（押跌的股票涨停）：原有的震屏、红闪、大字「被轧了！」配上专属音效 `squeeze`（低鼓一砸、不协和铜管、下坠滑音），不再借用远雷。
- **黑天鹅日**（每局最后一个交易日，`fx/swan.ts`、`trade/dayPlayback.ts` 的 `playDay`）：预告期顶栏日期行挂「黑天鹅 · 后天：大停电」标签、群聊最上面两行提示；
  最后一天点开盘，先全屏黑幕（`swanCurtain`）：两道闪电加全屏白闪、震屏，大字「黑天鹅 · 名字」缩放弹出，下面一行说明和一行避险提示，约 2 秒后淡出，音效 `swan`（电闪一击 + 滚雷，下跌类再落沉重低音，天降利好换上扬钟声）；
  收盘每格持仓压一层光（`swanGlow`）：躲过或受益亮绿光，被砸变灰并震一下屏，屏幕中间一行「躲过了黑天鹅 / 黑天鹅中招 ¥X」；结束页称号下面一行「黑天鹅「名字」：躲过 / 中招 ¥X」。
  减少动态效果下没有闪电、缩放、震屏，黑幕和字只淡入淡出；关动画（anim=0）不画黑幕。
- **抽新股**（代码里叫打新；真实行情的娱乐局，每月中旬一只新股；`trade/ipo.ts`、`fx/ipo.ts`、`trade/holdings.ts`；玩家看到的字不用「打新」「中签」「题材」，见 `tests/repo/view-copy.test.ts`）：
  - 申购日盘前群聊最上面一条金色「抽新股」横条（高 44，星标、新股名、风口和「后天出签」、右边「申购」小签，整条能点），点开申购面板（`IpoPanel`）：
    试一口 / 半仓 / 重仓三个按钮，每个写抽中率和冻结多少现金，下面一句「多冻结只提高抽中率，抽中了都只配 1 份」；点一档就申购，面板淡出期间不再响应，连点只算一次。
  - 申购后那一格画成「申购中」卡：卡面压一层灰，新股形象（`def.look ?? def.id`）置灰，写「申购中」和「后天出签 / 明天出签」、冻结几份；没有卖出键、没有加减、不能拖，悬停有说明。
  - 出签那天收盘（`ipoDraw`）：申购中的卡上五颗号码球在筒里乱跳约 1 秒，翻出结果——抽中是金卡（「抽中了！」加新股名、一撮金星），没抽中是「没抽中，现金退回」；音效 `ipo`（滚球轻点，抽中上行钟声、没抽中两个下行软音）。
  - 抽中的新股是正常持仓卡，名字左边挂「新」签（上市头两天；首日涨了写「新 +X%」，上市就跌写「新 −X%」，灰色）。首日收盘（`ipoGlow`）溢价的卡压一层金光并洒金星、上市就跌的盖灰，浮字「上市首日 +X%」/「上市就跌 −X%」。
  - 新股没有专属角色图标，用星标（`roleKey`）；形象和图鉴靠 `lookOf` 借同风口内容股的小人。结束页称号下面一行「抽新股：抽中 X 次 / 申购 Y 次，赚亏 ¥Z」（赚红亏绿，申购过才有）。
  - 减少动态效果下球不转、没有火花，只淡入淡出；关动画（anim=0）不画摇号，结果由卡片和大屏上的一行字交代。
- 以上三处的粒子和脉冲在「减少动态效果」下只剩一次淡入淡出（或不放），关动画时不放；音效照常，跟主音量和音效开关走。
- **通关 / 出局过场**（`EndScene` 的 `cutscene`）：结束页出来前 1.2 秒，通关放烟花（暖幕）、出局下雨（深灰幕），字后压一条横幅，一行大字；点一下跳过，关动画、减少动态效果时不放。过场之后才显示成绩页，通关再放一次彩带。

底线：这些动效加起来不能让一局明显变长（一局 12 个月多出的时间不超过半分钟）。

## 5.1 演出和节奏（0.24；对标 Balatro 一下一下算分的节奏）

所有演出走 `Animator`（`fx/anim.ts`）：`anim.instant`（关动画、快进、机器人代打、自动化）一律立即完成、不加等待；`anim.calm`（减少动态效果）只剩淡入淡出或直接出现；点一下或空格（`anim.hurry`）能跳过。画面层不改状态，回放和存档不受影响。

- **收盘逐张结算**（`trade/dayPlayback.ts` 的 `settleChain`）：开盘翻牌、道具之后，持仓按格子顺序一张一张结算：该张的「+¥金额」在卡上弹出、飞向顶栏账户大数字，账户数字跟着滚一下、跳一下，
  一张一声（`tally`：赚的音高沿 D 五声音阶逐张上行，亏的是低沉的一下，不上行）。账户层的加成（借钱放大、分散投资等道具）排在最后，数字从道具图标飞来；
  最后落到收盘后的真实总额，账户旁飘出这一天的合计。间隔 70–170 毫秒，按条数缩短，整段不超过原来整块滚动（0.52 秒）的 1.3 倍。
  平淡日自动快进、减少动态效果时沿用整块滚动，不逐张。涨停烟花、跌停雨云、黑天鹅光照照旧。
- **卖出落袋**：「+金额」从卡上飞到现金格时，到站一声「叮」（`pocket`）、现金格亮一下金边。
- **月底三选一**（`RewardPanel`）：三张卡逐张翻开（宽度从 0 展开，错开 110 毫秒，金卡的金框和闪光跟在自己那张翻开之后）；鼠标在哪张上，哪张抬起 10、放大 3%、跟着鼠标左右微倾（最多 2.5 度），移开落回；
  选中后那张飞起放大淡出、其余落下淡出、「都不要」淡出（约 0.3 秒），再执行选择；选稀有股票要先挑格子，取消回来时卡片摆回原位。卡的外壳以卡中心为原点，静止时按钮坐标和以前一样。
- **弹窗**（`ui/dialog.ts`，所有 `Dialog` 子类统一）：进场面板从 0.92 倍放大到 1 并淡入（200 毫秒），退场淡出并缩到 0.94（150 毫秒）；遮罩只淡入淡出。
  退场时弹窗本体立刻销毁（按键监听、回调不变），只有遮罩和面板摘出来播完动画，期间按钮锁住。减少动态效果只淡入淡出，关动画直接出现和消失。
  遮罩默认半透明（0.5）；新一局、每日挑战（含闪电盘、本周市场）这类占满大半个屏的大面板传 `SOLID_BACKDROP_ALPHA`（0.9），不然标题页右上角那排按钮的下半截会从面板上沿露出来。
  关闭方式三种：右上角有底的圆形 ✕（看得见直径 40，点区 ≥ 44）、Esc、点遮罩；必须做决定的（确认框、二选一、结算后的「这段日子」、成就解锁、好友挑战邀请）把 `closeOnBackdrop` 关掉，只留 ✕ 和按钮；
  整屏实底的大面板也不响应点遮罩。同时只开一个：新弹窗打开时旧的先关，确认框、提示框和从每日挑战类面板打开的排行榜（`stacksOnTop`）可以叠在面板上，最多两层，Esc 一次只关最上面一层。
  确认框按钮写动词；丢进度、没法撤回的（开新局、提前收手）用危险色，回车选「取消」，其余回车就是确认。
- **设置面板**（`ui/settingsPanel.ts`）：电脑上两栏、带分组小标题——左栏「声音」（主音量、音效、音乐、静音）和「画面和动画」（动画速度、涨跌配色、减少动态效果），右栏「玩法」
  （月底账单、新手教程、新手提示、收盘小结、平淡日）；手机横屏用两个页签分组（声音画面 含减少动态效果 / 玩法 含月底账单和提示节奏），不再加小标题。右下「完成」旁（手机在标题栏右侧）有「恢复默认」：
  点一下变成「再点一次」（3 秒内不点就还原），再点才把设置（`defaultSettings()`）和画面偏好（`DEFAULT_VIEW_PREFS`）恢复成默认，新手教程的进度不动。
  「减少动态效果」首次使用和恢复默认都跟系统的 `prefers-reduced-motion`。
- **字号**：界面文字从 `theme.ts` 的 `FS`（12 / 14 / 16 / 18 / 22 / 28）取，电脑上最小 12（`ui/text.ts` 的 `MIN_TEXT_SIZE`），快捷键角标也是 12；13、15 这类夹在中间的老字号保持原样。
- **素材没载入**：启动时有图加载失败（重试后仍缺），页面上方出一条「有图没载入，点这里刷新」，点了刷新页面；同一时间只有一条。
- **结束页**：先放通关 / 出局演出，再显示成绩；「这段日子」不再自动弹出来，是成绩页上的按钮（电脑、手机都在左栏、按 V 也行），每局第一次进结束页按钮闪两下金边提醒。

## 6. 铺满

- 全部场景用 Phaser 的 EXPAND：UI 按安全区摆（电脑 1280×720，手机按 `phoneWorld`），`viewport.ts` 的 `cameraFor` 按画布实际尺寸把世界居中；
  窗口缩放后各场景重摆相机；全屏遮罩、点击挡板按 `coverOf`（安全区的三倍大）画，窗口怎么变都盖得住。
- 小屋延伸（`tools/art/scene.ts` 的 `room_left` / `room_right` / `room_top` / `room_bottom`）：两侧各 320、上下各 108，接着画墙纸、护墙板、顶角线和桌子，
  覆盖 16:9 到 21:9 和 16:10；两侧有摆设（相框、存钱罐、绿植；便利贴、废纸篓）。四张图进对局时才加载。
- 1920 宽以上 UI 跟着整体放大，不另加字号。

## 7. 素材和性能

- 素材进图集（`public/assets/art/v3/atlas/`，`node tools/art/bake.ts` 2 倍烘焙），缺失时回退单张 SVG。图集是首开下载的大头，
  页图用有损 WebP（质量 0.8，手机上看不出差别）；改素材后重新烘焙，别把质量调回近无损。
  首屏只等标题页要用的那份：图集分 title（全部股票的平常 / 开心 / 眨眼三张脸、ui、fx，约 1.3 MB）、game（其余对局素材，约 1.7 MB）、meta 三组。
  `public/early.js` 在主程序还在下载时就取 title、game 两份入口，先下 title 的页图、下完再下 game 的（低优先级，不抢带宽）；`BootScene` 只等 title 组、固定素材和标题主视觉，
  标题页出来后 game 组在后台到齐，`Session` 进对局、结束页之前和图鉴等界面打开前都先等它（`ensureGameArt`），不会缺图。
  图集没下成就改用单张 SVG。early.js 是否预取的判断要和 `assets.ts` 用不用图集的判断一致（手机平板渲染倍数封顶 2，dpr 3 的 iPhone 也用图集）。
- 省内存设备渲染倍数封顶 2、整屏背景按 1 倍光栅化；视差、粒子、光层在省内存模式和「减少动态效果」下关掉。新增素材后跑 `--lowmem` 冒烟看显存估算。
